# 文件系统工具详解

DeepAgents 的 6 个文件系统工具（ls/read_file/write_file/edit_file/glob/grep）的完整参数和行为。

## 一、ls — 列出目录

```python
ls(path="/")  # 列出根目录

# 返回示例：
# [{"name": "workspace", "type": "dir", "size": 0, "modified": "2026-07-29T10:00:00"},
#  {"name": "report.md", "type": "file", "size": 2048, "modified": "2026-07-29T09:30:00"}]
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `path` | `str` | 目录路径，默认 `/` |

## 二、read_file — 读取文件

```python
# 基础读取
read_file(path="/report.md")

# 分页读取（大文件）
read_file(path="/large.csv", offset=0, limit=100)

# 多模态读取
read_file(path="/chart.png")  # 自动返回图片内容块
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `path` | `str` | 必填 | 文件路径 |
| `offset` | `int` | 0 | 起始行号 |
| `limit` | `int` | 2000 | 最大行数 |

**多模态支持**：自动识别图片（.png/.jpg/.gif/.webp/.heic）、视频（.mp4/.mov/.avi）、音频（.wav/.mp3）、文档（.pdf/.ppt/.pptx），返回结构化内容块而非纯文本。

## 三、write_file — 写入文件

```python
write_file(path="/workspace/analysis.py", content="""
import pandas as pd
df = pd.read_csv('data.csv')
print(df.describe())
""")
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `path` | `str` | 文件路径（不存在则创建） |
| `content` | `str` | 文件内容 |

> **覆盖写入**：始终覆盖现有文件，不支持追加。追加用 `read_file` + `edit_file` 组合。

## 四、edit_file — 编辑文件

```python
edit_file(
    path="/workspace/main.py",
    old_string="def add(a, b):\n    return a + b",
    new_string="def add(a: int, b: int) -> int:\n    \"\"\"Add two integers.\"\"\"\n    return a + b",
)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `path` | `str` | 文件路径 |
| `old_string` | `str` | 要替换的原字符串（**必须唯一**，否则失败） |
| `new_string` | `str` | 新字符串 |

> **限制**：`old_string` 在文件中出现多次时会报错。建议先 `read_file` 定位精确上下文。

## 五、glob — 文件名模式搜索

```python
# 当前目录下所有 .py
glob(pattern="*.py")

# 递归搜索
glob(pattern="**/*.md")

# 特定子目录
glob(pattern="workspace/*.csv")
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `pattern` | `str` | Glob 模式，支持 `*`（任意字符）和 `**`（递归） |

## 六、grep — 内容正则搜索

```python
# 搜索 TODO
grep(pattern="TODO", path="/")

# 正则 + 限定路径
grep(pattern=r"def\s+\w+\(.*\)", path="/src/")

# 指定输出模式
grep(pattern="import", path="/", output_mode="content")   # 显示匹配行
grep(pattern="class", path="/", output_mode="files_with_matches")  # 只显示文件名
grep(pattern="test", path="/", output_mode="count")       # 只显示计数
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `pattern` | `str` | 必填 | 正则模式 |
| `path` | `str` | `/` | 搜索目录 |
| `output_mode` | `str` | `files_with_matches` | content/files_with_matches/count |

## 七、使用限制

| 限制 | 说明 |
|------|------|
| 手动隐藏工具 | `HarnessProfile(excluded_tools={"write_file", "edit_file"})` |
| 后端决定存储 | StateBackend 不持久 / StoreBackend 持久 / SandboxBackend 隔离 |
| 权限优先级 | `permissions` 列表从上到下，第一个匹配生效 |
