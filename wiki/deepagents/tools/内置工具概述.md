# DeepAgents 内置工具

`create_deep_agent` 自动装配的内置工具来自其默认中间件栈。Agent 不需要用户手动传 `tools` 就能使用这些能力。

## 一、工具总览

| 工具名 | 来源中间件 | 作用 | 必装? |
|--------|-----------|------|:---:|
| `write_todos` | `TodoListMiddleware` | 创建和管理任务清单（pending/in_progress/completed） | ✅ |
| `ls` | `FilesystemMiddleware` | 列出目录内容 | ✅ |
| `read_file` | `FilesystemMiddleware` | 读取文件内容 | ✅ |
| `write_file` | `FilesystemMiddleware` | 写入文件 | ✅ |
| `edit_file` | `FilesystemMiddleware` | 编辑文件（基于字符串替换） | ✅ |
| `glob` | `FilesystemMiddleware` | 文件名模式匹配搜索 | ✅ |
| `grep` | `FilesystemMiddleware` | 文件内容正则搜索 | ✅ |
| `task` | `SubAgentMiddleware` | 派生子代理执行独立任务 | ✅ |
| `execute` | **backend**（非中间件） | 在沙箱中执行 shell 命令 | 仅沙箱/本地 shell 后端 |

### 钩子型中间件：不提供任何工具

以下中间件没有 `tools` 属性，不产生工具，但通过钩子改变 Agent 行为：

| 中间件 | 无工具，做什么 |
|--------|--------------|
| `SkillsMiddleware` | 扫描技能元数据 → 注入 system prompt；**指引模型用 `read_file` 读技能全文——该工具由 FilesystemMiddleware 提供（跨中间件依赖）** |
| `SummarizationMiddleware` | 上下文达阈值自动摘要/卸载（不产出工具，靠钩子触发） |
| `PatchToolCallsMiddleware` | 修复悬空工具调用（纯状态修复） |
| `MemoryMiddleware` | 加载 AGENTS.md 注入 system prompt |
| `HumanInTheLoopMiddleware` | 拦截工具调用等审批（不产出工具，拦截别人的工具） |

### 工具面构成

```
Agent 完整工具面 = 中间件提供的工具 ∪ 用户自定义工具（tools=）∪ MCP 工具
```

注意：工具列表**与 backend 无关**（所有 backend 下文件工具都一样），backend 只决定文件落到哪个空间；`execute` 是唯一例外——只有 backend 支持执行协议时才出现。

## 二、write_todos — 任务规划

```python
# Agent 内部调用
write_todos({
    "todos": [
        {"content": "搜索 LangGraph 最新版本", "status": "in_progress"},
        {"content": "对比 LangChain vs LangGraph", "status": "pending"},
        {"content": "生成报告", "status": "pending"},
    ]
})
# 状态值: pending / in_progress / completed
# 持久化在 AgentState 中
```

## 三、文件系统工具 — ls/read/write/edit/glob/grep

| 工具 | 调用示例 | 说明 |
|------|---------|------|
| `ls` | `ls(path="/")` | 列出根目录 |
| `read_file` | `read_file(path="/notes.txt")` | 读文件 |
| `write_file` | `write_file(path="/report.md", content="...")` | 写文件（覆盖） |
| `edit_file` | `edit_file(path="/x.py", old_string="...", new_string="...")` | 精确替换 |

这些工具的行为**取决于 backend**：

| Backend | 文件存储在哪 |
|---------|------------|
| `StateBackend`（默认） | LangGraph agent state 中（线程结束消失） |
| `FilesystemBackend` | 本地磁盘 |
| `StoreBackend` | LangGraph Store（跨线程持久） |
| Sandbox backend | 沙箱文件系统（容器/VM 隔离） |

> 详见：[[deepagents/backend/后端概述]]

### 限制暴露的工具子集

```python
from deepagents.middleware import FilesystemMiddleware

FilesystemMiddleware(
    backend=my_backend,
    tools=["read_file", "ls", "glob", "grep"],  # 只暴露读操作
)
# write_file 和 edit_file 不可用，Agent 无法写文件
```

## 四、task — 子代理派发

```python
# Agent 内部调用
task(
    subagent_type="general-purpose",  # 或自定义子代理名
    description="搜索 LangGraph 最新文档",
)
# 执行过程：
# 1. 创建隔离的子 Agent 实例
# 2. 子 Agent 独立执行（有自己的上下文、工具）
# 3. 只返回最终结果给主 Agent
# 4. 子 Agent 销毁
```

**关键特性**：
- 上下文隔离：子 Agent 的大量中间结果不污染主 Agent
- 无状态：子 Agent 不记忆之前的调用
- 单向通信：只返回最终一份报告，不能回传多轮消息

> 详见：[[deepagents/subagents/子代理概述]]

## 五、execute — 沙箱执行

```python
# 仅当使用 Sandbox backend 时可用
execute(command="python analysis.py")
# 在隔离容器/VM 中执行命令
```

> 详见：[[docker/Docker沙箱概述]] — 自建沙箱方案与 DeepAgents 沙箱对比

## 六、自定义工具与内置工具的融合

```python
from deepagents import create_deep_agent

def my_tool(query: str) -> str:
    """自定义搜索工具"""
    return f"结果: {query}"

agent = create_deep_agent(
    model=llm,
    tools=[my_tool],   # ← 自定义工具
    # 内置工具自动合并
)

# Agent 可用的完整工具集:
# write_todos, ls, read_file, write_file, edit_file, glob, grep, task, my_tool
```

## 七、MCP 工具集成

```python
from langchain_mcp_adapters.client import MultiServerMCPClient

async with MultiServerMCPClient({
    "github": {"transport": "http", "url": "http://localhost:8000/mcp"},
}) as client:
    mcp_tools = await client.get_tools()
    agent = create_deep_agent(
        model=llm,
        tools=[*mcp_tools, my_tool],  # MCP 工具 + 自定义工具 + 内置工具
    )
```
