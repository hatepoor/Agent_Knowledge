# DeepAgents 上下文管理

DeepAgents 通过四层机制管理上下文——从输入到压缩到隔离到长期记忆——支持跨 token 限制的多步骤长任务。

## 一、四层上下���管理

```
输入上下文层: system prompt + memory + skills + tool prompts
    ↓
压缩层: 自动摘要 + 上下文卸载（文件系统）
    ↓
隔离层: 子代理隔离重上下文子任务
    ↓
长期记忆层: Store backend 跨线程持久化
```

## 二、输入上下文层

Agent 启动时，以下内容汇入初始上下文：

| 来源 | 内容 | 配置方式 |
|------|------|---------|
| System prompt | 基础指令 + 用户自定义指令 | `system_prompt` 参数 |
| Memory | `AGENTS.md` 文件中的长期记忆 | `memory=["AGENTS.md"]` |
| Skills | 按需加载的 Markdown 技能 | `skills=["code_review"]` |
| Tool prompts | 每个工具的 description | 自动生成 |

## 三、压缩层——自动摘要

`SummarizationMiddleware` 在对话历史接近 token 限制时自动触发（默认无需配置）：

```python
# 默认行为（无需配置）
agent = create_deep_agent(model=llm)
```

**摘要策略**：
- 旧消息 → 压缩成一段摘要
- 最近 N 条消息 → 完整保留
- 工具输出 → 被摘要或卸载到文件系统

> 自定义触发策略（`trigger`/`keep` 参数）的完整配置与双层机制（20k 卸载 + 85% 摘要）见 [[deepagents/context/自动摘要机制]] ——本页不再重复。

## 四、压缩层——上下文卸载（文件系统）

Agent 可以把大段内容写入文件，需要时再读取：

```
Agent 搜索了 50 个网页，每页 2000 字 = 100K tokens
  ├── write_file("/research/page1.txt", content1)
  ├── write_file("/research/page2.txt", content2)
  ├── ...
  └── 写完全部 → Agent 上下文只有文件名列表（几百 token）
       需要哪页 → read_file("/research/page5.txt")
```

**这是 DeepAgents 处理大容量任务的核心理念**：文件系统 = 外部记忆，不在上下文窗口里占位。

## 五、隔离层——子代理

大量搜索/分析结果不返回主 Agent，只在子代理内处理：

```
主 Agent 调 task("搜索并总结 LangGraph 最新特性")
  └── 子 Agent 执行：
        ├── 搜索 20 个网页
        ├── 读每页内容
        ├── 汇总成一段总结
        └── 返回: "LangGraph 0.4 新增了..."
            （子 Agent 内部的大量中间结果不传给主 Agent）
```

## 六、长期记忆层

`MemoryMiddleware` 从 `AGENTS.md` 文件加载跨会话持久记忆：

```python
# AGENTS.md — 放在项目根目录
# Agent Name: Research Assistant
#记忆：
#- 用户偏好：深度研究报告，至少 2000 字
#- 上次研究主题：LangChain 中间件系统
#- 常用信息源：官方文档 > 社区博客 > 论文

agent = create_deep_agent(
    model=llm,
    memory=["AGENTS.md"],   # 启动时加载
)
# Agent 每次启动自动读取 AGENTS.md → 注入 system prompt
```

## 七、Prompt Caching（Anthropic/Bedrock 自动）

使用 Anthropic 或 Bedrock 模型时，`create_deep_agent` 自动启用 prompt caching：

- 静态部分（system prompt、memory、skills）被缓存
- 每次请求不重复计费 token
- 减少延迟（cache hit 时不用重新处理）
- **零配置，自动生效**
