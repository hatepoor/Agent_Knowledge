# DeepAgents 中间件栈

`create_deep_agent` 不是简单调用 `create_agent`——它构建了一个 **13 层预装配中间件栈**。理解这个栈是定制 Deep Agent 的前提。

## 一、主 Agent 默认中间件栈（从上到下）

| # | 中间件 | 类 | 必装? | 作用 |
|---|--------|-----|:---:|------|
| 1 | TodoList | `TodoListMiddleware` | ✅ | 提供 `write_todos` 工具，任务规划 |
| 2 | Skills | `SkillsMiddleware` | `skills` 参数非空时 | 按需加载 Markdown 技能文件 |
| 3 | Filesystem | `FilesystemMiddleware` | ✅ | ls/read_file/write_file/edit_file/glob/grep |
| 4 | SubAgent | `SubAgentMiddleware` | ✅ | 提供 `task` 工具，派生子代理 |
| 5 | Summarization | `SummarizationMiddleware` | ✅ | 长对话自动摘要压缩 |
| 6 | PatchToolCalls | `PatchToolCallsMiddleware` | ✅ | 修复悬空工具调用（中断恢复场景） |
| 7 | AsyncSubAgent | `AsyncSubAgentMiddleware` | 有异步子代理时 | 异步子代理调度 |
| 8 | **用户自定义** | 你的 `middleware` 参数 | 传了才有 | 合并到此处 |
| 9 | Profile 附加 | 模型 profile 中间件 | 有 profile 时 | 提供商特定中间件 |
| 10 | 排除工具 | 从 profile 过滤 | profile 有排除列表时 | 删除指定工具 |
| 11 | Prompt 缓存 | Anthropic/Bedrock | 这两个模型时 | Prompt Caching |
| 12 | Memory | `MemoryMiddleware` | `memory` 参数非空时 | 加载 AGENTS.md 记忆 |
| 13 | HITL | `HumanInTheLoopMiddleware` | `interrupt_on` 非空时 | 工具调用前暂停 |

**同步子 Agent 栈**：与主 Agent 相同，但**去掉了 SubAgentMiddleware**（子代理不能再派生孙子代理）。

## 二、中间件合并规则

用户传入的 `middleware` 通过 `.name` 字段判断如何融合到默认栈：

```python
# .name 匹配 → 替换原位
SummarizationMiddleware(
    name="SummarizationMiddleware",   # ← 匹配默认栈的第 5 层
    model=my_summary_model,           # 使用自定义参数
    trigger=("tokens", 100000),
)
# 结果: 替换栈中原来的 SummarizationMiddleware

# .name 不匹配 → 插入在第 8 层
CustomMiddleware(name="MyCustomThing")
# 结果: 插入在 PatchToolCalls 之后

# ❌ 不要试图通过 excluded_middleware 移除 SubAgentMiddleware
# 如果不需要子代理，用 subagents=[] 或 harness profile 禁用
```

## 三、覆盖默认中间件示例

### 调整摘要触发时机

> 本例演示**如何用 `.name` 覆盖默认中间件**；`trigger`/`keep` 各参数的权威取值说明见 [[deepagents/context/自动摘要机制]]。

```python
from deepagents.middleware import SummarizationMiddleware

agent = create_deep_agent(
    model=llm,
    middleware=[
        SummarizationMiddleware(
            model=summary_llm,
            trigger=("tokens", 100000),    # 超 100k tokens 才摘要
            keep=("messages", 30),          # 保留最近 30 条
        ),
    ],
)
```

### 限制文件系统工具

```python
from deepagents.middleware import FilesystemMiddleware

agent = create_deep_agent(
    model=llm,
    middleware=[
        FilesystemMiddleware(
            backend=my_backend,
            tools=["read_file", "ls", "glob", "grep"],
            # 只暴露读操作，不能写文件
        ),
    ],
)
```

> **注意**：覆盖而非合并。自定义 `FilesystemMiddleware` 必须完整配置 `backend` 和 `permissions`。

### 注入自定义工具中间件

```python
from langchain.agents.middleware import AgentMiddleware
from langchain_core.tools import tool

class WeatherMiddleware(AgentMiddleware):
    tools = [get_weather]  # ← 类属性，编译时被识别

agent = create_deep_agent(
    model=llm,
    middleware=[WeatherMiddleware()],
)
```

## 四、中间件提供的工具与组件关联

中间件是**工具的生产者**——但不是每个中间件都提供工具，分为"工具型"和"钩子型"两类。同时每个中间件都依赖其他组件（backend/checkpointer/model），构成完整链路。

### 4.1 工具型中间件（提供工具）

| 中间件 | 提供的工具 | 关联组件 | 关联方式 |
|--------|-----------|---------|---------|
| `TodoListMiddleware` | `write_todos` | AgentState | 任务清单持久化在状态中 |
| `FilesystemMiddleware` | `ls` `read_file` `write_file` `edit_file` `glob` `grep`（6 个） | **backend** | 工具列表与 backend 解耦：backend 决定文件落到哪个空间（内存/磁盘/Store/容器），**换 backend 工具不变** |
| `SubAgentMiddleware` | `task` | backend、subagents | 子代理的文件系统同样走 backend；子代理列表由 `subagents=` 提供 |
| Sandbox backend（非中间件） | `execute` | backend | **execute 工具由 backend 提供**，只有实现了执行协议的 backend（Sandbox 系列、LocalShellBackend）才出现 |

### 4.2 钩子型中间件（不提供工具）

| 中间件 | 不提供工具，做什么 | 关联组件 | 关联方式 |
|--------|-------------------|---------|---------|
| `SkillsMiddleware` | 扫描技能元数据 → 注入 system prompt，指引模型用 `read_file` 读技能全文 | **FilesystemMiddleware（跨中间件依赖！）** | 自身无任何 tools 属性，指引的 `read_file` 是 FilesystemMiddleware 提供的——**自定义架构若没有文件中间件，需自补 `load_skill` 读取通道** |
| `SummarizationMiddleware` | 上下文达阈值时自动摘要/卸载 | model（摘要模型）、backend（卸载落盘） | 摘要用独立模型实例；大输出卸载到 backend 的文件空间 |
| `PatchToolCallsMiddleware` | 修复中断恢复时的悬空工具调用 | — | 纯状态修复 |
| `AsyncSubAgentMiddleware` | 调度异步子代理 | 远程 LangGraph 部署 | 结果原文注入主上下文（隔离性弱于同步子代理） |
| `MemoryMiddleware` | 加载 AGENTS.md 注入 system prompt | **backend** | 从 backend 的文件空间读取记忆文件 |
| `HumanInTheLoopMiddleware` | 拦截指定工具调用，暂停等审批 | **checkpointer** | 中断恢复依赖 checkpointer 保存执行状态（不配会报错） |

### 4.3 关键关联关系图

```
SkillsMiddleware ──注入元数据──> system prompt
       │ (指引 read_file)
       ▼
FilesystemMiddleware ──提供 read_file──> 模型按路径读技能全文
       │ (工具转发)
       ▼
backend（State/Filesystem/Store/Sandbox）──决定文件落点 + 是否提供 execute
       ▲
MemoryMiddleware（读 AGENTS.md） / SubAgentMiddleware（子代理文件系统）都依赖它
       ▲
SummarizationMiddleware（卸载落盘）也依赖它
       ▲
HumanInTheLoopMiddleware ──依赖──> checkpointer（不是 backend）
```

### 4.4 组件关联速查

| 组件 | 被谁依赖 |
|------|---------|
| backend | FilesystemMiddleware、SkillsMiddleware（技能文件）、MemoryMiddleware（AGENTS.md）、SubAgentMiddleware（子代理 FS）、SummarizationMiddleware（卸载） |
| checkpointer | HumanInTheLoopMiddleware（必需）、会话持久化 |
| model | SummarizationMiddleware（摘要模型，可独立指定） |
| store | StoreBackend、长期记忆 |

## 五、与 LangChain 中间件的关系

DeepAgents 的所有内置中间件都是 LangChain 标准的 `AgentMiddleware` 子类。你完全可以把 DeepAgents 的中间件栈理解为 "LangChain 18 个中间件中挑选 6 个 + deepagents 自带的 7 个，按最佳实践预配置好的组合"。

| 来自 LangChain 内置 | 来自 deepagents |
|---------------------|-----------------|
| `TodoListMiddleware` | `SkillsMiddleware` |
| `FilesystemMiddleware` | `SubAgentMiddleware` |
| `SummarizationMiddleware` | `PatchToolCallsMiddleware` |
| `HumanInTheLoopMiddleware` | `AsyncSubAgentMiddleware` |
| | `MemoryMiddleware` |
