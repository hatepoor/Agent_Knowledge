# DeepAgents 自定义与扩展

DeepAgents 设计为"可覆盖可替换"的开放架构。不需要 fork——任何一层都能通过参数替换。

## 一、自定义层级

```
浅度自定义（参数级别）    深度自定义（架构级别）
─────────────────────    ─────────────────────
model → 换模型              subagents → 自定义子代理系统
system_prompt → 换指令      middleware → 替换/新增中间件
tools → 加工具               backend → 自定义存储后端
skills → 加载技能            profile → 注册 HarnessProfile
memory → 加载记忆文件        state_schema → 扩展 State
permissions → 配置文件权限    graph → 直接拿 CompiledGraph 定制
```

## 二、Harness Profile（模型配置）

```python
from deepagents import (
    GeneralPurposeSubagentProfile,
    HarnessProfile,
    register_harness_profile,
)

register_harness_profile(
    "anthropic",   # 模型提供商名
    HarnessProfile(
        base_system_prompt="你是 ACME 公司的技术支持助手。",
        general_purpose_subagent=GeneralPurposeSubagentProfile(
            system_prompt="你是研究子代理，引用来源。",
        ),
        system_prompt_suffix="始终用中文回答。",
    ),
)
```

**Profile 解析规则**：
- `base_system_prompt` + `system_prompt_suffix` → 主 Agent 的完整 prompt
- GP 子代理：子代理自定义 prompt > `base_system_prompt` > SDK 默认
- 只设 `system_prompt_suffix` 追加到已有 prompt；设 `base_system_prompt` 完全替换

## 三、文件系统权限

```python
from deepagents import create_deep_agent
from deepagents.middleware import FilesystemPermission

agent = create_deep_agent(
    model=llm,
    permissions=[
        FilesystemPermission(
            path="/workspace",          # 指定路径
            access="read_write",        # read / write / read_write
        ),
        FilesystemPermission(
            path="/tmp",
            access="read_write",
        ),
        # 其他路径默认不可访问
    ],
)
```

**子代理权限**：子代理默认继承主 Agent 的权限，可通过 `subagent.permissions` 覆盖。

## 四、禁用子代理

```python
# 方式 1：空子代理列表（仍保留 task 工具但无自定义子代理）
agent = create_deep_agent(model=llm, subagents=[])

# 方式 2：通过 harness profile 禁用
register_harness_profile("my-model", HarnessProfile(
    base_system_prompt="不要使用 task 工具。",
))

# ❌ 不要试图通过 excluded_middleware 移除 SubAgentMiddleware（会报错）
```

## 五、自定义中间件类

```python
from langchain.agents.middleware import AgentMiddleware
from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """查询城市天气"""
    return f"{city} 今天晴， 25°C"

class WeatherMiddleware(AgentMiddleware):
    """自动给 Agent 注入 get_weather 工具"""
    tools = [get_weather]  # ← 类属性，编译时被 Agent 工厂识别

agent = create_deep_agent(
    model=llm,
    middleware=[WeatherMiddleware()],
)
```

**关键规则**：不要在 `__init__` 后修改实例属性——用图状态（graph state）而非实例属性，避免竞态条件（子代理/并行工具/并发调用）。

## 六、限制消息增长（DeltaChannel）

DeepAgents 默认使用 `DeepAgentState`（继承自 `AgentState`），其中 messages 字段使用 **DeltaChannel** 而非普通的 `add_messages` reducer。区别：

| Reducer | 行为 | checkpoint 大小 |
|---------|------|:---:|
| `add_messages` | 每步追加完整消息列表 | O(N²) |
| `DeltaChannel` | 只保存增量 | O(N) |

零配置，自动生效。

## 七、响应格式

```python
from deepagents import create_deep_agent
from pydantic import BaseModel

class ReportFormat(BaseModel):
    title: str
    summary: str
    key_findings: list[str]
    sources: list[str]

agent = create_deep_agent(
    model=llm,
    response_format=ReportFormat,  # 强制模型输出结构化 JSON
)
```
