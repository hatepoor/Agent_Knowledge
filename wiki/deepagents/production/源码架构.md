# DeepAgents 源码架构

`deepagents` 的官方仓库源码结构（v0.6.12+，monorepo），理解它对自定义和排查问题至关重要。

## 〇、Monorepo 结构（v0.6+ 变更）

官方仓库从单包升级为 **uv monorepo**，核心 SDK 位于 `libs/deepagents/`：

```
deepagents（GitHub: langchain-ai/deepagents）
├── libs/
│   ├── deepagents/           # ★ 核心 SDK（本页讲解对象）
│   ├── code/                 #   deepagents-code：交互终端 UI（dcode）与编码 Agent
│   ├── cli/                  #   deepagents-cli：部署工具（init/dev/deploy）
│   ├── acp/                  #   deepagents-acp：Agent Client Protocol
│   ├── evals/                #   deepagents-harbor：评估基准集成
│   ├── talon/                #   实验性长时运行宿主
│   └── partners/             #   第三方沙箱（daytona/modal/runloop/quickjs/vercel）
├── examples/                 # 示例项目
└── README.md
```

> **pip install deepagents** 安装的就是 `libs/deepagents/` 这个包。

## 二、核心入口 — graph.py

`create_deep_agent()` 定义在此。核心流程：

```python
# graph.py 简化伪代码
def create_deep_agent(
    model, tools, system_prompt, middleware,
    subagents, skills, memory, backend,
    permissions, interrupt_on, ...
) -> CompiledStateGraph:

    # 1. 解析模型
    resolved_model = resolve_model(model)

    # 2. 构建默认中间件栈（按固定顺序）
    default_middleware = [
        TodoListMiddleware(),           # 任务规划
        SkillsMiddleware(skills) if skills else None,    # 技能
        FilesystemMiddleware(backend, permissions),       # 文件系统
        SubAgentMiddleware(subagents, model, tools),      # 子代理
        SummarizationMiddleware(...),                     # 摘要
        PatchToolCallsMiddleware(),                       # 修复悬挂调用
        AsyncSubAgentMiddleware(...) if async_subagents else None,
    ]

    # 3. 合并用户自定义中间件
    merged = _merge_middleware(default_middleware, middleware)

    # 4. 追加 profile 特定中间件 + 缓存 + 记忆 + HITL
    merged += _get_profile_middleware(resolved_model)
    if memory: merged += [MemoryMiddleware(memory)]
    merged += [AnthropicPromptCachingMiddleware(), BedrockPromptCachingMiddleware()]
    if interrupt_on: merged += [HumanInTheLoopMiddleware(interrupt_on)]

    # 5. 全部传给 create_agent
    return create_agent(model=resolved_model, tools=all_tools, middleware=merged, ...)
```

## 三、中间件合并机制

```python
def _merge_middleware(default: list, user: list) -> list:
    """用户中间件按 .name 匹配替换默认栈中的同名项"""
    default_by_name = {mw.name: i for i, mw in enumerate(default) if mw}

    for user_mw in user:
        if user_mw.name in default_by_name:
            idx = default_by_name[user_mw.name]
            default[idx] = user_mw    # 替换原位
        else:
            default.insert(6, user_mw) # 插入在第 6 层之后
    return default
```

| 版本 | 主要变更 |
