# DeepAgents 测试策略

Deep Agent 是"LLM + 中间件 + 工具"的组合，测试分层：**工具层**（纯函数测试）→ **中间件层**（mock 模型）→ **集成层**（真实模型 E2E）。

## 一、测试金字塔

```
        ▲  集成测试（少量）
       / \  真实模型 + 完整 Agent，验证整体行为
      /   \
     /─────\  中间件测试（适量）
    /       \  mock 模型，验证中间件逻辑（HITL/摘要/子代理）
   /─────────\ 工具与组件测试（大量）
  /           \ 纯函数，不涉及 LLM，快速稳定
```

原则：**越底层测试越多**，LLM 相关的测试最少（慢、贵、不稳定）。

## 二、工具层测试（无 LLM）

```python
# test_tools.py
from deepagents import create_deep_agent
from langchain_core.tools import tool

@tool
def add(a: int, b: int) -> int:
    """加法"""
    return a + b

def test_tool_direct():
    """直接测工具函数，不走 Agent"""
    assert add.invoke({"a": 1, "b": 2}) == 3

def test_tool_error_handling():
    """工具异常是否被包装"""
    with pytest.raises(ValueError):
        add.invoke({"a": "x", "b": 2})  # 类型错误
```

## 三、中间件层测试（mock 模型）

核心技巧：**用 FakeChatModel 替换真实 LLM**，让 Agent 的每一步输出可控。

```python
# test_middleware.py
import pytest
from langchain_core.messages import AIMessage, HumanMessage
from langchain_core.language_models.fake_chat_models import FakeMessagesListChatModel
from deepagents import create_deep_agent

def make_fake_model(messages: list):
    """按顺序返回预设回复的假模型"""
    return FakeMessagesListChatModel(responses=messages)

def test_agent_calls_tool_then_responds():
    """模拟：LLM 先调用工具，再用工具结果回复"""
    fake_llm = FakeMessagesListChatModel(responses=[
        # 第 1 轮：让 LLM "调用" add 工具
        AIMessage(
            content="",
            tool_calls=[{"name": "add", "args": {"a": 1, "b": 2}, "id": "call_1"}],
        ),
        # 第 2 轮：LLM 基于工具结果回复
        AIMessage(content="结果是 3"),
    ])

    agent = create_deep_agent(model=fake_llm, tools=[add])
    result = agent.invoke({
        "messages": [HumanMessage(content="1+2=?")]
    })
    assert result["messages"][-1].content == "结果是 3"
```

### 测试 HITL 中断

```python
def test_hitl_interrupt_and_approve():
    from langgraph.checkpoint.memory import MemorySaver
    from langgraph.types import Command

    fake_llm = FakeMessagesListChatModel(responses=[
        AIMessage(content="", tool_calls=[
            {"name": "send_email", "args": {"to": "a@b.com"}, "id": "call_1"}
        ]),
        AIMessage(content="邮件已发送"),
    ])

    agent = create_deep_agent(
        model=fake_llm,
        tools=[send_email],
        interrupt_on={"send_email": True},
        checkpointer=MemorySaver(),
    )
    config = {"configurable": {"thread_id": "t1"}}

    # 第一次调用 → 应中断
    result = agent.invoke(
        {"messages": [HumanMessage(content="发邮件")]}, config=config
    )
    assert "__interrupt__" in result  # 验证中断发生

    # 审批后恢复 → 应执行并回复
    result2 = agent.invoke(
        Command(resume={"decisions": [{"type": "approve"}]}), config=config
    )
    assert result2["messages"][-1].content == "邮件已发送"
```

### 测试子代理

```python
def test_subagent_delegation():
    fake_main = FakeMessagesListChatModel(responses=[
        AIMessage(content="", tool_calls=[
            {"name": "task", "args": {"query": "调研", "subagent": "researcher"}, "id": "c1"}
        ]),
        AIMessage(content="调研完成"),
    ])
    fake_sub = FakeMessagesListChatModel(responses=[
        AIMessage(content="找到了 3 条参考资料")
    ])

    agent = create_deep_agent(
        model=fake_main,
        subagents=[SubAgent(name="researcher", description="调研", model=fake_sub)],
    )
    result = agent.invoke({"messages": [HumanMessage(content="帮我调研")]})
    assert result["messages"][-1].content == "调研完成"
```

## 四、集成测试（真实模型）

数量少，但必须覆盖关键路径。**需要真实的 API Key**，用 pytest marker 隔离：

```python
# conftest.py
import pytest

@pytest.fixture(scope="session")
def real_llm():
    from langchain_deepseek import ChatDeepSeek
    return ChatDeepSeek(model="deepseek-v4-flash")

@pytest.mark.integration  # 需要真实 API
def test_rag_query(real_llm):
    agent = create_deep_agent(model=real_llm, tools=[search_knowledge])
    result = agent.invoke({"messages": [HumanMessage(content="RAG 是什么？")]})
    assert "检索" in result["messages"][-1].content
```

运行隔离：

```bash
# 只跑单元测试（默认）
pytest -m "not integration"

# 跑全部
pytest
```

## 五、工具 mock 模式

不想真的执行外部工具（网络请求、发邮件）时，mock 工具本身：

```python
# conftest.py
import pytest

@pytest.fixture
def mock_agent_tools(monkeypatch):
    """把外部工具替换为固定返回"""
    def fake_search(query: str) -> str:
        return f"模拟搜索结果: {query}"

    monkeypatch.setattr("my_agent.tools.internet_search", fake_search)
    return fake_search
```

## 七、调试技巧

| 场景 | 技巧 |
|------|------|
| 看 Agent 每一步在想什么 | `create_deep_agent(model=llm, debug=True)` |
| 定位工具调用参数错误 | 断言 `result["messages"]` 中 ToolMessage 的内容 |
| 检查中间件是否生效 | 断言状态中是否有中间件写入的字段（如 todos） |
| 断言子代理调用 | 检查 `result["messages"]` 中是否有 `task` 工具调用记录 |
