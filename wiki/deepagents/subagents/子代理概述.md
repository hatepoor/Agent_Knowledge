# DeepAgents 子代理系统

子代理是 DeepAgents 最核心的能力之一——让主 Agent 把复杂子任务**委派给专门的小 Agent**，隔离上下文并返回精简结果。

## 一、为什么需要子代理

```
没有子代理:
  主 Agent 读 50 个网页 → context 撑爆 → 摘要压缩 → 丢信息

有子代理:
  主 Agent 调 task("搜索 LangGraph") → 子 Agent 读 50 个网页 → 返回一段总结
  主 Agent 只看到 "LangGraph 最新版本是 0.4..."
  （50 个网页的原文在主 Agent 的 context 中不存在）
```

**核心价值**：上下文隔离 + 任务分解。

## 二、通用子代理（默认自带）

```python
# 不用配置，主 Agent 自动有 task 工具
agent = create_deep_agent(model=llm)
# Agent 内部可以调: task(subagent_type="general-purpose", description="搜索 X")
# general-purpose 子代理和主 Agent 指令相同、工具相同
```

**特性**：
- 独立上下文（从头开始）
- 拥有主 Agent 的所有工具
- 执行完毕自动销毁
- **只返回一份最终报告**，不能多轮回传

## 三、自定义子代理

```python
from deepagents import create_deep_agent, SubAgent

agent = create_deep_agent(
    model=llm,
    subagents=[
        SubAgent(
            name="researcher",             # 子代理名称 → task 工具的参数
            description="专门做网络搜索和资料研究",  # 告诉主 Agent 何时用它
            system_prompt="你是研究员。先搜索，再总结，引用来源。",
            model="deepseek-v4-flash",      # 可以和主 Agent 不同模型
            tools=[internet_search],         # 可以和主 Agent 不同工具
        ),
        SubAgent(
            name="code_reviewer",
            description="审查代码、找 bug、给改进建议",
            system_prompt="你是代码审查专家。按安全/性能/规范三个维度审查。",
            tools=[read_file],   # ← read_file 来自 FilesystemMiddleware 提供的文件系统工具
        ),
    ],
)
```

> **关于 `tools=[read_file]` 的来源**：子代理继承主 Agent 的完整中间件栈，因此自动拥有 `ls/read_file/write_file/edit_file/glob/grep` 文件系统工具（由 FilesystemMiddleware 提供）。在 `tools=[read_file]` 中显式列出只是**筛选**可用的工具子集，`read_file` 本身并非自定义工具——完整归属链见 [[deepagents/middleware/中间件栈概述]] 的"4.1 工具型中间件"。

**主 Agent 调度逻辑**：

```
主 Agent 见用户说"审查这段代码"
  → 看子代理列表：researcher（研究）、code_reviewer（审查代码）
  → 匹配 code_reviewer → task(subagent_type="code_reviewer", description="审查用户代码")
  → code_reviewer 执行 → 返回审查报告
  → 主 Agent 把报告回复用户
```

## 四、编译子代理（预构建图）

```python
from deepagents import create_deep_agent, CompiledSubAgent
from langgraph.graph import StateGraph

# 预构建一个 LangGraph 图作为子代理
custom_graph = (
    StateGraph(...)
    .add_node("research", research_node)
    .add_node("report", report_node)
    .add_edge("research", "report")
    .compile()
)

agent = create_deep_agent(
    model=llm,
    subagents=[
        CompiledSubAgent(
            name="custom_researcher",
            description="用自定义图做深度研究",
            runnable=custom_graph,
        ),
    ],
)
```

## 五、异步子代理（可并行）

```python
from deepagents import create_deep_agent, AsyncSubAgent

agent = create_deep_agent(
    model=llm,
    subagents=[
        AsyncSubAgent(
            name="parallel_researcher",
            description="异步执行，可同时派发多个",
            system_prompt="你是快速研究员...",
        ),
    ],
)
# 主 Agent 可以同时派发 3 个 parallel_researcher 子代理
# 它们并发执行，各自返回结果
```

## 六、子代理的限制

| 限制 | 说明 |
|------|------|
| 无状态 | 子代理不记忆之前的调用，每次从头开始 |
| 单向通信 | 只返回一份最终报告 |
| 不能派生孙子代理 | 同步子代理栈没有 SubAgentMiddleware |
| 异步子代理可以继续派生 | 异步子代理栈保留了 SubAgentMiddleware |
