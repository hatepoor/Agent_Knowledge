# PostgreSQL 学习路线图

> 目标:从"会写 SQL"到"能解释数据库为什么这样行为"。路线分为三个阶段,每阶段有明确的**能力出口**与**自测清单**。

## 一、总览

| 阶段 | 能力出口(学完能做到什么) | 建议投入 | 组织范式 |
|------|--------------------------|----------|----------|
| 一、入门 | 独立设计单表/多表模型,熟练 CRUD 与基础查询,能控制事务边界 | 2–3 周 | 顺序章节式 |
| 二、中段 | 面对一类需求能选对特性(窗口函数 / JSONB / 索引 / 分区 / FTS),会读执行计划 | 4–6 周 | 平行专题式 |
| 三、进阶 | 能从存储、MVCC、索引、WAL、锁五个层面解释性能与并发问题 | 8 周+ | 分层剖析式 |

**关键前置**:本地必须有一个可反复重建的 PostgreSQL 实例(Docker 一条命令即可,见第 01 章)。所有实验都在这个实例上做。

**起点**:零基础请从 [[postgresql/01-入门阶段-基础教程/第00章-学前准备/0.1-数据库与SQL是什么]] 开始,它不要求任何前置知识。

**自学时的常备参考(遇到不认识的东西查这三处)**

| 卡在哪 | 查哪里 |
|--------|--------|
| 不认识的**名词 / 关键字**(`CONSTRAINT`、`relation`、`xmin`、`oid`…) | [[postgresql/术语与关键字手册]] |
| 不认识的**函数**(`width_bucket`、`jsonb_path_query`…) | [[postgresql/函数手册]] |
| 看不懂**报错** | [[postgresql/01-入门阶段-基础教程/第00章-学前准备/0.4-看懂报错信息]] |

**阶段一自测清单**
- [ ] 能说出 `varchar(n)` 与 `text` 在 PostgreSQL 中的真实差异(性能上几乎无差异,差异在约束语义)
- [ ] 能解释 `timestamp` 与 `timestamptz` 的存储差异,以及该选哪个
- [ ] 能写出带 `ON CONFLICT ... DO UPDATE` 的幂等写入
- [ ] 能区分 `WHERE` 与 `HAVING` 的执行时机
- [ ] 能解释 `NULL = NULL` 的结果及其后果
- [ ] 能用 `LATERAL` 或子查询解决"取每组最新一条"

**阶段二自测清单**
- [ ] 能判断一个窗口函数能否用 `GROUP BY` 替代,以及为什么
- [ ] 能为 JSONB 选择正确的 GIN opclass,并解释 `jsonb_ops` 与 `jsonb_path_ops` 的取舍
- [ ] 能把一个 `Seq Scan` 的慢查询改造成走索引,并说明为什么原来没走
- [ ] 能解释 `EXPLAIN` 里 `rows` 估算值与 `actual rows` 差异巨大的原因
- [ ] 能做一次基于时间范围的分区表改造并验证分区裁剪
- [ ] 能设计"全量 + 增量"的备份策略

## 四、阶段三:进阶(分层剖析式)

> 特征:按**内核模块**分层,每篇遵循统一模板:现象 → 机制 → 数据结构 → 源码路径 → 实验验证 → 生产启示。
>
> **前置**:中段阶段已基本掌握,并且已经在真实项目里遇到过性能或并发问题。
>
> ⚠️ **重要提醒:这个阶段的内容会出现大量你从未见过的名词**(`xmin`、`ctid`、页头字段、WAL、快照……)。这些名词在这里会被逐个解释,但**如果你还没到"能写业务 SQL"的水平,读这一阶段必然是看不懂的**。看不懂请先回到入门阶段,不要硬啃。

**阶段三自测清单**
- [ ] 能画出 8KB 页的内部布局,并说出 `pd_lsn` / `pd_lower` / `pd_upper` 的含义
- [ ] 能解释 HOT 更新为什么能避免更新索引
- [ ] 能根据 `xmin` / `xmax` 手工判断一行对一个快照是否可见
- [ ] 能解释 `VACUUM FULL` 与 `VACUUM` 的本质区别,以及何时必须用前者
- [ ] 能从 WAL 的角度解释 `synchronous_commit=off` 丢数据的边界
- [ ] 能解释可串行化隔离(SI vs SSI)的区别及"串行化失败"为何需要重试
