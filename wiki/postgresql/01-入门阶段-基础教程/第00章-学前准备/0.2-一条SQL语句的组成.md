# 0.2 一条 SQL 语句的组成

## 学习目标

读完这一篇,你应该能:

- 把任意一条 SQL 语句拆成"关键字 / 标识符 / 字面量 / 运算符"四类成分
- 说清单引号、双引号、圆括号、方括号、点号、星号各起什么作用
- 不再被"引号用错"这类报错卡住

## 前置知识

## 正文

## 一、先解剖一条语句

```sql
SELECT email, name FROM users WHERE vip = true;
```

把它逐个词拆开:

```
SELECT   email  ,   name   FROM   users   WHERE   vip   =   true   ;
  │        │     │    │       │      │       │      │   │     │    │
  │        │     │    │       │      │       │      │   │     │    └─ 语句结束符
  │        │     │    │       │      │       │      │   │     └────── 字面量(真/假值)
  │        │     │    │       │      │       │      │   └──────────── 运算符(等于)
  │        │     │    │       │      │       │      └──────────────── 标识符(列名)
  │        │     │    │       │      │       └─────────────────────── 关键字(筛选)
  │        │     │    │       │      └─────────────────────────────── 标识符(表名)
  │        │     │    │       └────────────────────────────────────── 关键字(从哪取)
  │        │     │    └────────────────────────────────────────────── 逗号(分隔多个列)
  │        │     └─────────────────────────────────────────────────── 标识符(列名)
  │        └───────────────────────────────────────────────────────── 标识符(列名)
  └────────────────────────────────────────────────────────────────── 关键字(取什么)
```

**四类成分,含义各不同:**

| 成分 | 是什么 | 谁决定 | 例子 |
|------|--------|--------|------|
| **关键字** | 数据库预留的、有固定含义的词 | 数据库固定,你不能改 | `SELECT` `FROM` `WHERE` `INSERT` |
| **标识符** | 你自己起名字的东西:表名、列名 | 你决定(建表时定) | `users` `email` `vip` |
| **字面量** | 直接写出来的具体数值/文本/时间 | 你决定 | `'Ann'` `42` `true` `'2026-09-20'` |
| **运算符** | 表示运算或比较的符号 | 数据库固定 | `=` `>` `<` `+` `-` `AND` `OR` |

> **关键字和标识符的区别,决定了"能不能改名"**:关键字是数据库的词汇表,你无法改动;标识符是你自己起的名字,只要改得前后一致就行。
>
> **用关键字当表名/列名会怎样**:早期要加双引号才能用,但强烈不建议——会到处出问题。完整的保留字清单见 [[postgresql/术语与关键字手册]]。

## 二、四种东西的写法:各有各的引号规则

**这是新手最容易出错的地方。请重点看这一节。**

### 字符串:用单引号

```sql
SELECT 'Ann';              -- ✅ 文本
SELECT '2026-09-20';       -- ✅ 日期也先用单引号写成文本,再转换
SELECT 'it''s ok';         -- ✅ 字符串内部想写单引号,连写两个
```

### 数字:直接写,不加任何引号

```sql
SELECT 42;         -- ✅ 整数
SELECT 3.14;       -- ✅ 小数
SELECT '42';       -- ⚠️ 这是"文本 42",不是数字!参与计算时行为可能不同
```

### 布尔值:写 true / false

```sql
SELECT true;       -- ✅
SELECT false;      -- ✅
```

### 时间:先写成单引号文本,再告诉数据库它是什么

```sql
SELECT '2026-09-20'::date;                  -- 转成日期
SELECT '2026-09-20 10:30:00'::timestamptz;  -- 转成带时区的时间点

-- 也可以写成标准写法(等价,更啰嗦)
SELECT DATE '2026-09-20';
SELECT TIMESTAMP WITH TIME ZONE '2026-09-20 10:30:00';
```

> **`::date` 是什么**:两个冒号叫**类型转换运算符**,读作"把它当作"。`'2026-09-20'` 本来是一串文本,`::date` 告诉数据库"请按日期理解它"。第 2.6 篇会详细讲。

## 三、双引号的作用(和单引号完全不同)

**单引号包的是"内容",双引号包的是"名字"。** 这是两条完全不同的规则。

```sql
SELECT 'email';       -- 输出四行:email      ← 就是一段文本,不是列
SELECT "email";       -- 输出 email 这一列的值 ← 表示"名叫 email 的那一列"
```

**什么时候才需要双引号**:只有当你起的名字包含特殊字符、大写字母、或撞上关键字时,才必须用双引号精确指定:

```sql
-- 下面这个列名含空格,必须用双引号才能引用
CREATE TABLE t ("user name" text);
SELECT "user name" FROM t;      -- ✅ 必须加
SELECT user name FROM t;        -- ❌ 报错,数据库以为你在说两个东西
```

> **实践建议**:**永远不要用需要双引号的名字**。标识符一律小写 + 下划线,就永远不需要双引号了。这是本套文档的书写约定,请照做。

## 四、标点符号速查

| 符号 | 名称 | 作用 | 例子 |
|------|------|------|------|
| `;` | 分号 | 一条语句结束 | `SELECT 1;` |
| `,` | 逗号 | 分隔同级的多个项 | `SELECT a, b FROM t;` |
| `.` | 点号 | 表示从属关系:`表.列` | `users.email` |
| `*` | 星号 | "所有列" | `SELECT * FROM users;` |
| `()` | 圆括号 | 括住参数、分组、控制优先级 | `count(*)`、`(a+b)*c` |
| `[]` | 方括号 | 取数组的某个元素 | `tags[1]` |
| `'` | 单引号 | 包住文本内容 | `'Ann'` |
| `"` | 双引号 | 精确指定一个名字 | `"user name"` |
| `--` | 双减号 | 注释到行尾 | `-- 说明` |
| `/* */` | 斜杠星 | 多行注释 | `/* 说明 */` |
| `::` | 双冒号 | 类型转换 | `'42'::integer` |
| `\|\|` | 双竖线 | 拼接两个文本 | `'a' \|\| 'b'` → `'ab'` |
| `\d` | 反斜杠 | psql 的元命令(**不是 SQL**) | `\dt` |

> **`\d` 这类反斜杠命令要单独说明**:它们是 **psql 客户端**的命令,不是 SQL,所以**不需要分号结尾**。SQL 语句要以分号结尾,psql 元命令不用。

**点号的两种用法**

```sql
-- 用法一:表名.列名,用于多表时指明"是哪个表的列"
SELECT users.email FROM users;

-- 用法二:库名.表名 或 模式名.表名
SELECT * FROM app.orders;       -- app 是"模式"(见 3.1),orders 是表
```

## 五、注释怎么用(本套文档依赖它)

```sql
-- 两个减号注释掉本行后面的内容
SELECT 1;   -- 也可以写在语句后面,解释这一行在做什么

/*
   多行注释
   可以跨若干行
*/
```

> 本套文档的每个代码块都用 `--` 逐行解释。**你可以整段复制粘贴到 psql 执行**,数据库会自动忽略 `--` 及其后的内容。看到看不懂的行,先读它的注释。

## 六、语句的书写可以换行

下面两种写法**完全等价**:

```sql
-- 写法一:一行写完
SELECT email, name FROM users WHERE vip = true;

-- 写法二:换行缩进(推荐,长语句必用)
SELECT email,
       name
FROM users
WHERE vip = true;
```

换行、空格、缩进对数据库**没有任何影响**(它们只是让你自己看得清)。**唯一不能省的是分号。**

## 小结

- 一条语句由四类成分组成:**关键字**(数据库的)、**标识符**(你起的)、**字面量**(具体值)、**运算符**。
- **单引号包内容,双引号包名字**。字符串用单引号,数字不加引号,布尔写 `true`/`false`。
- 换行缩进不影响执行,**分号不能省**。
- `\d` 开头的是 psql 元命令,不加分号;SQL 语句要加分号。
- 反斜杠命令、`::`、`.`、`*` 的含义见上表。
- **不要用需要双引号的标识符**——一律小写加下划线。
