# 入门阶段 · 章节目录

> **组织范式:顺序章节式。** 本阶段的知识彼此存在依赖:类型 → 建表 → 写入 → 查询 → 事务。因此目录带序号,**请按顺序推进,不要跳。**
>
> 每篇文档统一采用五段结构:**学习目标 → 前置知识 → 正文 → 小结 → 练习**。
>
> **零基础请从第 00 章开始。** 第 00 章不要求任何前置知识,只解决一件事:让你能连上数据库、看懂语句、看懂报错。
>
> **入门阶段的定位**:学完能**独立写业务 SQL**(建表、增删改查、多表查询、聚合分组、会用事务)。索引优化、执行计划、复制备份等属于中段与进阶阶段。

## 本阶段统一实践数据集

以下脚本贯穿本阶段所有练习。**建议只在 Docker 实例上执行**。

> **给初学者的提示**:这段脚本里已经出现了第 02~03 章才会讲的东西——`GENERATED ALWAYS AS IDENTITY`(自增列)、`numeric(12,2)`(精确小数)、`CHECK`(检查约束)、`REFERENCES ... ON DELETE CASCADE`(外键级联)、`text[]`(数组)、`jsonb`。
> **现在看不懂完全正常,直接执行即可**,等学完第 02、03 章再回头看一遍,你会发现每一行都读得懂。这不影响后续练习。

```sql
DROP TABLE IF EXISTS order_items, orders, products, users CASCADE;

CREATE TABLE users (
    id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    email      text NOT NULL UNIQUE,
    name       text NOT NULL,
    vip        boolean NOT NULL DEFAULT false,
    profile    jsonb,
    created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE products (
    id       bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    sku      text NOT NULL UNIQUE,
    name     text NOT NULL,
    price    numeric(12,2) NOT NULL CHECK (price >= 0),
    tags     text[] NOT NULL DEFAULT '{}'
);

CREATE TABLE orders (
    id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    user_id    bigint NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    status     text NOT NULL DEFAULT 'pending'
                 CHECK (status IN ('pending','paid','shipped','done','canceled')),
    total      numeric(12,2) NOT NULL DEFAULT 0,
    created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE order_items (
    order_id   bigint NOT NULL REFERENCES orders(id) ON DELETE CASCADE,
    product_id bigint NOT NULL REFERENCES products(id),
    qty        integer NOT NULL CHECK (qty > 0),
    unit_price numeric(12,2) NOT NULL,
    PRIMARY KEY (order_id, product_id)
);
```
