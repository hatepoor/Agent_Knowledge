# PostgreSQL 速查索引

> 语法速查。写 SQL 时先查这里,不必回翻教程。凡标注版本的特性请对照你的实际部署版本。
>
> **注意本页的定位**:这里只给**语法骨架**与**名字清单**,不逐个解释。
> - 看不懂**函数名**(例如 `jsonb_path_query`、`gin_clean_pending_list`)→ [[postgresql/函数手册]]
> - 看不懂**关键字或名词**(例如 `CONSTRAINT`、`relation`、`xmin`)→ [[postgresql/术语与关键字手册]]

## 一、psql 常用元命令

| 命令 | 作用 |

| `\l` / `\l+` | 列出数据库 |

## 二、系统信息视图 / 函数

| 对象 | 用途 |
|------|------|
| `pg_stat_activity` | 当前连接/查询状态(排查阻塞第一入口) |
| `pg_stat_statements` | 归一化 SQL 的耗时统计(**必装扩展**) |
| `pg_locks` | 当前锁 |
| `pg_stat_user_tables` | 表级统计:seq_scan / idx_scan / n_dead_tup |
| `pg_stat_user_indexes` | 索引使用次数(找无用索引) |
| `pg_stat_progress_vacuum` | VACUUM 进度 |
| `pg_stat_progress_create_index` | (PG12+) 创建索引进度 |
| `pg_stat_progress_cluster` | (PG12+) CLUSTER/VACUUM FULL 进度 |
| `pg_stat_replication` | 复制状态与延迟 |
| `pg_stat_io` | (PG18 重写) I/O 统计 |
| `pg_stat_database` | 库级统计:blks_hit / blks_read / deadlocks |
| `pg_indexes`, `pg_class`, `pg_attribute` | 系统目录元数据 |
| `pg_size_pretty(pg_total_relation_size('t'))` | 表+索引+TOAST 总大小 |
| `pg_relation_size('t')` | 表主体大小 |
| `pg_stat_get_...` 系列 | 底层统计函数 |
| `version()` / `current_setting('server_version')` | 版本 |
| `pg_backend_pid()` / `pg_cancel_backend(pid)` / `pg_terminate_backend(pid)` | 进程控制 |
| `pg_relation_filepath('t')` | 表在磁盘上的相对路径(内核实验用) |

## 三、常用数据类型速查

| 类别 | 类型 | 说明 |
|------|------|------|
| 整数 | `smallint` / `integer` / `bigint` | 2 / 4 / 8 字节 |
| 自增 | `GENERATED ALWAYS AS IDENTITY` | **推荐**,优于 `serial` |
| 高精度 | `numeric(p,s)` | 精确十进制,金额用它 |
| 浮点 | `real` / `double precision` | 近似值,不用于金额 |
| 字符 | `text` | **默认选它** |
| 字符 | `varchar(n)` | 需要长度上限时用 |
| 字符 | `char(n)` | 定长、空格补齐,少用 |
| 时间 | `date` / `time` / `interval` | |
| 时间 | `timestamptz` | **推荐**,内部存 UTC 瞬时 |
| 时间 | `timestamp` | 无时区语义,存"墙上时间" |
| 布尔 | `boolean` | 接受 `true/t/yes/1/on` 等 |
| 二进制 | `bytea` | 存二进制,`\x` 十六进制字面量 |
| UUID | `uuid` / `uuidv7()` | PG18 起有 `uuidv7()`,索引局部性更好 |
| JSON | `jsonb` | **推荐**,支持索引与高效操作 |
| 数组 | `integer[]` / `text[]` | 支持 `@>` `<@` `&&` `ANY` |
| 范围 | `int4range` / `tsrange` / `daterange` | PG14+ 支持 multirange |
| 网络 | `inet` / `cidr` / `macaddr` | |

## 四、SQL 语法骨架

```sql
-- 建表(推荐写法)
CREATE TABLE orders (
    id          bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    user_id     bigint NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    amount      numeric(12,2) NOT NULL CHECK (amount >= 0),
    status      text NOT NULL DEFAULT 'pending',
    payload     jsonb,
    created_at  timestamptz NOT NULL DEFAULT now()
);

-- UPSERT(幂等写入)
INSERT INTO users (email, name) VALUES ('a@b.c', 'Ann')
ON CONFLICT (email) DO UPDATE SET name = EXCLUDED.name
RETURNING id, (xmax = 0) AS inserted;

-- 分页(PG13+ 支持 FETCH FIRST)
SELECT * FROM orders ORDER BY created_at DESC LIMIT 20 OFFSET 40;
SELECT * FROM orders ORDER BY created_at DESC FETCH FIRST 20 ROWS ONLY;

-- 取每组最新一条
SELECT * FROM (
  SELECT *, row_number() OVER (PARTITION BY user_id ORDER BY created_at DESC) AS rn
  FROM orders
) t WHERE rn = 1;

-- 窗口函数
SELECT user_id, amount,
       sum(amount) OVER (PARTITION BY user_id ORDER BY created_at
                         ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS running_total
FROM orders;

-- 递归 CTE
WITH RECURSIVE tree AS (
  SELECT id, parent_id, 1 AS depth FROM nodes WHERE parent_id IS NULL
  UNION ALL
  SELECT n.id, n.parent_id, t.depth + 1 FROM nodes n JOIN tree t ON n.parent_id = t.id
)
SELECT * FROM tree ORDER BY depth;

-- JSONB 查询
SELECT payload->>'city' AS city FROM orders WHERE payload @> '{"vip": true}';
SELECT jsonb_path_query(payload, '$.items[*] ? (@.qty > 2)') FROM orders;

-- 执行计划
EXPLAIN (ANALYZE, BUFFERS, VERBOSE) SELECT ...;

-- 查看对象大小
SELECT pg_size_pretty(pg_total_relation_size('orders'));
```

## 五、配置参数速查(调优高频)

| 参数 | 作用 | 经验起点 |
|------|------|----------|
| `shared_buffers` | 共享缓冲区 | 物理内存 25% |
| `work_mem` | 单次排序/哈希内存 | 内存高时 32–128MB |
| `maintenance_work_mem` | VACUUM/建索引内存 | 256MB–1GB |
| `effective_cache_size` | 规划器"预期可缓存量" | 物理内存 50–75% |
| `max_connections` | 最大连接数 | 高并发用连接池替代 |
| `random_page_cost` | 随机页代价 | SSD 上可降到 1.1–2.0 |
| `wal_level` | WAL 级别 | `replica`(逻辑复制需 `logical`) |
| `max_wal_size` | 触发检查点的 WAL 量 | 1–4GB |
| `checkpoint_timeout` | 检查点间隔 | 15min–30min |
| `synchronous_commit` | 提交是否同步刷盘 | 默认 `on`;`off` 有丢数据窗口 |
| `io_method` | (PG18+) AIO 方式 | `worker`(默认) / `io_uring` |
| `default_statistics_target` | 统计信息采样 | 100(复杂查询可调高) |
| `autovacuum_vacuum_scale_factor` | autovacuum 触发比例 | 大表调低 |
| `log_min_duration_statement` | 慢查询阈值(ms) | 200–1000 |
| `track_io_timing` | 采集 I/O 耗时 | `on`(配合 `EXPLAIN BUFFERS`) |

## 六、扩展速查

| 扩展 | 用途 | 安装 |
|------|------|------|
| `pg_stat_statements` | 查询级性能统计 | `CREATE EXTENSION pg_stat_statements;` |
| `pg_trgm` | 模糊匹配 / 三元组索引 | `CREATE EXTENSION pg_trgm;` |
| `pgcrypto` | 摘要、随机、加密 | `CREATE EXTENSION pgcrypto;` |
| `pgvector` | 向量检索(RAG) | 需单独安装并可 `CREATE EXTENSION` |
| `postgis` | 地理空间 | 需单独安装 |
| `hstore` | 键值对 | `CREATE EXTENSION hstore;` |
| `pg_cron` | 库内定时任务 | 需预加载 |
| `postgres_fdw` | 跨库/跨实例访问 | `CREATE EXTENSION postgres_fdw;` |

查看可装扩展:`SELECT * FROM pg_available_extensions ORDER BY name;`
