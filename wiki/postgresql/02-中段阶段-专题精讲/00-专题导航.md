## 准备实验数据

下面这段 SQL 在本阶段会反复用到:它往 `orders` 里灌 20 万行有规律的时间序列数据,便于做窗口函数、分区、索引实验。**逐行都加了说明。**

```sql
-- ① 给订单表增加一个"渠道"列
ALTER TABLE orders ADD COLUMN channel text;

-- ② 用取余运算给已有数据分配渠道
--    ARRAY['web','app','store']      构造一个三元素数组
--    [ ... ]                         按下标取元素(下标从 1 开始)
--    1 + (id % 3)                    结果只可能是 1 / 2 / 3
UPDATE orders SET channel = (ARRAY['web','app','store'])[1 + (id % 3)];

-- ③ 生成 20 万行测试数据
INSERT INTO orders (user_id, status, total, created_at, channel)
SELECT
    1 + (g % 50),                                                       -- user_id:在 1~50 之间循环
    (ARRAY['pending','paid','shipped','done','canceled'])[1 + (g % 5)],  -- 状态:五选一
    round((random() * 1000)::numeric, 2),                                -- 金额:0~1000 随机,保留 2 位
    now() - (g || ' minutes')::interval,                                 -- 时间:从此刻往前推 g 分钟
    (ARRAY['web','app','store'])[1 + (g % 3)]                            -- 渠道:三选一
FROM generate_series(1, 200000) AS g;
--   ↑ generate_series 是"表函数":它返回多行,因此可以直接当作 FROM 的数据源
--   ↑ AS g 是给它起别名,后面用 g 引用当前行的值

-- ④ 收集统计信息(不能省!否则规划器估不准行数,执行计划会失真)
ANALYZE orders;
```

**这段代码用到的三个关键写法**

| 写法 | 含义 | 详解位置 |
|------|------|----------|
| `generate_series(1, 200000) AS g` | 表函数:生成 20 万行序号。`AS g` 给结果起别名,后续用 `g` 引用 | [[postgresql/01-入门阶段-基础教程/第02章-数据类型/2.3-日期时间类型]] |
| `ARRAY['a','b','c'][n]` | 先构造数组,再按**下标**取元素(下标从 **1** 开始,不是 0) | [[postgresql/01-入门阶段-基础教程/第02章-数据类型/2.5-数组与JSON初步]] |
| `(g \|\| ' minutes')::interval` | 把数字拼成 `'120 minutes'` 文本,再转成时间间隔;`now() - 间隔` 得到"过去某时刻" | [[postgresql/01-入门阶段-基础教程/第02章-数据类型/2.3-日期时间类型]] |

> **前置依赖**:第 ③ 步需要**入门阶段第 03~04 章已建好的 `orders` 表**,并且该表要有 `user_id` / `status` / `total` / `created_at` 四列。若你还没走完入门阶段,用下面的"免依赖版本"直接建一张实验表:

```sql
-- 免依赖版本:自带建表,可独立执行
CREATE TABLE IF NOT EXISTS orders (
    id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    user_id    bigint        NOT NULL,
    status     text          NOT NULL,
    total      numeric(12,2) NOT NULL,
    channel    text,
    created_at timestamptz   NOT NULL DEFAULT now()
);
-- 建好后,再执行上面第 ③④ 步即可
```
