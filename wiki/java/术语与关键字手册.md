## 二、内存与 GC

| 名词 | 一句话含义 | 详解 |
|------|-----------|------|
| **堆（Heap）** | 存放所有 `new` 出来的对象，**线程共享**，GC 主战场 | [[java/02-中段阶段-专题精讲/JVM/JVM内存区域与对象布局]] |
| **虚拟机栈** | 每线程一个，存方法调用的栈帧（局部变量、操作数栈） | 同上 |
| **栈帧（Frame）** | 一次方法调用的内存结构，方法返回即销毁 | 同上 |
| **方法区 / 元空间（Metaspace）** | 存类信息、静态变量、常量池；JDK 8 起用元空间替代永久代 | 同上 |
| **程序计数器（PC）** | 每线程一个，记录当前执行到哪条字节码 | 同上 |
| **对象头（Mark Word）** | 对象内存中的元数据：哈希码、GC 年龄、锁状态 | 同上 |
| **TLAB** | 线程本地分配缓冲，减少多线程分配对象的竞争 | 同上 |
| **逃逸分析** | 判断对象是否「逃出」方法，不逃逸可栈上分配/标量替换 | 同上 |
| **GC** | 垃圾回收：自动回收无人引用的对象 | [[java/02-中段阶段-专题精讲/JVM/垃圾回收与调优]] |
| **可达性分析** | 判活算法：从 GC Roots 出发能否走到对象 | 同上 |
| **GC Roots** | 判活起点：栈上引用、静态变量、常量、JNI 引用等 | 同上 |
| **Stop-The-World（STW）** | GC 时暂停所有业务线程——GC 调优的本质是缩短 STW | 同上 |
| **新生代 / 老年代** | 分代模型：新对象在 Eden，熬过多次 GC 进老年代 | 同上 |
| **Eden / Survivor** | 新生代的三个区域（Eden + S0 + S1），复制算法 | 同上 |
| **G1** | JDK 9+ 默认回收器，按 Region 管理堆，可预测停顿 | 同上 |
| **ZGC** | 超低停顿回收器（亚毫秒级），JDK 21+ 分代 ZGC | 同上 |
| **CMS** | 老年代并发回收器，JDK 14 移除 | 同上 |
| **强引用 / 软引用 / 弱引用 / 虚引用** | 四种引用强度，决定对象何时可被回收 | [[java/02-中段阶段-专题精讲/JVM/垃圾回收与调优]] |

| **原子性 / 可见性 / 有序性** | 并发三大问题 | 同上 |
| **`volatile`** | 保证可见性与禁止重排序；⚠️ **不保证原子性** | 同上 |
| **happens-before** | 前一个操作的结果对后一个可见的 7 条规则 | 同上 |
| **内存屏障** | 阻止编译器/CPU 重排序的硬件机制 | 同上 |
| **安全发布** | 让其他线程看到完整构造对象的方式（不可变、volatile、final） | 同上 |
| **`synchronized`** | 关键字加锁；⚠️ **锁的是对象不是代码** | [[java/02-中段阶段-专题精讲/并发编程/03-锁机制与原子操作]] |
| **锁升级** | 无锁 → 偏向 → 轻量级 → 重量级；⚠️ 偏向锁 JDK 15 起废弃 | 同上 |
| **Monitor** | `synchronized` 的底层对象，含 EntryList/Owner/WaitSet | 同上 |
| **`ReentrantLock`** | 可中断、可超时、可公平、支持多条件队列的显式锁 | 同上 |
| **`Condition`** | 与 `wait/notifyAll` 对应，支持多个条件队列 | 同上 |
| **CAS** | Compare-And-Swap，无锁并发的基础操作 | 同上 |
| **AQS** | JDK 并发同步器的抽象基类：状态量 + 等待队列 | 同上 |
| **原子类（Atomic）** | `AtomicInteger` 等，用 CAS 保证单操作原子性 | 同上 |
| **死锁（deadlock）** | 互相等待对方持有的锁；四条件 + 固定加锁顺序可避免 | 同上 |
| **`ThreadPoolExecutor`** | Java 线程池核心类，七个构造参数 | [[java/02-中段阶段-专题精讲/并发编程/04-线程池与任务调度]] |
| **阻塞队列（BlockingQueue）** | 线程池的任务缓冲；⚠️ `LinkedBlockingQueue` 默认无界会 OOM | 同上 |
| **拒绝策略（RejectedExecutionHandler）** | 池满时的处理：Abort / CallerRuns / Discard / DiscardOldest | 同上 |
| **`CompletableFuture`** | 异步编排工具；⚠️ 异步异常不会自动传播到主线程 | [[java/02-中段阶段-专题精讲/并发编程/05-并发容器与虚拟线程]] |
| **`CountDownLatch`** | 倒计数门闩，等待 N 个任务完成 | 同上 |
| **`ConcurrentHashMap`** | 并发哈希表；CAS + synchronized 锁桶头节点 | 同上 |
| **虚拟线程（virtual thread）** | Java 21+，轻量线程；⭐ 阻塞式写法 + 高并发 | 同上 |
| **载体线程（carrier thread）** | 承载虚拟线程的平台线程，数量约等于 CPU 核数 | 同上 |
| **pinning（钉住）** | 虚拟线程在 `synchronized` 内阻塞会占住载体线程；⚠️ JDK 24 的 JEP 491 修复 | 同上 |
| **Scoped Values** | Java 25 正式，替代 `ThreadLocal` 的上下文传递方案 | 同上 |
