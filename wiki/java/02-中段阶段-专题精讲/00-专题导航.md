## 中段阶段的五条通用原则

1. **⚠️ 先看现象再看原理。** JVM 问题先用工具拿到数据（`jstat`/`jstack`/GC 日志），别凭经验猜；
2. **⚠️ 堆不是唯一会 OOM 的地方。** 元空间、直接内存、线程栈都会 OOM，别只盯 `-Xmx`；
3. **⚠️ `@Transactional` 不是万能开关。** 同类内部调用、非 public 方法、异常被吞——三种情况事务都会静默失效；
4. **⚠️ 自动配置是「约定优于配置」，不是魔法。** 出问题时先看「为什么这个 Bean 被装配了」，而不是怀疑框架；
5. **⚠️ 版本兼容是硬约束。** Spring Boot 4.1 不支持 Java 27（见 [[java/README]] 版本基线）——升级前先查支持矩阵。

## 并发专题的额外纪律

6. **⚠️ 生产代码不手写 `new Thread`，也不直接用 `Executors` 工厂方法。** 前者无治理，后者用无界队列会 OOM——必须显式 `new ThreadPoolExecutor(...)`（见 [[java/02-中段阶段-专题精讲/并发编程/04-线程池与任务调度]]）；
7. **⚠️ 虚拟线程不是「更快的线程」。** 它是「阻塞式写法 + 高并发」，CPU 密集任务仍要平台线程，且不能池化（见 [[java/02-中段阶段-专题精讲/并发编程/05-并发容器与虚拟线程]]）。
