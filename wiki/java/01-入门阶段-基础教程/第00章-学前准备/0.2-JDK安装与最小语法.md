# JDK 安装与最小语法

> **什么时候该读**：要动手跑第一个 Java 程序；或者需要一份「够用就行」的语法速览。

## 学习目标

读完本篇，你应当能够：

1. 在本机装好 JDK 25 并验证
2. 用 `javac` + `java` 跑通第一个程序
3. 掌握写业务代码所需的**最小语法集**（类型、类、方法、集合、异常）
4. 用 Maven 建一个可打包的项目骨架

## 一、安装 JDK 25

### 方式一：包管理器（Linux，最省事）

```bash
sudo apt update
sudo apt install -y openjdk-25-jdk
java -version
# openjdk version "25.x.x" ...
```

### 方式二：跨平台发行版（Windows/macOS）

推荐 **Eclipse Temurin**（Adoptium 的 OpenJDK 构建，免费、无许可问题）：

1. 下载 JDK 25 的安装包（Windows `.msi` / macOS `.pkg`）；
2. 安装时勾选「设置 JAVA_HOME」；
3. 验证：

```bash
java -version
javac -version
```

⚠️ **两个常见问题**：

- `java` 能跑但 `javac` 找不到 → 装的是 JRE 不是 JDK，重装 JDK；
- 同时装了多个版本 → 用 `JAVA_HOME` 决定用哪个；Linux/macOS 上 `which java` 看实际路径。

## 二、第一个程序

### 目录与文件

```text
hello/
└── Hello.java      ← ⚠️ 文件名必须与类名完全一致（含大小写）
```

### 代码

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java 25");
    }
}
```

### 编译与运行

```bash
javac Hello.java     # 生成 Hello.class
java Hello           # 运行（⚠️ 不要写 Hello.class）
```

⭐ **`public static void main(String[] args)` 逐词拆解**（这是 Java 唯一的程序入口签名）：

| 部分 | 含义 |
|------|------|
| `public` | 公开，JVM 才能调用 |
| `static` | 静态，不需要 new 对象就能调用 |
| `void` | 无返回值 |
| `main` | 固定的方法名 |
| `String[] args` | 命令行参数数组 |

## 三、最小语法集（够写业务）

### 变量与基本类型

```java
int age = 25;                    // 整数（4 字节）
long id = 9000000000L;           // 长整数（8 字节，字面量要加 L）
double price = 19.99;            // 双精度浮点
boolean ok = true;               // 布尔
char grade = 'A';                // 单字符（单引号）
String name = "张三";             // 字符串（⚠️ 引用类型，双引号）
var count = 10;                  // Java 10+ 局部类型推断，等价 int count = 10;
```

⚠️ **`String` 不是基本类型**——它是类，所以有方法、可以为 `null`。

### 条件与循环

```java
if (age >= 18 && ok) {
    System.out.println("成年");
} else if (age > 0) {
    System.out.println("未成年");
}

for (int i = 0; i < 3; i++) {
    System.out.println(i);
}

// 增强 for（类似 Python 的 for x in list）
int[] nums = {1, 2, 3};
for (int n : nums) {
    System.out.println(n);
}
```

### 集合（对标 Python 的 list / dict）

```java
import java.util.*;

List<String> names = new ArrayList<>();      // 类似 list，可变
names.add("张三");
names.add("李四");
String first = names.get(0);                 // ⚠️ 是 get(0) 不是 names[0]

Map<String, Integer> scores = new HashMap<>();   // 类似 dict
scores.put("张三", 90);
int s = scores.getOrDefault("李四", 0);

// 遍历 Map
for (Map.Entry<String, Integer> e : scores.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}
```

### 方法与类

```java
public class Calculator {
    // 实例方法
    public int add(int a, int b) {
        return a + b;
    }

    // 静态方法（不需要 new）
    public static int mul(int a, int b) {
        return a * b;
    }
}

// 使用
Calculator c = new Calculator();
int x = c.add(1, 2);
int y = Calculator.mul(3, 4);
```

### 构造器与封装

```java
public class User {
    private String name;      // private：只能类内部访问
    private int age;

    public User(String name, int age) {   // 构造器：与类同名、无返回值
        this.name = name;                 // this 指当前对象
        this.age = age;
    }

    public String getName() { return name; }   // getter
    public void setName(String name) { this.name = name; }  // setter
}
```

### 异常处理

```java
try {
    int r = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("除零：" + e.getMessage());
} finally {
    System.out.println("无论如何都执行");
}
```

⚠️ **Java 有「受检异常」概念**（必须在方法签名声明或 catch），Python 没有——详见 [[java/01-入门阶段-基础教程/第00章-学前准备/0.3-Java与Python的差异]]。

## 四、用 Maven 建项目（从单文件到工程）

单文件 `javac` 只适合练手。真实项目用 **Maven**：

```text
demo/
├── pom.xml
└── src/main/java/com/example/App.java
```

`pom.xml` 最小骨架：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0">
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.example</groupId>
  <artifactId>demo</artifactId>
  <version>1.0.0</version>

  <properties>
    <maven.compiler.release>25</maven.compiler.release>
  </properties>
</project>
```

三条常用命令：

```bash
mvn compile        # 编译
mvn package        # 打包成 target/demo-1.0.0.jar
mvn spring-boot:run  # 有 Spring Boot 插件时直接运行
```

⭐ Maven 的 `pom.xml` 对标 Python 的 `pyproject.toml` + `requirements.txt`；`~/.m2/repository` 对标 pip 的缓存。

## 五、陷阱

1. **⚠️ 文件名与 public 类名不一致**——必须完全相同（含大小写），否则编译报错；
2. **⚠️ `java Hello.class`**——运行时只写类名 `java Hello`；
3. **⚠️ 字符串用 `==` 比较**——`==` 比的是引用地址，比内容必须用 `equals()`（详见下一篇）；
4. **⚠️ `int` 溢出**——`int` 最大约 21 亿，涉及金额/ID 用 `long` 或 `BigDecimal`（金额绝不用 `double`）；
5. **⚠️ 数组越界**——Java 不会像 Python 那样支持负索引，`arr[arr.length-1]` 才是最后一个。

## 小结

- 装 **JDK 25**（不是 JRE），`javac` 编译、`java` 运行
- 入口必须是 `public static void main(String[] args)`
- 最小语法集：基本类型 + `String` + `if/for` + `List/Map` + 类与构造器 + `try-catch`
- 工程化用 **Maven**（`pom.xml` + `mvn package`）
- 五个高频坑：文件名、`java` 不带后缀、`equals`、`int` 溢出、数组下标

## 练习

1. 写一个 `Hello.java`，编译运行成功；再故意把类名改成 `hello`，观察报错。
2. 用 `List` 和 `Map` 实现「统计一组名字出现次数」，对照 Python 的 `Counter`。
3. 写一个 `User` 类（name/age + 构造器 + getter），在 `main` 里创建两个对象打印。
4. 用 Maven 建一个项目，`mvn package` 产出 jar 并运行。
