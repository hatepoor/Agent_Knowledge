# 运算符与流程控制

> **什么时候该读**：想把 Python 里的 `if/elif/for` 翻译成 Java，或者被 `switch` 的「不贯穿」和 `&&` 的短路绕晕。

## 学习目标

读完本篇，你应当能够：

6. 写出 `switch` 的三种形态：传统带 `break`、`switch` 表达式 + `yield`（Java 14+）、模式匹配 `switch`（Java 21+）
7. 选择合适的循环，并解释增强 `for` 遍历集合时底层发生了什么

## 一、算术运算符

Java 的算术运算符分两类：**整数运算**和**浮点运算**。两边都有 `+ - * /`，整数独有 `%`（取余）。

| 运算符 | 名称 | 例子 | 结果 |
|--------|------|------|------|
| `+` | 加 | `10 + 3` | `13` |
| `-` | 减 | `10 - 3` | `7` |
| `*` | 乘 | `10 * 3` | `30` |
| `/` | 除 | `10 / 3` | `3`（整数除法，**小数部分直接丢弃**） |
| `%` | 取余（求模） | `10 % 3` | `1` |

### 1.1 整数除法会截断

```java
int a = 10 / 3;      // 3
int b = 10.0 / 3;    // ⚠️ 3.333...（10.0 是 double，整体走浮点运算）
double c = 10 / 3;   // ⚠️ 也是 3.333...！先算 int 除法再赋给 double 已经晚了
double d = (double) 10 / 3;  // ✅ 3.333...  先强转再除
```

⭐ **记住**：整数除法先算完再赋值，`double` 只在**左边**不起作用。要么把其中一个操作数变成浮点数，要么显式强转。

### 1.2 取余的负数行为 ⚠️

Java 的 `%`（以及 Python 的 `%`）**结果符号跟被除数走，不跟除数走**：

```java
System.out.println(7 % 3);    //  1
System.out.println(-7 % 3);   // -1  ⚠️ 不是 2
System.out.println(7 % -3);   //  1  ⚠️ 不是 -2
System.out.println(-7 % -3);  // -1
```

规则：`a % b` 的结果 = `a - b * (a / b 的整数商)`，符号取自 `a`。

⚠️ **这不是 Python 的行为**——Python 的 `%` 在结果非零时**保证为正**：

```python
-7 % 3    # 2   ← Python
-7 % 3    # -1  ← Java
```

```java
// Java 里想要 Python 那种「非负余数」：
int mod = ((x % m) + m) % m;
```

这条差异在「分页取模」「环形索引」这类场景里经常被忽略。

### 1.3 自增自减：前置与后置

`++`（自增）和 `--`（自减）让变量加/减 1。区别只在**这个表达式本身的值**：

| 写法 | 含义 | 表达式结果 |
|------|------|-----------|
| `++i`（前置） | 先加 1，**再**用新值 | 加 1 后的值 |
| `i++`（后置） | **先用**旧值，**再**加 1 | 加 1 前的值 |

```java
int i = 5;
int a = i++;      // a = 5（用旧值），然后 i 变成 6
int j = 5;
int b = ++j;      // b = 6（先用新值），j 也是 6
```

⚠️ **两条硬规则**：

1. **同一条语句里对同一个变量自增两次，结果是「未定义行为」**（不同编译器/版本可能给出不同结果），不要写：

```java
int i = 1;
int r = i++ + ++i;   // ❌ 千万别这么写，不同 JDK 结果可能不同
```

2. **单独一行时，前置和后置完全等价**——所以循环里写 `i++` 或 `++i` 性能一样（现代 JIT 会优化掉），风格问题而已。

### 1.4 复合赋值

`+=` `-=` `*=` `/=` `%=` 以及位运算的 `&=` `|=` `^=` `<<=` `>>=` `>>>=`，等价于「算完再赋回同一个变量」。

```java
int x = 10;
x += 5;      // 等价 x = x + 5;
x *= 2;      // 等价 x = x * 2;
```

⚠️ **复合赋值自带一次隐式强转**，`byte` 就有意思了：

```java
byte b = 10;
b += 1;      // ✅ 合法！等价于 b = (byte)(b + 1)，编译器帮你强转了
b = b + 1;   // ❌ 编译报错：b + 1 是 int，不能赋给 byte
```

## 二、比较运算符与 `==` 的两副面孔

| 运算符 | 含义 |
|--------|------|
| `>` `<` `>=` `<=` | 大小比较，产出 `boolean` |
| `==` | **等于** |
| `!=` | **不等于** |

⚠️ **`==` 的语义取决于两边是什么类型**：

| 比较对象 | `==` 比较的是什么 | 例子 |
|---------|----------------|------|
| **两个基本类型** | **数值** | `int a = 5; a == 5;` → `true` |
| **两个引用类型** | **是否为同一个对象（地址）** | `new String("a") == new String("a")` → `false` |
| 一个基本 + 一个包装 | 拆箱后比数值 | `Integer.valueOf(1) == 1` → `true` |

```java
int a = 5, b = 5;
System.out.println(a == b);            // true  ← 比数值

String s1 = new String("hi");
String s2 = new String("hi");
System.out.println(s1 == s2);          // false ⚠️ 两个不同对象
System.out.println(s1.equals(s2));     // true  ✅ 比内容
```

⭐ **字符串的 `==` 与 `equals` 详见 [[java/01-入门阶段-基础教程/第01章-核心语法/1.4-字符串与包装类]]**——这是 Java 面试第一高频题。

## 三、逻辑运算符与短路求值

| 运算符 | 名称 | 含义 |
|--------|------|------|
| `&&` | 与（AND） | 两边都为 `true` 才为 `true` |
| `\|\|` | 或（OR） | 有一边为 `true` 就为 `true` |
| `!` | 非（NOT） | 取反 |

⚠️ Java 的 `&&` / `||` **两边必须是 `boolean`**，不能像 C 那样对整数用；`&` 和 `|` 才是位运算（见第四节）。

### 3.1 短路求值（short-circuit evaluation）

**短路求值**指的是：左边已经能决定结果时，**右边根本不会执行**。

```text
a && b
   │
   ├─ a 为 false → 直接返回 false，b 根本不求值  ✅ 短路
   └─ a 为 true  → 才去求值 b

a || b
   │
   ├─ a 为 true  → 直接返回 true，b 根本不求值  ✅ 短路
   └─ a 为 false → 才去求值 b
```

**这个特性是刚需**，因为它让「先判空再取值」变得安全：

```java
String s = null;
if (s != null && s.length() > 0) {   // ✅ 短路：s 为 null 时不会调 length()
    System.out.println("非空");
}

if (s != null && s.length() > 0) { ... }
if (s.length() > 0 && s != null) { ... }   // ❌ 顺序反了：先调 length() → NPE
```

⚠️ **和 Python 的差异**：Python 的 `and` / `or` **也是短路的**（这点常被误解）——`x is not None and len(x) > 0` 同样安全。真正的区别有两处：

| | Java | Python |
|---|------|--------|
| 运算符 | `&&` `\|\|`（只接受 boolean） | `and` `or`（接受任意值，返回其中一个操作数） |
| 短路 | ✅ 短路 | ✅ 也短路 |
| `x or y` 的返回 | 只能是 `true`/`false` | 返回**实际的操作数**（如 `0 or "a"` → `"a"`） |
| 位运算的 `&` `\|` | 对 boolean 用就是逻辑运算，**不短路** | 同样不短路 |

⚠️ **别把 Python 的 `&`/`|` 搬过来当 `&&`/`||`**：Python 里 `a & b` 永远两边都算；Java 里 `boolean a = x != null & x.isEmpty();` 也永远两边都算，`x` 为 null 时直接 NPE。

```java
boolean ok = s != null && !s.isEmpty();   // ✅ 用 &&，短路
boolean bad = s != null & !s.isEmpty();    // ❌ 用 &，不短路，s 为 null 时炸
```

## 四、位运算符

**位运算**直接对二进制位做操作，主要用在标志位（flag）、掩码、权限、状态压缩上。

| 运算符 | 名称 | 语义 |
|--------|------|------|
| `&` | 与（AND） | 位都为 1 才为 1 |
| `\|` | 或（OR） | 有一位为 1 就为 1 |
| `^` | 异或（XOR） | **两位不同**才为 1 |
| `~` | 取反（NOT） | 每位翻转 |
| `<<` | 左移 | 整体左移，右侧补 0 |
| `>>` | **算术**右移 | 整体右移，左侧**补符号位**（负数补 1） |
| `>>>` | **逻辑**右移 | 整体右移，左侧**补 0** |

### 4.1 补码：理解负数的前提

Java 的整数用**补码（two's complement）** 表示：正数照常，负数取反加一。

以 8 位为例：

```text
 5  = 0000 0101
-5  = 1111 1011      ← 5 取反得 1111 1010，再 +1
```

补码让**加减法可以用同一套电路完成**，也让 `~x` 有一条极好用的性质：

```java
~x == -x - 1     // 对任何 int 都成立
```

所以 `~5 == -6`，`~(-5) == 4`。

### 4.2 标志位的经典用法

```java
final int FLAG_READ  = 1 << 0;   // 0001
final int FLAG_WRITE = 1 << 1;   // 0010
final int FLAG_EXEC  = 1 << 2;   // 0100

int perm = FLAG_READ | FLAG_WRITE;   // 0011 —— 组合权限
perm = perm & ~FLAG_WRITE;           // 0010 —— 去掉写权限
perm = perm | FLAG_EXEC;             // 0110 —— 加执行权限
boolean canWrite = (perm & FLAG_WRITE) != 0;   // 判断某位
```

⭐ `1 << n` 就是「第 n 位的标志」，`&` 做检测、`|` 做置位、`& ~` 做清除——这套写法在任何语言里都一样。

### 4.3 `>>` 与 `>>>` 的区别

只有**负数**上才有区别，因为正数右移时补 0 补 1 一样：

```java
int n = -8;
System.out.println(n >> 1);    // -4  算术右移：左侧补符号位 1
System.out.println(n >>> 1);   // 2147483644  逻辑右移：左侧补 0
```

```text
-8 的 32 位补码：1111 1111 1111 1111 1111 1111 1111 1000

n >> 1  → 1111 1111 1111 1111 1111 1111 1111 1100  = -4
n >>> 1 → 0111 1111 1111 1111 1111 1111 1111 1100  = 2147483644
```

⚠️ **移位次数会取模**：`int` 的移位量按 `n & 0x1F`（即 32 取模）处理，`long` 按 64 取模。所以 `1 << 32` 对 `int` 来说等于 `1 << 0`，结果是 1 而不是 4294967296。

## 五、三元运算符

**三元运算符（ternary operator）** 是 `?:`，一个内联的「if-else 赋值」：

```java
int max = (a > b) ? a : b;
String label = (score >= 60) ? "及格" : "不及格";
```

语法：`条件 ? 表达式1 : 表达式2` —— 条件为 `true` 取前者，为 `false` 取后者。

- 三个部分都能是表达式，不只是变量；
- **整个表达式的类型由「两个分支中类型更宽的那个」决定**（如果一个是 `int` 一个是 `long`，结果是 `long`）；
- 只会求值**其中一个**分支（天然短路）。

⚠️ 别把它写成嵌套金字塔——超过两层就该换成 `if-else if` 或提前 `return`。

## 六、条件分支

### 6.1 if / else if / else

```java
if (age >= 18) {
    System.out.println("成年");
} else if (age >= 14) {
    System.out.println("青少年");
} else if (age > 0) {
    System.out.println("儿童");
} else {
    System.out.println("未出生");
}
```

条件必须是 `boolean`（不能写 `if (age)`）。

⚠️ **「else if」其实不是新关键字**，它就是「else 里面嵌了一个 if」——所以每个分支只会命中一个，天然互斥。

### 6.2 switch：三种形态

#### 形态一：传统 switch（务必写 `break`）

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("周一");
        break;              // ⚠️ 没有 break 会继续往下「贯穿」
    case 2:
        System.out.println("周二");
        break;
    case 3:
        System.out.println("周三");
        break;
    default:
        System.out.println("其他");
}
```

⭐ **Java 的 `switch` 不会自动贯穿（fall-through）**。不加 `break` 会**继续执行下一个 case 的代码**，这是 Java 与 C 的最大行为差异：

```java
int x = 1;
switch (x) {
    case 1:
        System.out.println("一");     // 打印
    case 2:
        System.out.println("二");     // ⚠️ 也会打印！贯穿了
        break;
}
// 输出：一 / 二
```

⚠️ Python 也没有贯穿（Python 的 `match/case` 天然互斥），所以这条**不是**「Python 会贯穿 Java 不会」的反向差异，而是**Java 与 C 的差异**——从 C 过来的人最容易踩。

`switch` 可以用于：`int`、`short`、`byte`、`char`、`enum`（枚举）、`String`（Java 7+）、以及包装类。

```java
String s = "b";
switch (s) {                     // Java 7+ 支持 String
    case "a":
        System.out.println("A");
        break;
    case "b":
        System.out.println("B");
        break;
    default:
        System.out.println("其他");
}
```

#### 形态二：switch 表达式 + `yield`（Java 14+）

Java 14 把 `switch` 升级成**表达式**——可以直接产生一个值，并且**用箭头语法 `->` 天然不贯穿、不需要 `break`**：

```java
int day = 3;
String name = switch (day) {
    case 1, 2 -> "工作日开头";       // 多个值用逗号合并（Java 14 起支持）
    case 3 -> "周三";
    case 6, 7 -> "周末";
    default -> "其他";
};
System.out.println(name);   // 周三
```

需要多条语句时用 `yield`：

```java
int score = 85;
String grade = switch (score / 10) {
    case 10, 9 -> "A";
    case 8, 7 -> "B";
    case 6 -> "C";
    default -> {
        if (score >= 60) {
            yield "及格";       // yield 的值就是整个表达式的值
        }
        yield "不及格";
    }
};
```

⭐ **`switch` 表达式的优点**：

1. 箭头语法**不贯穿**，不用写 `break`；
2. **编译器要求所有分支都有结果**——漏了 `default` 或某条路径没返回值，**编译期就报错**，不会出现「运行到某个分支没赋值」；
3. 可以直接作为参数、`return` 值、赋值右值。

⚠️ **冒号写法也能用在 `switch` 表达式里**，但要配 `yield` 而不是 `break`，且**不写 `break` 就会贯穿**：

```java
String grade = switch (score / 10) {
    case 10, 9:
        yield "A";     // ⚠️ 这里是 yield，不是 break
    case 8, 7:
        yield "B";
    default:
        yield "C";
};
```

⭐ **新代码一律用箭头语法 `->`**——它天生不贯穿，出错的可能性更低。

#### 形态三：模式匹配 switch（Java 21+）

Java 21 把 `switch` 的分支条件从「常量值」升级为「**类型模式（type pattern）**」：

```java
static String describe(Object o) {
    return switch (o) {
        case Integer i -> "整型 " + i;         // i 在这个分支里已经定型为 Integer
        case String s  -> "字符串 " + s;
        case int[] arr -> "整型数组，长度 " + arr.length;   // Java 21+
        case null      -> "null";               // 显式处理 null
        default        -> "其他类型";
    };
}
```

⭐ **和 `sealed`（密封类/接口，Java 17+）配合是杀手锏**：编译器能穷举所有子类型，**漏写某个分支会直接编译报错**，不再需要 `default`：
```java
// Java 17+ sealed 接口，Java 21+ 模式匹配 switch
// record（Java 16+）是「不可变数据载体」的简写语法，这里只当作普通类用
sealed interface Shape permits Circle, Square {}
record Circle(double r) implements Shape {}
record Square(double s) implements Shape {}

static double area(Shape shape) {
    return switch (shape) {
        case Circle c -> Math.PI * c.r() * c.r();
        case Square s -> s.s() * s.s();
        // ⚠️ 不写 default：编译器知道 Shape 只有这两种实现，穷举了
    };
}
```

`sealed` 与模式匹配的细节属于第 02 章的内容，本篇只需知道「**编译器帮你检查分支是否穷尽**」这件事。

## 七、三种循环

### 7.1 for：计数循环

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

三个部分用分号隔开：初始化 → 条件 → 更新。三个都可以省略（但分号不能少）。

**增强 for（for-each）** 遍历数组或集合：

```java
String[] names = {"张三", "李四"};
for (String n : names) {
    System.out.println(n);
}
```

### 7.2 while：条件循环

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

### 7.3 do-while：先执行再判断（至少执行一次）

```java
int i = 0;
do {
    System.out.println(i);   // 至少会执行一次
    i++;
} while (i < 5);
```

```text
for / while：先判断 → 再执行（可能 0 次）
do-while：先执行 → 再判断（至少 1 次）
```

⭐ **不要用 `do-while` 实现菜单循环**——用户输错一次就会退出循环，很反直觉。

### 7.4 增强 for 遍历集合时底层是迭代器

这是本节最值得记住的机制：

```java
import java.util.*;   // List / ArrayList / Map / Iterator 都在 java.util 包

List<String> list = new ArrayList<>(List.of("a", "b", "c"));
for (String s : list) {
    System.out.println(s);
}
```

等价于（编译器帮你展开成）：

```java
Iterator<String> it = list.iterator();   // 迭代器：逐个取元素的老式写法
while (it.hasNext()) {                   // 还有下一个吗
    String s = it.next();                // 取下一个
    System.out.println(s);
}
```

⭐ **三个后果**：

1. **迭代器是「fail-fast」的**：遍历过程中如果集合结构被修改（增删元素），会抛 `ConcurrentModificationException`（并发修改异常，一种 `RuntimeException`，表示「你一边遍历一边改集合」）——这是 Java 集合最经典的坑之一，详见 [[java/01-入门阶段-基础教程/第04章-集合框架/4.2-List集合详解]]；
2. **增强 for 不能直接删元素**：`for (String s : list) { list.remove(s); }` 会抛异常或行为异常，要删必须用 `list.removeIf(...)` 或显式 `Iterator.remove()`；
3. 遍历 `Map` 不能直接用增强 for（`Map` 不是 `Collection`），要用 `for (Map.Entry<K,V> e : map.entrySet())`——`Map.Entry` 是 `Map` 里的一个「键值对」嵌套接口，`entrySet()` 返回所有键值对的集合（详见第 04 章）。

## 八、break、continue 与标签

| 关键字 | 作用 |
|--------|------|
| `break` | 立刻跳出**当前**循环（或 `switch`） |
| `continue` | 立刻开始**下一轮**循环（跳过本次剩余代码） |
| `label: ` | 给循环或 `switch` 起个名字，配合 `break label` / `continue label` |

### 8.1 跳出双层循环：标签

普通 `break` 只能跳一层。Python 里用「标志位变量」，Java 用**标签（label）**更直接：

```java
// 找出二维数组里的目标值，用标签一次跳出双层循环
int[][] grid = {{1, 2}, {3, 4}};
int target = 4;

outer:
for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        if (grid[i][j] == target) {
            System.out.println("找到于 " + i + "," + j);
            break outer;          // ⚠️ break + 标签名：跳出被标记的那层循环
        }
    }
}
```

```java
// continue label：跳到被标记循环的下一轮（不是下一层循环）
int[][] matrix = {{1, 0, 2}, {3, 0, 4}};

outer:
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        if (matrix[i][j] == 0) {
            continue outer;       // 本行剩余的 j 循环全部跳过，i 进入下一轮
        }
    }
}
```

⚠️ 标签只能贴在**循环或 `switch`** 前面，不能贴在普通语句上。

## 九、与 Python 的对照

| 场景 | Python | Java |
|------|--------|------|
| 条件分支 | `if / elif / else` | `if / else if / else` |
| 计数循环 | `for i in range(5)` | `for (int i = 0; i < 5; i++)` |
| 遍历集合 | `for x in lst` | `for (String x : lst)` |
| 条件循环 | `while cond:` | `while (cond) { }` |
| 至少执行一次 | `while True: ... break` | `do { } while (cond);` |
| 三元 | `a if cond else b` | `cond ? a : b` |
| 逻辑与/或 | `and` / `or`（短路） | `&&` / `\|\|`（短路） |
| 逻辑非 | `not x` | `!x` |
| 整除 | `//` | `/`（两边都是整数时） |
| 取模（负数） | 结果非负（`-7 % 3 == 2`） | **结果跟被除数走**（`-7 % 3 == -1`） |
| 真假字面量 | `True` / `False` | `true` / `false` |
| 多分支匹配 | `match/case`（Python 3.10+） | `switch`（Java 14+ 表达式 / 21+ 模式匹配） |
| 跳出双层循环 | 标志位 / 函数返回 | 标签 `break outer;` |

⚠️ **取模负数行为是这两张表里唯一「静默出错」的差异**——它不报错，编译能过，结果却不同。分页、环形索引、hash 分桶的代码都要留意。

## 陷阱

1. **⚠️ 整数除法先算后转**——`double d = 10 / 3;` 的结果是 `3.0` 不是 `3.333...`，要写成 `(double) 10 / 3`；
2. **⚠️ 取余符号跟被除数**——`-7 % 3 == -1`（Java），而 Python 是 `2`；做环形索引时记得 `((x % m) + m) % m`；
3. **⚠️ 同一条语句里对同一变量自增两次**——`i++ + ++i` 是未定义行为，不同 JDK 结果可能不同；
4. **⚠️ `switch` 不写 `break` 会贯穿**——Java 不像 C 那样自动贯穿，从 C 转过来的人常踩；建议一律用箭头语法 `->`；
5. **⚠️ `switch` 表达式的分支必须都有结果**——漏写 `default` 或有路径不赋值会编译报错（这是好事，别用 `yield` 硬绕）；
6. **⚠️ 用 `&` / `|` 代替 `&&` / `||`**——位运算**不短路**，`s != null & !s.isEmpty()` 在 `s` 为 null 时直接 NPE；
7. **⚠️ 以为 Python 的 `and`/`or` 不短路**——它们**是**短路的；不短路的是 Python 的 `&`/`|`，而这恰恰是 Java 里最容易误用的；
8. **⚠️ 引用类型用 `==` 比较内容**——`new String("a") == new String("a")` 是 `false`，必须用 `.equals()`；
9. **⚠️ 增强 for 遍历时修改集合**——会抛 `ConcurrentModificationException`，删除要用 `removeIf()`；
10. **⚠️ `>>` 和 `>>>` 混用**——对负数右移，前者补 1（保留符号），后者补 0（结果变成大正数）；
11. **⚠️ 移位次数取模**——`1 << 32` 对 `int` 等于 `1 << 0`；
12. **⚠️ 用 `do-while` 做菜单**——用户输错一次就退出循环了。

## 小结

- 算术：`/` 整数除法会截断，`%` 结果符号跟**被除数**（与 Python 不同）
- `++` 前置后置只影响**表达式本身的值**；单独一行时等价；一行内自增两次是未定义行为
- `+=` 自带隐式强转（`byte` 上 `b += 1` 合法，`b = b + 1` 报错）
- `==`：基本类型比数值，引用类型比地址
- `&&` / `||` **短路**——`s != null && s.length() > 0` 是刚需写法；`&` / `|` 不短路
- 位运算：补码表示负数，`~x == -x - 1`；`>>` 补符号位、`>>>` 补 0
- `switch`：传统写法**必须 `break`**（Java 不自动贯穿）；`switch` 表达式（Java 14+）用 `->` + `yield`；模式匹配 `switch`（Java 21+）配合 `sealed`（Java 17+）可让编译器检查穷尽
- 三种循环：`for` / `while` / `do-while`（至少执行一次）；增强 for 底层是**迭代器**
- `break` / `continue` 只影响一层，跨层用**标签**
