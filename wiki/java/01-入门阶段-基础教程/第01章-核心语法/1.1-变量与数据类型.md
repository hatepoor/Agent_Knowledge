# 变量与数据类型

> **什么时候该读**：刚开始写 Java，第一行代码就要求你声明类型；或者从 Python 过来，被「为什么要写 `int`」问住。
> **阅读门槛**：能跑通一个 `Hello.java`（见 [[java/01-入门阶段-基础教程/第00章-学前准备/0.2-JDK安装与最小语法]]）；看得懂 `int age = 25;` 这一行即可。

## 学习目标

读完本篇，你应当能够：

1. 说清局部变量、成员变量、静态变量的区别与各自的作用域
2. 背出 8 种基本类型的字节数、取值范围、默认值，并知道为什么 `char` 没有负数
3. 正确书写整数、小数、字符、布尔、`null` 五类字面量，包括 `L` / `f` / `_` / `0x` / `\u` 这些后缀与前缀
4. 判断一次赋值会不会编译报错（隐式转换的允许方向）
5. 手写一次窄化转换，并判断有没有发生精度丢失
6. 说清 `final` 的三种用法，以及 `final int MAX = 127;` 为什么能当 `case` 标签用
7. 在合适的地方用 `var`，并能说出它的四条限制

## 一、变量：Java 里存东西的三种位置

**变量（variable）** 是给一块内存起的名字，用来存数据。Java 中有三种变量，它们的存放位置和生命周期完全不同。

| 类别 | 也叫 | 声明位置 | 生命周期 | 有默认值吗 |
|------|------|---------|---------|-----------|
| **局部变量** | — | 方法体、构造器体、代码块内 | 方法每次被调用时创建，方法结束即销毁 | ❌ 没有，必须先赋值再用 |
| **成员变量**（实例变量 / 字段） | field | 类体内、方法体外 | 跟随**每一个对象**，对象创建时分配 | ✅ 有（见下表） |
| **静态变量**（类变量） | static field | 类体内、方法体外、且带 `static` | 跟随**类**，全类共享一份 | ✅ 有 |

```java
public class VarScopeDemo {
    // 成员变量：每个对象各有一份。⚠️ 有默认值，int 默认 0、String 默认 null
    private int count = 0;
    private String name;

    // 静态变量：整个类共享一份，改一次全体可见
    static int instanceCount = 0;

    public static void main(String[] args) {
        // 局部变量：写在方法里，必须初始化
        int age = 25;
        System.out.println(age);          // 25

        // ⚠️ 局部变量未初始化就用 → 编译报错
        // int price;
        // System.out.println(price);    // error: variable price might not have been initialized

        // ⚠️ 成员变量可以先不赋值，直接读（读到的默认值）
        VarScopeDemo d = new VarScopeDemo();
        System.out.println(d.count);      // 0
        System.out.println(d.name);       // null

        instanceCount++;
        System.out.println(instanceCount); // 1
    }
}
```

### 作用域：变量能活到哪一行

**作用域（scope）** 指一个变量在代码中可以被引用到的范围。规则很简单：

```text
方法体 {                        ← 局部变量的作用域从这里开始
    int a = 1;                  ← a 从这一行开始可见
    if (true) {
        int b = 2;              ← b 只在 if 块内可见
        System.out.println(a);  // ✅ 可以看到外层的 a
    }
    // System.out.println(b);   // ❌ 出了块就没了，编译报错
}
```

⭐ **成员变量和静态变量的作用域是整个类**（只要能访问到这个类或对象，就能访问它的成员变量）；**局部变量的作用域是它所在的那对 `{}`**。

### 命名规范

Java 变量名由字母、数字、下划线 `_`、美元符号 `$` 组成，**不能以数字开头，不能是关键字**。

| 类别 | 规范 | 示例 |
|------|------|------|
| 局部变量 | 小驼峰（lowerCamelCase） | `userName`、`totalPrice` |
| 成员变量 | 小驼峰 | `maxRetry` |
| 静态变量 | **全大写 + 下划线** | `MAX_RETRY_COUNT`、`DEFAULT_TIMEOUT` |
| 常量（`static final`） | **全大写 + 下划线** | `PI`、`MAX_SIZE` |
| 类名 | 大驼峰（UpperCamelCase） | `UserService`、`OrderItem` |

⚠️ `$` 合法但不建议使用——它和自动生成的内部类名（如 `Outer$Inner`）撞车。

## 二、8 种基本类型

**基本类型（primitive type）** 是 Java 内置的、最基础的 8 种数据类型。它们**不是对象**，变量里直接存值，不占堆空间，没有方法。

| 类型 | 字节数 | 取值范围 | 默认值 | 大类 |
|------|-------|---------|-------|------|
| `byte` | 1 | -128 ~ 127 | `0` | 整数型 |
| `short` | 2 | -32,768 ~ 32,767 | `0` | 整数型 |
| `int` | 4 | -2,147,483,648 ~ 2,147,483,647 | `0` | 整数型 |
| `long` | 8 | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 | `0` | 整数型 |
| `float` | 4 | 约 ±3.4×10³⁸（单精度，含小数位约 7 位） | `0.0f` | 浮点型 |
| `double` | 8 | 约 ±1.7×10³⁰⁸（双精度，含小数位约 15–16 位） | `0.0d` | 浮点型 |
| `char` | 2 | 0 ~ 65,535（**无符号**） | `'\u0000'` | 字符型 |
| `boolean` | 1（实际占 1 字节） | 只有 `true` / `false` | `false` | 布尔型 |

### 逐个要点

- **整数默认是 `int`**。写 `long id = 9000000000;` 会报错（这个数超出 `int` 范围），必须写 `9000000000L`。超过 `long` 范围（1.8×10¹⁹）的字面量**连 `long` 都放不下**，必须用 `BigInteger`（`java.math` 包里的任意精度整数类，详见 [[java/01-入门阶段-基础教程/第01章-核心语法/1.4-字符串与包装类]] 的金额精度话题）。
- **`char` 是无符号的**，所以它的范围是 `0 ~ 65535`，没有负数。原因见「char 与 int 的关系」一节。
- **`double` 是小数默认类型**。`double d = 1;` 合法（整数字面量可以直接赋给 `double`），但 `float f = 1;` **报错**——必须写 `1f` 或 `1.0f`。
- **`float` 精度只有约 7 位十进制有效数字**，算钱、算科学数据基本不能用；小数一律用 `double`。
- **`boolean` 不能参与算术**。`int + boolean` 是编译错误；C/C++ 里 `true` 是 1，Java 里不是。
- **`char` 存的是 UTF-16 编码单元**，不是「一个字符」。一个汉字占 1 个 `char`，但一个 emoji（多数）占 2 个 `char`。

### 记忆口诀

```text
整型四兄弟：byte(1) short(2) int(4) long(8)
浮点两兄弟：float(4) double(8)
其他两兄弟：char(2)  boolean(1)
```

⭐ **Java 只有 8 种基本类型，没有 `unsigned`（无符号整型）**。想要无符号语义，只能自己用 `long`/`int` 组合运算来模拟，或用 `Integer.toUnsignedLong()` 这类 API。

## 三、字面量：给数据写的「源码里的写法」

**字面量（literal）** 指直接写在源码里的数据值本身。比如 `25`、`3.14`、`'A'`、`true`、`"hi"`、`null` 都是字面量。

### 整数

```java
int dec = 100;          // 十进制，默认
int hex = 0xFF;         // 十六进制，0x / 0X 开头（0xFF = 255）
int oct = 010;          // 八进制，前导 0（010 = 8）⚠️ 写 09 会报错
int bin = 0b1010;       // 二进制，0b / 0B 开头（Java 7+）
long big = 100L;        // 加 L / l 表示 long
long big2 = 0xFFL;      // 进制前缀和后缀可以同时用
```

⚠️ **八进制的前导 `0` 是 Java 的历史包袱**，新手极易写错。Java 8+ 推荐用 `0b`/`0x`，或者干脆用下划线。

### 数值分隔符

Java 7+ 允许用 `_` 把长数字分组，编译器会忽略它：

```java
int million = 1_000_000;
long creditCard = 4_111_111_111_111_111L;   // 比一串数字好读得多
double pi = 3.141_592_653;
```

⚠️ 下划线**只能夹在数字中间**，不能出现在开头、结尾或小数点旁边。`1_000_` 和 `_100` 都报错。

### 小数

```java
double d = 3.14;        // 默认 double
float f = 3.14f;        // 加 f / F 表示 float
float f2 = 3f;          // 合法，整数加 f 也算 float
double sci = 1.5e3;     // 科学计数法：1.5 × 10³ = 1500.0
```

### 字符与字符串

```java
char c = 'A';           // 单引号 = 单个 char
char newline = '\n';    // 转义字符
String s = "hello";     // 双引号 = String 对象（引用类型，不是基本类型）
```

### 布尔与 null

```java
boolean ok = true;      // 小写 t / f
boolean no = false;
String ref = null;      // null：引用类型的「空引用」，不是基本类型能用的值
```

### Unicode 转义

`\uXXXX` 是 **Unicode 转义**，Java 会在编译前把它替换成对应字符，**写在任何位置都生效**（连注释里也生效）：

```java
char a = 'A';
char a2 = '\u0041';     // 等价于 'A'
String s = "\u4F60\u597D";  // "你好"
```

⚠️ **`\uXXXX` 和普通转义（`\n`、`\t`）不是一回事**：普通转义只在字符/字符串字面量里有效，而 `\uXXXX` 是**源码级的文本替换**，所以 `// \u000A` 会把这行注释变成换行，导致后面那行代码被注释掉。

## 四、引用类型：变量里存的到底是什么

**引用类型（reference type）** 是除 8 种基本类型之外的一切类型：`String`、数组、`List`/`Map` 这些集合、以及你自己写的每一个类。

关键区别只有一句话：

> **基本类型的变量里直接存「值」；引用类型的变量里存「对象的地址（引用）」。**

```text
栈（Stack）                    堆（Heap）
┌────────────────────┐         ┌──────────────────────────┐
│ int  n = 10;       │  值就   │                          │
│         → 值 10    │  在栈上  │                          │
├────────────────────┤         │  ┌────────────────────┐  │
│ String s ──────────┼────────▶│  │ String 对象 "hello" │  │
│         ↑ 存的是   │  引用    │  └────────────────────┘  │
│         引用(地址)  │         │                          │
└────────────────────┘         └──────────────────────────┘
```

由此推出两个必然结果：

| | 基本类型 | 引用类型 |
|---|---|---|
| 默认值 | `0` / `0.0` / `false` / `'\u0000'` | 全部是 `null` |
| 能调方法吗 | ❌ 不能（`int` 没有 `.length()`） | ✅ 能（`s.length()`） |
| 比较相等 | 用 `==` | 用 `.equals()`（详见 [[java/01-入门阶段-基础教程/第01章-核心语法/1.4-字符串与包装类]]） |
| 内存占用 | 固定，栈上 | 对象在堆上，栈上只存引用 |

⚠️ **`null` 是「引用指向空」，不是「对象是空」**。`null` 上调用任何方法或访问任何字段，都会抛 `NullPointerException`（NPE）。

## 五、类型转换

### 5.1 隐式转换（自动转换）

**隐式转换（widening conversion / 自动类型转换）** 是编译器自动完成的小类型 → 大类型转换，不需要写任何东西：

```text
byte → short → int → long → float → double
char → int → long → float → double
```

规律：**往「更大的」方向走一定安全**，因为大类型能表示的范围一定包含小类型的范围。

```java
byte b = 10;
int i = b;          // ✅ 自动 widening：byte 的值一定能放进 int
long l = i;
double d = l;
```

⚠️ 反方向（**窄化转换 narrowing**，大 → 小）**必须显式强转**，编译器不会放行：

```java
int i = 300;
byte b = i;         // ❌ 编译报错：possible lossy conversion
byte b2 = (byte) i; // ✅ 显式强转
```

### 5.2 精度丢失：强转会发生什么

```java
int i = 300;
byte b = (byte) i;
System.out.println(b);      // 44
```

为什么是 44？因为 `int` 是 32 位、`byte` 是 8 位，强转时**只保留最低 8 位**（其余位直接丢弃）：

```text
i   = 300   = 0000 0000 0000 0000 0000 0001 0010 1100
                                 ↓ 保留最低 8 位
b   = 44    =                              0010 1100
```

⚠️ 这叫**溢出（overflow）**，不是「四舍五入」。`int` 溢出会绕回（`2147483647 + 1 == -2147483648`），而窄化强转会**截断高位**。

### 5.3 char 与 int 的关系

`char` 本质上就是一个 **16 位无符号整数**，所以它和 `int` 之间存在双向转换：

```java
char c = 'A';
int code = c;             // ✅ 自动转成 int，code = 65（'A' 的 ASCII/Unicode 码点）
char back = (char) 65;    // ✅ 强转回来，back = 'A'
System.out.println((int) 'a');   // 97
```

⚠️ 三个容易踩的点：

1. **`char` 参与算术运算时按数值算**：`'a' + 1` 的结果是 `int` 的 98，不是字符 `'b'`。想得到 `'b'` 要写 `(char)('a' + 1)`。
2. **`char` 没有负数**：`char` 是无符号的，而 `byte` 是有符号的（-128 ~ 127），所以 `byte` 的范围比 `char`「小」但方向相反——这也是为什么 `char → byte` 要强转、`byte → char` 也要强转（值可能超范围）。
3. **字符字面量 `'A'` 的类型就是 `char`**，不是 `int`——但 `'A' + 1` 会因为运算提升（数值运算中 `char` 自动当 `int` 算）而变成 `int`。

### 5.4 编译期常量与类型推断规则

`final` 修饰、且初始化为**编译期常量表达式**的变量，叫**编译期常量（compile-time constant）**：

```java
final int MAX = 127;      // ✅ 编译期常量
final int SUM = MAX + 1;  // ✅ 也是编译期常量（表达式全是常量）
final double PI = 3.14;   // ✅ 是编译期常量
```

它有两个特权：

1. **可以当 `switch` 的 `case` 标签**（非常量表达式不行）；
2. **可以窄化赋值到更小的类型**（因为值在编译期已知，编译器能判断安不安全）：

```java
final int MAX = 127;
byte b = MAX;             // ✅ 合法！127 在 byte 范围内
int i = 300;
byte b2 = i;              // ❌ 报错：i 不是编译期常量，编译器无法确定
```

⭐ **类型推断规则**：`final` 基本类型变量的类型由声明时写死的类型决定，不存在推断；而 `final var x = 127;`（Java 10+）推断出 `int`，`final var y = 127L;` 推断出 `long`。

## 六、final 的三种用法

**`final`** 是 Java 的关键字，意思是「终态的、不可再赋值」。它有三种典型用法：

### 用法一：常量（最常见）

```java
public class Config {
    static final int MAX_RETRY = 3;      // 惯例：static + final + 全大写
    static final double PI = 3.141592653589793;

    public static void main(String[] args) {
        System.out.println(Config.MAX_RETRY);  // 推荐用类名.常量访问
    }
}
```

⭐ **「编译期常量」的定义比你想的宽**：只要是 `final` + 基本类型（或 `String`）+ 用常量表达式初始化，**无论有没有 `static`** 都是编译期常量。它的值会在编译时**直接内联替换进使用处**，所以运行期即使通过非常规手段改了那个字段，已编译的调用方拿到的仍是编译时的旧值——这是它「高效」也是它「不灵活」的原因。

### 用法二：不可变引用（引用不能换，内容可以变）

```java
final List<String> list = new ArrayList<>();
list.add("a");      // ✅ 修改对象内容：允许
// list = new ArrayList<>();   // ❌ 换引用：不允许——final 锁的是「指向谁」，不是「里面是什么」
```

⚠️ 这就是 `final` 的准确语义：**它禁止的是「重新赋值」，不是「修改对象」**。和「不可变对象（immutable object）」是两回事。

### 用法三：final 参数

```java
public static int add(final int a, int b) {
    // a = 10;     // ❌ 编译报错：参数不可重新赋值
    return a + b;
}
```

用途：保护方法内部不误改入参（尤其在方法体很长、或有匿名内部类捕获它时）。

## 七、var：局部变量类型推断（Java 10+）

`var` 让编译器**自己推断**局部变量的类型，语法上仍然必须写 `var` 关键字：

```java
var count = 10;                 // 推断为 int
var price = 19.99;              // 推断为 double
var name = "Tom";               // 推断为 String
var list = new ArrayList<String>();  // 推断为 ArrayList<String>（java.util 包，需 import）
```

⚠️ **四条硬限制**：

| 限制 | 说明 | 例子 |
|------|------|------|
| **不能用于字段** | 成员变量、静态变量必须写明类型 | `var a = 1;` 写在类体里 → 编译报错 |
| **不能用于方法参数和返回值** | 参数列表里写 `var` 非法 | `void f(var x)` → 编译报错 |
| **不能初始化为 `null`** | `null` 没有类型信息，无从推断 | `var x = null;` → 编译报错 |
| **必须有初始值，且类型一次定死** | 推断完成后和普通变量一样不可改类型 | `var x = 1; x = "s";` → 编译报错 |

补充：Java 11+ 才允许在 **Lambda 参数**里用 `var`（`list.forEach(var item -> ...)`）；Java 10 只能用局部变量。

⭐ **`var` 什么时候用**：类型一眼能看出来的时候（`var count = list.size();`）用，能省不少重复；类型要靠泛型嵌套才能看出来的（`var` 到底推断成什么）就别用。**不要用它掩盖类型**——初学者应该先写全类型，等类型系统熟悉了再偷懒。

## 八、与 Python 的对照

```python
age = 25          # 不用声明类型
name = "张三"
big = 10 ** 30    # 任意精度，不会溢出
flag = True       # 首字母大写
empty = None      # 空值
```

```java
int age = 25;        // 必须声明
String name = "张三";
long big = ...;       // 超出 long 范围要改用 BigInteger
boolean flag = true;  // 小写
String empty = null;  // 空引用
```

| 维度 | Java | Python |
|------|------|--------|
| 类型声明 | 必需（静态强类型） | 可省略（动态类型） |
| 整数溢出 | `int` 超 21 亿会绕回 | `int` 任意精度，永不溢出 |
| 布尔字面量 | `true` / `false` | `True` / `False` |
| 空值 | `null`（只能给引用类型） | `None` |
| 浮点默认值 | `0.0` | `0.0`（变量无默认值，未赋值即 `Undefined` 是另一种错误） |
| 未初始化变量 | 局部变量必须先赋值，否则编译报错 | 变量必须先赋值，否则运行时报 `NameError` |

⚠️ **「Python 的 int 是任意精度，Java 不是」是迁移时最实用的一条**。Python 里 `2 ** 63` 只是个整数；Java 里你必须从一开始就选对 `int` / `long` / `BigInteger`，选错了编译能过、跑起来才出事。

---

## 陷阱

1. **⚠️ 以为 `char` 有负数**——`char` 是 16 位**无符号**整数，范围 `0 ~ 65535`，不能表示负数；
2. **⚠️ 以为 `float f = 1;` 能编译**——小数默认是 `double`，赋给 `float` 必须写 `1f`；反过来 `double d = 1;` 完全合法；
3. **⚠️ 整数溢出当成正常结果**——`int` 超过 21 亿会绕回成负数，不是报错；计数器、订单号请用 `long`，金额请用 `BigDecimal`（见 [[java/01-入门阶段-基础教程/第01章-核心语法/1.4-字符串与包装类]]）；
4. **⚠️ 把 `byte` 的范围记成 0~255**——那是无符号的 `byte`（C/C++ 的 `unsigned char`），Java 的 `byte` 是 -128 ~ 127；
5. **⚠️ 强转当成四舍五入**——`(byte) 300` 是**截断**得到 44，不是 44 也不是别的舍入值；
6. **⚠️ 局部变量忘记初始化**——Java 是「先赋值后使用」，编译期就拦下你；Python 也是类似规则但错误发生在运行期；
7. **⚠️ 用 `final` 指望对象内容不可变**——`final` 只锁引用，不锁对象内部状态；
8. **⚠️ 在注释里写 `\uXXXX`**——它会在编译前被替换成真实字符，可能把代码注释掉，行为极其诡异；
9. **⚠️ 八进制字面量写成 `010`**——这是 8 不是 10；要十进制就去掉前导 0；
10. **⚠️ 用 `var` 初始化为 `null`**——编译器无从推断类型，必须写明 `String s = null;`。

## 小结

- 变量分三种：**局部**（方法内，必须初始化）、**成员**（每个对象一份）、**静态**（全类一份）；前两者之外还有 `final` 常量的惯用法
- 8 种基本类型：`byte(1)` `short(2)` `int(4)` `long(8)` `float(4)` `double(8)` `char(2，无符号)` `boolean(1)`
- 小数默认 `double`；整数默认 `int`；`char` 用单引号、`String` 用双引号、布尔小写 `true/false`
- 字面量后缀/前缀：`L` `f` `_` `0x` `0b` `0` `e`；`\uXXXX` 是源码级替换
- **基本类型存值、引用类型存地址**；默认值分别是 `0` 和 `null`
- 转换：宽自动、窄必须强转；强转是**截断**不是舍入
- `final` 三用：常量、锁引用、锁参数；`final int` 常量能做 `case` 标签
- `var`（Java 10+）只能用于**有初始值的局部变量**
