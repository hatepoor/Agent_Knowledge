## 版本基线（2026-10-22 核实）

⚠️ **Java 的版本策略与 MySQL 不同：每 6 个月一个特性版，每 2 年一个 LTS。生产只跟 LTS，特性版只用于尝鲜。**

| 版本 | 类型 | 发布时间 | 状态（2026-10） |
|------|------|---------|----------------|
| **Java 25** | ⭐ **LTS** | 2025-09 | ⭐ **当前生产基线**，Oracle Premier 支持至 2030-09、Extended 至 2033-09 |
| Java 21 | LTS | 2023-09 | 仍在支持（扩展至 2031-09），⚠️ **Oracle 免费条款 2026-09 已到期** |
| Java 17 | LTS | 2021-09 | 仍可用（企业存量最大），扩展支持到 2029-09 |
| Java 26 | 特性版 | 2026-03 | 非 LTS，仅 6 个月支持期 |
| Java 27 | 特性版 | 2026-09 | 非 LTS；`⚠️ Spring Boot 4.1 不支持` |

**Java 25 的三个关键变化**（决定要不要升级）：

1. ⭐ **虚拟线程（Virtual Threads）真正可用于生产**——JEP 491（JDK 24）修复了 `synchronized` 阻塞时「钉住载体线程」的问题，Java 25 是第一个包含该修复的 LTS；
2. **Scoped Values 正式**（JEP 506），替代 `ThreadLocal` 的现代方案；
3. 紧凑对象头（Java 27 起默认）、AOT 缓存（JEP 514/515）——容器场景启动更快、内存更省。

### Spring Boot 版本

| 版本 | 发布 | OSS 支持截止 | 状态 |
|------|------|-------------|------|
| **4.1.x** | 2026-06 | 2027-07-31 | ⭐ **当前线**（本文档以此为基线） |
| 4.0.x | 2025-11 | 2026-12-31 | 维护中，年底到期 |
| 3.5.x | 2025-05 | **2026-06-30 已 EOL** | ⚠️ 仅商业支持 |
| 4.2 | 预计 2026-11 | — | 首个支持 Java 27 的版本 |

⚠️ **两个必须记住的版本坑**：

1. **Spring Boot 4.x 的 Java 基线是 17，推荐 25**——不是「必须 25」；
2. ⚠️ **Spring Boot 4.1 只支持 Java 17–26，装了 JDK 27 反而会报错**——「装最新版」在这里是错的。

Boot 4 的大件升级：**Spring Framework 7**、**Jakarta EE 11**、Jackson 3、Hibernate 7——从 2.x/3.x 升上来主要是 `javax.*` → `jakarta.*` 的包名迁移。

## 一句话技术画像

| 维度 | 特点 |
|------|------|
| 运行方式 | 源码 → 字节码（`.class`）→ JVM 解释 + JIT 编译执行 |
| 内存管理 | 自动 GC（G1 为默认回收器），无手动 `free` |
| 并发模型 | 线程 + 线程池；Java 21+ 虚拟线程（25 起生产可用） |
| 主流框架 | **Spring Boot 4.x**（Spring Framework 7 + Jakarta EE 11） |
| 构建工具 | Maven / Gradle |
| 典型岗位 | 后端开发、企业系统、金融/电商高并发服务 |
