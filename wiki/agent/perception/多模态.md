# 多模态（Multimodal）

## 定义
多模态是指 AI 模型同时处理文本、图像、音频、视频等多种信息形式的能力。这是当前大模型最核心的发展方向之一，让 AI 从"只能读文字"进化为"能看、能听、能说"。

## 为什么需要多模态
现实世界不是由文字组成的，而是由多种感官信息共同构成。纯文本模型无法处理图片、音频、视频等非文本信息。多模态让 AI 更接近人类的感知方式。

## 核心能力
| 能力 | 说明 | 典型应用 |
| --- | --- | --- |
| 图像理解 | 看图说话、OCR、图表分析 | 医学影像分析、文档识别 |
| 语音交互 | 语音识别(ASR)+语音合成(TTS) | 语音助手、实时翻译 |
| 视频理解 | 视频内容分析、摘要 | 视频监控、内容审核 |
| 图文生成 | 根据文字生成图片 | 设计、广告创意 |
| 跨模态检索 | 以文搜图、以图搜文 | 商品搜索、素材管理 |

## 主流多模态模型
| 模型 | 公司 | 特点 |
| --- | --- | --- |
| GPT-4o | OpenAI | 文本+图像+音频，原生多模态 |
| Gemini | Google | 原生多模态，支持长视频理解 |
| Claude | Anthropic | 文本+图像，PDF/图片分析能力强 |
| 通义千问VL | 阿里 | 中文多模态，图文理解优秀 |

## 在 Agent 中的角色
多模态是 [[agent/harness/Agent_三层架构]] 中**感知层**的关键扩展。传统 Agent 只能接收文本输入，多模态 Agent 可以：
- 理解截图、设计稿、图表（图像输入）
- 听懂语音指令（音频输入）
- 生成图片、语音（多模态输出）
- 操作屏幕上的 UI 元素（环境感知）

## 技术原理概述
多模态模型通过**模态对齐**（Modality Alignment）将不同模态的信息映射到统一的向量空间。典型架构：
- 图像编码器（如 ViT）将图片转为向量
- 文本编码器将文字转为向量
- 跨模态注意力机制融合两种表示
- 统一的解码器生成输出
