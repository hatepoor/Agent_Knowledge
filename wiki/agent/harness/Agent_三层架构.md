# Agent 三层架构

## 定义

AI Agent 的基础架构由三层组成：**感知层→思考层→执行层**。这是一个高度统一的通用框架，几乎所有 Agent 系统都可以映射到这三层结构上。

## 核心组成

### 1. 感知层（Perception）
- 接收用户输入：文本、语音、多模态信号
- 输入清洗：格式校验、关键词提取、意图识别
- 将非结构化输入转化为思考层可处理的结构化信息

### 2. 思考层（Thinking）
- Agent 的"大脑"，核心决策模块
- 包含三个关键子系统：
  - **规划**：任务拆解、步骤编排、优先级判断
  - **记忆**：短期上下文管理 + 长期知识存储与检索
  - **工具调用**：判断何时需要外部工具，选择并调用合适的工具
- 接收感知层的输入，综合记忆和可用工具，制定执行计划

### 3. 执行层（Execution）
- 执行思考层的指令：
  - 调用外部工具（搜索、数据库、API 等）
  - 生成自然语言回答
  - 触发外部动作（发消息、写文件、调接口等）
- 将执行结果返回给用户，同时反馈给思考层作为新的上下文

## 工作流程

```
用户输入 → [感知层] 清洗/提取 → [思考层] 规划+记忆+工具决策 → [执行层][[ 执行+返回结果 → 用户
```

这是一个闭环：执行结果会作为新的感知输入，回到思考层形成持续迭代。
