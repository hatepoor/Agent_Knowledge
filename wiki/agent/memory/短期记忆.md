# 短期记忆（Short-term Memory）

## 概述

短期记忆是让应用在**单个线程/会话**内记住之前交互信息的系统。对于 AI Agent 来说，记忆至关重要——它让 Agent 能记住之前的交互、从反馈中学习、适应用户偏好。

**会话历史（Conversation History）** 是最常见的短期记忆形式。但长对话对 LLM 构成挑战：
- 完整历史可能**超出上下文窗口**，导致信息丢失或报错
- 即使模型支持足够长的上下文，过长的历史也会让模型"分心"——被过时或无关内容干扰，同时响应变慢、成本升高

> 需要跨会话记住信息？请参阅 [[Agent_Memory]] 中关于长期记忆的部分。

## 核心机制：Checkpointer

LangChain 的 Agent 通过 **Checkpointer（检查点保存器）** 管理短期记忆。状态会被持久化到数据库（或内存）中，线程可以随时恢复。

### 工作原理

1. 短期记忆在 Agent 被调用或步骤（如工具调用）完成时**更新**
2. 状态在每一步开始时**读取**
3. 通过 `thread_id` 区分不同会话，实现会话隔离

### 基本用法

```python
# 导入 Agent 创建函数和内存检查点保存器
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

# 定义一个工具函数
def get_user_info() -> str:
    """查询当前用户的信息"""
    return "暂无用户档案。"

# 创建 Agent，配置内存检查点（开发环境用内存存储）
agent = create_agent(
    model="anthropic:claude-sonnet-4-6",  # 指定使用的模型
    tools=[get_user_info],                 # 绑定可用工具
    checkpointer=InMemorySaver(),          # 使用内存检查点保存对话状态
)

# 配置线程 ID，用于标识和隔离不同会话
thread_config = {"configurable": {"thread_id": "1"}}

# 第一轮对话：告诉 Agent 我的名字
response = agent.invoke(
    {"messages": [{"role": "user", "content": "你好！我叫 Bob。"}]},
    thread_config,
)["messages"][-1].content
print(response)  # "你好 Bob！很高兴见到你。最近怎么样？"

# 第二轮对话：测试记忆——Agent 应该记得我的名字
response = agent.invoke(
    {"messages": [{"role": "user", "content": "我叫什么名字？"}]},
    thread_config,
)["messages"][-1].content
print(response)  # "你叫 Bob！"  ← 短期记忆生效
```

### 生产环境：使用数据库持久化

开发时用 `InMemorySaver`（进程结束即丢失），生产环境应使用数据库：

```python
# 安装 PostgreSQL 检查点库
# pip install langgraph-checkpoint-postgres

from langchain.agents import create_agent
from langgraph.checkpoint.postgres import PostgresSaver

def get_user_info() -> str:
    """查询当前用户的信息"""
    return "暂无用户档案。"

# 数据库连接字符串
DB_URI = "postgresql://postgres:postgres@localhost:5432/postgres?sslmode=disable"

# 使用上下文管理器连接 PostgreSQL
with PostgresSaver.from_conn_string(DB_URI) as checkpointer:
    checkpointer.setup()  # 自动创建所需的数据库表

    agent = create_agent(
        "gpt-5.5",
        tools=[get_user_info],
        checkpointer=checkpointer,  # 使用 PostgreSQL 持久化
    )
```

其他支持的检查点后端：SQLite、Azure Cosmos DB 等。

## 自定义 Agent 状态

默认情况下，Agent 使用 `AgentState` 管理短期记忆（通过 `messages` 键存储对话历史）。

你可以**扩展 `AgentState`** 添加自定义字段（如用户 ID、偏好设置），通过 `state_schema` 参数传入：

```python
from langchain.agents import create_agent, AgentState
from langgraph.checkpoint.memory import InMemorySaver

# 继承 AgentState，添加自定义字段
class CustomAgentState(AgentState):
    user_id: str           # 用户 ID
    preferences: dict      # 用户偏好设置

# 创建 Agent 时指定自定义状态结构
agent = create_agent(
    "gpt-5.5",
    tools=[get_user_info],
    state_schema=CustomAgentState,     # 使用自定义状态
    checkpointer=InMemorySaver(),
)

# 调用时传入自定义状态数据
result = agent.invoke(
    {
        "messages": [{"role": "user", "content": "你好"}],
        "user_id": "user_123",
        "preferences": {"theme": "dark"}   # 例如深色主题偏好
    },
    {"configurable": {"thread_id": "1"}}
)
```

## 上下文管理策略

启用短期记忆后，长对话可能**超出 LLM 上下文窗口**。以下是四种常见解决方案：

| 策略 | 原理 | 适用场景 |
|------|------|----------|
| **裁剪消息（Trim）** | 删除最早或最新的 N 条消息 | 简单快速，适合大多数场景 |
| **删除消息（Delete）** | 从状态中永久删除特定消息 | 需要精确控制哪些消息被移除 |
| **摘要压缩（Summarize）** | 用 LLM 将早期消息压缩为摘要 | 需要保留关键信息但减少 token |
| **自定义策略** | 消息过滤等自定义逻辑 | 特殊业务需求 |

### 策略一：裁剪消息

当消息历史接近上下文窗口限制时，裁剪掉早期消息，只保留最近几轮。

使用 `@before_model` 中间件装饰器，在**模型调用之前**自动裁剪：

```python
from langchain.messages import RemoveMessage
from langgraph.graph.message import REMOVE_ALL_MESSAGES
from langgraph.checkpoint.memory import InMemorySaver
from langchain.agents import create_agent, AgentState
from langchain.agents.middleware import before_model
from langgraph.runtime import Runtime
from langchain_core.runnables import RunnableConfig
from typing import Any

# 使用 @before_model 装饰器：在每次模型调用前执行
@before_model
def trim_messages(state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
    """只保留最近几条消息，防止超出上下文窗口"""
    messages = state["messages"]

    # 如果消息少于 3 条，无需裁剪
    if len(messages) <= 3:
        return None  # 返回 None 表示不做修改

    # 保留第一条（系统/初始消息）+ 最近 3-4 条
    first_msg = messages[0]
    recent_messages = messages[-3:] if len(messages) % 2 == 0 else messages[-4:]
    new_messages = [first_msg] + recent_messages

    # 先删除所有消息，再写入保留的消息
    return {
        "messages": [
            RemoveMessage(id=REMOVE_ALL_MESSAGES),  # 清空所有消息
            *new_messages                            # 写入保留的消息
        ]
    }

# 创建 Agent 并注册裁剪中间件
agent = create_agent(
    "gpt-5.5",
    tools=[...],
    middleware=[trim_messages],       # 注册裁剪中间件
    checkpointer=InMemorySaver(),
)

config: RunnableConfig = {"configurable": {"thread_id": "1"}}

# 模拟多轮对话
agent.invoke({"messages": "你好，我叫 bob"}, config)
agent.invoke({"messages": "写一首关于猫的小诗"}, config)
agent.invoke({"messages": "再写一首关于狗的"}, config)

# 最后一轮：测试 Agent 是否还记得用户的名字
final_response = agent.invoke({"messages": "我叫什么名字？"}, config)
final_response["messages"][-1].pretty_print()
# 输出："你叫 Bob。你之前告诉过我。"
```

### 策略二：删除消息

使用 `RemoveMessage` 从状态中**永久删除**特定消息。

```python
from langchain.messages import RemoveMessage

def delete_messages(state):
    """删除最早两条消息"""
    messages = state["messages"][[
    if len(messages) > 2:
        # 通过消息 ID 删除前两条
        return {"messages": [RemoveMessage(id=m.id) for m in messages[:2]]}
```

删除**所有**消息：

```python
from langgraph.graph.message import REMOVE_ALL_MESSAGES

def delete_messages(state):
    """清空全部消息历史"""
    return {"messages": [RemoveMessage(id=REMOVE_ALL_MESSAGES)]}
```

> **注意**：删除消息后，确保剩余的消息历史仍然合法。例如：某些模型要求历史以 `user` 消息开头；`assistant` 的工具调用消息后面必须跟对应的 `tool` 结果消息。

使用 `@after_model` 中间件在模型调用**之后**删除旧消息：

```python
from langchain.messages import RemoveMessage
from langchain.agents import create_agent, AgentState
from langchain.agents.middleware import after_model
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.runtime import Runtime
from langchain_core.runnables import RunnableConfig

# 使用 @after_model 装饰器：在每次模型调用后执行
@after_model
def delete_old_messages(state: AgentState, runtime: Runtime) -> dict | None:
    """移除旧消息，保持对话可管理"""
    messages = state["messages"][[
    if len(messages) > 2:
        # 删除最早的两条消息
        return {"messages": [RemoveMessage(id=m.id) for m in messages[:2]]}
    return None  # 不足 2 条时不操作

agent = create_agent(
    "gpt-5-nano",
    tools=[...],
    system_prompt="请简洁回答。",
    middleware=[delete_old_messages],   # 注册删除中间件
    checkpointer=InMemorySaver(),
)
```

### 策略三：摘要压缩

裁剪和删除的缺点是可能**丢失重要信息**。摘要压缩用 LLM 将早期对话压缩为摘要，既减少 token 又保留关键信息。

使用内置的 `SummarizationMiddleware`：

```python
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware
from langgraph.checkpoint.memory import InMemorySaver
from langchain_core.runnables import RunnableConfig

checkpointer = InMemorySaver()

agent = create_agent(
    model="gpt-5.5",
    tools=[...],
    middleware=[
        SummarizationMiddleware(
            model="gpt-5.4-mini",        # 用于生成摘要的模型（可用更便宜的模型）
            trigger=("tokens", 4000),     # 当 token 数超过 4000 时触发摘要
            keep=("messages", 20)         # 摘要后保留最近 20 条消息
        )
    ],
    checkpointer=checkpointer,
)

config: RunnableConfig = {"configurable": {"thread_id": "1"}}
agent.invoke({"messages": "你好，我叫 bob"}, config)
agent.invoke({"messages": "写一首关于猫的小诗"}, config)
agent.invoke({"messages": "再写一首关于狗的"}, config)

# 即使经过摘要压缩，Agent 仍能记住用户的名字
final_response = agent.invoke({"messages": "我叫什么名字？"}, config)
final_response["messages"][-1].pretty_print()
# 输出："你叫 Bob！"
```

## 访问和修改记忆

Agent 的短期记忆（状态）可以在多个位置被读取和修改：

### 1. 在工具中读取记忆

通过 `runtime` 参数（类型为 `ToolRuntime`）在工具中访问状态。此参数对模型**不可见**（不会出现在工具签名中），但工具可以内部使用：

```python
from langchain.agents import create_agent, AgentState
from langchain.tools import tool, ToolRuntime

# 自定义状态，添加 user_id 字段
class CustomState(AgentState):
    user_id: str

@tool
def get_user_info(runtime: ToolRuntime) -> str:
    """查询用户信息"""
    # 通过 runtime.state 读取当前状态
    user_id = runtime.state["user_id"]
    return "用户是张三" if user_id == "user_123" else "未知用户"

agent = create_agent(
    model="gpt-5-nano",
    tools=[get_user_info],
    state_schema=CustomState,  # 使用自定义状态
)

result = agent.invoke({
    "messages": "查询用户信息",
    "user_id": "user_123"
})
print(result["messages"][-1].content)
# > 用户是张三。
```

### 2. 在工具中写入记忆

工具可以通过返回 `Command` 对象来**修改** Agent 的状态，实现跨工具的信息传递：

```python
from langchain.tools import tool, ToolRuntime
from langchain.messages import ToolMessage
from langchain.agents import create_agent, AgentState
from langgraph.types import Command
from pydantic import BaseModel

class CustomState(AgentState):
    user_name: str  # 存储用户名

class CustomContext(BaseModel):
    user_id: str

@tool
def update_user_info(runtime: ToolRuntime[CustomContext, CustomState]) -> Command:
    """查询并更新用户信息到状态中"""
    user_id = runtime.context.user_id
    name = "张三" if user_id == "user_123" else "未知用户"
    # 返回 Command 对象，更新状态中的 user_name 字段
    return Command(update={
        "user_name": name,    # 写入自定义状态字段
        "messages": [         # 同时更新消息历史
            ToolMessage(
                "已成功查询用户信息",
                tool_call_id=runtime.tool_call_id
            )
        ]
    })

@tool
def greet(runtime: ToolRuntime[CustomContext, CustomState]) -> str | Command:
    """向用户打招呼（需要先调用 update_user_info 获取用户名）"""
    user_name = runtime.state.get("user_name", None)
    if user_name is None:
        # 如果还没有用户名，提示先调用查询工具
        return Command(update={
            "messages": [
                ToolMessage(
                    "请先调用 update_user_info 工具获取用户名。",
                    tool_call_id=runtime.tool_call_id
                )
            ]
        })
    return f"你好 {user_name}！"

agent = create_agent(
    model="gpt-5-nano",
    tools=[update_user_info, greet],
    state_schema=CustomState,
    context_schema=CustomContext,
)
```

### 3. 在 Prompt 中动态使用记忆

使用 `@dynamic_prompt` 中间件，根据状态或上下文**动态生成系统提示词**：

```python
from langchain.agents import create_agent
from typing import TypedDict
from langchain.agents.middleware import dynamic_prompt, ModelRequest

class CustomContext(TypedDict):
    user_name: str

def get_weather(city: str) -> str:
    """查询城市天气"""
    return f"{city}的天气总是晴天！"

# 动态提示词：根据上下文中的用户名定制系统提示
@dynamic_prompt
def dynamic_system_prompt(request: ModelRequest) -> str:
    user_name = request.runtime.context["user_name"]
    return f"你是一个有用的助手。请称呼用户为 {user_name}。"

agent = create_agent(
    model="gpt-5-nano",
    tools=[get_weather],
    middleware=[dynamic_system_prompt],  # 注册动态提示词中间件
    context_schema=CustomContext,
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "旧金山天气怎么样？"}][[},
    context=CustomContext(user_name="张三"),
)
# Agent 会用 "张三" 称呼用户来回答问题
```
