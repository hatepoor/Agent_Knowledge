# 向量数据库（Vector Database）

## 概述
向量数据库是专门用于存储、索引和检索高维向量数据的数据库系统。与传统数据库通过精确匹配查询不同，向量数据库通过**相似度**查询——找到与给定对象"最像"的那些东西。它是 RAG、推荐系统、多模态搜索等 AI 应用的核心基础设施。

## 核心概念

### 向量与嵌入
- **向量**：一组有序数字，代表对象的语义特征，维度通常 128-4096
- **嵌入（Embedding）**：将文本/图片/音频等转为向量的过程，由嵌入模型完成
- **核心原则**：语义相近的对象，向量在空间中距离更近

### 相似度计算
| 方法 | 原理 | 适用场景 |
| 余弦相似度 | 计算两向量夹角余弦值 [-1,1][[ | 文本语义搜索（首选） |
| 欧氏距离 | 两点直线距离 [0,∞) | 图像检索、坐标数据 |
| 点积 | 向量各分量乘积之和 | 推荐系统、归一化场景 |

### 索引算法
| 算法 | 特点 | 适用 |
| Flat（暴力） | 精确但慢，O(n) | <10万数据，精度优先 |
| IVF | 先聚类再搜索 | 中大规模 |
| HNSW | 多层图结构，最主流 | 通用首选，速度快精度高 |

## 主流产品对比
| 数据库 | 类型 | 适用场景 | 难度 |
| Chroma | 开源嵌入式 | RAG原型、AI应用开发 | 入门 |
| Qdrant | 开源（Rust） | 生产级推荐，性能优先 | 中级 |
| Weaviate | 开源多模态 | 多模态检索、知识图谱 | 中级 |
| Milvus | 开源分布式 | 亿级数据，企业大规模 | 进阶 |
| Pinecone | 商业SaaS | 快速上线，零运维 | 入门 |
| pgvector | PG扩展 | 已有PostgreSQL的项目 | 入门 |

### 选型决策树
- 已有PG且<500万数据 → pgvector
- AI原型快速验证 → Chroma
- 生产级500万-1亿 → Qdrant
- 超大规模>1亿有K8s → Milvus
- 无运维能力愿付费 → Pinecone

- 知识库问答（RAG）
- 长期记忆存取
- 语义搜索
- 用户偏好检索
