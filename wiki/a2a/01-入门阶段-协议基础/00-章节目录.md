# A2A 协议 · 入门阶段章节目录

> **本阶段是零基础起点，不要求任何前置知识。**（默认你听说过「Agent」和「工具调用」这两个词，[[a2a/README|README]] 的门槛表有更严格的判断标准。）
>
> ⚠️ **知识有强线性依赖，请按章节顺序推进，不要跳读第01章。** 第00章建立定位和动机，第01章的每个对象都建立在这个定位之上。

---

## 学习顺序

```
第00章 学前准备（3 篇）
  0.1 A2A是什么                    ← 它是什么 + 官方明确的「不是什么」
  0.2 为什么需要A2A                ← 它解决的四类具体困境
  0.3 版本演进与治理历程            ← 从 Google 私有到中立基金会
       ↓
第01章 核心对象（4 篇）★ 本阶段重点
  1.1 AgentCard与智能体发现        ← 契约：对方如何被知道
  1.2 Task/Message/Part/Artifact   ← 四个数据对象
  1.3 三种交互机制与协议绑定        ← 流式、推送、三套传输
  1.4 Task生命周期与状态机          ← A2A 与 MCP 最大的差异点
       ↓
第02章 工程实践（2 篇）
  2.1 Python SDK最小可用实现       ← 跑通一个服务端 + 客户端
  2.2 把远端Agent包装成本地工具     ← 接进现有系统的正确姿势
```
