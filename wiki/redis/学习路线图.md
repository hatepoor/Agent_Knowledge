## 一、总路线

```
【入门】会用：选对类型存取 + 接入 Python 项目          ← 已建成 ✅
```

## 二、入门阶段（已建成）

**能力出口**：给定一个 Python 项目需求（缓存 / 会话 / 计数 / 队列 / 排行），能独立完成"选类型 → 写命令 → redis-py 接入 → 设过期 → 排错"。

**毕业自测清单**（每条都能不查资料回答/做到，即为过关）：

- [ ] 一句话讲清 Redis 与 PostgreSQL 的分工
- [ ] `SET` 的 `NX` / `EX` / `KEEPTTL` 各自解决什么问题
- [ ] `INCR` 为什么不需要锁；GET+SET 计数错在哪
- [ ] 五种类型各举一个场景；"字段级更新"选谁、"TopN"选谁、"判断在不在"选谁
- [ ] `TTL` 的 `-1` 与 `-2` 区别；`SET` 覆盖后 TTL 怎么了
- [ ] `KEYS` 为什么生产禁用；`SCAN` 的结束判据是什么
- [ ] redis-py 的 `decode_responses=True` 影响什么；`DEL` 对应的方法名
- [ ] pipeline 与事务的区别（答出"网络优化 vs 不被插队"即可）

## 三、中段阶段（已建成：12 个专题）

目录：`02-中段阶段-生产实践/`，平行专题可跳读。**前置：入门阶段已学完。**
入口：[[redis/02-中段阶段-生产实践/00-专题导航]]（内含"按目标选路径"表）

| # | 专题 | 核心问题 | 主要依赖 |
|---|------|----------|----------|
| 1 | **持久化：RDB 与 AOF** | 重启后数据恢复到多久之前？混合持久化怎么配？ | 入门 |
| 2 | **发布订阅与 Stream** | 消息不丢的多消费者队列；at-least-once 与幂等 | 入门（List 队列） |
| 3 | **缓存三大问题与缓存模式** | Cache-Aside；穿透/击穿/雪崩的解法；延迟双删 | 入门（TTL、SET NX） |
| 4 | **事务与 Lua 脚本** | 多命令不被插队；WATCH 乐观锁；不回滚语义 | 入门（pipeline） |
| 5 | **管道与性能** | RTT 数学；SLOWLOG/bigkeys/LATENCY 四板斧 | 入门 |
| 6 | **分布式锁** | 三零件锁；看门狗续期；效率锁 vs 正确性锁 | 专题 4 |
| 7 | **内存淘汰与 maxmemory** | 8 种策略选型；大 key 治理；容量与水位 | 专题 1（COW）、5 |
| 8 | **高可用：主从 / 哨兵 / 集群** | 复制/故障转移/分片；脑裂；故障演练 | 专题 1、7 |
| 9 | **缓存一致性：与数据库同步** | 四种写序推演；删缓存失败兜底（重试/binlog）；复制延迟 | 专题 3、2、8 |
| 10 | **大 Key 与热 Key 治理** | 判定标准；发现工具全景；治理 SOP；热 key 应急 | 专题 5、7 |
| 11 | **安全加固与生产监控** | 网络隔离；ACL；危险命令治理；INFO 全景与告警 | 专题 5、7、8 |
| 12 | **Agent 场景实战：缓存、会话与任务分发** | LLM/embedding 缓存；会话与 Checkpointer；Stream 任务分发；限流 | 专题 2、3、6、7 |

**中段毕业标准**：能为一个真实服务设计完整的 Redis 使用方案（缓存策略 + 持久化配置 + 容量规划 + 故障预案），并说清每个决策的理由。

## 四、进阶阶段（规划：4 个专题）

| # | 专题 | 核心问题 |
|---|------|----------|
| 1 | **单线程模型与事件循环** | 为什么单线程反而快？6.0+ 的 IO 多线程改了什么 |
| 2 | **RESP 协议** | 客户端与服务端到底在说什么；RESP2 vs RESP3 |
| 3 | **内部编码** | listpack / quicklist / skiplist / intset：内存与速度的取舍 |
| 4 | **过期与淘汰的源码视角** | 定期删除的采样算法、LRU/LFU 的近似实现 |

**进阶毕业标准**：能读懂 Redis 相关的故障报告与性能分析，能评估"这个操作在服务端到底发生了什么"。

## 五、给你的 Agent 技术栈的建议路线

结合你当前的主线（LangChain/LangGraph 多智能体系统），建议的中段阅读顺序：

1. **专题 3（缓存模式）+ 专题 1（持久化）先行** —— Agent 的 LLM 响应缓存、embedding 缓存、会话存储是马上能落地的
2. **专题 2（Stream）第二** —— Agent 间异步任务分发、事件流
3. **专题 4（事务/Lua）→ 专题 6（分布式锁）** —— 多实例部署时的并发正确性
4. **专题 5（性能）、专题 7（淘汰）、专题 8（高可用）** —— 规模化阶段再回来读
5. **专题 9（一致性）、专题 10（大 key/热 key）、专题 11（安全监控）** —— 多服务/上规模前的必修；**专题 12（Agent 实战）** 是 01-08 的整合落地篇，结合你的 LangChain/LangGraph 项目通读
