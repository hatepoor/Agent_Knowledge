# Redis 速查索引

> **定位**：写命令 / 写代码时忘了**语法骨架**，来这里查。只给骨架与返回形态，**不给解释**——解释在正文，见各条目链接或 [[redis/Redis命令与术语手册]]。
> 约定：`key` 缩写为 `k`；`Redis N.x+` 表示需要该版本以上。

---

## 一、响应前缀 ↔ Python 返回类型（必背）

| redis-cli 显示 | 类型 | redis-py（decode=True） |
|----------------|------|------------------------|
| `OK` / `PONG` | 成功 | `True` |
| `(integer) n` | 整数 | `int` |
| `"(nil)"` | 无 | `None` |
| `(empty array)` | 空列表 | `[]` |
| 多行 | 列表 | `list[str]` / `list[(成员, float)]` |
| Hash 全量 | 映射 | `dict[str, str]` |
| Set 全量 | 集合 | `set[str]`（**无序**） |

## 二、String

```
SET k v [EX 秒 | PX 毫秒] [NX | XX] [KEEPTTL] [GET]     ← KEEPTTL 6.0+，GET 6.2+
GET k
GETDEL k                                                  6.2+
INCR k | DECR k | INCRBY k n | DECRBY k n | INCRBYFLOAT k x
MSET k1 v1 k2 v2 ...          MGET k1 k2 ...
APPEND k v | STRLEN k | GETRANGE k 起 止 | SETRANGE k 偏移 v
```

```python
r.set("k", "v", ex=60, nx=True)
r.get("k")                       # str | None
r.incr("c")                      # int
r.mget(["a", "b"])               # [str|None, ...] 位置对齐
```

## 三、List

```
LPUSH k v... | RPUSH k v...          ← LPUSH a b c 终序为 c b a
LPOP k [n] | RPOP k [n]                                  n: 6.2+
LRANGE k 起 止                        ← 闭区间，0 -1 全部
LLEN k | LINDEX k i | LSET k i v
LREM k 计数 v                         ← 正:从头 n 个；负:从尾；0:全删
LTRIM k 起 止                        ← 只保留区间
LMOVE 源 目标 LEFT|RIGHT LEFT|RIGHT   6.2+
BLPOP k 超时 | BRPOP k 超时           ← 超时 0 = 无限等；空返回 nil
```

```python
r.rpush("q", "j1", "j2")
r.blpop("q", timeout=5)           # ('q', 'j1') | None ← 判空！
r.lrange("feed", 0, 99)
```

## 四、Hash

```
HSET k f v [f v...] | HGET k f | HMGET k f... | HGETALL k
HDEL k f... | HEXISTS k f | HLEN k
HKEYS k | HVALS k | HSETNX k f v
HINCRBY k f n | HINCRBYFLOAT k f x
HRANDFIELD k [n]                      6.2+
HSCAN k 游标 [COUNT n] [MATCH m]
```

```python
r.hset("session", mapping={"user": "u1", "turns": 0})
r.hget("session", "user")         # str | None
r.hgetall("session")              # dict（无序）
r.hincrby("session", "turns", 1)  # int
```

## 五、Set

```
SADD k m... | SREM k m...
SISMEMBER k m | SMISMEMBER k m...     SMISMEMBER: 6.2+
SCARD k | SMEMBERS k
SRANDMEMBER k [n]      ← 不删       SPOP k [n] ← 删除
SINTER k1 k2 | SUNION k1 k2 | SDIFF k1 k2      (+ ...STORE 目标)
SINTERCARD k1 k2 [LIMIT n]            7.0+
SSCAN k 游标 [COUNT n] [MATCH m]
```

```python
r.sadd("tags", "python")
r.sismember("tags", "python")     # True / False
r.smembers("tags")                # set（无序）
r.sinter("a", "b")                # set
```

## 六、Sorted Set

```
ZADD k 分数 成员 [分数 成员...]
ZSCORE k 成员 | ZCARD k
ZRANK k 成员 | ZREVRANK k 成员          ← 0 起
ZRANGE k 起 止 [WITHSCORES]             ← 名次区间（默认！）
ZRANGE k min max BYSCORE [REV] [LIMIT o c]    6.2+ ← 分数区间
ZREVRANGE k 起 止 [WITHSCORES]
ZCOUNT k min max | ZINCRBY k 增量 成员
ZREM k 成员 | ZPOPMIN k [n] | ZPOPMAX k [n]
分数写法: 闭区间 100 200 | 开区间 (200 | 无穷 +inf -inf
```

```python
r.zadd("rank", {"alice": 350})
r.zincrby("rank", 50, "alice")        # 400.0 ← float！
r.zrevrange("rank", 0, 9, withscores=True)   # [(m, float), ...]
r.zrevrank("rank", "alice")           # int | None（0 起）
r.zrange("rank", 300, "+inf", byscore=True)  # 分数 ≥ 300
```

## 七、通用与过期

```
DEL k... | UNLINK k... (4.0+, 删大 key) | EXISTS k... (多键返回计数)
TYPE k | RENAME k 新 | RENAMENX k 新 | RANDOMKEY | COPY 源 目标 (6.2+)
SCAN 游标 [MATCH m] [COUNT n] [TYPE t]     ← 起点 0，游标归 0 结束
EXPIRE k 秒 | PEXPIRE k 毫秒 | EXPIREAT k 时间戳
EXPIRE k 秒 NX|XX|GT|LT                 7.0+
TTL k | PTTL k          ← 正数=剩余 | -1=永久 | -2=不存在
PERSIST k | GETEX k [EX 秒] (6.2+)
```

```python
r.delete("k")                     # DEL 唯一改名例外
r.unlink("bigkey")
r.expire("k", 3600)
r.ttl("k")
for key in r.scan_iter("user:*", count=500): ...   # SCAN 生成器
```

## 八、redis-py 连接骨架

```python
# 同步
import redis
r = redis.Redis(host="localhost", port=6379, db=0, decode_responses=True)
r = redis.from_url("redis://localhost:6379/0", decode_responses=True)

# 连接池（共享）
pool = redis.ConnectionPool(host="localhost", db=0,
                            decode_responses=True, max_connections=50)
r = redis.Redis(connection_pool=pool)

# asyncio（FastAPI 用）
import redis.asyncio as redis
r = redis.from_url("redis://localhost:6379/0", decode_responses=True)
await r.ping()
await r.aclose()

# pipeline（网络优化，默认非事务）
with r.pipeline() as pipe:
    pipe.set("k1", "v1").incr("c").rpush("log", "e1")
    results = pipe.execute()      # [True, 1, 1] 按入队序
```

## 九、危险命令清单（执行前停一秒）

| 命令 | 危险 | 安全替代 |
|------|------|----------|
| `KEYS *` | O(N) 阻塞全服务 | `SCAN` / `scan_iter` |
| `DEL 大key` | 释放内存卡住主线程 | `UNLINK` |
| `FLUSHDB` / `FLUSHALL` | 清库 / 清实例 | 无替代，靠权限控制 |
| `HGETALL`/`SMEMBERS`/`LRANGE 0 -1` 大 key | 全量传输 | `HMGET` / `SSCAN` / `HSCAN` / 具体区间 |
| `BLPOP ... 0` | 无限阻塞 | 带超时 + 判空 |
| `SET k v`（对带 TTL 的 k） | **TTL 被清空** | `SET k v KEEPTTL` |

## 十、中段速查（生产实践）

### 持久化配置（生产推荐形态）

```conf
save 3600 1
save 300 100
appendonly yes
appendfsync everysec            # 丢失窗口 ≤1s
aof-use-rdb-preamble yes        # 混合持久化 4.0+
auto-aof-rewrite-percentage 100
auto-aof-rewrite-min-size 64mb
dir /data
```

```bash
BGSAVE | BGREWRITEAOF | redis-check-aof --fix   # 恢复演练三件
INFO persistence      # rdb_last_save_time / aof_delayed_fsync
```

### Stream 消费者组

```
XADD k MAXLEN ~ 100000 * field value       # 生产（限长防膨胀）
XGROUP CREATE k 组 0                       # 建组（0=全量 $=只新）
XREADGROUP GROUP 组 消费者 COUNT 10 BLOCK 5000 STREAMS k >
XACK k 组 ID
XPENDING k 组 | XAUTOCLAIM k 组 消费者 60000 0 COUNT 10
XINFO GROUPS k | XRANGE k - + COUNT 10
```

```python
r.xgroup_create(STREAM, GROUP, id="0")     # BUSYGROUP = 已存在
r.xreadgroup(GROUP, CONSUMER, {STREAM: ">"}, count=10, block=5000)
r.xack(STREAM, GROUP, msg_id)
r.xautoclaim(STREAM, GROUP, CONSUMER, min_idle_time=60000, count=10)
```

### 事务 / 乐观锁 / 脚本

```
WATCH k → 读 → MULTI → 命令入队 → EXEC    # EXEC nil = 冲突，重试循环
EVAL "脚本" numkeys k1... a1...
```

```python
pipe = r.pipeline(transaction=True)        # MULTI/EXEC 打包
with r.pipeline() as pipe:
    pipe.watch("stock")                    # 乐观锁
    ...; pipe.multi(); pipe.set(...); pipe.execute()   # 冲突抛 WatchError
UNLOCK = r.register_script("...")          # EVALSHA/EVAL 自动回退
UNLOCK(keys=[...], args=[...])
```

### 分布式锁三零件

```
SET lock:key 唯一token NX PX 30000         # 原子抢占 + TTL 防死锁
释放必须 Lua：GET==token 才 DEL            # 防删别人的锁
```

```python
with r.lock("lock:key", timeout=30, blocking_timeout=5):
    ...                                    # redis-py 内置；长任务用 lock.extend() 续期
```

### 缓存模式

```
读: GET → 命中返回 / 未命中 → 查库 → SET ... EX (TTL+随机抖动)
写: 更新库 → DEL 缓存（延迟双删：隔 0.5~1s 再 DEL 一次）
穿透: 空值缓存 EX 60 | 布隆过滤器（BF.*）
击穿: SET lock:{key} 1 NX EX 10 互斥重建 | 逻辑过期
```

### 淘汰策略速查

| 场景 | 配置 |
|------|------|
| 纯缓存 | `maxmemory-policy allkeys-lru`（冷热分明用 allkeys-lfu） |
| 混布（存储键全带 TTL） | `volatile-lru` |
| 存储 | `noeviction` + 容量规划报警 |
| maxmemory | 物理内存 × 50~60%（给 COW/缓冲留余量） |

```
INFO memory   → used_memory_human(>70% 报警) / mem_fragmentation_ratio(>1.5 片化)
INFO stats    → evicted_keys（存储场景 >0 即事故）
```

### 监控指标速查

```
INFO clients      → connected_clients / blocked_clients
```

## 十一、速记口诀

| 场景 | 口诀 |
|------|------|
| 类型选型 | 整存整取 String，字段级 Hash，两端 List，判重在 Set，排名 ZSet |
| TTL | SET 覆盖 TTL 清，KEEPTTL 保平安；-1 永久 -2 无 |
| 遍历 | KEYS 一刀切，SCAN 分批走，游标归零才算完 |
| 删除 | 小键 DEL，大键 UNLINK |
| 计数 | 永远 INCR，绝不 GET+SET |
| ZSet 查询 | 默认按名次，BYSCORE 才分数 |
| 持久化 | 缓存可关持久化；要数据 AOF everysec + 混合；没演练的备份等于没备份 |
| 锁 | NX + PX + 唯一值 + Lua 释放；Redis 锁保效率不保正确 |
| 缓存 | 先库后删缓存；TTL 必带随机抖动；穿透空值、击穿互斥、雪崩抖动 |
| Stream | 不 ACK 就在 pending；XAUTOCLAIM 收僵尸；消费必须幂等 |
| 淘汰 | 缓存 allkeys-lru，存储 noeviction；maxmemory 只给六成 |
| 高可用 | 主从冗余、哨兵换主、集群分片；从库也要开 AOF |
| 一致性 | 先库后删缓存；双删异步、按 P99 定延迟；上了订阅就下双删 |
| 安全 | 不上公网、default 处理、ACL 最小权限、@dangerous 禁用 |
| 监控 | 内存七成、命中率八成、拒绝连接零容忍、fork 百毫秒关注 |
| Agent | 缓存可丢状态不丢；temperature=0 才缓存；集合必设上界；限流绑 Lua |
