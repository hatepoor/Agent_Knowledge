# SQLModel 模型定义

> SQLModel 模型 = 一个 Python 类，同时是 **SQLAlchemy 数据库表**（`table=True`）和 **Pydantic 校验模型**（默认）。字段类型即列类型，`Field()` 同时配置列属性和校验规则。

## 核心：`table=True` 参数

```python
from sqlmodel import SQLModel, Field

# ① 表模型：对应数据库中的一张表
class Hero(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str
    secret_name: str

# ② 纯校验模型：不建表，只做数据校验（API 请求/响应体）
class HeroIn(SQLModel):
    name: str
    secret_name: str
```

| | `table=True` | 默认（不写） |
|---|---|---|
| 建数据库表 | ✅ 是 | ❌ 否 |
| 进 `SQLModel.metadata` | ✅ | ❌ |
| 用途 | 数据库持久化 | API 请求/响应 Schema |
| 类比 | SQLAlchemy Model | 纯 Pydantic BaseModel |

**关键规则**：表模型中的字段**必须带默认值**（`Field(default=None)`）或设为可选——因为数据库列需要有可推断的定义。纯校验模型则无此限制。

## Field() 全参数详解

```python
class Hero(SQLModel, table=True):
    id: int | None = Field(
        default=None,           # 默认值
        primary_key=True,       # 主键
        index=True,             # 建数据库索引（加速查询）
    )
    name: str = Field(
        min_length=1,           # Pydantic 校验：最小长度
        max_length=50,          # Pydantic 校验：最大长度
        unique=True,            # 唯一约束（列级）
    )
    age: int | None = Field(
        default=None,
        ge=0,                   # Pydantic 校验：>= 0
        lt=150,                 # Pydantic 校验：< 150
        index=True,
    )
    team_id: int | None = Field(
        default=None,
        foreign_key="team.id",  # 外键：指向 team 表的 id 列
    )
```

| 参数 | 作用域 | 说明 |
|------|--------|------|
| `default` / `default_factory` | 列+校验 | 默认值 / 可变默认值工厂 |
| `primary_key` | 数据库列 | 主键 |
| `index` | 数据库列 | 建索引，加速 WHERE 查询 |
| `unique` | 数据库列 | 唯一约束 |
| `foreign_key` | 数据库列 | 外键，格式 `"表名.列名"` |
| `nullable` | 数据库列 | 是否允许 NULL（通常由类型推断） |
| `min_length` / `max_length` | Pydantic | 字符串长度校验 |
| `ge` / `gt` / `le` / `lt` | Pydantic | 数值范围校验 |
| `pattern` | Pydantic | 正则校验 |
| `description` | Pydantic | 字段说明（OpenAPI 文档） |
| `alias` | Pydantic | 字段别名 |

> **一个 `Field()` 管两层**：`index`/`foreign_key`/`unique` 生成数据库 DDL；`ge`/`min_length`/`pattern` 是 Pydantic 校验，实例化时就生效。

## 类型与列类型映射

```python
class User(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str                    # VARCHAR
    age: int                     # INTEGER
    score: float                 # FLOAT
    is_active: bool              # BOOLEAN
    bio: str | None              # VARCHAR NULLABLE
    tags: list[str]              # JSON（SQLite 下自动转 JSON 存储）
    created_at: datetime         # DATETIME
```

| Python 类型 | SQL 列类型 |
|-------------|-----------|
| `str` | VARCHAR |
| `int` | INTEGER |
| `float` | FLOAT / REAL |
| `bool` | BOOLEAN |
| `datetime` | DATETIME / TIMESTAMP |
| `list[...]` / `dict[...]` | JSON（需数据库支持） |
| `Optional[X]` / `X \| None` | 可空列 |

## 建表：`SQLModel.metadata.create_all`

```python
from sqlmodel import SQLModel, create_engine

engine = create_engine("sqlite:///database.db")
SQLModel.metadata.create_all(engine)
# 扫描所有 table=True 的模型 → 在数据库中创建缺失的表
# 幂等：重复执行安全，已存在的表跳过
```

**注意**：`create_all` 只**建新表**，不修改已存在的表结构。改字段后需迁移工具（Alembic），不能靠它自动 ALTER。

## 模型的双重身份（关键理解）

```python
class Hero(SQLModel, table=True):
    ...

# ① 作为 SQLAlchemy 模型：存入数据库
with Session(engine) as session:
    session.add(Hero(name="Deadpond", secret_name="Dive Wilson"))
    session.commit()

# ② 作为 Pydantic 模型：校验 + 序列化
hero = Hero(name="Spider-Boy", secret_name="Pedro Parqueador")
hero.model_dump()       # Pydantic 方法：→ dict
Hero.model_validate({}) # Pydantic 方法：dict → 模型（自动校验）
```

## 常见误区

```python
# ❌ 表模型字段没有默认值/可选
class Bad(SQLModel, table=True):
    name: str = Field()    # 报错：表模型字段必须有默认值或可选
    # 原因：数据库列定义需要能推断出完整信息

# ✅ 正确
class Good(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str = Field(default="")

# ❌ 一个类既是表又要做 API 响应体（表模型会暴露所有列）
# ✅ 正确做法：表模型 + 单独的非表 Schema 模型
class HeroBase(SQLModel):
    name: str
    secret_name: str

class Hero(HeroBase, table=True):   # 表模型继承基类
    id: int | None = Field(default=None, primary_key=True)

class HeroRead(HeroBase):            # 纯校验模型（响应用）
    id: int
```
