# SQLModel 查询进阶

> 查询的核心是 `select()` 构建 SQL 语句 + `session.exec()` 执行。本节覆盖过滤、排序、聚合、JOIN、分页等进阶用法，全部用 SQLModel 风格编写。

## 基础回顾

```python
from sqlmodel import Session, select

with Session(engine) as session:
    heroes = session.exec(select(Hero)).all()          # 全部
    hero = session.exec(select(Hero).where(Hero.name == "Deadpond")).first()
```

## 一、条件过滤 `.where()`

### 逻辑运算

```python
# 与：多个条件并列
select(Hero).where(Hero.age > 30, Hero.name == "Deadpond")
# 等价 AND

# 或
from sqlalchemy import or_, and_

select(Hero).where(or_(Hero.age < 18, Hero.age > 60))

# 非（不等于）
select(Hero).where(Hero.name != "Deadpond")
```

### 常用操作符

| 需求 | SQL | SQLModel |
|------|-----|----------|
| 等于 | `=` | `Hero.name == "x"` |
| 不等于 | `<>` | `Hero.name != "x"` |
| 大于/小于 | `> <` | `Hero.age > 30` |
| 大于等于 | `>=` | `Hero.age >= 18` |
| 包含 | `IN` | `Hero.name.in_(["a", "b"])` |
| 模糊 | `LIKE` | `Hero.name.like("%man%")` |
| 为空 | `IS NULL` | `Hero.age.is_(None)` |
| 非空 | `IS NOT NULL` | `Hero.age.is_not(None)` |
| 范围 | `BETWEEN` | `Hero.age.between(18, 60)` |

```python
# 实际使用
with Session(engine) as session:
    # NULL 判断（注意：不能用 == None）
    no_age = session.exec(select(Hero).where(Hero.age.is_(None))).all()

    # 包含
    names = session.exec(select(Hero).where(Hero.name.in_(["a", "b"]))).all()

    # 模糊匹配
    like = session.exec(select(Hero).where(Hero.name.like("%man%"))).all()
```

> **坑**：判空必须用 `Hero.age.is_(None)`，不能用 `Hero.age == None`（会被当作恒假表达式）。

## 二、排序 `.order_by()`

```python
from sqlmodel import col

# 升序
select(Hero).order_by(Hero.age)

# 降序
select(Hero).order_by(Hero.age.desc())

# 多字段排序
select(Hero).order_by(Hero.age.desc(), Hero.name)
# 先按 age 降序，age 相同再按 name 升序

# 字符串字段用 col() 排序（消除歧义）
select(Hero).order_by(col(Hero.name))
```

## 三、分页 `.offset()` + `.limit()`

```python
# 第 2 页，每页 10 条
page, page_size = 2, 10
statement = (
    select(Hero)
    .order_by(Hero.id)
    .offset((page - 1) * page_size)   # 跳过前 10 条
    .limit(page_size)                  # 最多取 10 条
)
heroes = session.exec(statement).all()
```

## 四、聚合函数

```python
from sqlalchemy import func

# 计数
count = session.exec(select(func.count()).select_from(Hero)).one()

# 最大值 / 最小值 / 平均值
max_age = session.exec(select(func.max(Hero.age))).one()
min_age = session.exec(select(func.min(Hero.age))).one()
avg_age = session.exec(select(func.avg(Hero.age))).one()

# 分组统计
rows = session.exec(
    select(Hero.team_id, func.count(Hero.id))
    .group_by(Hero.team_id)
).all()
# [(team_id, 数量), ...]
```

## 五、JOIN 关联查询

```python
# 模型（Team 与 Hero 一对多）
class Team(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str
    headquarters: str

class Hero(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str
    secret_name: str
    age: int | None = None
    team_id: int | None = Field(default=None, foreign_key="team.id")
```

### 隐式 JOIN（用关系属性）

```python
from sqlmodel import Relationship

# 在模型上加 relationship 属性后：
class Team(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str
    headquarters: str
    heroes: list["Hero"] = Relationship(back_populates="team")

class Hero(SQLModel, table=True):
    ...
    team_id: int | None = Field(default=None, foreign_key="team.id")
    team: "Team | None" = Relationship(back_populates="heroes")

with Session(engine) as session:
    # 拿到英雄的所属队伍（自动 JOIN）
    hero = session.exec(select(Hero).where(Hero.name == "Deadpond")).one()
    print(hero.team.name)          # 自动跨表取数据
```

> 详细关系配置见 [[sqlmodel/关系与关联]]。

### 显式 JOIN

```python
from sqlmodel import select

statement = (
    select(Hero, Team)
    .join(Team, Hero.team_id == Team.id)   # JOIN team 表
    .where(Team.name == "Z-Force")
)
rows = session.exec(statement).all()
# rows: list[tuple[Hero, Team]] —— 每行是 (英雄, 队伍) 元组

for hero, team in rows:
    print(hero.name, "→", team.name)
```

| JOIN 类型 | SQLModel 方法 |
|-----------|--------------|
| INNER JOIN | `.join(Team, 条件)` |
| LEFT JOIN | `.join(Team, 条件, isouter=True)` |
