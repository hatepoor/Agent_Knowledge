# SQLModel 概述

> SQLModel 是 FastAPI 作者（Sebastián Ramírez）开发的 ORM 库，核心价值是 **"一个类同时是 SQLAlchemy 模型 + Pydantic 模型"**——定义一次字段，同时获得数据库持久化和请求校验能力。官方定位：`SQLAlchemy 遇上 Pydantic`。

## 解决的问题

SQLModel 出现之前，同一个数据库表要维护**两份类定义**：

```python
# 旧��案：一个表两个类，字段定义写两遍
class HeroDB(SQLAlchemy.BaseModel):      # ① ��据库模型（SQLAlchemy）
    name: str
    secret_name: str

class HeroIn(Pydantic.BaseModel):        # ② 请求校验模型（Pydantic）
    name: str
    secret_name: str
# 字段重复定义、校验规则重复写、改一处要同步两处 → 维护噩梦
```

SQLModel 合并为**一个类**：

```python
class Hero(SQLModel, table=True):        # 一个类：既是表又是校验模型
    id: int | None = Field(default=None, primary_key=True)
    name: str
    secret_name: str
```

## 三个核心概念

| 概念 | 说明 | 详情页 |
|------|------|--------|
| **模型定义** | `table=True` 控制"是表还是纯校验模型"；`Field` 同时管列属性与 Pydantic 校验 | [[sqlmodel/模型定义]] |
| **CRUD 与查询** | `Session` + `select()` 完成增删改查；`session.exec()` 是 SQLModel 特色（替代 SQLAlchemy 的 `session.execute()`） | [[sqlmodel/CRUD操作]]、[[sqlmodel/查询进阶]] |
| **关系与关联** | `foreign_key` + `relationship` 处理一对多/多对多，`Link` 模型做关联表 | [[sqlmodel/关系与关联]] |
| **引擎与 Session** | `create_engine` 连接数据库，内存库/外键/线程等防坑配置 | [[sqlmodel/引擎与Session]] |
