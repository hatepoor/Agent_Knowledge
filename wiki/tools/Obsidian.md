# Obsidian

## 概述

基于本地 Markdown 文件的知识管理应用，支持双向链接（wikilinks）、图谱视图和插件生态。本知识库即使用 Obsidian 作为浏览和组织环境。

## 关键属性
- 存储格式：本地 Markdown 文件（纯文本，可 Git 版本控制）
- 核心特性：`[[wikilink]]` 双向链接、图谱视图、YAML frontmatter
- 插件生态：Dataview、Templater、Web Clipper 等
