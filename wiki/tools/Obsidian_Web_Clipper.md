# Obsidian Web Clipper

## 概述

Obsidian 官方浏览器扩展，将网页文章一键剪裁为 Markdown 文件并保存到 Obsidian 库中，是知识库 `raw/` 来源收集的便捷工具。

## 关键属性
- 类型：浏览器扩展（Chrome/Firefox）
- 功能：网页 → Markdown 转换 + 保存到指定 Obsidian 库
- 用途：快速将网络文章作为来源文档导入知识库
