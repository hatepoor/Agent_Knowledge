# FAISS

## 概述

FAISS（Facebook AI Similarity Search）是 Meta 开源的向量相似度搜索库。它**不是数据库**，而是一个纯计算库——只做向量的索引和搜索，没有持久化、没有服务端、没有并发管理。

类比：FAISS 之于向量数据库，就像 numpy 之于数据分析。它是最底层的计算引擎，其他产品（包括 Chroma 的早期版本）都在它之上构建。

## 定位与适用场景

| 场景 | 是否适合 | 说明 |
|------|----------|------|
| 算法研究和实验 | 非常适合 | 可以自定义索引算法，最灵活 |
| 性能基准测试 | 非常适合 | 可以精确控制索引参数 |
| 大规模离线索引 | 适合 | 支持 GPU 加速，可以处理十亿级向量 |
| 生产环境直接使用 | 不适合 | 没有持久化、没有服务端、没有并发控制 |
| RAG 应用开发 | 不适合 | 没有元数据过滤、没有文本存储 |

## 安装

```bash
# CPU 版
pip install faiss-cpu

# GPU 版（需要 CUDA）
pip install faiss-gpu
```

## 基本使用

```python
import faiss
import numpy as np

# 维度
d = 768

# 创建索引
index = faiss.IndexFlatL2(d)  # L2 距离，暴力搜索（精确）

# 添加向量
vectors = np.random.random((10000, d)).astype("float32")
faiss.normalize_L2(vectors)  # 归一化（用于余弦相似度）
index.add(vectors)

# 查询
query = np.random.random((1, d)).astype("float32")
faiss.normalize_L2(query)
distances, indices = index.search(query, k=5)

print(f"最近邻 ID: {indices[0]}")
print(f"距离: {distances[0]}")
```

## 索引类型

FAISS 提供多种索引，这是它比 Chroma 灵活的核心原因：

```python
# 1. Flat —— 精确暴力搜索
index = faiss.IndexFlatL2(d)        # L2 距离
index = faiss.IndexFlatIP(d)        # 内积

# 2. IVF —— 倒排文件索引（先聚类再搜索）
quantizer = faiss.IndexFlatL2(d)
index = faiss.IndexIVFFlat(quantizer, d, nlist=100)  # 100 个聚类中心
index.train(vectors)   # 必须先训练
index.add(vectors)
index.nprobe = 10      # 搜索时检查 10 个聚类

# 3. HNSW —— 图索引
index = faiss.IndexHNSWFlat(d, M=32)  # M=每个节点的连接数

# 4. PQ —— 乘积量化（压缩向量）
index = faiss.IndexPQ(d, m=8, nbits=8)  # 8 个子空间，每个 8 bit
index.train(vectors)
index.add(vectors)

# 5. 组合索引
# IVF + PQ：先聚类再量化，适合大规模
index = faiss.IndexIVFPQ(quantizer, d, nlist=100, m=8, nbits=8)
```

| 索引 | 速度 | 精度 | 内存 | 适用规模 |
|------|------|------|------|----------|
| Flat | 最慢 | 100% | 低 | < 10 万 |
| IVF | 快 | 高 | 中 | 百万级 |
| HNSW | 最快 | 很高 | 高 | 百万级 |
| PQ | 快 | 中 | 最低 | 十亿级 |
| IVF+PQ | 快 | 中 | 低 | 十亿级 |

## 持久化（手动）

FAISS 没有自动持久化，需要手动保存和加载：

```python
# 保存
faiss.write_index(index, "my_index.faiss")

# 加载
index = faiss.read_index("my_index.faiss")
```

## GPU 加速

```python
# 将索引转移到 GPU
res = faiss.StandardGpuResources()
gpu_index = faiss.index_cpu_to_gpu(res, 0, index)  # GPU 0

# 批量 GPU
gpu_index = faiss.index_cpu_to_all_gpus(index)
```

GPU 加速在构建大规模索引时效果显著（10-100 倍加速），但查询时提升不明显。

## 与 Chroma 的区别

| | FAISS | Chroma |
|---|---|---|
| 本质 | 算法库 | 数据库 |
| 文本存储 | 无（只存向量） | 有（SQLite） |
| 元数据过滤 | 无 | 有 |
| 持久化 | 手动 | 自动 |
| 索引算法 | 可自选 | 固定 HNSW |
| GPU 支持 | 有 | 无 |
| LangChain 集成 | 需封装 | 原生支持 |
