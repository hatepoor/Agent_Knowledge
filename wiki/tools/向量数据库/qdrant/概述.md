# Qdrant

## 概述

Qdrant 是用 Rust 编写的开源向量数据库，以**单节点高性能**著称。相比 Milvus 的分布式复杂度，Qdrant 在单机或小集群上就能提供生产级的性能和可靠性。

## 定位与适用场景

| 场景 | 是否适合 | 说明 |
|------|----------|------|
| 生产环境（百万-千万级） | 非常适合 | Rust 实现，单节点性能极强 |
| 过滤密集型查询 | 非常适合 | 标量过滤性能优于 Milvus 和 Chroma |
| 多模态检索 | 适合 | 支持多种向量类型 |
| 中小团队 | 适合 | Docker 单机部署，运维简单 |
| 超大规模（十亿级） | 可以 | 支持分布式，但不如 Milvus 成熟 |
| 快速原型 | 一般 | API 比 Chroma 复杂一点 |

## 安装

```bash
# Docker（推荐）
docker run -p 6333:6333 -p 6334:6334 \
    -v ./qdrant_data:/qdrant/storage \
    qdrant/qdrant

# Python 客户端
pip install qdrant-client
```

## 基本使用

```python
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams, PointStruct

client = QdrantClient(host="localhost", port=6333)

# 创建 collection
client.create_collection(
    collection_name="my_docs",
    vectors_config=VectorParams(size=768, distance=Distance.COSINE),
)

# 插入数据
points = [
    PointStruct(
        id=1,
        vector=[0.1, 0.2, ...],  # 768 维
        payload={"text": "文档1", "source": "wiki"},
    ),
    PointStruct(
        id=2,
        vector=[0.3, 0.4, ...],
        payload={"text": "文档2", "source": "blog"},
    ),
]
client.upsert(collection_name="my_docs", points=points)

# 查询
results = client.query_points(
    collection_name="my_docs",
    query=[0.1, 0.2, ...],
    limit=5,
)
```

## 核心优势：过滤性能

Qdrant 的标量过滤在查询时**不会降级向量搜索性能**，这是它相比其他向量库的核心优势：

```python
from qdrant_client.models import Filter, FieldCondition, MatchValue

# 复杂过滤 + 向量搜索，性能依然很好
results = client.query_points(
    collection_name="my_docs",
    query=[0.1, 0.2, ...],
    query_filter=Filter(
        must=[
            FieldCondition(key="source", match=MatchValue(value="wiki")),
            FieldCondition(key="year", range={"gte": 2024}),
        ]
    ),
    limit=10,
)
```

## 多种向量存储

```python
# 一个 collection 可以有多个命名向量
client.create_collection(
    collection_name="multimodal",
    vectors_config={
        "text": VectorParams(size=768, distance=Distance.COSINE),
        "image": VectorParams(size=512, distance=Distance.EUCLID),
    },
)

# 插入时指定向量名称
client.upsert(collection_name="multimodal", points=[
    PointStruct(
        id=1,
        vector={"text": text_vec, "image": image_vec},
        payload={"text": "描述", "image_path": "img.png"},
    ),
])

# 按名称查询
results = client.query_points(
    collection_name="multimodal",
    using="text",  # 用文本向量搜索
    query=text_query,
    limit=5,
)
```

## 与 LangChain 集成

```python
from langchain_qdrant import QdrantVectorStore
from langchain_openai import OpenAIEmbeddings

vectorstore = QdrantVectorStore.from_documents(
    documents=docs,
    embedding=OpenAIEmbeddings(),
    url="http://localhost:6333",
    collection_name="my_docs",
)

results = vectorstore.similarity_search("查询", k=5)
```

## 与 Milvus 和 Chroma 对比

| | Qdrant | Milvus | Chroma |
|---|---|---|---|
| 语言 | Rust | Go+C++ | Python |
| 部署 | Docker 单机 | Docker/K8s | pip install |
| 单机性能 | 最强 | 一般 | 一般 |
| 分布式 | 支持（较新） | 成熟 | 不支持 |
| 过滤性能 | 最优 | 好 | 一般 |
| 多向量 | 支持 | 支持 | 不支持 |
| 运维复杂度 | 低 | 高 | 极低 |
