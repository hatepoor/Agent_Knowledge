# Pinecone

## 概述

Pinecone 是**全托管的向量数据库 SaaS 服务**。注册账号、拿到 API Key 就能用，不需要部署任何东西。适合不想运维基础设施、愿意付费换省心的团队。

## 定位与适用场景

| 场景 | 是否适合 | 说明 |
|------|----------|------|
| 零运维需求 | 非常适合 | 全托管，不用管服务器 |
| 快速上线产品 | 非常适合 | 注册即用，几分钟搞定 |
| 企业级生产 | 适合 | 高可用、自动扩缩、SOC2 合规 |
| 预算有限 | 不适合 | 免费额度有限，超出后按量计费 |
| 数据合规要求高 | 看情况 | 数据存在 Pinecone 的云上，部分地区有限制 |
| 离线开发 | 不适合 | 必须联网，没有本地版本 |

## 使用

### 注册

访问 [pinecone.io](https://pinecone.io) 注册账号，创建 Index，获取 API Key。

### 基本操作

```python
from pinecone import Pinecone

pc = Pinecone(api_key="your-api-key")

# 创建 Index（或通过 Web 界面创建）
pc.create_index(
    name="my-docs",
    dimension=768,
    metric="cosine",
    spec=pc.ServerlessSpec(cloud="aws", region="us-east-1"),
)

index = pc.Index("my-docs")

# 插入数据
index.upsert(vectors=[
    {"id": "doc1", "values": [0.1, 0.2, ...], "metadata": {"text": "文档1"}},
    {"id": "doc2", "values": [0.3, 0.4, ...], "metadata": {"text": "文档2"}},
])

# 查询
results = index.query(
    vector=[0.1, 0.2, ...],
    top_k=5,
    include_metadata=True,
)

# 带过滤
results = index.query(
    vector=[0.1, 0.2, ...],
    top_k=5,
    filter={"source": {"$eq": "wiki"}},
    include_metadata=True,
)
```

## 与 LangChain 集成

```python
from langchain_pinecone import PineconeVectorStore
from langchain_openai import OpenAIEmbeddings

vectorstore = PineconeVectorStore(
    index=index,
    embedding=OpenAIEmbeddings(),
)

vectorstore.add_documents(docs)
results = vectorstore.similarity_search("查询", k=5)
```

## 定价

| 方案 | 免费额度 | 超出后 |
|------|----------|--------|
| Starter（免费） | 最多 2000 条向量，1 个 Index | 不可扩展 |
| Serverless | 按量计费 | ~$0.0007 / 1000 次读写 |
| Dedicated | 固定月费 | 高并发场景更划算 |

## 与自托管方案对比

| | Pinecone | Chroma | Qdrant | Milvus |
|---|---|---|---|---|
| 部署 | 无（全托管） | pip install | Docker | Docker/K8s |
| 运维 | 零 | 低 | 低 | 高 |
| 成本 | 付费 | 免费 | 免费 | 免费 |
| 数据控制 | 在云上 | 本地 | 本地 | 本地 |
| 离线使用 | 不可以 | 可以 | 可以 | 可以 |
| 开源 | 否 | 是 | 是 | 是 |
