# Chroma

## 概述

Chroma 是一个开源的嵌入式向量数据库，专为 AI 应用和 Embedding 检索设计。它是当前最流行的轻量级向量数据库，可以直接嵌入 Python 进程，无需独立服务器。

## 定位

Chroma 的核心定位是**开发友好、快速原型**。它牺牲了分布式扩展能力，换来了极低的上手成本和最简单的部署方式。类比关系：Chroma 之于向量数据库，就像 SQLite 之于关系数据库。

## 核心特性

- **嵌入式运行**：直接 `import chromadb`，不需要启动任何服务
- **极简 API**：Collection 的 add/query/delete/get 四个核心方法
- **自动 Embedding**：内置默认 Embedding 函数（all-MiniLM-L6-v2），也可自定义
- **持久化存储**：后端支持 SQLite（默认）和 DuckDB
- **元数据过滤**：支持基于 metadata 的条件过滤 + 向量检索组合查询
- **多距离度量**：余弦相似度（默认）、欧氏距离、内积

## 适用场景

| 场景 | 是否适合 | 说明 |
|------|----------|------|
| 学习向量数据库概念 | 非常适合 | 三行代码跑起来，理解向量检索原理 |
| RAG 原型开发 | 非常适合 | 和 LangChain/LlamaIndex 集成最顺滑 |
| 个人项目 / 小工具 | 适合 | 几千到几万条文档完全够用 |
| 中小规模生产（< 50 万向量） | 可以 | 单机部署，需要评估性能 |
| 大规模生产（百万级以上） | 不适合 | 没有分布式能力，考虑 Qdrant/Milvus |
| 多模态检索 | 不适合 | 原生不支持多模态 Embedding |
