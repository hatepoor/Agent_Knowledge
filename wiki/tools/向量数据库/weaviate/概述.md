# Weaviate

## 概述

Weaviate 是开源的向量数据库，核心特色是**原生多模态支持**和 **GraphQL 查询接口**。它不仅能做向量搜索，还内置了向量化模块（Vectorizer），可以自动调用 Embedding 模型。

## 定位与适用场景

| 场景 | 是否适合 | 说明 |
|------|----------|------|
| 多模态检索（图文混合） | 非常适合 | 原生支持 CLIP 等多模态向量 |
| 知识图谱 + 向量 | 适合 | GraphQL 接口适合关联查询 |
| 需要内置向量化 | 适合 | Vectorizer 模块自动调用 Embedding API |
| 生产环境 | 适合 | 支持分布式，有云服务 |
| 纯文本 RAG | 一般 | 功能过剩，用 Chroma 更简单 |
| 快速原型 | 一般 | 概念多，学习曲线较陡 |

## 基本使用

```python
import weaviate

client = weaviate.connect_to_local()

# 创建 collection（Weaviate 叫 class）
client.collections.create(
    name="Document",
    properties=[
        {"name": "content", "dataType": ["text"]},
        {"name": "source", "dataType": ["text"]},
    ],
    vectorizer_config=weaviate.classes.config.Configure.Vectorizer.text2vec_openai(
        model="text-embedding-3-small",
    ),
)

# 插入数据（Weaviate 自动向量化！）
collection = client.collections.get("Document")
collection.data.insert(
    properties={"content": "LangChain 是 LLM 应用框架", "source": "wiki"},
)

# 查询
results = collection.query.near_text(
    query="什么是 LangChain？",
    limit=5,
)
```

## 核心特色

### 内置向量化（Vectorizer）

Weaviate 最大的特色：**插入文本时自动调用 Embedding API，不需要你自己算向量**。

```python
# 配置 OpenAI 向量化
collection = client.collections.create(
    name="Doc",
    vectorizer_config=Configure.Vectorizer.text2vec_openai(model="text-embedding-3-small"),
)
# 插入时只传文本，Weaviate 自动向量化
collection.data.insert(properties={"content": "..."})

# 也支持本地模型
Configure.Vectorizer.text2vec_transformers(model="BAAI/bge-small-zh-v1.5")

# 支持 Cohere、HuggingFace、Jina 等
```

### 多模态

```python
# 配置 CLIP 多模态
collection = client.collections.create(
    name="MultimodalDoc",
    vectorizer_config=Configure.Vectorizer.multi2vec_clip(
        image_fields=["image"],
        text_fields=["text"],
    ),
)

# 插入图片 + 文本
import base64
with open("photo.jpg", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()

collection.data.insert(
    properties={"text": "描述文本", "image": img_b64},
)

# 用文本搜索图片
results = collection.query.near_text(query="一只猫", limit=5)
# 用图片搜索文本
results = collection.query.near_image(image=img_b64, limit=5)
```

### GraphQL 查询

```python
# GraphQL 风格的关联查询
result = client.graphql.get(
    "Document",
    ["content", "source", "_additional { certainty }"],
    near_text={"concepts": ["AI 框架"]},
    where={"path": ["source"], "operator": "Equal", "valueText": "wiki"},
    limit=10,
)
```

## 与 LangChain 集成

```python
from langchain_weaviate import WeaviateVectorStore
from langchain_openai import OpenAIEmbeddings

vectorstore = WeaviateVectorStore(
    client=client,
    embedding=OpenAIEmbeddings(),
    index_name="Document",
    text_key="content",
)

results = vectorstore.similarity_search("查询", k=5)
```

## 与其他向量库对比

| | Weaviate | Milvus | Chroma | Qdrant |
|---|---|---|---|---|
| 多模态 | 原生支持 | 支持 | 不支持 | 支持 |
| 内置向量化 | 有（Vectorizer） | 无 | 有（默认模型） | 无 |
| 查询接口 | GraphQL + REST | gRPC + REST | REST | REST + gRPC |
| 部署复杂度 | 中 | 高 | 极低 | 低 |
| 学习曲线 | 陡 | 陡 | 平缓 | 中等 |
