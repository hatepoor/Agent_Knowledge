# Milvus

## 概述

Milvus 是 Zilliz 开源的分布式向量数据库，专为大规模生产环境设计。支持十亿级向量、多副本高可用、云原生架构。是当前功能最完整的开源向量数据库之一。

## 定位与适用场景

| 场景 | 是否适合 | 说明 |
|------|----------|------|
| 大规模生产（亿级向量） | 非常适合 | 原生分布式，水平扩展 |
| 高并发查询 | 非常适合 | 支持多副本读写分离 |
| 多模态检索 | 适合 | 支持多种向量类型和混合检索 |
| 多租户 | 适合 | 原生支持 partition 和 RBAC |
| 中小项目 | 不适合 | 部署复杂，运维成本高 |
| 快速原型 | 不适合 | 用 Chroma 或 Qdrant 更简单 |

## 架构

Milvus 采用存算分离架构：

```
接入层（Proxy）── 处理客户端请求
    ↓
协调服务（Root Coord / Query Coord / Data Coord / Index Coord）
    ↓
计算层（Query Node / Data Node / Index Node）── 无状态，可水平扩展
    ↓
存储层（etcd 元数据 + MinIO 对象存储 + Pulsar/Kafka 消息队列）
```

这意味着你需要部署至少 4-5 个组件，通常通过 Kubernetes 管理。

## 安装

### Docker（单机版 Lite）

```bash
# Milvus Lite —— 单机嵌入式版本（类似 Chroma 的体验）
pip install pymilvus

# 或 Docker Compose（完整版）
docker compose up -d
```

### Kubernetes（生产）

```bash
helm repo add milvus https://zilliztech.github.io/milvus-helm/
helm install milvus milvus/milvus
```

## 基本使用

```python
from pymilvus import (
    connections, Collection, FieldSchema,
    CollectionSchema, DataType, utility
)

# 1. 连接
connections.connect(host="localhost", port="19530")

# 2. 定义 Schema
fields = [
    FieldSchema(name="id", dtype=DataType.INT64, is_primary=True, auto_id=True),
    FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=768),
    FieldSchema(name="text", dtype=DataType.VARCHAR, max_length=65535),
]
schema = CollectionSchema(fields)
collection = Collection("my_docs", schema)

# 3. 创建索引
collection.create_index(
    field_name="embedding",
    index_params={"index_type": "HNSW", "metric_type": "COSINE", "params": {"M": 16, "efConstruction": 200}}
)

# 4. 插入数据
import numpy as np
texts = ["文档1", "文档2"]
embeddings = np.random.random((2, 768)).tolist()
collection.insert([embeddings, texts])

# 5. 查询（需要先 load 到内存）
collection.load()
results = collection.search(
    data=[embeddings[0]],
    anns_field="embedding",
    param={"metric_type": "COSINE", "params": {"ef": 50}},
    limit=5,
    output_fields=["text"],
)
```

## 核心特性

### 多种索引

| 索引 | 特点 |
|------|------|
| HNSW | 默认推荐，速度和精度平衡 |
| IVF_FLAT | 倒排文件 + 精确搜索 |
| IVF_PQ | 倒排文件 + 量化压缩 |
| ANNOY | Spotify 的树索引 |
| DISKANN | 磁盘索引，适合超大规模 |

### Partition 和 Partition Key

```python
# 按主题分区
collection.create_partition("python_docs")
collection.create_partition("java_docs")

# 查询时指定分区
results = collection.search(..., partition_names=["python_docs"])
```

### 混合检索

```python
# 向量搜索 + 标量过滤
results = collection.search(
    data=[query_vector],
    anns_field="embedding",
    param={"metric_type": "COSINE"},
    limit=10,
    expr='category == "tutorial" and year > 2024',  # 标量过滤
    output_fields=["text", "category"],
)
```

## Milvus Lite

Milvus 2.4+ 提供了 Lite 版本，可以像 Chroma 一样嵌入式使用：

```python
from pymilvus import MilvusClient

client = MilvusClient(uri="./milvus_demo.db")  # 本地文件
client.create_collection(
    collection_name="demo",
    dimension=768,
)

# 插入
client.insert(collection_name="demo", data=[
    {"id": 1, "vector": [0.1, 0.2, ...], "text": "文档1"}
])

# 查询
results = client.search(
    collection_name="demo",
    data=[[0.1, 0.2, ...]],
    limit=5,
)
```

Milvus Lite 适合开发调试，但生产环境建议用完整版。

## 与 Chroma 的区别

| | Milvus | Chroma |
|---|---|---|
| 部署 | Docker/K8s（复杂） | pip install（极简） |
| 扩展性 | 水平扩展，十亿级 | 单机，几十万级 |
| 索引选择 | 多种可选 | 固定 HNSW |
| 多租户 | 原生支持 | 不支持 |
| 运维成本 | 高 | 几乎为零 |
| Lite 版本 | 有（2.4+） | 本身就是 Lite |
