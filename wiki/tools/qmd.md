# qmd

## 概述

qmd 是一个针对 Markdown 文件的本地搜索引擎，支持混合 BM25 / 向量搜索和 LLM 重排序。它既有 CLI（LLM 可以 shell 调用），也有 MCP 服务器（LLM 可以将其作为原生工具使用）。

## 核心特性

- **混合搜索**：结合 BM25 关键词搜索和向量语义搜索
- **LLM 重排序**：使用 LLM 对搜索结果进行重排序，提升相关性
- **本地运行**：所有操作在本地完成，无需联网
- **MCP 支持**：可作为 MCP 服务器供 LLM 原生调用

## 在知识库工作流中的应用

当 wiki 规模增长到一定程度（数百页面以上），简单的索引文件可能不够高效。qmd 可以提供：
- 更精准的页面搜索
- 基于语义的相似内容发现
- 支持 LLM 自动查询 wiki 内容

## 与 Wiki 模式的关系

qmd 可以作为 wiki 模式的上层搜索增强。在 wiki 已建立结构化知识的基础上，qmd 提供快速检索能力，实现"编译 + 检索"的混合方案。
