# ChatGPT File Uploads

## 概述

OpenAI ChatGPT 的文件上传功能，允许用户上传 PDF、CSV 等文档，ChatGPT 基于上传内容回答问题。这是一种轻量级 RAG 实现。

## 关键属性
- 开发商：OpenAI
- RAG 模式：上传文件 → 自动解析 → 基于文件内容问答
- 特点：零配置 RAG，适合快速验证
