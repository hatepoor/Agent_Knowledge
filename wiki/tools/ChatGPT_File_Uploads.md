# ChatGPT File Uploads

## 概述

ChatGPT File Uploads 是 OpenAI 为 ChatGPT 提供的文件上传与分析功能。用户可以将文档（PDF、Word、图片、代码文件、数据文件等）上传到对话中，模型基于文件内容回答问题或执行分析。其进阶形态 **Advanced Data Analysis**（原 Code Interpreter）可在沙箱中执行代码进行深度数据处理。

## 核心特性

- **多格式支持**：PDF、Word、Excel、CSV、图片、音频、代码文件（Python/JS 等）、JSON、ZIP 等
- **上下文分析**：模型读取文件内容，结合对话上下文回答问题
- **Advanced Data Analysis**：在代码沙箱中执行 Python 代码进行数据分析、可视化、文件处理
- **多文件同时处理**：支持上传多个文件并交叉分析
- **图像理解**：GPT-4o 可分析上传图片内容（OCR、图表解读、视觉问答）

## 典型使用场景

- **文档摘要**：上传长文档，快速提取要点和结论
- **数据分析**：上传 CSV/Excel，生成统计分析和可视化图表
- **代码分析**：上传代码文件，获取解释、重构建议或 Bug 诊断
- **格式转换**：在沙箱中执行文件格式转换（如 CSV → JSON）
- **图像处理**：上传图片进行 OCR 识别、图像分析或简单编辑

## 局限性

- **临时性**：文件与对话绑定，关闭对话后不可访问，不持久化到知识库
- **无跨对话累积**：每次新对话从零开始，无法积累分析历史
- **文件大小限制**：单文件 512MB，免费版有使用频次限制
- **无交叉引用**：多个文件之间不建立持久化的关联关系
- **不可编程**：无法通过 API 定制检索逻辑或集成到工作流中

## 与 Wiki 模式的关系

ChatGPT 文件上传是 **RAG 模式的简单实现**：

| 维度 | ChatGPT 文件上传 | [[meta/LLM_Wiki_方法论|Wiki 模式]] |
|------|-----------------|-------------|
| 持久化 | 临时（对话结束即失） | 持久（wiki 持续累积） |
| 交叉引用 | 无 | 预先建立的链接网络 |
| 累积性 | 每次从零开始 | 增量编译，越用越丰富 |
| 可定制性 | 低 | 完全可控（Schema 定义结构） |
| 适合场景 | 临时性一次性分析 | 长期知识积累和体系化研究 |

## 与 NotebookLM 的对比

两者都是 Google/OpenAI 生态中 RAG 模式的产品实现：

| 维度 | ChatGPT File Uploads | [[tools/NotebookLM]] |
|------|---------------------|---------------------|
| 来源数量 | 单对话多文件 | 多来源持续引用 |
| 持久化 | 临时 | 笔记本级别持久 |
| 音频输出 | 无 | Audio Overview（播客） |
| 交叉引用 | 无 | 来源间交叉引用 |
| 定位 | 通用对话 + 文件分析 | 专项研究助手 |
