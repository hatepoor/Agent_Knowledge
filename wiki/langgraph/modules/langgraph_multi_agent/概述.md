# 多智能体概述

多智能体系统（Multi-Agent System）是 LangGraph 的高级应用模式，允许多个 AI 智能体协作完成复杂任务。每个智能体可以专注于特定领域，通过不同的协作模式共同解决问题。

## 核心概念

### 为什么使用多智能体？

- **专业化**：每个智能体专注于特定领域，提高准确性
- **模块化**：易于开发、测试和维护
- **可扩展性**：可以轻松添加新的智能体
- **灵活性**：不同的智能体可以使用不同的模型和工具
- **并行处理**：多个智能体可以同时工作

### 基本架构

多智能体系统通常包含：

1. **多个智能体**：每个智能体有自己的角色和能力
2. **通信机制**：智能体之间如何交换信息
3. **协调策略**：如何决定哪个智能体执行任务
4. **共享状态**：智能体之间共享的信息

## 三种主要模式

LangGraph 支持三种主要的多智能体协作模式：

### 1. 主管模式（Supervisor Pattern）

一个中央协调者（主管）负责分配任务给专业智能体。

```
         ┌─────────────┐
         │   主管      │
         │ Supervisor  │
         └──────┬──────┘
                │
       ┌────────┼────────┐
       │        │        │
  ┌────▼──┐ ┌──▼───┐ ┌──▼───┐
  │智能体A│ │智能体B│ │智能体C│
  │Agent A│ │Agent B│ │Agent C│
  └───────┘ └──────┘ └──────┘
```

**特点**：
- 中央控制，易于管理
- 主管决定任务分配
- 智能体之间不直接通信
- 适合明确的任务分工

**详细文档**：[[langgraph/modules/langgraph_multi_agent/主管模式|主管模式]]

### 2. 网络模式（Network Pattern）

智能体之间可以直接通信，没有中央协调者。

```
  ┌─────────┐     ┌─────────┐
  │智能体A  │◄───►│智能体B  │
  │Agent A  │     │Agent B  │
  └────┬────┘     └────┬────┘
       │               │
       │    ┌─────────┐│
       └───►│智能体C  │◄┘
            │Agent C  │
            └─────────┘
```

**特点**：
- 去中心化，更灵活
- 智能体可以直接交接任务
- 适合动态任务分配
- 智能体需要知道其他智能体的能力

**详细文档**：[[langgraph/modules/langgraph_multi_agent/网络模式|网络模式]]

### 3. 层级模式（Hierarchical Pattern）

多层级的智能体结构，管理者监督专业团队。

```
            ┌─────────────┐
            │   总监      │
            │   Director  │
            └──────┬──────┘
                   │
          ┌────────┼────────┐
          │        │        │
     ┌────▼──┐ ┌──▼───┐ ┌──▼───┐
     │经理A  │ │经理B  │ │经理C  │
     │Mgr A  │ │Mgr B  │ │Mgr C  │
     └───┬───┘ └───┬──┘ └───┬──┘
         │         │         │
    ┌────┼────┐   ┌┼┐   ┌────┼────┐
    │    │    │   │││   │    │    │
   ┌▼┐ ┌▼┐ ┌▼┐ ┌▼▼▼┐ ┌▼┐ ┌▼┐ ┌▼┐
   │S│ │S│ │S│ │S S│ │S│ │S│ │S│
   └─┘ └─┘ └─┘ └───┘ └─┘ └─┘ └─┘
```

**特点**：
- 多层级结构
- 管理者协调专业团队
- 适合大型复杂系统
- 可以扩展管理范围

**详细文档**：[[langgraph/modules/langgraph_multi_agent/层级模式|层级模式]]

## 模式对比

| 特性 | 主管模式 | 网络模式 | 层级模式 |
|------|----------|----------|----------|
| **控制方式** | 中央控制 | 去中心化 | 多层级 |
| **复杂度** | 低 | 中 | 高 |
| **灵活性** | 低 | 高 | 中 |
| **可扩展性** | 中 | 高 | 高 |
| **适用场景** | 明确分工 | 动态协作 | 大型系统 |
| **通信开销** | 低 | 高 | 中 |
| **调试难度** | 低 | 高 | 中 |

## 基本实现

### 共享状态

所有多智能体模式都需要共享状态来传递信息：

```python
from typing import Annotated
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages

class MultiAgentState(TypedDict):
    # 共享消息列表
    messages: Annotated[list, add_messages]
    # 当前活动的智能体
    active_agent: str
    # 任务信息
    task: str
    # 结果
    results: dict
```

### 智能体定义

每个智能体通常是一个 LangGraph 图或一个节点：

```python
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, START, END

def create_agent(name: str, tools: list):
    """创建智能体"""
    llm = ChatOpenAI(model="gpt-4")
    llm_with_tools = llm.bind_tools(tools)
    
    def agent_node(state):
        response = llm_with_tools.invoke(state["messages"])
        return {"messages": [response]}
    
    return agent_node

# 创建多个智能体
agent_a = create_agent("Agent A", [tool_a])
agent_b = create_agent("Agent B", [tool_b])
agent_c = create_agent("Agent C", [tool_c])
```

## 完整示例：主管模式

```python
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_openai import ChatOpenAI
from typing import Annotated
from typing_extensions import TypedDict

class State(TypedDict):
    messages: Annotated[list, add_messages]
    next_agent: str

# 创建智能体
def researcher(state):
    """研究员智能体"""
    llm = ChatOpenAI(model="gpt-4")
    response = llm.invoke(state["messages"])
    return {"messages": [response], "next_agent": "supervisor"}

def writer(state):
    """写作者智能体"""
    llm = ChatOpenAI(model="gpt-4")
    response = llm.invoke(state["messages"])
    return {"messages": [response], "next_agent": "supervisor"}

def supervisor(state):
    """主管智能体"""
    llm = ChatOpenAI(model="gpt-4")
    
    # 主管决定下一步
    prompt = """
    基于当前对话，决定下一步：
    - 如果需要研究，选择 "researcher"
    - 如果需要写作，选择 "writer"
    - 如果任务完成，选择 "FINISH"
    
    只返回选项名称。
    """
    
    response = llm.invoke(state["messages"] + [("user", prompt)])
    next_agent = response.content.strip()
    
    return {"next_agent": next_agent}

def route_after_supervisor(state):
    """主管后的路由"""
    next_agent = state.get("next_agent", "FINISH")
    
    if next_agent == "FINISH":
        return "end"
    elif next_agent == "researcher":
        return "researcher"
    elif next_agent == "writer":
        return "writer"
    else:
        return "end"

# 构建图
graph = StateGraph(State)
graph.add_node("researcher", researcher)
graph.add_node("writer", writer)
graph.add_node("supervisor", supervisor)

graph.add_edge(START, "supervisor")
graph.add_conditional_edges("supervisor", route_after_supervisor, {
    "researcher": "researcher",
    "writer": "writer",
    "end": END
})
graph.add_edge("researcher", "supervisor")
graph.add_edge("writer", "supervisor")

app = graph.compile()
```

## 选择指南

### 使用主管模式当：

- 任务分工明确
- 需要中央控制
- 智能体之间不需要直接通信
- 系统规模较小

### 使用网络模式当：

- 任务动态变化
- 智能体需要直接协作
- 需要更高的灵活性
- 智能体数量适中

### 使用层级模式当：

- 系统规模很大
- 需要多层级管理
- 团队结构清晰
- 需要扩展管理范围

## 最佳实践

### 1. 清晰的智能体角色

```python
# 好的做法：明确的角色定义
researcher_agent = create_agent(
    name="研究员",
    role="负责信息收集和分析",
    tools=[search_tool, analysis_tool]
)

writer_agent = create_agent(
    name="写作者",
    role="负责内容创作和编辑",
    tools=[writing_tool, editing_tool]
)

# 不好的做法：角色模糊
agent_1 = create_agent(name="智能体1", tools=[...])
```

### 2. 明确的通信协议

```python
class AgentMessage(TypedDict):
    from_agent: str
    to_agent: str
    content: str
    task_type: str
    priority: int
```

### 3. 状态管理

```python
# 使用结构化状态
class MultiAgentState(TypedDict):
    messages: Annotated[list, add_messages]
    agent_results: dict  # 每个智能体的结果
    current_task: str
    task_history: list
```
