# 人机交互概述

人机交互（Human-in-the-Loop）是 LangGraph 的核心功能之一，允许你在图执行过程中暂停，等待人类输入或审批，然后继续执行。这对于构建需要人类监督、审批或干预的 AI 应用至关重要。

## 核心概念

### 为什么需要人机交互？

- **安全控制**：在关键操作前需要人类审批
- **质量保证**：人类审核 AI 生成的内容
- **数据输入**：需要人类提供额外信息
- **决策确认**：重要决策需要人类确认
- **合规要求**：某些行业法规要求人类参与

### 核心机制

LangGraph 提供了三种主要的人机交互机制：

#### 1. interrupt() 函数

`interrupt()` 是最直接的人机交互方式，在节点内部显式暂停执行。

```python
from langgraph.types import interrupt, Command

def approval_node(state):
    # 执行一些逻辑
    result = process_data(state["data"])
    
    # 暂停，等待人类审批
    human_decision = interrupt({
        "action": "approve_or_reject",
        "data": result,
        "message": "请审批以下结果"
    })
    
    # 人类审批后继续
    if human_decision == "approve":
        return {"result": result}
    else:
        return {"result": None}
```

#### 2. interrupt_before / interrupt_after

在编译图时指定在哪些节点前后暂停。

```python
from langgraph.graph import StateGraph, START, END

graph = StateGraph(State)
graph.add_node("sensitive_action", sensitive_node)
graph.add_edge(START, "sensitive_action")
graph.add_edge("sensitive_action", END)

# 在 sensitive_action 节点之前暂停
app = graph.compile(
    checkpointer=checkpointer,
    interrupt_before=["sensitive_action"]
)
```

#### 3. Command 恢复

使用 `Command(resume=value)` 恢复暂停的图执行。

```python
# 恢复执行并传递人类输入
result = app.invoke(
    Command(resume="approved"),
    config={"configurable": {"thread_id": "1"}}
)
```

## 基本工作流程

```
1. 图开始执行
   ↓
2. 到达需要人类干预的点
   ↓
3. 图暂停，状态保存到检查点
   ↓
4. 人类审查并提供输入
   ↓
5. 使用 Command(resume=value) 恢复执行
   ↓
6. 图继续执行
```

## 完整示例

```python
from langgraph.graph import StateGraph, START, END
from langgraph.types import interrupt, Command
from langgraph.checkpoint.memory import MemorySaver
from typing_extensions import TypedDict

class State(TypedDict):
    data: str
    approved: bool
    result: str

def process_node(state: State):
    """处理数据"""
    return {"data": f"处理后的: {state['data']}"}

def approval_node(state: State):
    """等待人类审批"""
    # 暂停，等待人类输入
    decision = interrupt({
        "message": "请审批处理结果",
        "data": state["data"]
    })
    
    # 人类决策后继续
    if decision == "approve":
        return {"approved": True, "result": state["data"]}
    else:
        return {"approved": False, "result": "已拒绝"}

# 构建图
graph = StateGraph(State)
graph.add_node("process", process_node)
graph.add_node("approval", approval_node)
graph.add_edge(START, "process")
graph.add_edge("process", "approval")
graph.add_edge("approval", END)

# 编译图（需要检查点）
checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)

# 第一次执行（会在 approval 节点暂停）
config = {"configurable": {"thread_id": "1"}}
result = app.invoke({"data": "原始数据", "approved": False, "result": ""}, config)

# 此时图已暂停，等待人类输入
# 人类审批
app.invoke(Command(resume="approve"), config)

# 图继续执行并返回最终结果
```

## 常见模式

### 1. 工具调用审批

在执行敏感工具前需要人类审批。

```python
def tool_approval_node(state):
    """审批工具调用"""
    tool_call = state["pending_tool_call"]
    
    decision = interrupt({
        "tool": tool_call["name"],
        "arguments": tool_call["args"],
        "message": f"是否执行工具 {tool_call['name']}?"
    })
    
    if decision == "approve":
        # 执行工具
        result = execute_tool(tool_call)
        return {"tool_result": result}
    else:
        return {"tool_result": "工具调用被拒绝"}
```

### 2. 输出审核

在发送响应前审核内容。

```python
def review_output_node(state):
    """审核输出内容"""
    output = state["generated_output"]
    
    # 暂停等待审核
    feedback = interrupt({
        "output": output,
        "message": "请审核以下内容，或提供修改建议"
    })
    
    if feedback == "approve":
        return {"final_output": output}
    else:
        # 根据反馈修改
        return {"generated_output": feedback, "needs_revision": True}
```

### 3. 数据输入

在需要额外信息时暂停。

```python
def collect_additional_info(state):
    """收集额外信息"""
    # 暂停，请求人类提供信息
    additional_info = interrupt({
        "message": "请提供以下信息",
        "required_fields": ["name", "email", "phone"]
    })
    
    return {"additional_info": additional_info}
```

## interrupt() 机制详解

`interrupt()` 是人机交互的核心函数，它的工作流程如下：

1. **暂停执行**：当调用 `interrupt()` 时，图立即暂停
2. **保存状态**：当前状态自动保存到检查点
3. **返回值**：`interrupt()` 返回人类提供的输入
4. **恢复执行**：使用 `Command(resume=value)` 恢复执行

```python
from langgraph.types import interrupt, Command

def human_input_node(state):
    # 暂停并等待人类输入
    human_input = interrupt("请提供输入")
    
    # 恢复后，human_input 包含人类的输入
    return {"human_input": human_input}
```

## 检查点的必要性

人机交互**必须**使用检查点（checkpointer），因为：

- 状态需要持久化保存
- 图暂停后需要能够恢复
- 人类输入需要与正确的执行上下文关联

```python
from langgraph.checkpoint.memory import MemorySaver

# 必须提供检查点
checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)
```
