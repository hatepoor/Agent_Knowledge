# 状态更新模式

## 概述

LangGraph 中的节点通过返回一个字典来更新状态。根据字段 Reducer 的不同，更新行为也不同。本文档详细介绍各种状态更新模式及其最佳实践。

---

## 模式一：覆盖（Overwrite）

最基础的更新模式。节点返回的值直接替换状态中的旧值。适用于没有自定义 Reducer 的字段。

### 基本语法

```python
def my_node(state: GraphState) -> dict:
    """覆盖模式：直接替换字段值"""
    return {
        "query": "新的查询",      # 替换旧的 query
        "answer": "新的回答",     # 替换旧的 answer
        "retry_count": 0,        # 重置计数器
    }
```

### 完整示例

```python
from typing import TypedDict

class SimpleState(TypedDict):
    query: str
    answer: str
    status: str

def process_node(state: SimpleState) -> dict:
    """处理节点：更新多个字段"""
    old_query = state["query"]

    # 执行处理逻辑...
    new_answer = f"对 '{old_query}' 的回答"

    return {
        "answer": new_answer,   # 覆盖 answer
        "status": "completed",  # 覆盖 status
        # 注意：没有返回 query → query 保持不变
    }
```

### 覆盖模式的特点

- 新值完全替换旧值
- 适合标量字段（字符串、数字、布尔值）
- 适合"最新值才有意义"的场景

## 模式二：追加（Append）

通过 `add_messages` 等 Reducer，节点返回的值会追加到现有列表中，而不是替换。

### 基本语法

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages

class ChatState(TypedDict):
    messages: Annotated[list, add_messages]  # 使用追加 Reducer

def chatbot_node(state: ChatState) -> dict:
    """追加模式：添加新消息到列表"""
    # 返回的消息会追加到现有消息列表，而不是替换
    return {
        "messages": [AIMessage(content="这是新的回复")]
    }
    # 结果：原有消息保留，新消息追加到末尾
```

### 追加多条消息

```python
def multi_message_node(state: ChatState) -> dict:
    """一次追加多条消息"""
    return {
        "messages": [
            AIMessage(content="第一条回复"),
            AIMessage(content="第二条补充说明"),
        ]
    }
```

### 追加模式的特点

- 现有元素保留，新元素追加到末尾
- 适合消息列表、日志、历史记录等需要累积的场景
- 配合 `add_messages` 还支持按 ID 去重/更新

## 模式三：部分更新（Partial Update）

节点不需要返回所有字段，只返回需要修改的字段即可。未返回的字段保持不变。

### 基本语法

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages

class FullState(TypedDict):
    messages: Annotated[list, add_messages]
    query: str
    context: str
    answer: str
    confidence: float
    source: str
    retry_count: int

def retrieve_node(state: FullState) -> dict:
    """检索节点：只更新 context 字段"""
    # 只返回需要更新的字段
    return {
        "context": "检索到的文档内容",
        # query, answer, confidence 等字段保持不变
    }

def generate_node(state: FullState) -> dict:
    """生成节点：只更新 answer 和 confidence"""
    return {
        "answer": "生成的回答",
        "confidence": 0.95,
        # 其他字段保持不变
    }
```

### 部分更新的优势

```python
# ✅ 推荐：只返回修改的字段
def focused_node(state: GraphState) -> dict:
    return {"answer": "新回答"}  # 清晰、明确

# ❌ 不推荐：返回所有字段（包括未修改的）
def verbose_node(state: GraphState) -> dict:
    return {
        "query": state["query"],        # 未修改，不需要返回
        "context": state["context"],     # 未修改，不需要返回
        "answer": "新回答",              # 只有这个需要返回
        "confidence": state["confidence"],  # 未修改，不需要返回
    }
```

### 部分更新 + 覆盖 Reducer 的注意事项

```python
# 注意：部分更新在使用覆盖 Reducer 时是安全的
# 因为未返回的字段不会被修改

class State(TypedDict):
    a: str  # 覆盖
    b: str  # 覆盖
    c: str  # 覆盖

def node(state: State) -> dict:
    return {"a": "新值"}  # 只更新 a，b 和 c 保持不变
    # 最终状态：{"a": "新值", "b": "旧值b", "c": "旧值c"}
```

## 模式四：删除消息（RemoveMessage）

当需要从消息列表中删除特定消息时，使用 `RemoveMessage`。

### 基本语法

```python
from langchain_core.messages import RemoveMessage, HumanMessage, AIMessage

def cleanup_node(state: ChatState) -> dict:
    """清理节点：删除特定消息"""
    messages = state["messages"]

    # 找到要删除的消息
    messages_to_remove = [
        RemoveMessage(id=msg.id)
        for msg in messages
        if isinstance(msg, HumanMessage) and "系统" in msg.content
    ]

    return {"messages": messages_to_remove}
    # add_messages Reducer 会识别 RemoveMessage 并删除对应消息
```

### RemoveMessage 的工作原理

```python
from langchain_core.messages import RemoveMessage, HumanMessage, AIMessage
from langgraph.graph.message import add_messages

# 当前消息列表
existing = [
    HumanMessage(content="你好", id="msg-1"),
    AIMessage(content="你好！", id="msg-2"),
    HumanMessage(content="天气怎么样？", id="msg-3"),
    AIMessage(content="晴天", id="msg-4"),
]

# 删除 msg-1 和 msg-2
removals = [
    RemoveMessage(id="msg-1"),
    RemoveMessage(id="msg-2"),
]

result = add_messages(existing, removals)
# result = [
#     HumanMessage(content="天气怎么样？", id="msg-3"),
#     AIMessage(content="晴天", id="msg-4"),
# ]
```

### 实战：消息修剪（保留最近 N 条）

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import RemoveMessage

class ChatState(TypedDict):
    messages: Annotated[list, add_messages]

def trim_messages_node(state: ChatState, max_messages: int = 10) -> dict:
    """修剪消息列表，只保留最近 N 条"""
    messages = state["messages"]

    if len(messages) <= max_messages:
        return {}  # 不需要修剪，返回空更新

    # 计算需要删除的消息数量
    num_to_remove = len(messages) - max_messages
    messages_to_remove = messages[:num_to_remove]

    # 创建删除指令
    return {
        "messages": [RemoveMessage(id=msg.id) for msg in messages_to_remove]
    }
```

### 实战：删除所有 Human 消息

```python
def remove_all_human_messages(state: ChatState) -> dict:
    """删除所有 HumanMessage"""
    from langchain_core.messages import HumanMessage, RemoveMessage

    return {
        "messages": [
            RemoveMessage(id=msg.id)
            for msg in state["messages"]
            if isinstance(msg, HumanMessage)
        ]
    }
```

## 混合模式

一个节点可以同时使用多种更新模式：

```python
def mixed_update_node(state: AppState) -> dict:
    """混合更新：同时覆盖、追加、删除"""
    return {
        # 覆盖模式：直接替换
        "status": "processing",
        "retry_count": 0,

        # 追加模式：追加新消息（因为 messages 字段有 add_messages Reducer）
        "messages": [AIMessage(content="处理中...")],

        # 删除模式：删除旧消息
        # （同样通过 messages 字段的 add_messages Reducer 处理）
        # 可以在同一个返回中包含追加和删除
    }
```

### 追加 + 删除同时使用

```python
def replace_last_message(state: ChatState) -> dict:
    """替换最后一条消息：删除旧的，添加新的"""
    messages = state["messages"]
    last_msg = messages[-1]

    return {
        "messages": [
            RemoveMessage(id=last_msg.id),          # 删除最后一条
            AIMessage(content="替换后的新消息"),      # 添加新的
        ]
    }
```

## 最佳实践

### 1. 只返回需要变更的字段

```python
# ✅ 好：精确更新
def good_node(state: State) -> dict:
    return {"answer": "新回答"}

# ❌ 差：返回所有字段
def bad_node(state: State) -> dict:
    return {
        "query": state["query"],       # 没必要
        "context": state["context"],   # 没必要
        "answer": "新回答",
    }
```

### 2. 使用有意义的返回值

```python
# ✅ 好：返回空 dict 表示无需更新
def conditional_node(state: State) -> dict:
    if state["retry_count"] >= 3:
        return {"status": "failed"}
    return {}  # 无需更新
```

### 3. 避免在节点中直接修改状态

```python
# ❌ 错误：直接修改状态对象
def wrong_node(state: State) -> dict:
    state["answer"] = "新回答"   # 不要这样做！
    state["messages"].append(msg)  # 不要这样做！
    return state

# ✅ 正确：返回更新字典
def right_node(state: State) -> dict:
    return {"answer": "新回答"}  # 让框架处理合并
```

### 4. 消息字段始终使用 Annotated

```python
# ❌ 错误：忘记 Annotated
class WrongState(TypedDict):
    messages: list  # 会覆盖而不是追加！

# ✅ 正确：使用 Annotated
class RightState(TypedDict):
    messages: Annotated[list, add_messages]  # 正确追加
```

### 5. 初始化时提供所有必需字段

```python
# 调用图时，确保提供所有需要的初始字段
result = app.invoke({
    "messages": [],           # 空消息列表
    "query": "用户的问题",
    "retry_count": 0,         # 初始计数
    # 未提供的字段会使用 TypedDict 的默认值（None）
})
```

## 更新模式速查表

| 模式 | 语法 | Reducer | 适用场景 |
|------|------|---------|----------|
| 覆盖 | `return {"field": value}` | 默认 | 标量字段、最新值优先 |
| 追加 | `return {"messages": [msg]}` | `add_messages` | 消息列表、日志 |
| 部分更新 | 只返回变更字段 | 任意 | 所有场景（推荐） |
| 删除 | `return {"messages": [RemoveMessage(id=...)]}` | `add_messages` | 消息修剪、清理 |
| 累加 | `return {"count": 1}` | 自定义加法 Reducer | 计数器、统计 |
| 合并 | `return {"config": {...}}` | 自定义合并 Reducer | 配置、元数据 |
