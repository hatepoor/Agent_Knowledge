# langgraph-core 模块概述

`langgraph-core` 是 LangGraph 的**核心图引擎**，提供了构建和执行状态图的全部基础 API。它是整个 LangGraph 框架的基石，所有高级功能（持久化、流式、人机协作等）都建立在此模块之上。

## 是什么

核心模块提供了：
- **StateGraph**：状态图的定义和构建
- **节点（Node）**：执行操作的函数单元
- **边（Edge）**：节点间的连接和路由逻辑
- **编译与执行**：将图定义转换为可执行对象

## 基本用法

### 完整示例：构建一个简单的工作流

```python
"""
核心模块完整示例：构建一个文本处理工作流
"""
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 1. 定义状态
class State(TypedDict):
    """工作流状态"""
    text: str           # 原始文本
    word_count: int     # 字数统计
    processed: bool     # 是否已处理

# 2. 定义节点
def load_text(state: State) -> dict:
    """加载文本节点"""
    print(f"[加载] 原始文本: {state['text'][:50]}...")
    return {"processed": False}

def count_words(state: State) -> dict:
    """统计字数节点"""
    words = len(state["text"].split())
    print(f"[统计] 字数: {words}")
    return {"word_count": words}

def process_text(state: State) -> dict:
    """处理文本节点"""
    processed = state["text"].upper()
    print(f"[处理] 文本已转换")
    return {"text": processed, "processed": True}

# 3. 构建图
builder = StateGraph(State)

# 添加节点
builder.add_node("load", load_text)
builder.add_node("count", count_words)
builder.add_node("process", process_text)

# 添加边
builder.add_edge(START, "load")
builder.add_edge("load", "count")
builder.add_edge("count", "process")
builder.add_edge("process", END)

# 4. 编译
graph = builder.compile()

# 5. 执行
result = graph.invoke({
    "text": "LangGraph 是一个强大的编排框架，用于构建有状态的 AI Agent。"
})

print(f"\n最终结果:")
print(f"文本: {result['text']}")
print(f"字数: {result['word_count']}")
print(f"已处理: {result['processed']}")
```

### 输出

```
[加载] 原始文本: LangGraph 是一个强大的编排框架，用于构建有状态的 AI Age...
[统计] 字数: 13
[处理][[ 文本已转换

最终结果:
文本: LANGGRAPH 是一个强大的编排框架，用于构建有状态的 AI AGENT。
字数: 13
已处理: True
```

## 核心概念

### 1. StateGraph（状态图）

`StateGraph` 是图构建器，负责：
- 定义状态结构（通过 `state_schema` 参数）
- 注册节点（`add_node()`）
- 定义边（`add_edge()`、`add_conditional_edges()`）
- 编译为可执行图（`compile()`）

```python
builder = StateGraph(State)
builder.add_node("node_name", node_function)
builder.add_edge(START, "node_name")
graph = builder.compile()
```

详见 → [[langgraph/modules/langgraph_core/StateGraph|StateGraph 详解]]

### 2. 节点（Node）

节点是执行具体操作的函数。每个节点：
- 接收当前状态作为参数
- 返回状态的部分更新（字典）
- 可以是普通函数、异步函数、类实例或子图

```python
def my_node(state: State) -> dict:
    # 执行操作
    result = do_something(state["input"][[)
    # 返回状态更新
    return {"output": result}
```

详见 → [[langgraph/modules/langgraph_core/节点|节点详解]]

### 3. 边（Edge）

边定义节点间的执行顺序：
- **普通边**：固定的执行顺序
- **条件边**：根据状态动态路由
- **入口边**：从 `START` 到第一个节点
- **出口**：返回 `END` 或 `"__end__"`

```python
# 普通边
builder.add_edge("node_a", "node_b")

# 条件边
builder.add_conditional_edges("node_a", route_function)
```

详见 → [[langgraph/modules/langgraph_core/边|边详解]]

### 4. 编译与执行

编译后的 `CompiledStateGraph` 提供多种执行方式：
- `invoke()`：运行到完成，返回最终状态
- `stream()`：逐步执行，流式输出
- `astream()`：异步流式执行

```python
graph = builder.compile()

# 同步执行
result = graph.invoke(inputs)

# 流式执行
for step in graph.stream(inputs):
    print(step)
```

详见 → [[langgraph/modules/langgraph_core/编译与执行|编译与执行详解]]

## 设计原则

### 1. 状态是不可变的

节点不直接修改状态，而是返回更新。LangGraph 负责将更新合并到当前状态。

```python
# 错误：直接修改状态（不推荐）
def bad_node(state: State):
    state["count"] += 1  # 不要这样做
    return state

# 正确：返回部分更新
def good_node(state: State) -> dict:
    return {"count": state["count"] + 1}
```

### 2. 节点应该是纯函数

节点应该是**幂等的**——相同的输入产生相同的输出。这使得图更容易调试、测试和推理。

### 3. 图应该是可组合的

复杂图可以拆分为子图，子图可以复用在多个地方。

## 常见模式

### 模式一：线性管道

```
START → A → B → C → END
```

```python
builder.add_edge(START, "A")
builder.add_edge("A", "B")
builder.add_edge("B", "C")
builder.add_edge("C", END)
```

### 模式二：条件分支

```
         ┌→ B ─┐
START → A ─┤    ├→ END
         └→ C ─┘
```

```python
def route(state):
    return "B" if state["condition"] else "C"

builder.add_edge(START, "A")
builder.add_conditional_edges("A", route)
builder.add_edge("B", END)
builder.add_edge("C", END)
```

### 模式三：循环（Agent 模式）

```
START → Agent → Tools ─┐
         ↑              │
         └──────────────┘
         ↓
        END
```

```python
def should_continue(state):
    return "tools" if state["should_call_tool"][[ else END

builder.add_edge(START, "agent")
builder.add_conditional_edges("agent", should_continue)
builder.add_edge("tools", "agent")
```

## 错误处理

### 常见错误

1. **忘记添加入口边**
   ```python
   # 错误：没有从 START 到第一个节点的边
   builder.add_node("A", node_a)
   builder.add_edge("A", "B")
   
   # 正确
   builder.add_edge(START, "A")
   ```

2. **节点返回 None**
   ```python
   # 错误：节点必须返回字典
   def bad_node(state):
       do_something()
       # 没有 return
   
   # 正确
   def good_node(state):
       do_something()
       return {}  # 返回空字典表示不更新状态
   ```

3. **状态字段不匹配**
   ```python
   # 错误：返回状态中不存在的字段
   def bad_node(state: State) -> dict:
       return {"unknown_field": "value"}
   
   # 正确：只返回状态中定义的字段
   def good_node(state: State) -> dict:
       return {"known_field": "value"}
   ```

## 性能考虑

- **节点粒度**：节点应该是粗粒度的（执行较重的操作），避免创建过多小节点
- **状态大小**：保持状态精简，避免在状态中存储大量数据
- **并行执行**：如果多个节点没有依赖关系，可以使用 fan-out 并行执行
