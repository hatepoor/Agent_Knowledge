# 快速入门

在本教程中，你将从零开始构建一个功能完备的 LangGraph 聊天机器人。每一步都会引入一个新概念，最终构建出一个支持对话记忆的智能助手。

## 前置条件

- Python 3.9+
- OpenAI API 密钥（或其他 LLM 提供商的密钥）

## 第一步：安装 LangGraph

```bash
pip install langgraph langchain-openai
```

> 提示：`langgraph` 会自动安装 `langchain-core` 作为依赖。

## 第二步：定义状态

LangGraph 的核心概念是**状态（State）**——在节点之间流动和更新的共享数据。使用 `TypedDict` 定义状态结构：

```python
from typing import TypedDict, Annotated
from langgraph.graph import MessagesState

# 方式一：使用内置的 MessagesState（推荐用于聊天机器人）
# MessagesState 已经预定义了 messages 字段，并配置了追加 reducer

# 方式二：自定义状态
class MyState(TypedDict):
    """自定义状态结构"""
    messages: list  # 对话消息列表
    user_name: str  # 用户名称
    step_count: int  # 执行步骤计数
```

对于聊天机器人，我们使用内置的 `MessagesState`，它已经预定义了 `messages` 字段：

```python
from langgraph.graph import MessagesState

# MessagesState 等价于：
# class MessagesState(TypedDict):
#     messages: Annotated[list[BaseMessage], add_messages]
# 
# add_messages reducer 会自动将新消息追加到列表末尾
```

## 第三步：创建 StateGraph

`StateGraph` 是 LangGraph 的核心类，用于定义工作流的结构：

```python
from langgraph.graph import StateGraph, START, END

# 创建图构建器
builder = StateGraph(MessagesState)
```

## 第四步：添加节点

节点是执行具体操作的 Python 函数。每个节点接收当前状态，返回状态的**部分更新**：

```python
from langchain_openai import ChatOpenAI

# 初始化 LLM
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

def chatbot(state: MessagesState) -> dict:
    """
    聊天机器人节点
    接收消息列表，调用 LLM 生成回复
    """
    # 调用模型，传入所有历史消息
    response = model.invoke(state["messages"])
    # 返回状态更新（只更新 messages 字段）
    return {"messages": [response]}
```

## 第五步：添加边

边定义节点之间的执行顺序：

```python
# 添加节点到图
builder.add_node("chatbot", chatbot)

# 添加边：定义执行流程
builder.add_edge(START, "chatbot")  # 入口：从 START 到 chatbot
builder.add_edge("chatbot", END)    # 出口：从 chatbot 到 END
```

## 第六步：编译并执行

编译图并执行：

```python
# 编译图（生成可执行的 CompiledStateGraph）
graph = builder.compile()

# 执行图
result = graph.invoke({
    "messages": [("user", "你好！请介绍一下你自己")]
})

# 查看最终结果
print(result["messages"][-1].content)
```

## 完整示例：基础聊天机器人

将以上步骤组合成完整的可运行代码：

```python
"""
基础聊天机器人：最简单的 LangGraph 应用
"""
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, START, END, MessagesState

# 1. 初始化 LLM
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 2. 定义节点
def chatbot(state: MessagesState) -> dict:
    """调用 LLM 生成回复"""
    response = model.invoke(state["messages"])
    return {"messages": [response]}

# 3. 构建图
builder = StateGraph(MessagesState)
builder.add_node("chatbot", chatbot)
builder.add_edge(START, "chatbot")
builder.add_edge("chatbot", END)

# 4. 编译
graph = builder.compile()

# 5. 执行
result = graph.invoke({
    "messages": [("user", "你好！请介绍一下 LangGraph")]
})
print(result["messages"][-1].content)
```

## 第七步：添加条件边

条件边让图根据状态动态选择下一个节点。下面构建一个带工具的 Agent：

```python
"""
带工具的 Agent：使用条件边实现工具调用循环
"""
from typing import Literal
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, START, END, MessagesState
from langgraph.prebuilt import ToolNode
from langchain_core.tools import tool

# 1. 定义工具
@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息"""
    # 模拟天气数据
    weather_data = {
        "北京": "晴天，25°C",
        "上海": "多云，22°C",
        "广州": "小雨，28°C",
    }
    return weather_data.get(city, f"抱歉，没有{city}的天气数据")

@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    try:
        result = eval(expression)
        return f"计算结果：{expression} = {result}"
    except Exception as e:
        return f"计算错误：{e}"

# 2. 绑定工具到模型
tools = [get_weather, calculate]
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
model_with_tools = model.bind_tools(tools)

# 3. 定义节点
def chatbot(state: MessagesState) -> dict:
    """聊天机器人节点"""
    response = model_with_tools.invoke(state["messages"])
    return {"messages": [response]}

# 4. 定义路由函数
def should_continue(state: MessagesState) -> Literal["tools", END]:
    """
    判断是否需要调用工具
    如果 LLM 的回复包含工具调用，路由到 tools 节点
    否则结束对话
    """
    last_message = state["messages"][-1]
    if last_message.tool_calls:
        return "tools"
    return END

# 5. 构建图
builder = StateGraph(MessagesState)

# 添加节点
builder.add_node("chatbot", chatbot)
builder.add_node("tools", ToolNode(tools))

# 添加边
builder.add_edge(START, "chatbot")
builder.add_conditional_edges("chatbot", should_continue)  # 条件边
builder.add_edge("tools", "chatbot")  # 工具执行后返回 chatbot

# 6. 编译
graph = builder.compile()

# 7. 执行
result = graph.invoke({
    "messages": [("user", "北京今天天气怎么样？另外帮我算一下 123 * 456")]
})

# 打印对话过程
for msg in result["messages"]:
    print(f"{msg.type}: {msg.content}")
```

## 第八步：添加持久化（Checkpointer）

Checkpointer 让聊天机器人能够记住对话历史：

```python
"""
带记忆的聊天机器人：使用 Checkpointer 实现对话持久化
"""
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, START, END, MessagesState
from langgraph.checkpoint.memory import MemorySaver

# 1. 初始化 LLM
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 2. 定义节点
def chatbot(state: MessagesState) -> dict:
    """调用 LLM 生成回复"""
    response = model.invoke(state["messages"])
    return {"messages": [response]}

# 3. 构建图
builder = StateGraph(MessagesState)
builder.add_node("chatbot", chatbot)
builder.add_edge(START, "chatbot")
builder.add_edge("chatbot", END)

# 4. 创建 Checkpointer
checkpointer = MemorySaver()

# 5. 编译时传入 checkpointer
graph = builder.compile(checkpointer=checkpointer)

# 6. 执行多轮对话
config = {"configurable": {"thread_id": "user-001"}}

# 第一轮
result1 = graph.invoke(
    {"messages": [("user", "我叫小明")]},
    config=config
)
print("回复1:", result1["messages"][-1].content)

# 第二轮（机器人会记住用户的名字）
result2 = graph.invoke(
    {"messages": [("user", "我叫什么名字？")]},
    config=config
)
print("回复2:", result2["messages"][-1].content)
# 输出会包含"小明"，因为状态被持久化了
```

## 第九步：流式输出

使用 `stream()` 方法逐步获取执行结果：

```python
"""
流式输出：逐步获取 Agent 的执行过程
"""

# 流式输出每一步的状态更新
inputs = {"messages": [("user", "上海天气怎么样？")]}

for step in graph.stream(inputs, stream_mode="updates"):
    # step 是一个字典，包含当前步骤的节点名和状态更新
    for node_name, update in step.items():
        print(f"\n--- 节点: {node_name} ---")
        if "messages" in update:
            for msg in update["messages"][[:
                print(f"{msg.type}: {msg.content}")
```

## 关键概念总结

| 概念 | 说明 | 代码示例 |
|------|------|---------|
| State | 在节点间流动的共享数据 | `class State(TypedDict)` |
| Node | 执行操作的函数 | `def node(state) -> dict` |
| Edge | 节点间的连接 | `add_edge("from", "to")` |
| Conditional Edge | 动态路由 | `add_conditional_edges("from", route_fn)` |
| Checkpointer | 状态持久化 | `MemorySaver()` |
| START / END | 图的入口和出口 | `START`, `END` 常量 |

## 常见问题

### Q: 为什么节点返回字典而不是完整状态？

节点返回的是**部分更新**，LangGraph 会自动将其合并到当前状态。这样每个节点只需关注自己负责的字段。

### Q: MessagesState 和普通 TypedDict 有什么区别？

`MessagesState` 是预定义的状态类型，内置了 `messages` 字段和 `add_messages` reducer。reducer 决定了当节点返回新消息时，是追加到列表还是替换整个列表。

### Q: 如何调试 LangGraph 应用？

1. 使用 `stream_mode="updates"` 查看每一步的状态变化
2. 使用 LangSmith 追踪完整的执行过程
3. 使用 `graph.get_state(config)` 查看当前状态
