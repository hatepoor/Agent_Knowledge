# 系统提示词（System Prompt）

## 定义

System Prompt（系统提示词）是 Agent 的**角色和行为的顶层定义**，在每次模型调用时作为第一条消息送入对话上下文。它塑造 Agent 处理任务的方式，是所有对话轮次的行为基准。

## 三种写法

### 1. 字符串（最常用）

在 `create_agent()` 中直接传入字符串，内部自动转为 `SystemMessage`：

```python
from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search_tool],
    system_prompt="You are a helpful assistant. Be concise and accurate.",
)
```

### 2. `SystemMessage` 对象

效果等价，适合需要与消息系统交互的场景：

```python
from langchain.messages import SystemMessage

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search_tool],
    system_prompt=SystemMessage(content="You are a helpful assistant."),
)
```

### 3. `@dynamic_prompt` 装饰器（动态生成）

每次模型调用前重新生成，可访问运行时上下文和对话状态：

```python
from langchain.agents.middleware import dynamic_prompt
from langchain.agents.middleware.types import ModelRequest

@dynamic_prompt
def contextual_prompt(request: ModelRequest) -> str:
    """每次模型调用前生成"""
    user_name = request.runtime.context.user_name
    msg_count = len(request.state["messages"])

    return f"""You are assisting {user_name}.
This is turn #{msg_count}.
Be concise."""
```

## 推荐结构

实际项目中，推荐使用**多行字符串 + Markdown 分级标题**组织 system prompt：

```python
SYSTEM_PROMPT = """你是[角色定义]。

## 能力说明
- [能力 1]：[说明]
- [能力 2]：[说明]

## 行为规则
- [规则 1]
- [规则 2]

## 工作流程
1. [步骤 1]
2. [步骤 2]

## 输出要求
- [要求 1]
- [要求 2]
"""
```

### 结构说明

| 段落 | 作用 | 示例 |
|------|------|------|
| 角色定义（首句） | 声明角色身份 | `你是一位金融数据分析助手` |
| 能力说明 | 描述可用工具及用途 | `tavily_search：实时搜索互联网` |
| 行为规则 | 约束模型行为 | `不确定时直接说明，不要猜测` |
| 工作流程 | 定义任务处理顺序 | `1. 判断是否需要搜索 2. 搜索 3. 综合回答` |
| 输出要求 | 期望的输出格式 | `1. 结论 2. 论据 3. 局限性` |

## 编写原则

| 原则 | 说明 | 好写法 vs 差写法 |
|------|------|------------------|
| **角色优先** | 开头明确定义角色 | `你是一位...` 优于 `请帮助用户` |
| **负面约束** | 告诉模型不该做什么 | `不要猜测` 优于 `请尽量准确` |
| **工具时机** | 明确何时调用工具 | `当需要实时数据时，使用 tavily_search` |
| **输出结构化** | 用段落描述期望格式 | 用 Markdown 标题而非连续长篇 |
| **简洁克制** | 控制长度，通常 200-500 字 | 不超过上下文窗口的 10% |
| **中英文一致** | 与模型语言匹配 | 中文模型用中文 prompt |

## 完整示例

```python
from langchain.agents import create_agent
from langchain.agents.middleware import dynamic_prompt
from langchain.agents.middleware.types import ModelRequest
# ⚠️ langchain_community 已弃用，新项目使用 from langchain_tavily import TavilySearch
from langchain_community.tools import TavilySearchResults

tavily_tool = TavilySearchResults(max_results=5, search_depth="advanced")

@dynamic_prompt
def research_prompt(request: ModelRequest) -> str:
    return f"""你是研究助手，正在协助 {request.runtime.context.user_name}。

## 可用工具
- tavily_search：实时搜索互联网，获取最新信息

## 工作流程
1. 判断问题是否需要实时信息或超出知识范围
2. 如果是，调用 tavily_search 搜索
3. 基于搜索结果综合回答
4. 引用来源 URL

## 约束
- 不需要联网的问题直接回答，不要浪费工具调用
- 搜索到的信息要归纳提炼，不要直接粘贴原文
- 如果搜索无结果，说明未找到并建议其他方式
"""

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[tavily_tool][[,
    system_prompt=research_prompt,
)
```
