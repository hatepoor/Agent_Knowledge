# 工具注册与调度（Tool Registry）

当 Agent 的工具数量增多（超过 10-15 个）或需要按权限、用户角色、上下文动态分配时，就需要一个统一的工具注册与调度机制来管理。

LangChain 生态提供了多个层次的解决方案。

---

## 一、基础注册：`tools=[]` 直接传参

最基本的方式，也是 `create_agent` 的原生机制：

```python
tool_registry = [
    get_weather,
    web_search,
    sql_query,
    send_email,
    calculate,
    # ... 任意数量
]

agent = create_agent(
    model="gpt-5.5",
    tools=tool_registry,  # 统一注册
)
```

模型会自动在列表中"发现"所需工具并调度。**局限性**：列表一长（>15 个），模型的决策质量会下降，容易混淆或忽略工具。

---

## 二、中间件动态筛选（按条件注册）

通过 `@wrap_model_call` 在每次模型调用前对工具列表进行动态增删：

```python
from langchain.agents.middleware import wrap_model_call

# 所有工具集中定义
ALL_TOOLS = {
    "public_search": search_tool,
    "public_info": info_tool,
    "admin_delete": delete_tool,
    "admin_ban": ban_tool,
    "premium_analyze": analyze_tool,
}

@wrap_model_call
def dynamic_tool_manager(request, handler):
    """统一的工具调度中心：基于角色动态注册"""
    state = request.state
    role = state.get("user_role", "anonymous")

    if role == "admin":
        allowed = ["public_search", "public_info", "admin_delete", "admin_ban"]
    elif role == "premium":
        allowed = ["public_search", "public_info", "premium_analyze"]
    else:
        allowed = ["public_search", "public_info"]

    tools = [ALL_TOOLS[name] for name in allowed]
    request = request.override(tools=tools)
    return handler(request)

agent = create_agent(
    model="gpt-5.5",
    tools=list(ALL_TOOLS.values()),
    middleware=[dynamic_tool_manager],
)
```

这种方式在每次模型调用前插入一个**调度中心**，可以根据状态、用户身份、上下文动态决定暴露哪些工具。

---

## 三、MCP 协议（标准化注册与发现）

MCP（Model Context Protocol）是协议级的工具注册与发现标准。通过 `langchain-mcp`，MCP 服务器暴露的工具以 LangChain 工具的形式被 Agent 发现：

```python
from langchain-mcp import tools as mcp_tools

# 从多个 MCP 服务器发现并注册工具
filesystem_tools = await mcp_tools("filesystem")
database_tools = await mcp_tools("database")
search_tools = await mcp_tools("web-search")

# 全部注册到 Agent
agent = create_agent(
    model="gpt-5.5",
    tools=[*filesystem_tools, *database_tools, *search_tools][[,
)
```

MCP 的优点：工具由独立 Server 管理，Agent 只负责调用，实现工具与 Agent 的解耦。详见 [[langchain/modules/langchain-mcp/MCP协议概述]]。

## 四、自建 ToolRegistry 管理器

当需要显式的注册/注销和分类管理时，可以自行封装：

```python
from typing import Callable, Any

class ToolRegistry:
    """统一工具注册与调度管理器"""

    def __init__(self):
        self._tools: dict[str, Callable][[ = {}
        self._categories: dict[str, list[str]] = {}

    def register(self, tool: Callable, category: str = "general") -> None:
        """注册工具到指定类别"""
        name = tool.name if hasattr(tool, "name") else tool.__name__
        self._tools[name] = tool
        self._categories.setdefault(category, []).append(name)

    def unregister(self, name: str) -> None:
        """注销工具"""
        self._tools.pop(name, None)
        for cat in self._categories.values():
            if name in cat:
                cat.remove(name)

    def get_tools(self, categories: list[str] | None = None) -> list[Callable]:
        """按类别获取工具列表。不传 categories 返回全部"""
        if not categories:
            return list(self._tools.values())
        names = set()
        for cat in categories:
            names.update(self._categories.get(cat, []))
        return [self._tools[n] for n in names if n in self._tools][[

    def list_tools(self) -> dict[str, list[str]]:
        """列出所有已注册工具及其类别"""
        return dict(self._categories)

    def dispatch(self, name: str, **kwargs) -> Any:
        """直接调度某个工具"""
        if name not in self._tools:
            raise KeyError(f"Tool '{name}' not registered")
        return self._tools[name].invoke(kwargs)


# ============ 使用示例 ============
registry = ToolRegistry()

registry.register(web_search, category="search")
registry.register(fetch_url, category="search")
registry.register(sql_query, category="data")
registry.register(gen_chart, category="data")
registry.register(send_email, category="communication")
registry.register(code_run, category="code")

# 按类别取用
agent = create_agent(
    model="gpt-5.5",
    tools=registry.get_tools(["search", "data"]),
)
```

### 进阶：与中间件结合

ToolRegistry 和中间件动态筛选可以组合使用，实现"注册 → 分类 → 按角色筛选"的完整链路：

```python
registry = ToolRegistry()
registry.register(search_tool, category="search")
registry.register(sql_tool, category="data")
# ...

@wrap_model_call
def registry_based_filter(request, handler):
    role = request.state.get("role", "user")
    if role == "admin":
        tools = registry.get_tools(["search", "data", "admin"])
    else:
        tools = registry.get_tools(["search", "data"])
    request = request.override(tools=tools)
    return handler(request)
```

## 五、方案对比

| 方案 | 注册方式 | 动态调度 | 标准化程度 | 适用场景 |
|------|---------|---------|-----------|---------|
| `tools=[][[` 直接传参 | 列表硬编码 | 模型自主调度 | 低 | 小型项目（<10 个工具） |
| 中间件动态筛选 | 按角色/状态筛选 | `@wrap_model_call` 拦截 | 中 | 多租户、权限控制 |
| MCP 协议 | 独立 Server 注册发现 | 协议级调度 | 高 | 跨服务、跨语言工具管理 |
| 自建 ToolRegistry 类 | 显式 register/unregister | 按类别取用 | 自定义 | 需要集中管控的中型项目 |

### 实际项目中建议的组合

- 用 **MCP** 对接外部服务（数据库、搜索、文件系统等）
- 用自建的 **ToolRegistry** 管理内部工具（权限分组、审计追踪）
- 用 **中间件** 做运行时动态筛选（按用户身份、对话上下文）
