## 第 1 章：智能体创建

### 1.1 设计理念

LangChain v1 将智能体抽象为 **Agent = Model + Harness**：

- **Model（模型）**：推理引擎，决定调用哪些工具、如何解读结果、何时给出最终答案
- **Harness（框架）**：模型循环之外的一切：提示词、工具、中间件

`create_agent` 是 LangChain 提供的 **高度可配置工厂函数**，所有高级能力都通过中间件（middleware）以可组合方式叠加。详见 [[langchain/agents/Agent代理|Agent 核心文档]]。

### 1.2 最简示例：从零构建第一个智能体

```python
# 导入核心 API
from langchain.agents import create_agent  # create_agent 是 LangChain v1 推荐的工厂入口

# 定义一个工具：使用 @tool 装饰器
# 工具的 docstring 会被传给模型，用于解释"何时调用此工具"
def get_weather(city: str) -> str:
    """Get weather for a given city."""   # 描述必须清晰，模型据此判断是否调用
    return f"It's always sunny in {city}!"  # 实际业务中应调用真实天气 API

# 调用 create_agent 构建智能体
agent = create_agent(
    model="openai:gpt-5.5",   # provider:model 格式，支持 OpenAI/Anthropic/Google 等
    tools=[get_weather],      # 工具列表，可以是函数、@tool 装饰对象或字典
    system_prompt="You are a helpful assistant",  # 角色定义
)

# 调用智能体：messages 字段是消息列表
result = agent.invoke(
    {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
)
print(result["messages"][-1].content_blocks)  # 打印最后一条 AI 消息
```

**逐行解释**

| 行号 | 代码 | 作用 |
|------|------|------|
| 1 | `from langchain.agents import create_agent` | 导入 v1 推荐工厂函数 |
| 4-6 | `@tool` 装饰的 `get_weather` | docstring 自动成为工具描述，模型据此决定调用时机 |
| 9-13 | `create_agent(...)` | 返回一个可执行的 Agent（底层是编译好的 LangGraph） |
| 10 | `model="openai:gpt-5.5"` | `provider:model` 字符串形式，懒加载模型 |
| 11 | `tools=[get_weather]` | 工具列表，可混合 Python 函数、`BaseTool` 子类、字典 |
| 12 | `system_prompt=...` | 字符串形式会转为 `SystemMessage`；也可直接传 `SystemMessage` 对象 |
| 16 | `agent.invoke(...)` | 同步调用，返回完整的消息历史与结构化字段 |

### 1.3 进阶：自定义状态、上下文与结构化输出

```python
from dataclasses import dataclass
from pydantic import BaseModel, Field
from typing import Literal
from langchain.agents import create_agent, AgentState
from langchain.tools import tool

# ============ 1. 自定义状态（state_schema）============
class CustomAgentState(AgentState):
    """扩展默认 AgentState，添加业务字段"""
    user_id: str        # 用户标识，跨调用持久化
    preferences: dict   # 业务偏好

# ============ 2. 自定义运行时上下文（context_schema）============
@dataclass
class Context:
    """每次调用传入的不可变配置（区别于 State）"""
    user_id: str
    api_key: str

# ============ 3. 定义工具（带类型注解）============
@tool
def search(query: str, limit: int = 10) -> str:
    """Search the database.

    Args:
        query: 搜索关键词
        limit: 返回结果数量上限
    """
    return f"Found {limit} results for '{query}'"

# ============ 4. 定义结构化输出 ============
class Answer(BaseModel):
    """结构化输出：模型返回此 schema 的实例"""
    summary: str = Field(description="简明结论")
    confidence: float = Field(ge=0, le=1, description="置信度")
    category: Literal["fact", "opinion"] = Field(description="答案类别")

# ============ 5. 组装 Agent ============
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search],
    system_prompt="You are a helpful research assistant. Be concise.",
    state_schema=CustomAgentState,    # 传入自定义状态
    context_schema=Context,           # 传入自定义上下文
    response_format=Answer,           # 启用结构化输出（自动选择 ProviderStrategy 或 ToolStrategy）
)

# ============ 6. 调用：同时传 config 和 context ============
result = agent.invoke(
    {
        "messages": [{"role": "user", "content": "Summarize AI trends"}],
        "user_id": "user_123",          # 写入 state
        "preferences": {"theme": "dark"} # 写入 state
    },
    config={"configurable": {"thread_id": "1"}},  # 持久化 thread
    context=Context(user_id="user_123", api_key="sk-..."),
)

# ============ 7. 读取结果 ============
print(result["structured_response"])  # Answer 实例
print(result["messages"][-1][[.content) # 最终 AI 文本
```

**关键设计点**

1. **State vs Context 的区别**：
   - `State` 是**可变的、跨调用持久化**的（需要 checkpointer）
   - `Context` 是**不可变的、每次调用传入**的（如用户 ID、API key）
2. **`response_format`** 自动选择最优策略：模型支持原生结构化输出时用 `ProviderStrategy`，否则用 `ToolStrategy`（详见 [[langchain/structured-output/结构化输出]]）
3. **多模块协同**与 [[agent/harness/Agent_三层架构|Agent 三层架构]] 高度对齐：感知层=Tools、思考层=Model、执行层=Harness

### 1.4 中间件：可组合的扩展机制

```python
    model="openai:gpt-5.5",
    tools=[search],
    middleware=[
        SummarizationMiddleware(model="openai:gpt-5.4-mini", max_tokens=4000),
        HumanInTheLoopMiddleware(interrupt_on={"send_email": True}),  # 高危工具需人工审批
        ModelRetryMiddleware(max_retries=3),
    ][[,

```

**核心设计**：中间件是**单一职责的钩子**，在模型调用前后/工具执行前后挂入，可自由组合。详见 [[langchain/middleware/中间件概述]]。

## 第 2 章：上下文管理

### 2.1 上下文的本质

上下文 = **模型单次调用能"看到"的所有信息**，由以下部分组成：

1. **系统提示词**（system_prompt）
2. **对话历史**（messages）
3. **工具定义**（tool schemas）
4. **运行时上下文**（context）
5. **自定义状态字段**（state）
6. **技能 / 检索结果**（skills、retrieved docs）

上下文窗口（如 GPT-4o 128K、Claude 200K）是硬约束。管理策略详见 [[langchain/memory/短期记忆]] 和 [[agent/prompt/上下文工程]]。

### 2.2 上下文注入：把信息塞进模型

```python
from langchain.agents import create_agent
from langchain.agents.middleware import dynamic_prompt
from langchain.agents.middleware.types import ModelRequest

# ============ 1. 静态系统提示词 ============
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[...],
    system_prompt="You are a financial advisor. Always be precise.",
)

# ============ 2. 动态系统提示词（每次调用重新生成）============
@dynamic_prompt
def contextual_prompt(request: ModelRequest) -> str:
    """根据 runtime context 动态生成提示词"""
    user_name = request.runtime.context.user_name
    role = request.runtime.context.user_role
    msg_count = len(request.state["messages"])

    return f"""You are assisting {user_name} (role: {role}).
This is turn #{msg_count} of our conversation.
Be concise and respectful."""
```

**逐行解释**：`@dynamic_prompt` 装饰器在 `before_model` 钩子中执行，每次模型调用前动态生成系统提示词，访问 `request.runtime`（运行时）和 `request.state`（状态）。

### 2.3 截断策略：超长上下文怎么办

```python
from langchain.messages import RemoveMessage
from langgraph.graph.message import REMOVE_ALL_MESSAGES
from langchain.agents import create_agent, AgentState
from langchain.agents.middleware import before_model
from langgraph.runtime import Runtime
from typing import Any

@before_model
def trim_messages(state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
    """保留首条 system + 最近 N 条消息"""
    messages = state["messages"]
    if len(messages) <= 3:
        return None  # 不超过阈值，不处理

    first_msg = messages[0]              # 保留系统提示
    recent = messages[-3:]               # 保留最近 3 条
    new_messages = [first_msg] + recent

    # RemoveMessage(id=REMOVE_ALL_MESSAGES) 表示清空后重新插入
    return {
        "messages": [
            RemoveMessage(id=REMOVE_ALL_MESSAGES),
            *new_messages
        ]
    }

agent = create_agent(
    "gpt-5.5",
    tools=[...],
    middleware=[trim_messages],
)
```

**逐行解释**

- `@before_model`：在每次模型调用前执行
- `RemoveMessage(id=REMOVE_ALL_MESSAGES)`：使用 `add_messages` reducer 实现的"全删"标记
- `return None`：表示对状态不做任何修改

### 2.4 优先级排序：让关键信息不被淹没

```python
from langchain.agents.middleware import before_model

PRIORITY = {
    "system": 100,        # 系统提示词，最高
    "tool_result": 80,    # 工具结果
    "human": 60,          # 用户消息
    "ai": 40,             # AI 历史回复
    "tool_call": 20,      # 工具调用请求
}

@before_model
def reorder_messages(state: AgentState, runtime: Runtime) -> dict | None:
    """按优先级重排消息：关键信息靠前"""
    messages = state["messages"]
    sorted_msgs = sorted(
        messages,
        key=lambda m: -PRIORITY.get(m.type, 0)  # 倒序排列
    )
    if [m.id for m in sorted_msgs] != [m.id for m in messages][[:
        return {"messages": sorted_msgs}
    return None
```

## 第 3 章：记忆管理

### 3.1 记忆的两层架构

参考 [[agent/memory/Agent_Memory|Agent 记忆系统]]：

- **短期记忆**（Short-term）：当前对话的 messages，由 **Checkpointer** 持久化
- **长期记忆**（Long-term）：跨对话持久化的事实/偏好，由 **Store** 存储

### 3.2 短期记忆：Checkpointer

```python
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver  # 内存版（开发用）

# 1. 创建 checkpointer
checkpointer = InMemorySaver()

# 2. 注入到 Agent
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[...],
    checkpointer=checkpointer,
)

# 3. 用 thread_id 区分不同对话
config = {"configurable": {"thread_id": "user-1-thread-A"}}

# 第一次调用
agent.invoke(
    {"messages": [{"role": "user", "content": "Hi, I'm Bob."}]},
    config,
)

# 第二次调用：同一 thread_id，能记住前文
result = agent.invoke(
    {"messages": [{"role": "user", "content": "What's my name?"}]},
    config,
)
print(result["messages"][-1].content)  # "You are Bob!"
```

**生产环境**：用 `PostgresSaver` 替代 `InMemorySaver`：

### 3.3 长期记忆：Store

```python
from langgraph.store.memory import InMemoryStore
from langchain.tools import tool, ToolRuntime

# 1. 创建 store
store = InMemoryStore()

# 2. 工具中通过 runtime.store 访问
@tool
def save_user_info(user_id: str, info: dict, runtime: ToolRuntime) -> str:
    """保存用户信息到长期记忆"""
    runtime.store.put(("users",), user_id, info)
    return f"Saved info for {user_id}"

@tool
def recall_user_info(user_id: str, runtime: ToolRuntime) -> str:
    """从长期记忆读取用户信息"""
    item = runtime.store.get(("users",), user_id)
    return str(item.value) if item else "Unknown user"

# 3. 注入到 Agent
agent = create_agent(
    model="gpt-5.5",
    tools=[save_user_info, recall_user_info],
    store=store,
)

# 4. 使用：自动写入 + 跨 thread 读取
agent.invoke({"messages": [{"role": "user", "content": "Save: userid=abc123, name=Alice"}]})
agent.invoke({"messages": [{"role": "user", "content": "Get info for abc123"}]})
# 输出：Name: Alice ...
```

**Store 的命名空间设计**：`("users",)` 是 namespace，`user_id` 是 key。生产环境用 `PostgresStore` 实现持久化。

### 3.4 记忆遗忘机制

**策略 1：基于 TTL（Time-To-Live）**

```python
import time

@tool
def save_with_ttl(key: str, value: str, ttl_seconds: int, runtime: ToolRuntime) -> str:
    """带过期时间的记忆存储"""
    expires_at = time.time() + ttl_seconds
    runtime.store.put(("ephemeral",), key, {"value": value, "expires_at": expires_at})
    return f"Saved with TTL {ttl_seconds}s"

@tool
def recall_with_ttl(key: str, runtime: ToolRuntime) -> str:
    """自动跳过已过期记忆"""
    item = runtime.store.get(("ephemeral",), key)
    if not item:
        return "Not found"
    if item.value.get("expires_at", 0) < time.time():
        runtime.store.delete(("ephemeral",), key)
        return "Expired"
    return item.value["value"]
```

## 第 4 章：代码执行能力

### 4.1 安全风险

智能体执行代码存在 **4 类风险**：

| 风险 | 后果 | 缓解策略 |
|------|------|----------|
| 越权访问 | 读取敏感文件 | 文件系统隔离 |
| 资源耗尽 | CPU/内存耗尽 | 资源限额 |
| 网络外联 | 数据外泄 | 网络隔离 |
| 持久化破坏 | 写入系统目录 | 临时目录 |

### 4.2 沙箱配置：Docker 方案

```python
import subprocess
import tempfile
import os
from pathlib import Path
from langchain.tools import tool

class DockerSandbox:
    """基于 Docker 的代码沙箱"""

    def __init__(
        self,
        image: str = "python:3.12-slim",   # 基础镜像
        memory_limit: str = "128m",        # 内存限制
        cpu_quota: float = 0.5,            # CPU 配额
        network: str = "none",             # 禁用网络
        timeout: int = 30,                 # 执行超时
    ):
        self.image = image
        self.memory_limit = memory_limit
        self.cpu_quota = cpu_quota
        self.network = network
        self.timeout = timeout

    def execute(self, code: str) -> dict:
        """在沙箱中执行 Python 代码"""
        with tempfile.TemporaryDirectory() as tmpdir:
            script_path = Path(tmpdir) / "script.py"
            script_path.write_text(code, encoding="utf-8")

            cmd = [
                "docker", "run",
                "--rm",                                  # 退出后自动清理
                f"--memory={self.memory_limit}",         # 内存限额
                f"--cpus={self.cpu_quota}",              # CPU 限额
                f"--network={self.network}",             # 禁用网络
                f"--read-only",                          # 文件系统只读
                f"--tmpfs=/tmp:size=64m",                # /tmp 临时可写
                "-v", f"{tmpdir}:/work:ro",              # 挂载脚本（只读）
                "-w", "/work",
                self.image,
                "python", "/work/script.py",
            ]

            try:
                result = subprocess.run(
                    cmd,
                    capture_output=True,                  # 捕获 stdout/stderr
                    text=True,
                    timeout=self.timeout,                 # 进程级超时
                )
                return {
                    "stdout": result.stdout,
                    "stderr": result.stderr,
                    "returncode": result.returncode,
                    "success": result.returncode == 0,
                }
            except subprocess.TimeoutExpired:
                return {"error": "Execution timed out", "success": False}
```

**逐行解释**

- `tempfile.TemporaryDirectory()`：自动清理的临时目录
- `--memory=128m`：限制容器内存
- `--network=none`：禁止网络访问
- `--read-only`：根文件系统只读
- `--tmpfs=/tmp:size=64m`：仅 /tmp 可写，且限额 64MB
- `-v {tmpdir}:/work:ro`：把脚本以**只读**方式挂载进去
- `subprocess.run(..., timeout=30)`：进程级超时，防止 docker 卡死

### 4.3 工具化：让 Agent 调用沙箱

```python
sandbox = DockerSandbox()

@tool
def run_python(code: str) -> str:
    """在安全沙箱中执行 Python 代码并返回结果。

    Args:
        code: 合法 Python 代码
    """
    # 1. 静态安全检查
    forbidden = ["import os", "subprocess", "open(", "__import__", "eval(", "exec("]
    if any(f in code for f in forbidden):
        return "Error: 代码包含禁用 API"

    # 2. 调用沙箱
    result = sandbox.execute(code)

    # 3. 结构化返回
    if not result.get("success"):
        return f"执行失败：{result.get('stderr') or result.get('error')}"
    return result["stdout"] or "(无输出)"

agent = create_agent(
    model="gpt-5.5",
    tools=[run_python],
    system_prompt="你可以编写 Python 代码来解决计算问题。",
)
```

## 第 5 章：高级整合

### 5.1 在 LangChain 中实现 Skills 机制

参考 [[agent/skills/Skills|Skills 概念]]：Skills 是**按需加载的 SOP**。LangChain v1 的 `SkillsMiddleware` 直接实现此模式：

```python
from deepagents.middleware import SkillsMiddleware
from deepagents.backends import StateBackend

agent = create_agent(
    model="gpt-5.5",
    tools=[...],
    middleware=[
        SkillsMiddleware(
            backend=StateBackend(),
            sources=["./skills/"],  # 加载 skills 目录
        ),
    ][[,
)
```

**核心映射**：

| Skills 概念 | LangChain 实现 |
|------------|----------------|
| SKILL.md 文档 | `sources` 加载的 Markdown |
| 渐进式披露 | `SkillsMiddleware` 按需加载 |
| 自动匹配 | LLM 根据描述选择 skill |
| 与 MCP 区别 | Skills 是**知识**；MCP 是**能力** |

### 5.2 在 LangChain 中集成 MCP

参考 [[langchain/modules/langchain-mcp/MCP协议概述|MCP 协议]]。LangChain 通过 `langchain-mcp-adapters` 实现：

```python
from langchain-mcp.client import MultiServerMCPClient
from langchain.agents import create_agent

# 1. 配置 MCP 服务器
mcp_client = MultiServerMCPClient({
    "github": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-github"],
        "env": {"GITHUB_TOKEN": "..."},
        "transport": "stdio",
    },
    "filesystem": {
        "url": "http://localhost:3000/sse",
        "transport": "sse",
    },
})

# 2. 获取 MCP 提供的工具
mcp_tools = await mcp_client.get_tools()

# 3. 注入到 LangChain Agent
agent = create_agent(
    model="gpt-5.5",
    tools=[*mcp_tools, *local_tools][[,
)
```

**MCP 优势**：工具标准化、动态发现、生态互操作。
