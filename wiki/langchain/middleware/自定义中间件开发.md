# 自定义中间件开发

LangChain 提供**两种方式**编写自定义中间件：
1. **装饰器方式**（Decorator-based）— 快速、单钩子
2. **类方式**（Class-based）— 多钩子、复杂配置、可复用

## 一、装饰器方式

适用于**单钩子、无复杂配置**的快速场景。

### 1.1 可用装饰器

| 装饰器 | 风格 | 用途 |
|--------|------|------|
| `@before_agent` | Node | Agent 启动前 |
| `@before_model` | Node | 模型调用前 |
| `@after_model` | Node | 模型调用后 |
| `@after_agent` | Node | Agent 完成后 |
| `@wrap_model_call` | Wrap | 包裹模型调用 |
| `@wrap_tool_call` | Wrap | 包裹工具调用 |
| `@dynamic_prompt` | 便捷 | 动态生成系统提示 |

### 1.2 基础示例

```python
from langchain.agents.middleware import (
    before_model, wrap_model_call, AgentState, ModelRequest, ModelResponse,
)
from langgraph.runtime import Runtime
from typing import Any, Callable

@before_model
def log_before_model(state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
    print(f"[{runtime.context.get('user_id', 'unknown')}] 准备调模型，{len(state['messages'])} 条消息")
    return None

@wrap_model_call
def retry_model(
    request: ModelRequest,
    handler: Callable[[ModelRequest], ModelResponse],
) -> ModelResponse:
    for attempt in range(3):
        try:
            return handler(request)
        except Exception as e:
            if attempt == 2:
                raise
            print(f"重试 {attempt + 1}/3: {e}")

agent = create_agent(
    model="gpt-5.5",
    middleware=[log_before_model, retry_model],
    tools=[...],
)
```

### 1.3 动态提示（Dynamic Prompt）

```python
from langchain.agents.middleware import dynamic_prompt

@dynamic_prompt
def contextual_prompt(request: ModelRequest) -> str:
    user_name = request.runtime.context.get("user_name", "用户")
    msg_count = len(request.state["messages"])
    return f"你是 {user_name} 的助手。当前对话已 {msg_count} 轮。请简洁回答。"
```

## 二、类方式（继承 AgentMiddleware）

适用于：
- 单一中间件需要**多个钩子**
- 需要**同步+异步双实现**
- **复杂配置**（阈值、自定义模型等）
- **跨项目复用**（需要初始化时配置）

### 2.1 基础类结构

```python
from langchain.agents.middleware import (
    AgentMiddleware, AgentState, ModelRequest, ModelResponse,
)
from langgraph.runtime import Runtime
from typing import Any, Callable

class LoggingMiddleware(AgentMiddleware):
    """完整日志中间件"""

    def before_model(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
        print(f"[before] 调模型, msgs={len(state['messages'])}")
        return None

    def after_model(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
        print(f"[after] 模型返回: {state['messages'][-1].content[:100]}")
        return None

    async def abefore_model(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
        return None

    async def aafter_model(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
        print(f"[async after] 模型返回")
        return None

agent = create_agent(
    model="gpt-5.5",
    middleware=[LoggingMiddleware()],
    tools=[...],
)
```

### 2.2 类属性（编译时被识别）

`AgentMiddleware` 子类可声明三个类属性：

| 类属性 | 用途 |
|--------|------|
| `state_schema` | 扩展 Agent state 字段 |
| `tools` | 注册中间件自带的工具（如 `write_todos`） |
| `transformers` | 注册作用域感知的流转换器工厂 |

**示例**（带 tools）：
```python
from langchain_core.tools import tool

class TodoMiddleware(AgentMiddleware):
    tools = [write_todos_tool]   # 自动给 Agent 添加这个工具
    state_schema = TodoState     # 扩展 state

    def before_model(self, state, runtime):
        # 每次模型调用前自动注入 todos
        return None
```

### 2.3 构造时传参（推荐）

中间件类支持任意 `__init__` 参数：

```python
class RateLimitMiddleware(AgentMiddleware):
    """限流中间件：限制每分钟最多 N 次调用"""

    def __init__(self, max_per_minute: int = 10, **kwargs):
        super().__init__(**kwargs)
        self.max_per_minute = max_per_minute
        self.calls = []

    def before_model(self, state, runtime):
        now = time.time()
        self.calls = [t for t in self.calls if now - t < 60]
        if len(self.calls) >= self.max_per_minute:
            return {"jump_to": "end"}
        self.calls.append(now)
        return None

# 使用
RateLimitMiddleware(max_per_minute=20)
```

## 三、5 个实战示例

### 3.1 请求日志记录

```python
import json
import time
from langchain.agents.middleware import AgentMiddleware, AgentState
from langgraph.runtime import Runtime

class RequestLoggerMiddleware(AgentMiddleware):
    """记录每次 Agent 调用的耗时、消息数、token 数"""

    def __init__(self, log_file: str = "agent_logs.jsonl"):
        super().__init__()
        self.log_file = log_file
        self.start_time = None

    def before_agent(self, state: AgentState, runtime: Runtime):
        self.start_time = time.time()
        return None

    def after_agent(self, state: AgentState, runtime: Runtime):
        if not self.start_time:
            return None
        log_entry = {
            "timestamp": time.time(),
            "duration": time.time() - self.start_time,
            "total_messages": len(state["messages"]),
            "thread_id": runtime.context.get("thread_id"),
        }
        with open(self.log_file, "a", encoding="utf-8") as f:
            f.write(json.dumps(log_entry, ensure_ascii=False) + "\n")
        return None
```

### 3.2 敏感词过滤

```python
from langchain.agents.middleware import AgentMiddleware, AgentState
from langchain.messages import AIMessage, HumanMessage
from langgraph.runtime import Runtime

class SensitiveWordFilter(AgentMiddleware):
    """检测对话中的敏感词，违规时直接终止"""

    BLOCKED_WORDS = {"暴力", "色情", "赌博"}

    def after_model(self, state: AgentState, runtime: Runtime):
        last_msg = state["messages"][-1]
        if isinstance(last_msg, AIMessage):
            content = last_msg.content
            for word in self.BLOCKED_WORDS:
                if word in content:
                    return {
                        "messages": [AIMessage("抱歉，我不能回答这个问题。")],
                        "jump_to": "end",
                    }
        return None
```

### 3.3 调用次数限制

```python
from langchain.agents.middleware import AgentMiddleware, AgentState
from langgraph.runtime import Runtime

class CallCounterMiddleware(AgentMiddleware):
    """限制单次调用的模型调用次数，超过后强制结束"""

    def __init__(self, max_calls: int = 10):
        super().__init__()
        self.max_calls = max_calls
        self.count = 0

    def before_model(self, state: AgentState, runtime: Runtime):
        self.count += 1
        if self.count > self.max_calls:
            return {"jump_to": "end"}
        return None

    def after_agent(self, state, runtime):
        self.count = 0  # 重置（每次新 invoke 重置）
        return None
```

### 3.4 动态工具选择

```python
from typing import Callable
from langchain.agents.middleware import (
    AgentMiddleware, ModelRequest, ModelResponse,
)

class DynamicToolSelector(AgentMiddleware):
    """根据用户输入动态选择可用工具"""

    def __init__(self, all_tools: list):
        super().__init__()
        self.all_tools = all_tools

    def wrap_model_call(
        self,
        request: ModelRequest,
        handler: Callable[[ModelRequest], ModelResponse],
    ) -> ModelResponse:
        # 根据最后一条用户消息决定可用工具
        last_user_msg = next(
            (m for m in reversed(request.state["messages"])
             if isinstance(m, HumanMessage)),
            None,
        )
        if not last_user_msg:
            return handler(request)

        relevant = self._select_relevant_tools(last_user_msg.content)
        return handler(request.override(tools=relevant))

    def _select_relevant_tools(self, query: str) -> list:
        # 实际实现：关键词匹配、向量相似度、LLM 筛选
        keywords = ["天气", "温度"] if "天气" in query else []
        relevant = [t for t in self.all_tools
                    if any(k in t.name for k in keywords) or not keywords]
        return relevant or self.all_tools
```

### 3.5 Prompt 缓存（Anthropic 专用）

```python
from langchain.agents.middleware import (
    AgentMiddleware, ModelRequest, ModelResponse,
)
from langchain.messages import SystemMessage
from typing import Callable

class AnthropicPromptCache(AgentMiddleware):
    """为 Anthropic 添加 prompt caching，减少重复 token 计费"""

    def wrap_model_call(
        self,
        request: ModelRequest,
        handler: Callable[[ModelRequest], ModelResponse],
    ) -> ModelResponse:
        # 把大文档注入 system message 并标记 cache_control
        new_content = list(request.system_message.content_blocks) + [
            {
                "type": "text",
                "text": "<large_document>...</large_document>",
                "cache_control": {"type": "ephemeral"},
            }
        ]
        new_system_msg = SystemMessage(content=new_content)
        return handler(request.override(system_message=new_system_msg))
```

## 四、状态管理高级用法

### 4.1 自定义 State Schema

```python
from typing_extensions import NotRequired
from langchain.agents.middleware import AgentMiddleware, AgentState

class MyAgentState(AgentState):
    user_id: NotRequired[str]
    request_count: NotRequired[int]
    last_error: NotRequired[str]

class MyMiddleware(AgentMiddleware):
    state_schema = MyAgentState  # 类属性声明
```

### 4.2 跨钩子共享数据

```python
class UsageTracker(AgentMiddleware):
    state_schema = UsageState  # 自定义 state

    def before_model(self, state, runtime):
        # 从 state 读历史计数
        count = state.get("request_count", 0)
        print(f"第 {count + 1} 次调用")
        return None

    def after_model(self, state, runtime):
        # 写新计数到 state
        return {"request_count": state.get("request_count", 0) + 1}
```

## 六、最佳实践

1. **保持中间件职责单一** —— 每个中间件只做一件事
2. **优雅处理错误** —— 避免中间件错误导致 Agent 崩溃
3. **选择合适的钩子类型**：
   - Node-style 用于**顺序逻辑**（日志、验证）
   - Wrap-style 用于**控制流**（重试、回退、缓存）
4. **清晰记录自定义状态属性**
5. **独立单元测试中间件后再集成**
6. **考虑执行顺序** —— 关键中间件放在列表前面
7. **优先使用内置中间件** —— 内置覆盖了 90% 场景
