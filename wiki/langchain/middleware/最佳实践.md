# 中间件最佳实践

## 一、执行顺序与影响

中间件在 `create_agent(middleware=[...])` 中**按列表顺序**注册，但不同钩子类型的执行方向不同：

| 钩子类型 | 执行方向 |
|----------|----------|
| `before_*` | **正序**（先注册先执行） |
| `after_*` | **逆序**（后注册先执行，类似栈） |
| `wrap_*` | **嵌套**（第一个中间件包裹所有其他） |

### 1.1 顺序对结果的影响

```python
middleware=[
    Middleware_A,  # 第一个
    Middleware_B,  # 第二个
    Middleware_C,  # 第三个
]
```

**执行流程**：
```
before_model: A → B → C
wrap_model_call: A(包裹(B(包裹(C(模型))))
after_model: C → B → A
```

### 1.2 关键中间件放前面

**重试、回退类**（wrap-style）应放最前——它们需要包裹所有其他中间件：

```python
middleware=[
    ModelRetryMiddleware(max_retries=3),    # 最外层，最先执行
    ModelFallbackMiddleware(...),           # 重试失败后回退
    PIIMiddleware(...),                     # 内部：PII 脱敏
    SummarizationMiddleware(...),           # 内部：摘要
]
```

**日志、监控类**（node-style）应放最前——它们最全面地记录状态：

```python
middleware=[
    RequestLoggerMiddleware(...),    # 最外层日志
    ErrorTrackingMiddleware(...),    # 错误跟踪
    ModelCallLimitMiddleware(...),   # 限制
    # ... 业务中间件
]
```

### 1.3 反模式

```python
# ❌ 重试放最里层（无效）
middleware=[
    PIIMiddleware(...),
    SummarizationMiddleware(...),
    ModelRetryMiddleware(max_retries=3),  # 只重试最后一步，前面错误捕获不到
]

# ✅ 重试放最外层
middleware=[
    ModelRetryMiddleware(max_retries=3),  # 包裹所有
    PIIMiddleware(...),
    SummarizationMiddleware(...),
]
```

## 二、生产环境推荐配置

### 2.1 最小推荐配置

```python
from langchain.agents import create_agent
from langchain.agents.middleware import (
    ModelCallLimitMiddleware,
    ToolCallLimitMiddleware,
    ModelFallbackMiddleware,
    ToolRetryMiddleware,
    SummarizationMiddleware,
    PIIMiddleware,
    HumanInTheLoopMiddleware,
)
from langchain_deepseek import ChatDeepSeek
from langgraph.checkpoint.memory import InMemorySaver

main_model = ChatDeepSeek(model="deepseek-v4-flash", temperature=1.0)
summary_model = ChatDeepSeek(model="deepseek-v4-flash", temperature=0.0)

checkpointer = InMemorySaver()  # 生产建议用 PostgresSaver

agent = create_agent(
    model=main_model,
    tools=tools,
    checkpointer=checkpointer,
    middleware=[
        # 1. 可靠性（最外层，包裹所有）
        ModelRetryMiddleware(max_retries=3, initial_delay=1.0),
        ModelFallbackMiddleware(
            first_model="claude-sonnet-4-6",
            "gpt-5.5",
        ),
        # 2. 可观测性
        RequestLoggerMiddleware(log_file="agent.log"),
        # 3. 成本控制
        ModelCallLimitMiddleware(thread_limit=30, run_limit=15),
        ToolCallLimitMiddleware(thread_limit=20, run_limit=10),
        # 4. 关键工具重试
        ToolRetryMiddleware(max_retries=2, tools=["web_search", "database_query"]),
        # 5. 上下文管理
        SummarizationMiddleware(
            model=summary_model,
            trigger=("tokens", 4000),
            keep=("messages", 20),
        ),
        # 6. 隐私保护
        PIIMiddleware(pii_type="email", strategy="redact"),
        PIIMiddleware(pii_type="cn_phone", detector=r"1[3-9]\d{9}", strategy="mask"),
        # 7. 关键操作审批
        HumanInTheLoopMiddleware(
            interrupt_on={
                "send_email": True,
                "delete_file": True,
                "execute_query": True,
            },
        ),
    ],
)
```

### 2.2 不同场景的精简配置

**RAG 问答（轻量）**：
```python
middleware=[
    ModelCallLimitMiddleware(run_limit=5),
    ToolCallLimitMiddleware(tool_name="web_search", run_limit=3),
    SummarizationMiddleware(model=summary_model, trigger=("tokens", 3000)),
]
```

**代码 Agent（重型）**：
```python
middleware=[
    ModelRetryMiddleware(max_retries=3),
    FilesystemMiddleware(),
    FilesystemFileSearchMiddleware(root_path="/project"),
    ShellToolMiddleware(execution_policy=DockerExecutionPolicy(...)),
    ToolCallLimitMiddleware(run_limit=50),  # 工具调用频繁
    HumanInTheLoopMiddleware(interrupt_on={"execute_command": True}),
]
```

**客服 Agent（合规）**：
```python
middleware=[
    PIIMiddleware(pii_type="email", strategy="redact"),
    PIIMiddleware(pii_type="cn_phone", strategy="mask"),
    PIIMiddleware(pii_type="credit_card", strategy="block"),
    HumanInTheLoopMiddleware(interrupt_on={"refund": True, "cancel_order": True}),
    SummarizationMiddleware(model=summary_model, trigger=("tokens", 5000)),
]
```

## 三、性能优化

### 3.1 减少 LLM 调用次数

```python
# ❌ 不必要的筛选
middleware=[
    LLMToolSelectorMiddleware(model=main_model, max_tools=5),  # 用主模型筛选
]

# ✅ 用便宜模型筛选
middleware=[
    LLMToolSelectorMiddleware(model=cheap_model, max_tools=5),
]
```

### 3.2 摘要触发阈值

```python
# ❌ 阈值太低（频繁摘要）
SummarizationMiddleware(model=summary_model, trigger=("tokens", 500))

# ❌ 阈值太高（来不及）
SummarizationMiddleware(model=summary_model, trigger=("tokens", 100000))

# ✅ 根据模型窗口设定
# 128K 窗口 → trigger 8000-10000
# 8K 窗口 → trigger 3000-4000
SummarizationMiddleware(model=summary_model, trigger=("tokens", 8000))
```

### 3.3 token_counter 选择

```python
# ❌ 默认（粗略字符计数）— 可能过早触发
SummarizationMiddleware(model=summary_model, trigger=("tokens", 4000))

# ✅ 精确计数（用模型自身方法）
SummarizationMiddleware(
    model=summary_model,
    trigger=("tokens", 4000),
    token_counter=main_model.get_num_tokens_from_messages,
)
```

### 3.4 PII 检测范围最小化

```python
# ❌ 全范围检测（性能差）
PIIMiddleware(pii_type="email", apply_to_input=True, apply_to_output=True, apply_to_tool_results=True)

# ✅ 只检测输入
PIIMiddleware(pii_type="email", apply_to_input=True)
```

## 四、调试技巧

### 4.1 打印中间件执行流

```python
class TraceMiddleware(AgentMiddleware):
    def before_model(self, state, runtime):
        print(f"→ [before_model] msgs={len(state['messages'])}")
        return None

    def after_model(self, state, runtime):
        print(f"← [after_model] last={state['messages'][-1].type}")
        return None

    def wrap_model_call(self, request, handler):
        print(f"⊃ [wrap_model_call] tools={[t.name for t in request.tools]}")
        response = handler(request)
        print(f"⊃ [wrap_model_call done]")
        return response
```

### 4.2 单独测试每个中间件

```python
# 单元测试样例
def test_pii_middleware():

    from langchain.messages import HumanMessage

    pii = PIIMiddleware(pii_type="email", strategy="redact")
    state = {"messages": [HumanMessage("邮箱是 alice@example.com")]}
    # ... 调用 before_model 验证
```

### 4.3 用 stream_events 观察

```python
async for event in agent.astream_events(input, config, version="v3"):
    event_type = event.get("event")
    if event_type == "on_chain_start":
        print(f"开始: {event['name']}")
    elif event_type == "on_chain_end":
        print(f"结束: {event['name']}")
    elif event_type == "on_tool_start":

        print(f"  ← 结果: {str(event['data'].output)[:100]}")
```

## 五、常见反模式

### 5.1 ❌ 太多中间件

```python
# ❌ 10+ 中间件互相干扰
middleware=[m1, m2, m3, m4, m5, m6, m7, m8, m9, m10]

# ✅ 精选 5-7 个真正用得上的
middleware=[Retry, Fallback, PII, Summary, HITL, Logging, Limit]
```

### 5.2 ❌ 业务逻辑写在中间件

```python
# ❌ 中间件管业务
class BusinessLogicMiddleware(AgentMiddleware):
    def after_model(self, state, runtime):
        if "订单" in state["messages"][-1].content:
            # 复杂的订单处理逻辑
            ...

# ✅ 业务逻辑应该是 tool
@tool
def process_order(order_id: str):
    ...
```

### 5.3 ❌ 中间件依赖 state 中的未声明字段

```python
# ❌ 访问不存在的字段
class BadMiddleware(AgentMiddleware):
    def before_model(self, state, runtime):
        return {"undefined_field": 42}  # 抛 KeyError

# ✅ 先声明 state_schema
class MyState(AgentState):
    defined_field: NotRequired[int]

class GoodMiddleware(AgentMiddleware):
    state_schema = MyState
```

### 5.4 ❌ 同步钩子做 I/O

```python
# ❌ 同步钩子发 HTTP 请求
class BadMiddleware(AgentMiddleware):
    def before_model(self, state, runtime):
        requests.post(...)  # 阻塞！阻塞整个 Agent

# ✅ 异步钩子
class GoodMiddleware(AgentMiddleware):
    async def abefore_model(self, state, runtime):
        async with aiohttp.ClientSession() as session:
            await session.post(...)
```

### 5.5 ❌ 状态更新用错 API

```python
# ❌ Node-style 钩子用 Command
@before_model
def bad(state, runtime):
    return Command(update={"x": 1})  # 错误！Node-style 直接返回 dict

# ✅
@before_model
def good(state, runtime):
    return {"x": 1}  # dict
```

```python
# ❌ Wrap-style 钩子返回 dict
@wrap_model_call
def bad(request, handler):
    return {"x": 1}  # 错误！Wrap-style 必须返回 ExtendedModelResponse

# ✅
@wrap_model_call
def good(request, handler):
    response = handler(request)
    return ExtendedModelResponse(
        model_response=response,
        command=Command(update={"x": 1}),
    )
```

## 六、监控与告警

### 6.1 关键指标

```python
class MetricsMiddleware(AgentMiddleware):
    """发送关键指标到监控系统"""

    def after_agent(self, state, runtime):
        metrics = {
            "total_messages": len(state["messages"]),
            "model_calls": state.get("model_call_count", 0),
            "tool_calls": state.get("tool_call_count", 0),
            "duration": time.time() - self.start_time,
        }
        # 发送到 Prometheus / StatsD / CloudWatch
        statsd.gauge("agent.usage", metrics)
```

### 6.2 错误跟踪

```python
import sentry_sdk

class SentryMiddleware(AgentMiddleware):
    def wrap_model_call(self, request, handler):
        try:
            return handler(request)
        except Exception as e:
            sentry_sdk.capture_exception(e, extra={
                "messages": len(request.state["messages"]),
                "tools": [t.name for t in request.tools],
            })
            raise
```
