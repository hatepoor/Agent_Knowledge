# 模型（Models）

LLM（大语言模型）是强大的 AI 工具，能像人类一样理解和生成文本。它们是 [Agent](https://docs.langchain.com/oss/python/langchain/agents) 的推理引擎。

LangChain 的标准模型接口让你能访问许多不同的提供商集成，便于实验和切换模型。

## 基础用法

### 初始化模型

使用 `init_chat_model` 从所选提供商初始化模型：

```python
import os
from langchain.chat_models import init_chat_model

# OpenAI
os.environ["OPENAI_API_KEY"] = "sk-..."
model = init_chat_model("gpt-5.5")

# Anthropic
os.environ["ANTHROPIC_API_KEY"] = "sk-..."
model = init_chat_model("claude-sonnet-4-6")

# Google Gemini
os.environ["GOOGLE_API_KEY"] = "..."
model = init_chat_model("google_genai:gemini-2.5-flash-lite")

# AWS Bedrock
model = init_chat_model(
    "us.anthropic.claude-sonnet-4-6",
    model_provider="bedrock_converse",
)
```

### 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `model` | string | 模型名称或标识符 |
| `temperature` | number | 控制输出随机性 |
| `max_tokens` | number | 限制响应中的最大 token 数 |
| `timeout` | number | 等待响应最大秒数 |
| `max_retries` | number | 失败时最大重试次数（默认 6） |

```python
model = init_chat_model(
    "claude-sonnet-4-6",
    temperature=0.7,
    timeout=30,
    max_tokens=1000,
    max_retries=6,
)
```

## 调用

### invoke

```python
response = model.invoke("Why do parrots have colorful feathers?")
```

### 消息列表调用

```python
conversation = [
    {"role": "system", "content": "You translate English to French."},
    {"role": "user", "content": "Translate: I love programming."},
    {"role": "assistant", "content": "J'adore la programmation."},
    {"role": "user", "content": "Translate: I love building applications."}
]
response = model.invoke(conversation)
```

### stream（流式传输）

```python
for chunk in model.stream("Why do parrots have colorful feathers?"):
    print(chunk.text, end="|", flush=True)
```

### batch（批量调用）

```python
responses = model.batch([
    "Why do parrots have colorful feathers?",
    "How do airplanes fly?",
    "What is quantum computing?"
])
```

## 工具调用（Tool Calling）

模型可以请求调用执行任务的工具：

```python
from langchain.tools import tool

@tool
def get_weather(location: str) -> str:
    """Get the weather at a location."""
    return f"It's sunny in {location}."

model_with_tools = model.bind_tools([get_weather])
response = model_with_tools.invoke("What's the weather like in Boston?")

for tool_call in response.tool_calls:
    print(f"Tool: {tool_call['name']}")
    print(f"Args: {tool_call['args']}")
```

### 工具执行循环

```python
# 步骤 1: 模型生成工具调用
messages = [{"role": "user", "content": "What's the weather in Boston?"}]
ai_msg = model_with_tools.invoke(messages)
messages.append(ai_msg)

# 步骤 2: 执行工具并收集结果
for tool_call in ai_msg.tool_calls:
    tool_result = get_weather.invoke(tool_call)
    messages.append(tool_result)

# 步骤 3: 将结果传回模型获取最终响应
final_response = model_with_tools.invoke(messages)
```

### 并行工具调用

```python
response = model_with_tools.invoke("What's the weather in Boston and Tokyo?")
# 模型可以生成多个工具调用并行执行
```

## 结构化输出

```python
from pydantic import BaseModel, Field

class Movie(BaseModel):
    title: str = Field(description="The title of the movie")
    year: int = Field(description="The year the movie was released")
    director: str = Field(description="The director")
    rating: float = Field(description="Rating out of 10")

model_with_structure = model.with_structured_output(Movie)
response = model_with_structure.invoke("Provide details about Inception")
```

## 高级主题

### 模型配置（Configurable Models）

```python
configurable_model = init_chat_model(temperature=0)
configurable_model.invoke(
    "what's your name",
    config={"configurable": {"model": "gpt-5-nano"}},
)
configurable_model.invoke(
    "what's your name",
    config={"configurable": {"model": "claude-sonnet-4-6"}},
)
```

### 动态模型选择

```python
from langchain.agents.middleware import wrap_model_call

@wrap_model_call
def dynamic_model_selection(request, handler):
    """Choose model based on conversation complexity."""
    message_count = len(request.state["messages"][[)
    model = advanced_model if message_count > 10 else basic_model
    return handler(request.override(model=model))
```

### 多模态

某些模型可以处理图像、音频和视频等非文本数据。

许多提供商提供提示词缓存功能以降低延迟和成本。

### 模型提供商接入方式

LangChain 接入模型厂商有两种方式：**专用客户端**和 **OpenAI 兼容客户端**。

**专用客户端**（如 `ChatDeepSeek`、`ChatAnthropic`、`ChatGoogleGenerativeAI`）由厂商或社区专门维护，支持该厂商的所有特有功能。

**OpenAI 兼容客户端**（`ChatOpenAI` + `base_url`）利用大多数厂商兼容 OpenAI 协议的特点，通过切换端点地址来接入不同厂商。

```python
# 方式一：专用客户端（推荐，功能完整）
from langchain_deepseek import ChatDeepSeek
llm = ChatDeepSeek(
    model="deepseek-reasoner",
    thinking={"type": "enabled"},       # DeepSeek 特有：深度推理
    reasoning_effort="high",            # DeepSeek 特有：推理强度
)

# 方式二：OpenAI 兼容客户端（通用，但特有参数需逃生舱）
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(
    model="deepseek-reasoner",
    base_url="https://api.deepseek.com",
    api_key="sk-xxx",
    extra_body={                         # 非标准参数通过逃生舱传递
        "thinking": {"type": "enabled"},
        "reasoning_effort": "high",
    },
)
```

**核心差异**：

| 维度 | 专用客户端 | OpenAI 兼容客户端 |
|------|-----------|-----------------|
| 特有功能 | 原生支持（thinking、reasoning_effort 等） | 需 `extra_body` 逃生舱 |
| 特殊消息类型 | 正确解析（如推理过程 `reasoning_content`） | 可能丢失非标准信息 |
| 类型安全 | 有 IDE 提示和参数校验 | 逃生舱参数无类型检查 |
| 维护时效 | 厂商维护，API 更新后第一时间适配 | 依赖 `langchain-openai`，可能有延迟 |
| 切换厂商 | 需换包和换类 | 只改 `base_url` + `api_key` |
| 依赖数量 | 每个厂商一个包 | 统一用 `langchain-openai` |

**选型建议**：

| 场景 | 推荐方式 |
|------|---------|
| 只用一个模型厂商 | 专用客户端 |
| 需要厂商特有功能（thinking、特殊参数） | 专用客户端 |
| 需要快速切换多个厂商 | OpenAI 兼容模式 |
| 厂商没有专用包 | OpenAI 兼容模式（大多数国内厂商兼容 OpenAI 协议） |
| 原型验证 | OpenAI 兼容模式（零额外依赖） |

> `init_chat_model` 是 LangChain 推荐的统一入口，内部会自动选择对应的专用客户端。如果需要厂商特有参数，仍建议直接使用专用客户端。
