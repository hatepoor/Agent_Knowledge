# 长期记忆

跨会话持久化的记忆系统。Agent 记住用户偏好、历史事实、经验总结，下次对话时自动加载。类似 Claude Code 的 CLAUDE.md——项目级/用户级的持久化知识。

## 一、短期记忆 vs 长期记忆

| 维度 | 短期记忆 | 长期记忆 |
|------|---------|---------|
| 生命周期 | 一次对话内 | 跨对话、永久 |
| 存储内容 | 当前对话消息历史 | 用户偏好、事实、经验 |
| 容量 | 有限（上下文窗口） | 理论无限（外部存储） |
| 存储位置 | 内存（Checkpointer） | 数据库 / 向量库 / 文件 |
| 管理方式 | 自动（框架管理） | 主动（Agent 或用户触发） |
| 类比 | 正在打的这通电话 | 脑子里记住的"这个人喜欢什么" |

### 与 Claude Code 的对应

| Claude Code | Agent 记忆 | 说明 |
|-------------|-----------|------|
| `~/.claude/CLAUDE.md`（用户级） | 长期记忆 - 用户偏好 | 跨所有项目/会话 |
| `项目/CLAUDE.md`（项目级） | 长期记忆 - 项目知识 | 跨会话，同一项目 |
| 当前对话上下文 | 短期记忆 | 本次会话的消息 |
| `/remember` 命令 | `remember()` 工具 | 主动写入长期记忆 |
| 上下文窗口截断 | 短期记忆 trim/summarize | 容量管理 |

## 二、整体架构

```
新对话开始
  │
  ▼
┌─────────────────────────────────┐
│  加载长期记忆                     │  ← 类似读 CLAUDE.md
│  "用户是 Python 开发者"           │
│  "用户喜欢简洁回答"              │
│  "上次讨论了 LangGraph"          │
└──────────────┬──────────────────┘
               │ 注入 system prompt
               ▼
┌─────────────────────────────────┐
│  对话进行中（短期记忆）            │  ← Checkpointer 管理
│  消息1 → 消息2 → 消息3 → ...    │
└──────────────┬──────────────────┘
               │ 对话结束 / 触发条件
               ▼
┌─────────────────────────────────┐
│  提取 → 写入长期记忆              │  ← 类似更新 CLAUDE.md
│  "用户正在做 Agent 项目"          │
│  "用户偏好配置驱动"              │
└─────────────────────────────────┘
```

## 三、方案一：结构化存储（SQLite）

适合精确事实：用户信息、配置、明确的偏好。

```python
import sqlite3
import time

class StructuredMemory:
    """结构化长期记忆：精确查找和修改"""
    
    def __init__(self, db_path: str = "data/long_term.db"):
        self.conn = sqlite3.connect(db_path, check_same_thread=False)
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS memories (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                user_id TEXT NOT NULL,
                category TEXT NOT NULL,
                key TEXT NOT NULL,
                value TEXT NOT NULL,
                created_at REAL,
                updated_at REAL,
                UNIQUE(user_id, key)
            )
        """)
        self.conn.commit()
    
    # ===== 增/改 =====
    def remember(self, user_id: str, key: str, value: str, category: str = "fact"):
        """记住一条信息（key 存在则覆盖）"""
        now = time.time()
        self.conn.execute("""
            INSERT INTO memories (user_id, category, key, value, created_at, updated_at)
            VALUES (?, ?, ?, ?, ?, ?)
            ON CONFLICT(user_id, key) DO UPDATE SET value=?, updated_at=?, category=?
        """, (user_id, category, key, value, now, now, value, now, category))
        self.conn.commit()
    
    # ===== 查 =====
    def recall(self, user_id: str, key: str) -> str | None:
        """精确查找一条记忆"""
        row = self.conn.execute(
            "SELECT value FROM memories WHERE user_id=? AND key=?",
            (user_id, key)
        ).fetchone()
        return row[0] if row else None
    
    def recall_by_category(self, user_id: str, category: str) -> list[dict]:
        """按分类获取所有记忆"""
        rows = self.conn.execute(
            "SELECT key, value, updated_at FROM memories WHERE user_id=? AND category=? ORDER BY updated_at DESC",
            (user_id, category)
        ).fetchall()
        return [{"key": r[0], "value": r[1], "updated_at": r[2]} for r in rows]
    
    def search(self, user_id: str, query: str) -> list[dict]:
        """模糊搜索"""
        rows = self.conn.execute(
            "SELECT key, value, category FROM memories WHERE user_id=? AND (key LIKE ? OR value LIKE ?)",
            (user_id, f"%{query}%", f"%{query}%")
        ).fetchall()
        return [{"key": r[0], "value": r[1], "category": r[2]} for r in rows]
    
    # ===== 删 =====
    def forget(self, user_id: str, key: str):
        """删除一条记忆"""
        self.conn.execute("DELETE FROM memories WHERE user_id=? AND key=?", (user_id, key))
        self.conn.commit()
    
    def forget_all(self, user_id: str):
        """清空某用户所有记忆"""
        self.conn.execute("DELETE FROM memories WHERE user_id=?", (user_id,))
        self.conn.commit()
    
    # ===== 注入 prompt =====
    def get_context_for_prompt(self, user_id: str) -> str:
        """生成注入 system prompt 的记忆上下文"""
        rows = self.conn.execute(
            "SELECT category, key, value FROM memories WHERE user_id=? ORDER BY category, updated_at DESC LIMIT 20",
            (user_id,)
        ).fetchall()
        if not rows:
            return ""
        
        lines = ["[用户记忆]"]
        current_category = ""
        for category, key, value in rows:
            if category != current_category:
                lines.append(f"\n## {category}")
                current_category = category
            lines.append(f"- {key}: {value}")
        return "\n".join(lines)
```

### 记忆分类

| category | 存什么 | 示例 |
|----------|--------|------|
| `preference` | 用户偏好 | "喜欢简洁回答"、"代码注释用中文" |
| `fact` | 客观事实 | "服务器IP是10.0.0.5"、"用 Python 3.12" |
| `experience` | 经验总结 | "上次部署时 Nginx 配置踩了坑" |
| `project` | 项目知识 | "这个项目用 LangGraph + FastAPI" |
| `relationship` | 人物关系 | "张三是前端负责人" |

## 四、方案二：语义存储（向量数据库）

适合模糊记忆：对话摘要、经验教训、不精确的描述。

```python
from langchain.vectorstores import Chroma
from langchain.embeddings import init_embeddings
import time, uuid

class SemanticMemory:
    """语义长期记忆：通过相似度检索"""
    
    def __init__(self, persist_dir: str = "data/semantic_memory"):
        self.embeddings = init_embeddings("openai:text-embedding-3-small")
        self.vectorstore = Chroma(
            persist_directory=persist_dir,
            embedding_function=self.embeddings,
            collection_name="long_term_memory",
        )
    
    def remember(self, content: str, user_id: str, category: str = "general"):
        """存储一条记忆"""
        memory_id = f"{user_id}_{uuid.uuid4().hex[:8]}"
        self.vectorstore.add_texts(
            texts=[content],
            metadatas=[{
                "user_id": user_id,
                "category": category,
                "timestamp": time.time(),
            }],
            ids=[memory_id],
        )
    
    def recall(self, query: str, user_id: str, top_k: int = 5) -> list[str]:
        """语义检索相关记忆"""
        results = self.vectorstore.similarity_search(
            query, k=top_k,
            filter={"user_id": user_id},
        )
        return [doc.page_content for doc in results]
    
    def forget(self, memory_id: str):
        """删除一条记忆"""
        self.vectorstore._collection.delete(ids=[memory_id])
    
    def get_context_for_prompt(self, user_id: str, current_topic: str) -> str:
        """根据当前话题检索相关记忆，注入 prompt"""
        memories = self.recall(current_topic, user_id, top_k=3)
        if not memories:
            return ""
        return "[相关记忆]\n" + "\n".join(f"- {m}" for m in memories)
```

## 五、两种方案对比

| 维度 | 结构化（SQLite） | 语义（向量库） |
|------|-----------------|---------------|
| 查找方式 | 精确 key 匹配 / LIKE | 语义相似度 |
| 适合存 | 事实、配置、用户信息 | 对话摘要、经验、模糊描述 |
| 修改 | 直接 UPDATE | 需删除旧的 + 写入新的 |
| 删除 | 按 key 精确删 | 按 ID 或条件 |
| 典型查询 | "用户的邮箱是什么" | "之前讨论过什么关于部署的问题" |
| 依赖 | 无（标准库） | 需要 embedding 模型 |

**实际项目中两者结合：** SQLite 存精确事实，向量库存模糊记忆。

## 六、封装成 Agent 工具

让 Agent 自己管理记忆（增删改查）：

```python
from langchain.tools import tool

memory = StructuredMemory()
semantic = SemanticMemory()

@tool
def save_memory(key: str, value: str, category: str = "fact") -> str:
    """保存一条重要信息到长期记忆。
    当用户告诉你需要记住的事情时使用。
    category 可选: preference(偏好), fact(事实), experience(经验), project(项目)"""
    memory.remember(user_id="current_user", key=key, value=value, category=category)
    return f"已记住: {key} = {value}"

@tool
def recall_memory(query: str) -> str:
    """从长期记忆中检索相关信息。
    当需要回忆之前记住的内容时使用。"""
    # 先精确查
    exact = memory.search(user_id="current_user", query=query)
    if exact:
        return "\n".join(f"- {m['key']}: {m['value']}" for m in exact)
    # 再语义查
    fuzzy = semantic.recall(query, user_id="current_user", top_k=3)
    if fuzzy:
        return "\n".join(f"- {m}" for m in fuzzy)
    return "没有找到相关记忆"

@tool
def forget_memory(key: str) -> str:
    """删除一条记忆。当用户要求忘记某事时使用。"""
    memory.forget(user_id="current_user", key=key)
    return f"已忘记: {key}"

@tool
def list_memories(category: str = "") -> str:
    """列出所有记忆。可选按分类过滤。"""
    if category:
        items = memory.recall_by_category("current_user", category)
    else:
        items = memory.search("current_user", "%")
    if not items:
        return "暂无记忆"
    return "\n".join(f"- [{m.get('category','')}] {m['key']}: {m['value']}" for m in items)
```

## 七、完整集成：记忆 + Agent

```python
from langchain.agents import create_agent
from langchain_core.messages import HumanMessage, SystemMessage
from langgraph.checkpoint.memory import InMemorySaver

# 初始化
checkpointer = InMemorySaver()  # 短期记忆
long_term = StructuredMemory()  # 长期记忆
semantic = SemanticMemory()     # 语义记忆

# 记忆工具
memory_tools = [save_memory, recall_memory, forget_memory, list_memories]

# Agent（带记忆工具）
agent = create_agent(
    "openai:gpt-4o",
    tools=[*other_tools, *memory_tools],
    checkpointer=checkpointer,
)

async def chat(user_id: str, message: str, thread_id: str) -> str:
    """带长期记忆的对话入口"""
    
    # 1. 从长期记忆构建上下文
    memory_context = long_term.get_context_for_prompt(user_id)
    topic_context = semantic.get_context_for_prompt(user_id, message)
    
    # 2. 组装 system prompt
    system_parts = ["你是智能助手。"]
    if memory_context:
        system_parts.append(memory_context)
    if topic_context:
        system_parts.append(topic_context)
    
    # 3. 调用 Agent（短期记忆由 checkpointer 自动管理）
    result = await agent.ainvoke(
        {"messages": [
            SystemMessage(content="\n\n".join(system_parts)),
            HumanMessage(content=message),
        ]},
        config={"configurable": {"thread_id": thread_id}},
    )
    
    reply = result["messages"][-1].content
    
    # 4. 自动提取值得记住的信息（可选）
    await auto_extract_memory(user_id, message, reply)
    
    return reply

async def auto_extract_memory(user_id: str, user_msg: str, agent_reply: str):
    """从对话中自动提取值得长期记住的信息"""
    # 简单规则匹配（生产环境可用 LLM 判断）
    triggers = ["记住", "我喜欢", "我的", "我是", "以后"]
    if any(t in user_msg for t in triggers):
        # 用 LLM 提取结构化信息
        extract_agent = create_agent("openai:gpt-4o-mini", tools=[])
        result = await extract_agent.ainvoke({
            "messages": [{"role": "user", "content": f"""从以下用户消息中提取值得长期记住的信息。
输出 JSON 格式: {{"key": "...", "value": "...", "category": "preference|fact|experience"}}
如果没有值得记住的，输出: {{"key": "", "value": "", "category": ""}}

用户消息: {user_msg}"""}]
        })
```

## 八、Agent 使用记忆的行为示例

```
用户: "记住我的服务器 IP 是 10.0.0.5"
  → Agent 调用 save_memory(key="服务器IP", value="10.0.0.5", category="fact")
  → "已记住"

（新对话，第二天）
用户: "我的服务器 IP 是多少？"
  → system prompt 中已注入: "- 服务器IP: 10.0.0.5"
  → Agent 直接回答: "你的服务器 IP 是 10.0.0.5"
  （或者调用 recall_memory("服务器IP")）

用户: "IP 改成 192.168.1.100 了"
  → Agent 调用 save_memory(key="服务器IP", value="192.168.1.100")
  → 覆盖旧值

用户: "把服务器 IP 忘掉"
  → Agent 调用 forget_memory(key="服务器IP")
```

## 九、记忆的生命周期管理

| 操作 | 触发条件 | 实现 |
|------|---------|------|
| 写入 | 用户明确说"记住" / 自动提取 | `remember()` |
| 检索 | 每次对话开始 / Agent 主动调用 | `recall()` / `get_context_for_prompt()` |
| 更新 | 同一 key 的新信息 | `remember()` 覆盖（UPSERT） |
| 衰减 | 长期未访问的记忆 | 定期清理 `updated_at` 过旧的 |
| 删除 | 用户说"忘记" / 信息过时 | `forget()` |
| 压缩 | 记忆太多 | 用 LLM 合并相似记忆 |

### 衰减策略

```python
def cleanup_old_memories(days: int = 90):
    """清理超过 N 天未更新的记忆"""
    cutoff = time.time() - days * 86400
    conn.execute("DELETE FROM memories WHERE updated_at < ?", (cutoff,))
    conn.commit()
```

## 十、常见陷阱

### 1. 记忆无限膨胀

```python
# 错误：什么都记，几个月后几千条
# 正确：只记有价值的信息 + 定期衰减清理
# 规则：preference 和 fact 永久保留，experience 90 天衰减
```

### 2. 每次对话都注入全部记忆

```python
# 错误：100 条记忆全塞进 system prompt → 浪费 token
memory_context = long_term.get_all(user_id)  # 可能几千字

# 正确：只注入相关的（按当前话题检索 top 5）
memory_context = semantic.get_context_for_prompt(user_id, current_message)
```

### 3. 新旧信息冲突

```python
# 错误：记了"IP是10.0.0.5"，后来又记了"IP是192.168.1.100"，两条都在
# 正确：用 UNIQUE(user_id, key) 约束，同 key 覆盖
# 或者更新时先删旧的
```

### 4. 隐私问题

```python
# 错误：所有用户共享一个记忆库
# 正确：每条记忆绑定 user_id，检索时必须过滤
recall(query, user_id="user_001")  # 只能查自己的
```
