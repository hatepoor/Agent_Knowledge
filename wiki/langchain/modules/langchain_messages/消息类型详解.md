# 消息类型详解

## 概述

LangChain 定义了多种消息类型来统一不同 LLM 提供商的聊天 API 格式。每种消息类型对应对话中的不同角色和用途。

## HumanMessage

代表**用户输入**，对应 API 中的 `user` 角色。

```python
from langchain.messages import HumanMessage

# 纯文本
msg = HumanMessage(content="What's the weather?")

# 多模态（详见 [[langchain/modules/langchain_messages/多模态消息|多模态消息]]）
msg = HumanMessage(content=[
    {"type": "text", "text": "What's in this image?"},
    {"type": "image", "url": "https://example.com/cat.jpg"},
])
```

**特点**：
- `type` 值为 `"human"`
- 支持字符串或内容块列表作为 `content`
- 在对话历史中触发模型响应

## AIMessage

代表**AI 响应**，对应 API 中的 `assistant` 角色。

```python
from langchain.messages import AIMessage

# 普通响应
msg = AIMessage(content="It's sunny in Tokyo!")

# 带工具调用的响应
msg = AIMessage(
    content="",
    tool_calls=[{
        "id": "call_001",
        "name": "get_weather",
        "args": {"city": "Tokyo"},
        "type": "tool_call",
    }],
)

# 带推理内容的响应
msg = AIMessage(
    content="",
    additional_kwargs={"reasoning": "The user is asking about..."},
)
```

**特点**：
- `type` 值为 `"ai"`
- `tool_calls` 属性包含模型请求的工具调用列表
- `content` 可能为空字符串（当模型只请求工具调用时）
- `content_blocks` 提供规范化的内容块

## SystemMessage

代表**系统提示词**，对应 API 中的 `system` 角色。

```python
from langchain.messages import SystemMessage

msg = SystemMessage(content="You are a helpful assistant that speaks French.")
```

**特点**：
- `type` 值为 `"system"`
- 通常放在消息列表的最前面
- 定义模型的行为边界和角色
- 不参与对话轮次计数

## ToolMessage

代表**工具执行结果**，对应 API 中的 `tool` 角色。

```python
from langchain.messages import ToolMessage

msg = ToolMessage(
    content="It's sunny in Tokyo, 25 degrees C.",
    tool_call_id="call_001",  # 必须匹配对应的 tool_call.id
    name="get_weather",       # 工具名称（可选但推荐）
)
```

**特点**：
- `type` 值为 `"tool"`
- 必须包含 `tool_call_id`，与 `AIMessage.tool_calls` 中的 `id` 匹配
- `name` 字段标识工具名称
- 通常紧跟在包含对应 `tool_call` 的 `AIMessage` 之后

## 完整工具调用消息流

```python
from langchain.messages import HumanMessage, AIMessage, ToolMessage

messages = [
    # 1. 用户提问
    HumanMessage(content="What's the weather in Tokyo?"),

    # 2. AI 决定调用工具
    AIMessage(
        content="",
        tool_calls=[{
            "id": "call_001",
            "name": "get_weather",
            "args": {"city": "Tokyo"},
            "type": "tool_call",
        }],
    ),

    # 3. 工具执行结果
    ToolMessage(
        content="Sunny, 25 degrees C",
        tool_call_id="call_001",
        name="get_weather",
    ),

    # 4. AI 基于工具结果给出最终回答
    AIMessage(content="It's sunny in Tokyo at 25 degrees C!"),
]
```

## FunctionMessage（已弃用）

```python
# 不推荐使用，已被 ToolMessage 取代
from langchain.messages import FunctionMessage
msg = FunctionMessage(content="result", name="my_function")
```

## ChatMessage

自定义角色消息，用于需要非标准角色的场景：

```python
from langchain.messages import ChatMessage
msg = ChatMessage(content="Hello", role="moderator")
```

## 构造函数返回类型

| 构造函数 | 返回类型 | 示例 |
|---------|---------|------|
| `HumanMessage(content="...")` | `HumanMessage` | 用户消息 |
| `AIMessage(content="...")` | `AIMessage` | AI 回复 |
| `SystemMessage(content="...")` | `SystemMessage` | 系统指令 |
| `ToolMessage(content="...", tool_call_id="...")` | `ToolMessage` | 工具执行结果 |

## 消息属性类型

| 属性 | 类型 | 说明 | 适用消息 |
|------|------|------|---------|
| `.content` | `str` | 消息文本内容 | 所有 |
| `.type` | `str` | 消息类型标识 | 所有（`"human"` / `"ai"` / `"system"` / `"tool"`） |
| `.id` | `str` | 消息唯一 ID | 所有 |
| `.tool_calls` | `list[ToolCall]` | 工具调用列表 | AIMessage |
| `.tool_call_id` | `str` | 对应的工具调用 ID | ToolMessage |
| `.usage_metadata` | `dict` | Token 使用量 | AIMessage |
| `.response_metadata` | `dict` | API 响应元数据 | AIMessage |
| `.content_blocks` | `list[ContentBlock][[` | 内容块列表 | AIMessage（多模态） |
