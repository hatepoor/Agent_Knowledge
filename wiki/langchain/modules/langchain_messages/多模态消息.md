# 多模态消息

## 概述

LangChain 的消息系统支持多模态内容，允许在单条消息中混合文本、图像、音频和视频等不同类型的内容。这通过**内容块列表**（content blocks）实现。

## 内容块格式

将 `content` 设为列表而非字符串，每个元素是一个 `dict`，包含 `type` 字段：

| type | 说明 | 常用字段 |
|------|------|---------|
| `"text"` | 文本内容 | `text` |
| `"image"` | 图像 | `url` 或 `data`（base64） |
| `"audio"` | 音频 | `url` 或 `data`（base64） |
| `"video"` | 视频 | `url` |

## 文本 + 图像

```python
from langchain.messages import HumanMessage

msg = HumanMessage(content=[
    {"type": "text", "text": "What's in this image?"},
    {"type": "image", "url": "https://example.com/cat.jpg"},
])
```

## 多图像

```python
msg = HumanMessage(content=[
    {"type": "text", "text": "Compare these two images:"},
    {"type": "image", "url": "https://example.com/image1.jpg"},
    {"type": "image", "url": "https://example.com/image2.jpg"},
])
```

## 音频输入

```python
msg = HumanMessage(content=[
    {"type": "text", "text": "Transcribe this audio:"},
    {"type": "audio", "url": "https://example.com/recording.mp3"},
])
```

## Base64 内联数据

当无法使用 URL 时，可以直接嵌入 base64 编码的数据：

```python
import base64

with open("image.png", "rb") as f:
    image_data = base64.b64encode(f.read()).decode()

msg = HumanMessage(content=[
    {"type": "text", "text": "Analyze this screenshot:"},
    {"type": "image", "data": image_data},
])
```

## 获取规范化的内容块

使用 `content_blocks` 属性而非 `content` 来获取跨 provider 标准化的内容块：

```python
msg = AIMessage(content="Hello")
blocks = msg.content_blocks  # 标准化的内容块列表
# [{"type": "text", "text": "Hello"}][[
```

`content_blocks` 会自动将不同 provider 的格式差异规范化，是推荐的数据访问方式。

## 推理内容（Reasoning）

部分模型支持在响应中包含推理过程：

```python
from langchain.messages import AIMessage

reasoning_msg = AIMessage(
    content="",
    additional_kwargs={"reasoning": "The user is asking about..."},
)
```

## 注意事项

- 并非所有提供商都支持所有多模态类型，需检查具体集成包的兼容性
- 图像 URL 需要模型能够访问（部分模型要求公网可访问的 URL）
- 大文件建议使用 base64 内联而非 URL
- 推荐用 `content_blocks` 而非 `content` 获取规范化数据
