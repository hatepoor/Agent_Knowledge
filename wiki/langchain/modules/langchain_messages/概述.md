# messages 模块

## 是什么

`langchain.messages` 定义 LangChain 系统中所有**消息类型**。对话历史、Agent 输入输出、工具调用结果等都使用这些消息类。底层是 `langchain_core.messages`。

## 有什么用

- 统一不同 LLM 聊天 API 的消息格式
- 支持多模态内容（文本、图像、音频）
- 支持工具调用与结构化响应

## 关键类

| 类 | 角色 | 用途 |
|------|------|------|
| `HumanMessage` | user | 用户输入 |
| `AIMessage` | assistant | AI 响应（含 tool_calls） |
| `SystemMessage` | system | 系统提示词 |
| `ToolMessage` | tool | 工具执行结果 |
| `FunctionMessage` | function | 旧式函数调用（已弃用） |
| `ChatMessage` | 任意 | 自定义角色 |
| `RemoveMessage` | - | 删除消息（配合 reducer） |

> 各消息类型详细说明见 [[langchain/modules/langchain_messages/消息类型详解|消息类型详解]]

## 基础消息示例

```python
from langchain.messages import (
    HumanMessage, AIMessage, SystemMessage, ToolMessage,
    AnyMessage,
)

# 构造对话
msgs = [
    SystemMessage(content="You are a helpful assistant."),
    HumanMessage(content="What's the weather in Tokyo?"),
    AIMessage(content="Let me check..."),
    HumanMessage(content="Thanks!"),
]

# 消息属性
msg = AIMessage(content="Hello")
print(msg.type)           # "ai"
print(msg.content)        # "Hello"
print(msg.content_blocks) # 标准化的 content blocks 列表
print(msg.tool_calls)     # [] （无工具调用）
print(msg.id)             # uuid
```

## 消息属性速查

| 属性 | 说明 |
|------|------|
| `type` | 消息角色（"human"/"ai"/"system"/"tool"） |
| `content` | 字符串或内容块列表 |
| `content_blocks` | 标准化的内容块（规范化不同 provider） |
| `tool_calls` | AI 消息中的工具调用列表 |
| `tool_call_id` | ToolMessage 对应的 tool_call.id |
| `name` | ToolMessage 的工具名 |
| `id` | 消息唯一 ID |
| `additional_kwargs` | provider 特定字段 |
| `response_metadata` | provider 返回的元信息 |

## 与 Agent 配合

```python
from langchain.agents import create_agent
from langchain.messages import HumanMessage
from langchain_core.utils.uuid import uuid7
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    "openai:gpt-5.5",
    tools=[],
    checkpointer=InMemorySaver(),
)
result = agent.invoke(
    {"messages": [HumanMessage(content="Hello")]},
    config={"configurable": {"thread_id": str(uuid7())}},
)
print(result["messages"][-1][[.content)  # AI 响应
```

## 何时使用

- 与 ChatModel 交互时构造消息列表
- 维护对话历史
- 处理工具调用与多模态输入

## 注意事项

- 多模态内容块格式：`{"type": "text"|"image"|"audio"|"video", ...}`
- 不同 provider 的工具调用格式已通过 `tool_calls` 统一
- 推荐用 `content_blocks` 而非 `content` 获取规范化数据
