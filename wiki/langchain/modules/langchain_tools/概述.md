# tools 模块

## 是什么

`langchain.tools` 是 LangChain 的**工具系统模块**，让 LLM 能调用外部函数、API、数据库等。底层是 `langchain_core.tools`。

## 有什么用

- 将普通 Python 函数包装为 LLM 可调用的工具
- 注入 `ToolRuntime` 参数以访问 State、Context、Store、流写入
- 标准化工具描述（name、description、args_schema）

## 关键 API

| API | 返回类型 | 作用 |
|-----|---------|------|
| `@tool` 装饰器 | `StructuredTool`（`BaseTool` 子类） | 将函数转为工具 |
| `BaseTool` | — | 工具抽象基类 |
| `ToolRuntime` | — | 工具运行时参数（含 state/context/store 等） |
| `InjectedState` | — | 注入 state（已弃用，推荐 ToolRuntime） |
| `InjectedStore` | — | 注入 store（已弃用，推荐 ToolRuntime） |
| `tool_call(...)` | `ToolCall`（`TypedDict`） | 手工构造工具调用 |
| `tool.invoke(input)` | `str`（默认）或函数返回类型 | 执行工具 |
| `tool.run(...)` | `str` | 执行工具（旧接口） |

### 工具函数返回类型

工具函数的返回类型决定了 LangChain 如何处理结果：

```python
# 返回 str → 作为 ToolMessage.content 直接传给模型

@tool
def get_weather(city: str) -> str:
    """获取天气"""
    return f"晴天, 28°C"

# 返回 dict → 序列化为 JSON 字符串后传给模型

@tool
def get_data(query: str) -> dict:
    """获取数据"""
    return {"result": "data", "count": 5}

# 返回 Command → 框架执行状态更新，不生成 ToolMessage

@tool
def update_state(value: str) -> Command:
    """更新状态"""
    return Command(update={"field": value})
```

## 基础工具示例

```python
from langchain.tools import tool

@tool
def search(query: str, limit: int = 5) -> str:
    """Search the database for records.

    Args:
        query: Search terms
        limit: Maximum number of results
    """
    return f"Found {limit} results for '{query}'"
```

> 更多运行时、返回值等高级用法详见子页面。

## 何时使用

- Agent 需要与外部世界交互
- 需要根据 State/Context/Store 动态响应
- 需要更新 state 但不仅返回数据

## 注意事项

- 函数必须有 **docstring**（默认成为工具描述）
- 类型注解**必须**（用于生成 JSON schema）
- 推荐 `snake_case` 命名
- 详细返回类型约束见 [[langchain/tools/工具]]
