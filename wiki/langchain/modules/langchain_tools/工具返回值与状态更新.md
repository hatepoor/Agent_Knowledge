# 工具返回值类型与状态更新

## 概述

LangChain 工具支持多种返回值类型，不同类型决定了工具执行后框架的后续行为。理解返回值机制是正确使用工具的关键。

## 保留参数名

工具函数签名中，以下参数名为系统保留，不可用于自定义参数：

| 参数名 | 用途 |
|--------|------|
| `config` | 系统保留，传 `RunnableConfig` |
| `runtime` | 系统保留，传 `ToolRuntime` |

## 返回值类型

| 返回类型 | 行为 |
|---------|------|
| `str` | 转为 `ToolMessage`，模型继续处理 |
| `dict` / 对象 | 序列化为结构化内容 |
| `Command` | 更新 state + 追加消息 |
| `list[dict]` | 多模态内容（文本+图像） |

### 字符串返回（最常用）

```python
@tool
def search(query: str) -> str:
    """Search for information."""
    return f"Found results for '{query}'"
```

返回值自动包装为 `ToolMessage`，模型将基于此内容继续推理。

### 字典/对象返回

```python
@tool
def get_user(user_id: str) -> dict:
    """Get user profile."""
    return {"name": "Alice", "age": 30, "role": "admin"}
```

结构化数据会被序列化为 `ToolMessage` 的内容。

### Command 返回（状态更新）

当工具需要**同时更新 Agent 状态和返回消息**时，使用 `Command`：

```python
from langchain.messages import ToolMessage
from langchain.tools import tool, ToolRuntime
from langgraph.types import Command

@tool
def increment_counter(amount: int, runtime: ToolRuntime) -> Command:
    """Increment the request counter in state."""
    return Command(update={
        "request_count": amount,
        "messages": [ToolMessage(
            content=f"Counter += {amount}",
            tool_call_id=runtime.tool_call_id,
        )],
    })
```

使用 `Command` 时需要：
1. 在 `update` 中包含要更新的状态字段
2. 在 `messages` 中手动构造 `ToolMessage`，并使用 `runtime.tool_call_id`
