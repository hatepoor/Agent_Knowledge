# runnables 模块

## 是什么

`langchain_core.runnables` 是 LangChain 的**核心可执行协议**，所有可调用组件（Prompts、Models、Parsers、Tools、Retrievers 等）都实现 `Runnable` 接口。**LCEL**（LangChain Expression Language）是其声明式组合语法。

## 有什么用

- 用 `|` 操作符链式组合任意 Runnable
- 统一 `invoke` / `ainvoke` / `stream` / `astream` / `batch` / `abatch` 接口
- 支持同步、异步、流式、批处理自动适配

## 关键类

| 类 | 用途 |
|-----|------|
| `Runnable` | 抽象基类，所有可执行组件 |
| `RunnableLambda` | 包装普通函数 |
| `RunnablePassthrough` | 透传输入 |
| `RunnableParallel` | 并行执行多个 Runnable |
| `RunnableSequence` | 串行序列（用 `\|` 自动创建） |
| `RunnableBranch` | 条件分支 |
| `RunnableConfig` | 调用配置（tags、metadata、callbacks） |
| `RunnableWithFallbacks` | 失败时回退 |
| `RunnableRetry` | 失败时重试 |
| `RunnableConfigurableFields` | 可配置字段（运行时切换） |

## Runnable 统一接口

| 方法 | 同步 | 异步 | 流式 | 批 |
|------|------|------|------|------|
| 调用 | `invoke` | `ainvoke` | `stream` | `batch` |
| 输入 | 单个 | 单个 | 单个 | 列表 |
| 输出 | 单个 | 单个 | 生成器 | 列表 |

### 各 Runnable 类的返回类型

| Runnable 类 | invoke() 返回 | stream() 产出 |
|------------|-------------|--------------|
| `RunnableLambda` | `fn(input)` 的返回值 | 同 invoke |
| `RunnablePassthrough` | 输入的透传（相同类型） | 同 invoke |
| `RunnableParallel` | `dict[str, Any]` | `dict[str, Any]` |
| `RunnableBranch` | 匹配分支的返回值 | 同 invoke |
| `RunnableSequence` (chain) | 最后一个组件的返回类型 | 最后一个组件的产出类型 |
| `RunnableWithFallbacks` | 主 Runnable 或回退的返回值 | 同 invoke |

## 基础 LCEL 链

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain.chat_models import init_chat_model
from langchain_core.output_parsers import StrOutputParser

model = init_chat_model("openai:gpt-5.5")

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a translator to {language}."),
    ("human", "{text}"),
][[)
chain = prompt | model | StrOutputParser()
print(chain.invoke({"language": "French", "text": "Hello world"}))
```

## 注意事项

- 所有 LangChain 组件（ChatModel、Retriever、Tool 等）都实现 Runnable
- `|` 操作符是 `RunnableSequence` 的语法糖
- 旧式 `LLMChain`、`RetrievalQA` 等已弃用，统一用 LCEL
