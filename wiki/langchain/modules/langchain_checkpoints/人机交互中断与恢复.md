# 人机交互中断与恢复

LangGraph 通过 Checkpointer 和 `HumanInTheLoopMiddleware` 支持 **Agent 执行过程中的人工审批中断**，审批后可恢复执行。

## 原理

1. 配置 `HumanInTheLoopMiddleware`，指定哪些工具需要人工审批
2. Agent 调用需审批的工具时自动中断
3. 中断信息存储在 `result["__interrupt__"]` 中
4. 人工审批后，通过 `Command(resume=...)` 恢复执行

## 基本配置

```python
import os
os.environ["OPENAI_API_KEY"] = "sk-..."

from langgraph.checkpoint.memory import InMemorySaver
from langchain.agents import create_agent
from langchain.agents.middleware import HumanInTheLoopMiddleware
from langgraph.types import Command

# 配置需要人工审批的工具
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[send_email, search_web],
    middleware=[
        HumanInTheLoopMiddleware(
            interrupt_on={"send_email": True}  # send_email 需要审批
        )
    ],
    checkpointer=InMemorySaver(),
)
```

## 触发中断

```python
config = {"configurable": {"thread_id": "1"}}

# Agent 执行到 send_email 时自动中断
result = agent.invoke(
    {"messages": [{"role": "user", "content": "Send email to bob"}]},
    config,
)

# 检查中断信息
print(result["__interrupt__"])
# 包含待审批动作的详细信息
```

## 审批并恢复

```python
# 批准后恢复执行
result2 = agent.invoke(
    Command(resume={"decisions": [{"type": "approve"}]}),
    config,
)
# Agent 继续执行 send_email 工具
```

## 拒绝执行

```python
# 拒绝后恢复执行
result3 = agent.invoke(
    Command(resume={"decisions": [{"type": "deny", "reason": "Not appropriate"}][[}),
    config,
)
# Agent 收到拒绝，可能选择其他方案或结束
```

## 多工具审批策略

```python
# 只审批高风险工具
middleware = HumanInTheLoopMiddleware(
    interrupt_on={
        "send_email": True,     # 发送邮件需审批
        "delete_file": True,    # 删除文件需审批
        "search_web": False,    # 搜索不需要审批
    }
)
```

## 使用场景

| 场景 | 说明 |
|------|------|
| 邮件发送审批 | Agent 生成邮件后等待人工确认 |
| 文件操作审批 | 删除、覆盖等高风险操作需确认 |
| 金额交易审批 | 涉及金额的工具需人工授权 |
| 内容发布审核 | Agent 生成的内容需人工审核后发布 |

## 注意事项

- 中断和恢复**依赖 Checkpointer**，必须配置持久化后端
- `interrupt_on` 中指定的工具名必须与工具定义匹配
- 恢复时必须使用**相同的 config**（包含 thread_id）
- `Command(resume=...)` 的格式需与中间件的预期匹配
- 可以在 UI 中展示中断信息，让用户做出决策
