# checkpoints 模块

## 是什么

`langgraph.checkpoint` 提供 LangGraph/LangChain Agent 的**状态检查点持久化**能力。每次 Agent 步骤后保存完整状态，支持时间旅行、人机交互、容错恢复。

## 有什么用

- 持久化多轮对话
- 线程隔离（thread_id）
- 时间旅行（回到任意检查点）
- 人机审批中断与恢复
- 故障恢复

## 关键类

| 类 | 模块 | 用途 |
|-----|------|------|
| `BaseCheckpointSaver` | `langgraph.checkpoint` | 抽象基类 |
| `InMemorySaver` | `langgraph.checkpoint.memory` | 内存版（开发用） |
| `PostgresSaver` | `langgraph.checkpoint.postgres` | Postgres（生产） |
| `SqliteSaver` | `langgraph.checkpoint.sqlite` | SQLite（轻量生产） |
| `AzureCosmosDBSaver` | `langgraph.checkpoint.cosmos` | Azure Cosmos DB |
| `AsyncPostgresSaver` | `langgraph.checkpoint.postgres` | 异步版本 |

## 核心 API

| 方法 | 作用 |
|------|------|
| `get(config)` | 读取指定 thread 的最新检查点 |
| `get_tuple(config)` | 读取完整 CheckpointTuple（含 metadata） |
| `list(config, ...)` | 列出 thread 的所有检查点 |
| `put(config, checkpoint, metadata, ...)` | 写入 |
| `put_writes(...)` | 写入 pending writes |
| `delete_thread(thread_id)` | 删除整个 thread |

## 何时使用

| 场景 | 推荐 |
|------|------|
| 开发调试 | `InMemorySaver` |
| 单机轻量生产 | `SqliteSaver` |
| 分布式生产 | `PostgresSaver` |
| Azure 云 | `AzureCosmosDBSaver` |
| 异步高并发 | `AsyncPostgresSaver` |

## 注意事项

- `thread_id` 是关键隔离维度
- Checkpoint 包含**完整状态**（可能很大）
- PostgresSaver 自动用 thread_id 区分数据
- 删除整个 thread：`checkpointer.delete_thread(thread_id)`
- 部署 LangGraph Server 时 checkpointer 自动配置
