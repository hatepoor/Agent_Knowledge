# langchain-core 包

## 是什么

`langchain-core` 是 LangChain 的**最底层抽象包**，定义了框架全部核心接口与数据模型。不依赖任何第三方 LLM 提供商，可独立使用。

## 有什么用

- 定义统一的 **Runnable 协议**，让所有组件可组合
- 定义 **Messages、Documents、Embeddings** 等基础数据模型
- 定义 **Tools、VectorStores、Retrievers** 等抽象基类
- 提供 **LCEL**（LangChain Expression Language）声明式组合语法

## 关键类与函数

| 类/函数 | 模块 | 作用 |
|---------|------|------|
| `Runnable` | `schema.runnable` | 可执行组件的统一接口 |
| `RunnableLambda` | `schema.runnable` | 将函数包装为 Runnable |
| `RunnablePassthrough` | `schema.runnable` | 透传输入 |
| `RunnableParallel` | `schema.runnable` | 并行执行多个 Runnable |
| `RunnableConfig` | `schema.runnable` | 调用配置（tags、metadata、callbacks） |
| `langchain_core.load.load` | `load` | 序列化/反序列化 |
| `langchain_core.load.dumpd` | `load` | 转为可序列化 dict |

## 安装

```bash
pip install langchain-core
```

> 注：`pip install langchain` 已自动包含 `langchain-core`。

## 完整示例

```python
"""
示例：用 Runnable 协议组合一个简单的"取输入 + 翻倍 + 格式化"流水线
"""
from langchain_core.runnables import RunnableLambda, RunnableParallel

# 1. 将普通函数包装为 Runnable
double = RunnableLambda(lambda x: x * 2)
add_ten = RunnableLambda(lambda x: x + 10)

# 2. 用 | 操作符串行组合（等价于 LCEL chain）
pipeline = double | add_ten
print(pipeline.invoke(5))     # 输出：20  （5*2 + 10）

# 3. 并行执行
parallel = RunnableParallel(
    doubled=double,
    original=RunnableLambda(lambda x: x),
)
print(parallel.invoke(7))     # 输出：{'doubled': 14, 'original': 7}

# 4. 同步 / 异步 / 流式 / 批 全部统一
import asyncio
print(pipeline.batch([1, 2, 3]))                    # 批处理
for chunk in pipeline.stream(5):                    # 流式
    print(chunk, end=" ")
print()
# 异步
async def main():
    result = await pipeline.ainvoke(5)
    print("async:", result)
asyncio.run(main())
```

## Runnable 协议返回类型

### 方法签名与返回类型

| 方法 | 签名 | 返回类型 | 说明 |
|------|------|---------|------|
| `invoke` | `invoke(input: Any) -> Any` | 取决于具体 Runnable | 同步执行，返回完整结果 |
| `ainvoke` | `ainvoke(input: Any) -> Any` | 取决于具体 Runnable | 异步执行 |
| `stream` | `stream(input: Any) -> Iterator[Any]` | `Iterator` | 流式执行，逐步产出 |
| `astream` | `astream(input: Any) -> AsyncIterator[Any]` | `AsyncIterator` | 异步流式 |
| `batch` | `batch(inputs: list) -> list` | `list` | 批量执行 |
| `abatch` | `abatch(inputs: list) -> list` | `list` | 异步批量 |

### 各组件具体返回类型

| 组件 | invoke() 返回 | stream() 产出 |
|------|-------------|--------------|
| `PromptTemplate` | `StringPromptValue` | `StringPromptValue` |
| `ChatPromptTemplate` | `ChatPromptValue` | `ChatPromptValue` |
| `ChatModel` (如 ChatOpenAI) | `AIMessage` | `AIMessageChunk` |
| `StrOutputParser` | `str` | `str`（逐 token） |
| `JsonOutputParser` | `dict` | `dict`（完整时） |
| `PydanticOutputParser` | Pydantic 实例 | Pydantic 实例 |
| `VectorStoreRetriever` | `list[Document]` | `list[Document][[` |
| `RunnableLambda(fn)` | `fn` 的返回值 | `fn` 的返回值 |
| `RunnableParallel({...})` | `dict` | `dict` |
| `RunnableSequence` (chain) | 最后一个组件的返回类型 | 最后一个组件的产出 |

## 何时使用

- 需要自定义可组合组件时
- 需要与 LangChain 其他模块组合时（任何 chain 都用 Runnable 接口）
- 需要序列化/反序列化组件时（用 `dumpd`/`load`）

## 注意事项

- `langchain-core` 不包含具体 LLM 集成，要用 OpenAI/Anthropic 需安装 `langchain-openai`、`langchain-anthropic` 等
- Runnable 是 LangChain **唯一推荐的组合协议**，旧式 Chain 类已弃用
