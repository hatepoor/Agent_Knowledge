# with_structured_output 结构化输出

## 概述

`with_structured_output` 是 `BaseChatModel` 提供的方法，用于约束模型的输出格式为指定的 Pydantic 模型或 JSON Schema。调用后模型将直接返回结构化的 Python 对象而非自由文本。

## 基本用法

```python
from pydantic import BaseModel
from langchain.chat_models import init_chat_model

# 定义输出结构
class MovieInfo(BaseModel):
    title: str
    year: int
    director: str

# 加载模型并启用结构化输出
model = init_chat_model("openai:gpt-5.5")
structured_model = model.with_structured_output(MovieInfo)

# 调用 — 直接返回 MovieInfo 实例
movie = structured_model.invoke("Provide info about Inception")
print(movie.title)      # "Inception"
print(movie.year)        # 2010
print(movie.director)    # "Christopher Nolan"
```

## 工作原理

1. 将 Pydantic 模型转为 JSON Schema
2. 通过底层 API（如 OpenAI 的 function calling）约束输出
3. 自动将模型返回的 JSON 解析为 Pydantic 实例

## 嵌套结构

```python
from pydantic import BaseModel
from typing import List

class Actor(BaseModel):
    name: str
    role: str

class MovieCast(BaseModel):
    title: str
    year: int
    cast: List[Actor]

structured_model = model.with_structured_output(MovieCast)
result = structured_model.invoke("List the cast of The Matrix")
for actor in result.cast:
    print(f"{actor.name} as {actor.role}")
```

## 与 Agent 配合

在 `create_agent` 中，可以使用 `response_format` 参数实现类似效果：

```python
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[...][[,
    response_format=MovieInfo,  # Agent 最终输出为结构化数据
)
```

## 注意事项

- 并非所有提供商都支持结构化输出，需要检查集成包的兼容性
- Pydantic 模型的字段名和类型注解会影响 JSON Schema 生成
- 结构化输出与 `bind_tools` 可以同时使用，但行为取决于提供商实现
