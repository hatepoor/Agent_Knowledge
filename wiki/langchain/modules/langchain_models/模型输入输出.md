# ChatModel 输入与输出

> ChatModel 的输入接受多种格式（字符串、消息列表、字典、PromptValue），输出统一为 `AIMessage` 对象。理解输入输出的格式是正确使用 LangChain 的基础。

## 输入格式

ChatModel 的 `invoke()` 接受四种输入格式，内部统一转为消息列表后发送给 LLM API：

| 输入格式 | 类型 | 适用场景 |
|---------|------|---------|
| 纯字符串 | `str` | 简单单轮问答 |
| 消息对象列表 | `list[BaseMessage]` | 多轮对话（最常用） |
| 字典列表 | `list[dict]` | 轻量写法 |
| `PromptValue` | `PromptValue` | LCEL 链中自动传递 |

### 方式1：纯字符串（最简单）

```python
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4o-mini")

# 直接传字符串，等价于一条 HumanMessage
response = model.invoke("你好")
print(response.content)
```

### 方式2：消息对象列表（最常用）

```python
from langchain_core.messages import HumanMessage, SystemMessage

response = model.invoke([
    SystemMessage(content="你是一个翻译专家"),
    HumanMessage(content="请把这段话翻译成英文：今天天气不错"),
])
```

### 方式3：字典列表（轻量写法）

```python
response = model.invoke([
    {"role": "system", "content": "你是一个翻译专家"},
    {"role": "user", "content": "请把这段话翻译成英文"},
])
```

### 方式4：PromptValue（LCEL 链中自动传递）

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是{role}"),
    ("human", "{question}"),
])

prompt_value = prompt.invoke({"role": "专家", "question": "什么是AI？"})
response = model.invoke(prompt_value)  # PromptValue 也可以直接传给模型
```

## 输出格式

不管哪种输入，`invoke()` 始终返回 `AIMessage` 对象：

```python
response = model.invoke("你好")

# AIMessage 的核心属性
response.content              # "你好！有什么可以帮你的？"  ← 文本内容
response.tool_calls           # []                         ← 工具调用（绑了工具时可能有）
response.response_metadata    # {"model": "gpt-4o-mini", "finish_reason": "stop", ...}
response.usage_metadata       # {"input_tokens": 10, "output_tokens": 25, "total_tokens": 35}
response.id                   # "chatcmpl-xxx"
```

### 不同场景下 content 的形态

```python
# 普通回答
response.content  # "这是一段普通文本回答"

# 绑了工具、模型选择调用工具时
response.content   # ""（通常为空）
response.tool_calls
# [{"name": "get_weather", "args": {"city": "东京"}, "id": "call_xxx"}][[

# 结构化输出时（with_structured_output）
structured_model = model.with_structured_output(MovieInfo)
result = structured_model.invoke("介绍《盗梦空间》")
# result 直接是 MovieInfo Pydantic 对象，不是 AIMessage
```

## 在 LCEL 链中的流转

链里每一步的输出自动成为下一步的输入：

```python
chain = prompt | model | StrOutputParser()
#         ↓        ↓          ↓
#    PromptValue  AIMessage   str
#    (输入model)  (输入parser) (最终输出)
```

| 步骤 | 输入类型 | 输出类型 |
|------|---------|---------|
| `prompt.invoke()` | `dict` | `PromptValue` |
| `model.invoke()` | `PromptValue` 或消息列表 | `AIMessage` |
| `parser.invoke()` | `AIMessage` | `str`（StrOutputParser）|
