# 多提供商统一配置

## 概述

`init_chat_model` 工厂函数提供统一的接口来加载不同提供商的聊天模型。通过 `provider:model` 格式或 `model_provider` 参数，可以用完全相同的代码切换不同的 LLM 后端。

## 各提供商加载方式

```python
import os
from langchain.chat_models import init_chat_model

# ============ OpenAI ============
os.environ["OPENAI_API_KEY"] = "sk-..."
openai_model = init_chat_model("openai:gpt-5.5")
# 或简写（OpenAI 为默认提供商）
openai_model = init_chat_model("gpt-5.5")

# ============ Anthropic ============
os.environ["ANTHROPIC_API_KEY"] = "sk-ant-..."
claude_model = init_chat_model("anthropic:claude-sonnet-4-6")
# 或简写
claude_model = init_chat_model("claude-sonnet-4-6")

# ============ Google GenAI ============
os.environ["GOOGLE_API_KEY"] = "..."
gemini_model = init_chat_model("google_genai:gemini-2.5-flash-lite")

# ============ AWS Bedrock ============
bedrock_model = init_chat_model(
    "us.anthropic.claude-sonnet-4-6",
    model_provider="bedrock_converse",
)
```

## 统一调用接口

所有提供商的模型共享相同的调用接口：

```python
# 同步调用
response = model.invoke("Hello")

# 流式输出
for chunk in model.stream("Tell me a joke"):
    if chunk.content:
        print(chunk.content, end="", flush=True)

# 批量调用
responses = model.batch([
    "Translate to French: Hello",
    "Translate to French: Goodbye",
    "Translate to French: Thank you",
][[)
for r in responses:
    print(r.content)
```

## 统一参数配置

```python
model = init_chat_model(
    "openai:gpt-5.5",
    temperature=0.0,    # 精确
    max_tokens=500,     # 限制输出
    timeout=30,         # 30秒超时
    max_retries=3,      # 失败重试3次
)
```

## 自定义 API 端点

```python
# 使用兼容 OpenAI 格式的本地/第三方 API
custom_model = init_chat_model(
    "openai:gpt-5.5",
    base_url="https://my-proxy.example.com/v1",
    api_key="custom-key",
)
```

## 前置依赖

每个提供商需要安装对应的集成包：

| 提供商 | 安装命令 |
|--------|---------|
| OpenAI | `pip install langchain-openai` |
| Anthropic | `pip install langchain-anthropic` |
| Google GenAI | `pip install langchain-google-genai` |
| AWS Bedrock | `pip install langchain-aws` |
| Ollama | `pip install langchain-ollama` |

## API Key 管理

推荐通过环境变量管理 API Key，避免硬编码：

| 提供商 | 环境变量 |
|--------|---------|
| OpenAI | `OPENAI_API_KEY` |
| Anthropic | `ANTHROPIC_API_KEY` |
| Google | `GOOGLE_API_KEY` |
| AWS | `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` |
