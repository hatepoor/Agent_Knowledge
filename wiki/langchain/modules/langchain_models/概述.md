# chat_models 模块

## 是什么

`langchain.chat_models` 是 LangChain 的**模型统一入口**，提供 `init_chat_model` 工厂函数从不同提供商加载聊天模型。是 `langchain_core.language_models.chat_models` 的对外封装。

## 有什么用

- 用相同接口访问 OpenAI、Anthropic、Google、AWS Bedrock、Ollama 等
- 统一参数：temperature、max_tokens、timeout、max_retries
- 支持模型无关的工具调用、结构化输出、流式传输

## 关键 API

| API | 返回类型 | 作用 |
|-----|---------|------|
| `init_chat_model(...)` | `BaseChatModel` | 工厂函数，按 `provider:model` 加载 |
| `model.invoke(...)` | `AIMessage` | 调用 LLM |
| `model.stream(...)` | `Iterator[AIMessageChunk][[` | 流式调用 |
| `model.bind_tools(...)` | `Runnable`（带工具绑定的模型） | 绑定工具 |
| `model.with_structured_output(schema)` | `Runnable` | 启用结构化输出 |
| `model.with_config(...)` | `Runnable` | 注入配置 |
| `BaseChatModel` | — | 所有聊天模型基类 |
| `ConfigurableField` | — | 可配置字段（运行时切换模型） |

## 基础用法

```python
from langchain.chat_models import init_chat_model

# 加载模型（provider:model 格式）
model = init_chat_model("openai:gpt-5.5")

# 统一调用
response = model.invoke("Why do parrots have colorful feathers?")
print(response.content)

# 统一参数配置
precise_model = init_chat_model(
    "openai:gpt-5.5",
    temperature=0.0,    # 精确
    max_tokens=500,     # 限制输出
    timeout=30,         # 30秒超时
    max_retries=3,      # 失败重试3次
)
```

## 常用参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `model` | str | `provider:model` 形式 |
| `temperature` | float | 0~1 随机性 |
| `max_tokens` | int | 最大输出 token |
| `timeout` | float | 超时秒数 |
| `max_retries` | int | 最大重试 |
| `streaming` | bool | 默认流式 |
| `model_provider` | str | 显式指定 provider |
| `base_url` | str | 自定义 API 地址 |
| `api_key` | str | 显式传 key |

## 何时使用

- 任何需要调用 LLM 的场景
- 多提供商测试或切换
- 需要工具调用、结构化输出等高级能力

## 注意事项

- 必须先安装对应提供商的集成包（`langchain-openai` / `langchain-anthropic` 等）
- 部分 provider 特定参数（如 Anthropic 的 `thinking`）需用 `ChatAnthropic` 原生类
- API key 推荐用环境变量（`OPENAI_API_KEY` 等）
