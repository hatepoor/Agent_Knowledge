# embeddings 模块

## 是什么

`langchain_core.embeddings` 是 LangChain 的**嵌入接口抽象**，定义将文本转为向量的统一 API。具体实现由 `langchain-openai`、`langchain-huggingface` 等集成包提供。

## 有什么用

- 统一不同 embedding 提供商（OpenAI、HuggingFace、Cohere 等）
- 与 VectorStore 无缝集成
- 支持批量嵌入与异步

## 关键类

| 类 | 模块 | 用途 | 返回类型 |
|-----|------|------|----------|
| `Embeddings` | `langchain_core.embeddings` | 抽象基类 | — |
| `embed_documents(texts: list[str][[)` | `Embeddings` | 嵌入多个文档（批量） | `list[list[float]]`（文档向量列表） |
| `embed_query(text: str)` | `Embeddings` | 嵌入单个查询（可与文档用不同模型） | `list[float]`（单个查询向量） |
| `aembed_query(text: str)` | `Embeddings` | 异步嵌入单个查询 | `list[float]`（异步） |
| `aembed_documents(texts: list[str][[)` | `Embeddings` | 异步嵌入多个文档 | `list[list[float]]`（异步） |
| `OpenAIEmbeddings` | `langchain-openai` | OpenAI text-embedding-3-* | — |
| `HuggingFaceEmbeddings` | `langchain-huggingface` | HF sentence-transformers | — |
| `CohereEmbeddings` | `langchain-cohere` | Cohere embed | — |
| `OllamaEmbeddings` | `langchain-ollama` | 本地 Ollama | — |
| `CacheBackedEmbeddings` | `langchain.embeddings.cache` | 带缓存的嵌入 | — |

## 基础用法

```python
from langchain_openai import OpenAIEmbeddings
import os
os.environ["OPENAI_API_KEY"] = "sk-..."

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=1536,
)

# 嵌入查询
query_vec = embeddings.embed_query("What is LangChain?")
print(f"Query vector: {len(query_vec)} dims")

# 嵌入文档
docs = ["First document.", "Second document."]
doc_vecs = embeddings.embed_documents(docs)
print(f"Doc vectors: {len(doc_vecs)} x {len(doc_vecs[0])} dims")
```

### 返回值详解

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings()

# embed_query 返回 list[float] —— 一个浮点数列表
query_vec = embeddings.embed_query("什么是 LangChain？")
print(type(query_vec))     # <class 'list'>
print(len(query_vec))      # 1536（维度，取决于模型）
print(query_vec[:5])       # [0.0023, -0.0094, 0.0156, -0.0032, 0.0087][[
# 每个值是一个 -1 到 1 之间的浮点数

# embed_documents 返回 list[list[float]] —— 多个向量的列表
doc_vecs = embeddings.embed_documents([
    "LangChain 是一个 LLM 应用开发框架",
    "LangGraph 用于构建有状态的 Agent 工作流",
])
print(type(doc_vecs))      # <class 'list'>
print(len(doc_vecs))       # 2（与输入文档数相同）
print(len(doc_vecs[0]))    # 1536（每个向量的维度）
print(doc_vecs[0][:3])     # [-0.0045, 0.0112, -0.0078]
print(doc_vecs[1][:3])     # [0.0067, -0.0023, 0.0091][[
```

## 注意事项

- 不同模型的向量**不通用**（OpenAI 与 HF 嵌入维度不同）
- 切换 embedding 必须**重建向量库**
- 嵌入成本：按 token 计费，关注重复率与缓存
- 中文场景推荐 `text-embedding-3-small` 或 `BAAI/bge-large-zh-v1.5`
