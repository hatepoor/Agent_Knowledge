# agents 模块

## 是什么

`langchain.agents` 是 LangChain v1 的**官方 Agent 工厂模块**，提供 `create_agent` 工厂函数快速构建可执行的 Agent（底层为编译好的 LangGraph）。

## 有什么用

- **一行代码创建 Agent**：处理模型循环、消息传递、工具调度
- 通过参数注入模型、工具、提示词、状态、上下文
- 通过 middleware 扩展上下文管理、容错、护栏、人工审批等能力

## 关键 API

| API | 作用 |
|-----|------|
| `create_agent(...)` | 工厂函数，返回可调用的 Agent |
| `AgentState` | 默认状态类型（消息列表 + 自定义字段） |

> 完整参数表详见 [[langchain/modules/langchain_agents/create_agent参数|create_agent 参数详解]]

## 完整示例

```python
"""
示例：从零构建一个完整可用的 Agent
"""
from dataclasses import dataclass
from langchain.agents import create_agent, AgentState
from langchain.tools import tool
from langgraph.checkpoint.memory import InMemorySaver

# ============ 1. 定义工具 ============
@tool
def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

# ============ 2. 自定义运行时上下文 ============
@dataclass
class AppContext:
    user_id: str
    session_id: str

# ============ 3. 自定义状态（扩展默认 AgentState）============
class AppState(AgentState):
    request_count: int

# ============ 4. 创建 Agent ============
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
    state_schema=AppState,
    context_schema=AppContext,
    checkpointer=InMemorySaver(),
)

# ============ 5. 调用 ============
config = {"configurable": {"thread_id": "user-1"}}
result = agent.invoke(
    {"messages": [{"role": "user", "content": "Weather in Tokyo?"}]},
    config=config,
    context=AppContext(user_id="u1", session_id="s1"),
)
print(result["messages"][-1][[.content)
```

## 何时使用

- 需要**多轮对话 + 工具调用**的智能体
- 需要结构化输出或自定义状态
- 需要可组合的 middleware 扩展能力

## 注意事项

- `tools` 中的函数必须有 **docstring**（作为工具描述传给模型）
- 启用 `checkpointer` 后才能使用 `thread_id` 持久化对话
- v1 之前的 `create_react_agent` 等已弃用，统一用 `create_agent`
