# 文本分割器

## 是什么

文本分割器（Text Splitters）将长文档**切分为较小的 chunks**，使其适合嵌入向量化和检索。`langchain_text_splitters` 提供多种分割策略。

## 导入

```python
from langchain_text_splitters import (
    RecursiveCharacterTextSplitter,
    CharacterTextSplitter,
    TokenTextSplitter,
)
```

## RecursiveCharacterTextSplitter（推荐）

最常用的分割器，按字符优先级递归分割：

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_core.documents import Document

long_text = "..." * 1000
doc = Document(page_content=long_text, metadata={"source": "long.txt"})

splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,        # 每块最多 500 字符
    chunk_overlap=50,      # 相邻块重叠 50 字符
    separators=["\n\n", "\n", "。", "，", " ", ""],  # 优先按段落分割
)
chunks = splitter.split_documents([doc])
print(f"Split into {len(chunks)} chunks")
for i, chunk in enumerate(chunks):
    print(f"Chunk {i}: {chunk.page_content[:50]}... | metadata={chunk.metadata}")
```

### 关键参数

| 参数 | 默认 | 描述 |
|------|------|------|
| `chunk_size` | 1000 | 每块最大字符数 |
| `chunk_overlap` | 200 | 相邻块重叠字符数 |
| `separators` | `["\n\n", "\n", " ", ""]` | 分割优先级（先段落，再行，再句） |
| `length_function` | `len` | 长度度量函数 |
| `is_separator_regex` | False | 是否为正则 |

## CharacterTextSplitter

按单一字符分割：

```python
from langchain_text_splitters import CharacterTextSplitter

splitter = CharacterTextSplitter(
    separator="\n\n",      # 按双换行（段落）分割
    chunk_size=1000,
    chunk_overlap=200,
)
chunks = splitter.split_documents(docs)
```

## TokenTextSplitter

按 token 数量分割，适合需要精确控制 token 数的场景：

```python
from langchain_text_splitters import TokenTextSplitter

splitter = TokenTextSplitter(
    chunk_size=512,        # 每块最多 512 tokens
    chunk_overlap=50,
    encoding_name="cl100k_base",  # OpenAI tokenizer
)
chunks = splitter.split_documents(docs)
```

## 分割纯文本

除了分割 Document 列表，也可以直接分割纯文本字符串：

```python
texts = splitter.split_text(long_text)  # 返回 List[str][[
```

## 选择建议

| 场景 | 推荐 |
|------|------|
| 通用文本分割 | `RecursiveCharacterTextSplitter` |
| 按段落/章节分割 | `CharacterTextSplitter` with `separator="\n\n"` |
| 按 token 控制 | `TokenTextSplitter` |
| 中文场景 | `RecursiveCharacterTextSplitter`，separators 加 `。`、`，` |

## 注意事项

- `chunk_overlap` 影响检索召回率：太小可能丢失上下文，太大增加冗余
- 中文场景建议 separators 包含 `。`、`，`、`；`
- chunk 的 metadata 会继承原始 Document 的 metadata
- 分割后的 chunks 可直接传入 Embeddings → VectorStore
