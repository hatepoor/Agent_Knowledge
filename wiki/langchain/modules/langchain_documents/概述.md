# documents 模块

## 是什么

`langchain_core.documents` 定义 LangChain 的**文档数据模型**，是 RAG、文档问答、知识库等场景的基础类型。`langchain_community.document_loaders` 和 `langchain_text_splitters` 提供加载与分割能力。

## 有什么用

- 统一表示文本及其元数据
- 从 PDF、Word、网页、数据库等加载文档
- 分割长文档为可嵌入的 chunks

## 关键类与函数

| 类/函数 | 模块 | 作用 |
|---------|------|------|
| `Document` | `langchain_core.documents` | 文档数据模型（page_content + metadata） |
| `BaseLoader` | `langchain_community.document_loaders` | 文档加载器抽象基类 |
| `TextLoader` | `document_loaders` | 加载 .txt 文件 |
| `PyPDFLoader` | `document_loaders` | 加载 PDF |
| `UnstructuredWordDocumentLoader` | `document_loaders` | 加载 .docx |
| `WebBaseLoader` | `document_loaders` | 加载网页 |
| `NotionDBLoader` | `document_loaders` | 加载 Notion |
| `TextSplitter` | `langchain_text_splitters` | 文本分割器基类 |
| `RecursiveCharacterTextSplitter` | `text_splitters` | 按字符递归分割（推荐） |
| `CharacterTextSplitter` | `text_splitters` | 按字符分割 |
| `TokenTextSplitter` | `text_splitters` | 按 token 分割 |

## 注意事项

- 元数据（metadata）会随 chunk 一路传到 VectorStore、Retriever，必须用简单 JSON 可序列化类型
- `chunk_overlap` 影响检索召回率与冗余度
- 中文场景建议加 `。`、`，` 到 separators
- 部分 loader 需额外依赖（如 `pip install pypdf`）
