# prompts 模块概述

`langchain_core.prompts` 是 LangChain 的**提示词模板系统**，提供声明式方式构建结构化提示词（系统提示、对话模板、few-shot 示例等）。它是 LangChain 中最常用的模块之一，用于动态生成提示词。

## 有什么用

- **动态内容注入**：用模板变量注入动态内容，避免硬编码
- **多消息组合**：组合多条消息为完整提示（system + human + ai）
- **历史管理**：复用 few-shot 示例与对话历史占位符
- **类型安全**：提供类型提示和验证，减少错误
- **可复用性**：同一模板可用于不同场景，只需传入不同变量

## 包结构

```
langchain_core.prompts
├── PromptTemplate                    # 基础字符串模板
├── ChatPromptTemplate                # 聊天消息模板（最常用）
├── SystemMessagePromptTemplate       # 系统消息模板
├── HumanMessagePromptTemplate        # 用户消息模板
├── AIMessagePromptTemplate           # AI 消息模板
├── MessagesPlaceholder               # 消息占位符
├── FewShotPromptTemplate             # Few-shot 模板
├── FewShotChatMessagePromptTemplate  # 聊天版 few-shot
└── ChatMessagePromptTemplate         # 自定义角色模板
```

## 变量语法

| 语法 | 含义 | 示例 |
|------|------|------|
| `{var}` | 单值变量 | `"你好，{name}"` |
| `{var}` 在 list 中 | 多值列表变量 | `["{item1}", "{item2}"][[` |
| `MessagesPlaceholder("name")` | 插入历史消息列表 | 用于多轮对话 |
| `partial(var=value)` | 预填充变量 | 固定某些变量值 |

## 何时使用

- **需要动态构造多轮提示词**：使用 `ChatPromptTemplate` + `MessagesPlaceholder`
- **需要 few-shot 学习（chat 模型）**：使用 `FewShotChatMessagePromptTemplate`（推荐）
- **需要 few-shot 学习（completion 模型）**：使用 `FewShotPromptTemplate`
- **需要复用同一模板**：创建模板对象，用不同变量多次调用
- **需要固定某些变量**：使用 `partial()` 预填充
- **需要结构化输出**：结合 `with_structured_output()` 使用

## 注意事项

- `MessagesPlaceholder` 名称必须与调用时传入的 key 一致
- 模板只在 `format_messages()` 或链式调用时才填充变量
- `partial()` 会覆盖同名变量，注意使用顺序
- 不同消息类型（system/human/ai）各有用途，不要混用
- 模板创建是一次性成本，应该复用模板对象
- 使用 `input_variables` 属性检查需要的变量，避免遗漏
- `FewShotPromptTemplate` 的 `example_prompt` 必须是 `PromptTemplate`，不能传 `ChatPromptTemplate`
- `FewShotChatMessagePromptTemplate` 的 `example_prompt` 必须是 `ChatPromptTemplate`，不能传 `PromptTemplate`
- 除非需要兼容老式 completion 模型，否则一律使用 `FewShotChatMessagePromptTemplate`
