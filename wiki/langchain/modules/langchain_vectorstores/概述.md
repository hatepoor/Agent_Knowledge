# vectorstores 模块

## 是什么

`langchain_core.vectorstores` 是 LangChain 的**向量存储抽象接口**。具体实现位于 `langchain_community.vectorstores`（FAISS、Chroma 等）和各集成包（`langchain-pgvector` 等）。

## 有什么用

- 统一不同向量数据库的 API
- 与 Embeddings 集成，自动完成向量化
- 提供相似度搜索、过滤、删除等基础能力

## 关键类

| 类 | 用途 |
|-----|------|
| `VectorStore` | 抽象基类 |
| `InMemoryVectorStore` | 内存版（开发用） |
| `FAISS` | Facebook FAISS（本地） |
| `Chroma` | Chroma（本地/服务端） |
| `PGVector` | Postgres + pgvector（生产） |
| `Pinecone` | Pinecone（云服务） |
| `Weaviate` | Weaviate |
| `Qdrant` | Qdrant |
| `Milvus` | Milvus |

## 通用接口

| 方法 | 作用 | 返回类型 |
|------|------|----------|
| `add_documents(documents, **kwargs)` | 添加文档 | `list[str]`（返回文档 ID 列表） |
| `add_texts(texts, metadatas, **kwargs)` | 添加文本 | `list[str]`（返回文本 ID 列表） |
| `similarity_search(query, k=4, **kwargs)` | 相似度搜索 | `list[Document][[` |
| `similarity_search_with_score(query, k=4)` | 返回带分数结果 | `list[tuple[Document, float]]` |
| `similarity_search_by_vector(embedding, k=4)` | 用向量搜索 | `list[Document]` |
| `as_retriever(**kwargs)` | 转为 Retriever | `VectorStoreRetriever` |
| `delete(ids, **kwargs)` | 删除 | `None` |
| `from_documents(documents, embedding, **kwargs)` | 从文档构造 | `VectorStore` 实例 |
| `from_texts(texts, embedding, metadatas, **kwargs)` | 从文本构造 | `VectorStore` 实例 |

## 何时使用

| 场景 | 推荐 |
|------|------|
| 开发测试 | `InMemoryVectorStore` |
| 本地原型 | `FAISS`、`Chroma` |
| 生产中型 | `PGVector`（已有 PG） |
| 生产大型 | `Pinecone`、`Qdrant`、`Milvus`、`Weaviate` |
| 隐私要求 | 本地 FAISS 或 Chroma |

## 注意事项

- 切换 VectorStore 后端**必须重建索引**（向量模型不通用）
- 距离度量：默认 cosine；不同后端支持 dot_product、euclidean 等
- 元数据过滤语法**因后端而异**（Chroma 用 `$gte`，Pinecone 用 `gte`）
- `InMemoryVectorStore` 重启即丢失

## 完整代码示例

```python
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain_core.documents import Document

# 1. 创建向量存储
embeddings = OpenAIEmbeddings()
vectorstore = InMemoryVectorStore(embedding=embeddings)

# 2. 添加文档
docs = [
    Document(page_content="LangChain 是一个 LLM 应用开发框架", metadata={"source": "docs"}),
    Document(page_content="LangGraph 用于构建有状态的 Agent 工作流", metadata={"source": "docs"}),
    Document(page_content="RAG 是检索增强生成，结合搜索与生成", metadata={"source": "docs"}),
]

# add_documents 返回 list[str] —— 每个文档的唯一 ID
ids = vectorstore.add_documents(docs)
print(type(ids))       # <class 'list'>
print(ids)             # ['doc-id-1', 'doc-id-2', 'doc-id-3']

# 3. 相似度搜索 —— 返回 list[Document]
results = vectorstore.similarity_search("什么是 LangChain？", k=2)
print(type(results))   # <class 'list'>
print(len(results))    # 2
for doc in results:
    print(f"  [{type(doc).__name__}] {doc.page_content[:50]}")
    # [Document] LangChain 是一个 LLM 应用开发框架
    # [Document][[ RAG 是检索增强生成，结合搜索与生成

# 4. 带分数的搜索 —— 返回 list[tuple[Document, float]]
results_with_score = vectorstore.similarity_search_with_score("Agent 框架", k=1)
print(type(results_with_score))  # <class 'list'>
for doc, score in results_with_score:
    print(f"  score={score:.4f} | {doc.page_content[:50]}")
    # score=0.8923 | LangGraph 用于构建有状态的 Agent 工作流

# 5. 转为检索器 —— 返回 VectorStoreRetriever
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})
print(type(retriever))  # <class 'VectorStoreRetriever'>

# retriever.invoke() 返回 list[Document]
retrieved = retriever.invoke("什么是 RAG？")
print(type(retrieved))  # <class 'list'>
for doc in retrieved:
    print(f"  [{type(doc).__name__}] {doc.page_content[:50][[}")
```

## 避免重复存储

多次运行索引会导致文档重复存入。以下是常用去重策略：

### 内容哈希 ID（推荐）

```python
import hashlib
from langchain_core.documents import Document

def generate_doc_id(doc: Document) -> str:
    """基于内容生成唯一 ID，相同内容得到相同 ID"""
    raw = f"{doc.metadata.get('source', '')}:{doc.page_content[:200]}"
    return hashlib.md5(raw.encode()).hexdigest()

# 给每个块生成确定性 ID
for chunk in chunks:
    chunk.metadata["id"] = generate_doc_id(chunk)

ids = [chunk.metadata["id"] for chunk in chunks]
vectorstore.add_documents(chunks, ids=ids)
# Chroma 的 add_documents 默认是 upsert 行为：
# 相同 ID → 更新；新 ID → 插入。不会重复存入。
```

### 文件修改时间检查

```python
import os, json
from pathlib import Path

INDEX_LOG = "./index_log.json"

def should_reindex(file_path: str) -> bool:
    """检查文件是否需要重新索引"""
    log = json.loads(Path(INDEX_LOG).read_text()) if Path(INDEX_LOG).exists() else {}
    mtime = os.path.getmtime(file_path)
    return file_path not in log or log[file_path] != mtime
```

### 各数据库去重支持

| 数据库 | 去重方式 |
|--------|---------|
| Chroma | 原生 upsert（相同 ID 自动更新） |
| FAISS | 无原生支持，需自己维护 ID→原文映射 |
| PGVector | 通过主键约束实现 upsert |
| Pinecone | 原生 upsert（相同 ID 自动更新） |
