# retrievers 模块

## 是什么

`langchain_core.retrievers` 是 LangChain 的**检索器抽象**，比 VectorStore 更高层，支持多路召回、重排序、查询变换等高级 RAG 能力。

## 有什么用

- 把 VectorStore 包成 Retriever（统一调用接口）
- 实现多路召回（向量 + BM25 + 关键词）
- 在检索前后做查询改写、结果重排

## 关键类

| 类 | 用途 |
|-----|------|
| `BaseRetriever` | 抽象基类 |
| `VectorStoreRetriever` | VectorStore 包装 |
| `MultiQueryRetriever` | 多查询改写后合并 |
| `SelfQueryRetriever` | 自查询（LLM 解析过滤条件） |
| `ContextualCompressionRetriever` | 上下文压缩 |
| `EnsembleRetriever` | 多路融合（Reciprocal Rank Fusion） |
| `ParentDocumentRetriever` | 父文档检索（小 chunk + 大 context） |
| `TimeWeightedVectorStoreRetriever` | 时间加权（近期优先） |
| `BM25Retriever` | 关键词检索（不需 embedding） |
| `WebResearchRetriever` | 网络研究检索 |

## Retriever vs VectorStore

| 维度 | VectorStore | Retriever |
|------|-------------|-----------|
| 抽象层级 | 存储 + 搜索 | 检索策略 |
| 输入 | query string 或 embedding | query string |
| 输出 | Documents | Documents |
| 高级能力 | 元数据过滤 | 多路融合、查询改写、压缩 |

## 核心接口

| 方法 | 作用 | 返回类型 |
|------|------|----------|
| `retriever.invoke(query)` | 执行检索 | `list[Document][[` |
| `retriever.batch(queries)` | 批量检索 | `list[list[Document]]` |
| `retriever.ainvoke(query)` | 异步检索 | `list[Document]` |

## 何时使用

| 场景 | 推荐 |
|------|------|
| 简单相似度搜索 | `VectorStoreRetriever` |
| 多角度召回 | `MultiQueryRetriever` |
| 减少冗余 | MMR 或 `ContextualCompressionRetriever` |
| 自然语言过滤 | `SelfQueryRetriever` |
| 向量+关键词融合 | `EnsembleRetriever` |
| 自定义逻辑 | 实现 `BaseRetriever` |

## 注意事项

- Retriever 是 Runnable 协议实现，可直接链入 LCEL
- `EnsembleRetriever` 通过 Reciprocal Rank Fusion 融合多路结果
- 高级 Retriever 每次调用都会触发 LLM 调用，注意成本

## 完整代码示例

```python
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain_core.documents import Document

# 准备向量存储
vectorstore = InMemoryVectorStore(embedding=OpenAIEmbeddings())
vectorstore.add_documents([
    Document(page_content="Python 是一种解释型编程语言", metadata={"topic": "python"}),
    Document(page_content="JavaScript 是 Web 开发的核心语言", metadata={"topic": "javascript"}),
    Document(page_content="Rust 注重内存安全和并发性能", metadata={"topic": "rust"}),
])

# 创建检索器
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

# invoke() 返回 list[Document][[
results = retriever.invoke("哪种语言适合 Web 开发？")
print(type(results))    # <class 'list'>
print(len(results))     # 2

for i, doc in enumerate(results):
    print(f"\n--- Document {i+1} ---")
    print(f"类型: {type(doc).__name__}")      # Document
    print(f"内容: {doc.page_content}")         # JavaScript 是 Web 开发的核心语言
    print(f"元数据: {doc.metadata}")           # {"topic": "javascript"}

# batch() 返回 list[list[Document]] —— 多个查询的结果
batch_results = retriever.batch([
    "Web 开发语言",
    "系统编程语言",
])
print(type(batch_results))    # <class 'list'>
print(len(batch_results))     # 2（查询数）
print(len(batch_results[0][[))  # 2（每个查询返回 k 个文档）
```
