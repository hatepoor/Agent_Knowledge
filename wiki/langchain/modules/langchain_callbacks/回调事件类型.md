# 回调事件类型

LangChain 回调系统覆盖了 LLM、Chain、Tool、Agent、Retriever 等组件的完整生命周期。

## 全部事件列表

| 事件 | 触发时机 |
|------|---------|
| `on_llm_start` | LLM 调用开始 |
| `on_llm_new_token` | LLM 流式生成新 token |
| `on_llm_end` | LLM 调用结束 |
| `on_llm_error` | LLM 调用出错 |
| `on_chain_start` | Chain 开始 |
| `on_chain_end` | Chain 结束 |
| `on_chain_error` | Chain 出错 |
| `on_tool_start` | 工具调用开始 |
| `on_tool_end` | 工具调用结束 |
| `on_tool_error` | 工具调用出错 |
| `on_agent_action` | Agent 决策动作 |
| `on_agent_finish` | Agent 结束 |
| `on_retriever_start` | 检索器开始 |
| `on_retriever_end` | 检索器结束 |
| `on_text` | 自定义文本事件 |

## LLM 事件

```python
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.outputs import LLMResult

class LLMEventLogger(BaseCallbackHandler):
    def on_llm_start(self, serialized: dict, prompts: list[str], **kwargs) -> None:
        print(f"[LLM START] prompts count: {len(prompts)}")

    def on_llm_new_token(self, token: str, **kwargs) -> None:
        print(token, end="", flush=True)

    def on_llm_end(self, response: LLMResult, **kwargs) -> None:
        print(f"[LLM END] generations: {len(response.generations)}")

    def on_llm_error(self, error: BaseException, **kwargs) -> None:
        print(f"[LLM ERROR] {error}")
```

## Tool 事件

```python
class ToolEventLogger(BaseCallbackHandler):
    def on_tool_start(self, serialized: dict, input_str: str, **kwargs) -> None:
        print(f"[TOOL START] {serialized.get('name')} called with: {input_str}")

    def on_tool_end(self, output: str, **kwargs) -> None:
        print(f"[TOOL END] returned: {output[:100]}")

    def on_tool_error(self, error: BaseException, **kwargs) -> None:
        print(f"[TOOL ERROR] {error}")
```

## Chain 事件

```python
class ChainEventLogger(BaseCallbackHandler):
    def on_chain_start(self, serialized: dict, inputs: dict, **kwargs) -> None:
        print(f"[CHAIN START] {serialized.get('name')}")

    def on_chain_end(self, outputs: dict, **kwargs) -> None:
        print(f"[CHAIN END] keys: {list(outputs.keys())}")

    def on_chain_error(self, error: BaseException, **kwargs) -> None:
        print(f"[CHAIN ERROR] {error}")
```

## Agent 事件

```python
class AgentEventLogger(BaseCallbackHandler):
    def on_agent_action(self, action, **kwargs) -> None:
        print(f"[AGENT ACTION] tool: {action.tool}, input: {action.tool_input}")

    def on_agent_finish(self, finish, **kwargs) -> None:
        print(f"[AGENT FINISH] output: {finish.return_values}")
```

## Retriever 事件

```python
class RetrieverEventLogger(BaseCallbackHandler):
    def on_retriever_start(self, serialized: dict, query: str, **kwargs) -> None:
        print(f"[RETRIEVER START] query: {query}")

    def on_retriever_end(self, documents: list, **kwargs) -> None:
        print(f"[RETRIEVER END][[ found: {len(documents)} docs")
```

## 事件触发顺序

典型的 Chain 调用事件流：

```
on_chain_start
  -> on_llm_start
    -> on_llm_new_token (流式时多次触发)
  -> on_llm_end
  -> on_tool_start (如有工具调用)
  -> on_tool_end
on_chain_end
```
