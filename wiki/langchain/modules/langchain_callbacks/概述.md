# callbacks 模块

## 是什么

`langchain_core.callbacks` 是 LangChain 的**回调钩子系统**，在 LLM、Chain、Tool 等组件的**生命周期事件**（开始、结束、错误、token 流式）中触发用户自定义逻辑。

## 有什么用

- 日志与监控
- Token 消耗统计
- LangSmith 追踪
- 自定义指标采集

## 关键类

| 类 | 用途 |
|-----|------|
| `BaseCallbackHandler` | 回调处理器基类 |
| `StdOutCallbackHandler` | 打印到 stdout（调试用） |
| `FileCallbackHandler` | 写入文件 |
| `LangChainTracer` / `LangSmithTracer` | LangSmith 集成 |
| `get_openai_callback` | OpenAI 专用 token 计数 |
| `AsyncCallbackHandler` | 异步回调基类 |

## 何时使用

| 场景 | 推荐 |
|------|------|
| 调试 | `StdOutCallbackHandler` |
| 生产监控 | 自定义 `BaseCallbackHandler` |
| 追踪 | `LangSmithTracer` |
| 成本控制 | `get_openai_callback` |
| 实时 UI | 流式 token 回调 |

## 注意事项

- 回调处理器**共享状态**（handler 实例）
- 异步场景必须用 `AsyncCallbackHandler`
- LangSmith 是 LangChain 官方的生产级追踪方案
- v1 中部分回调可被 `middleware` 替代
