# MCP 模块

> `langchain-mcp-adapters` 是 LangChain 的**MCP（Model Context Protocol）客户端适配器**，让 LangChain Agent 直接调用符合 MCP 标准的外部工具服务器。

## 有什么用

- 把任何 MCP 服务器的工具注入 LangChain Agent
- 统一 stdio、SSE、WebSocket 三种传输方式
- 动态加载远程工具，无需重启

## 安装

```bash
pip install langchain-mcp-adapters
```

## 关键类

| 类 | 作用 |
|-----|------|
| `MultiServerMCPClient` | 多 MCP 服务器客户端 |
| `SingleServerMCPClient` | 单服务器客户端 |
| `load_mcp_tools(session)` | 从 session 加载 LangChain 工具 |
| `Connection` | 单连接配置 |

## 何时使用

| 场景 | 推荐 |
|------|------|
| 调用现有 MCP 服务器 | `MultiServerMCPClient` |
| 自定义工具服务器 | 写一个 MCP 服务器，客户端用此模块 |
| 多服务组合 | `MultiServerMCPClient` 多连接 |
| 单机本地工具 | 直接用 `@tool`（无需 MCP） |

## 注意事项

- MCP 服务器需独立启动（stdio）或可访问（SSE/WebSocket）
- 工具是**动态加载**的，每次调用都从服务器获取最新定义
- MCP 工具描述遵循 MCP 协议，由服务器决定
- v1 LangChain 中 MCP 工具与本地工具无差别
- 环境变量（`env`）用于 stdio 启动时的子进程环境
