# 命名空间设计

Store 使用 namespace（命名空间）元组来组织数据，实现多用户、多应用的数据隔离。

## 基本原则

- namespace 是一个**元组**，各层级用逗号分隔
- 元组的每个元素代表一个维度（如类别、用户ID、子类别）
- 不同 namespace 下的数据完全隔离

## 单租户

最简单的用法，所有数据共享同一 namespace：

```python
namespace = ("preferences",)

store.put(namespace, "theme", {"value": "dark"})
store.put(namespace, "language", {"value": "Chinese"})
```

## 多用户隔离

第二个元素用作用户 ID：

```python
# 用户 Alice
ns_alice = ("users", "alice", "preferences")
store.put(ns_alice, "theme", {"value": "dark"})

# 用户 Bob
ns_bob = ("users", "bob", "preferences")
store.put(ns_bob, "theme", {"value": "light"})

# 各自独立
alice_theme = store.get(ns_alice, "theme").value  # {"value": "dark"}
bob_theme = store.get(ns_bob, "theme").value      # {"value": "light"}
```

## 多层分级

可以按 `("应用", "用户", "类别")` 多层组织：

```python
# 应用1 - 用户偏好
ns = ("app1", "alice", "preferences")
store.put(ns, "theme", {"value": "dark"})

# 应用1 - 用户历史
ns = ("app1", "alice", "history")
store.put(ns, "msg_1", {"text": "Hello", "ts": 1234567890})

# 应用2 - 同一用户（隔离）
ns = ("app2", "alice", "preferences")
store.put(ns, "theme", {"value": "light"})  # 不影响 app1
```

## 在工具中使用

结合 `runtime.context` 动态构建 namespace：

```python
from langchain.tools import tool, ToolRuntime
from dataclasses import dataclass

@dataclass
class Context:
    user_id: str

@tool
def save_data(key: str, value: str, runtime: ToolRuntime) -> str:
    """Save data for current user."""
    ns = ("users", runtime.context.user_id, "data")
    runtime.store.put(ns, key, {"value": value})
    return f"Saved {key}"
```

## 设计建议

| 层级 | 用途 | 示例 |
|------|------|------|
| 第 1 层 | 应用/类别 | `"users"`, `"docs"`, `"prefs"` |
| 第 2 层 | 用户/租户 | `user_id`, `org_id` |
| 第 3 层 | 子类别 | `"preferences"`, `"history"`, `"sessions"` |

## 注意事项

- namespace 元组的长度不限，按实际需求设计
- 同一 Store 实例中不同 namespace 的数据互不影响
- `search` 方法只在指定 namespace 内搜索
- 删除 namespace 下所有数据需逐一 delete（无批量删除 namespace 的 API）
