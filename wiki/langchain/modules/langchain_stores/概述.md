# stores 模块

## 是什么

`langgraph.store` 提供 LangChain/LangGraph 的**长期记忆键值存储**抽象。Store 是 namespace 组织的多租户键值数据库，用于跨对话持久化数据（用户偏好、知识、事实等）。

## 有什么用

- 跨 thread 持久化数据
- 多用户多租户隔离（namespace）
- 工具中通过 `runtime.store` 访问
- 语义相似度检索（部分实现）

## 关键类

| 类 | 模块 | 用途 |
|-----|------|------|
| `BaseStore` | `langgraph.store` | 抽象基类 |
| `InMemoryStore` | `langgraph.store.memory` | 内存版（开发用） |
| `PostgresStore` | `langgraph.store.postgres` | Postgres + pgvector（生产） |
| `RedisStore` | `langgraph.store.redis` | Redis 实现 |

## 核心 API

| 方法 | 作用 |
|------|------|
| `get(namespace, key)` | 读取 |
| `put(namespace, key, value)` | 写入/更新 |
| `delete(namespace, key)` | 删除 |
| `search(namespace, query=..., limit=...)` | 检索（语义或前缀） |
| `batch(...)` | 批量操作 |

## 何时使用

| 场景 | 推荐 |
|------|------|
| 简单偏好 | `InMemoryStore` |
| 生产持久化 | `PostgresStore` |
| 已有 Redis 基础设施 | `RedisStore` |
| 需要语义检索 | `PostgresStore` + embedding |

## 注意事项

- Store 中的数据**独立于 checkpointer**（不受 thread 影响）
- namespace 元组用逗号分隔
- `value` 必须 JSON 可序列化
- 向量检索需在 `put` 时指定 `index` 字段名
- 配合 `runtime.store` 在工具中使用
