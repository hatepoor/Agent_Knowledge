# 错误处理

## 概述

在使用 LangChain 的输出解析器时，LLM 的输出可能不符合预期格式，导致解析失败。本文档介绍如何检测、捕获和处理这些错误。

---

## OutputParserException

`OutputParserException` 是 LangChain 中所有输出解析器在解析失败时抛出的异常类。它继承自 `Exception`，包含有用的上下文信息。

### 导入

```python
from langchain_core.exceptions import OutputParserException
```

### 异常属性

```python
from langchain_core.exceptions import OutputParserException

# 异常实例包含以下信息：
# - 错误消息（str）
# - 可选的 llm_output：LLM 的原始输出
# - 可选的 observation：额外观察信息
# - 可选的 send_to_llm：是否需要将错误发回给 LLM

try:
    # 某个解析操作
    pass
except OutputParserException as e:
    print(f"错误消息: {e}")
    print(f"LLM 原始输出: {getattr(e, 'llm_output', 'N/A')}")
```

### 何时会抛出

以下解析器在解析失败时会抛出 `OutputParserException`：

| 解析器 | 触发条件 |
|--------|---------|
| `PydanticOutputParser` | LLM 输出不是有效的 JSON 或不符合 Pydantic schema |
| `JsonOutputParser` | LLM 输出不是有效的 JSON |
| `EnumOutputParser` | LLM 输出的值不在枚举范围内 |
| `CommaSeparatedListOutputParser` | 极少抛出（逗号分割几乎总能成功） |
| `NumberedListOutputParser` | LLM 输出不包含编号格式 |

## try/except 基本模式

### 捕获解析异常

```python
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.exceptions import OutputParserException
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

model = ChatOpenAI(model="gpt-4o-mini")

class MovieReview(BaseModel):
    title: str = Field(description="电影名称")
    rating: float = Field(description="评分 1-10")
    genre: str = Field(description="类型")

parser = PydanticOutputParser(pydantic_object=MovieReview)

prompt = ChatPromptTemplate.from_messages([
    ("system", "写影评。{format_instructions}"),
    ("human", "评论电影《{movie}》。"),
])

chain = prompt | model | parser

try:
    result = chain.invoke({
        "movie": "肖申克的救赎",
        "format_instructions": parser.get_format_instructions(),
    })
    print(f"解析成功: {result.title}")
except OutputParserException as e:
    print(f"解析失败: {e}")
    # 可以在这里实现降级逻辑
    result = None
```

### 多重异常捕获

```python
from langchain_core.exceptions import OutputParserException

try:
    result = chain.invoke({...})
except OutputParserException as e:
    print(f"输出格式错误: {e}")
    result = None
except Exception as e:
    print(f"其他错误: {type(e).__name__}: {e}")
    result = None
```

## OutputFixingParser：自动重试修正

`OutputFixingParser` 是最常用的自动错误修正方案。当底层解析器失败时，它会再次调用 LLM 来修正格式。

### 基本用法

```python
from langchain.output_parsers import OutputFixingParser
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

model = ChatOpenAI(model="gpt-4o-mini")

class UserInfo(BaseModel):
    name: str = Field(description="姓名")
    age: int = Field(description="年龄")
    email: str = Field(description="邮箱")

base_parser = PydanticOutputParser(pydantic_object=UserInfo)

# 包装为自动修正解析器
fixing_parser = OutputFixingParser.from_llm(llm=model, parser=base_parser)

prompt = ChatPromptTemplate.from_messages([
    ("system", "提取用户信息。{format_instructions}"),
    ("human", "{text}"),
][[)

chain = prompt | model | fixing_parser

# 即使 LLM 首次输出格式不对，fixing_parser 会自动修正
result = chain.invoke({
    "text": "张三，28岁，邮箱是 zhangsan@example.com",
    "format_instructions": base_parser.get_format_instructions(),
})

print(result.name)   # 张三
print(result.age)    # 28
print(result.email)  # zhangsan@example.com
```

### 工作原理

```
1. LLM 生成初始输出
2. base_parser 尝试解析
3. 如果成功 → 直接返回
4. 如果失败 → OutputFixingParser 捕获 OutputParserException
5. 构造修正提示（包含错误信息和原始输出）
6. 再次调用 LLM 生成修正后的输出
7. base_parser 再次尝试解析
8. 如果成功 → 返回结果
9. 如果仍然失败 → 抛出异常
```

**注意：** `OutputFixingParser` **只重试一次**。如果修正后仍然失败，会直接抛出异常。

详见：[[langchain/modules/langchain_output_parsers/OutputFixingParser|OutputFixingParser]]

## RetryWithErrorOutputParser

`RetryWithErrorOutputParser` 是另一种自动修正方案，与 `OutputFixingParser` 的区别在于它会将**完整的原始提示词**重新发给 LLM，让 LLM 从头重新生成（而非只修正格式）。

### 基本用法

```python
from langchain.output_parsers import RetryWithErrorOutputParser
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

model = ChatOpenAI(model="gpt-4o-mini")

class AnalysisResult(BaseModel):
    topic: str = Field(description="分析主题")
    key_findings: list[str] = Field(description="关键发现")
    conclusion: str = Field(description="结论")

base_parser = PydanticOutputParser(pydantic_object=AnalysisResult)

# RetryWithErrorOutputParser 需要访问原始提示词
retry_parser = RetryWithErrorOutputParser.from_llm(
    llm=model,
    parser=base_parser,
)
```

### OutputFixingParser vs RetryWithErrorOutputParser

| 特性 | OutputFixingParser | RetryWithErrorOutputParser |
|------|-------------------|--------------------------|
| **修正策略** | 只修正格式错误 | 完全重新生成 |
| **发给 LLM 的内容** | 修正提示 + 错误信息 | 原始完整提示词 + 错误信息 |
| **需要原始提示词** | 否 | 是 |
| **Token 消耗** | 较少 | 较多 |
| **适用场景** | 格式小错误 | 内容或格式严重错误 |
| **重试次数** | 1次 | 1次 |

### 选择建议

```python
# 如果 LLM 的内容基本正确，只是格式有点问题
# → 使用 OutputFixingParser（省 token）
fixing_parser = OutputFixingParser.from_llm(llm=model, parser=base_parser)

# 如果 LLM 的输出可能完全偏离要求
# → 使用 RetryWithErrorOutputParser（更彻底）
retry_parser = RetryWithErrorOutputParser.from_llm(llm=model, parser=base_parser)
```

## 常见错误场景与解决方案

### 场景1：LLM 输出了 Markdown 代码块包裹的 JSON

```python
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.exceptions import OutputParserException
from pydantic import BaseModel, Field
import json
import re

class Data(BaseModel):
    name: str
    value: int

parser = PydanticOutputParser(pydantic_object=Data)

# LLM 输出：
llm_output = '```json\n{"name": "test", "value": 42}\n```'

try:
    result = parser.parse(llm_output)
except OutputParserException:
    # 手动去除 Markdown 代码块
    cleaned = re.sub(r'^```json\s*', '', llm_output)
    cleaned = re.sub(r'\s*```$', '', cleaned)
    result = parser.parse(cleaned)
    print(result)  # name='test' value=42
```

**更好的方案：** 在提示词中明确要求不要使用代码块：

```python
prompt = ChatPromptTemplate.from_messages([
    ("system", "直接输出 JSON，不要用 ``` 代码块包裹。\n{format_instructions}"),
    ("human", "{question}"),
][[)
```

### 场景2：LLM 在 JSON 前加了说明文字

```python
from langchain_core.output_parsers import JsonOutputParser
from langchain_core.exceptions import OutputParserException
import json
import re

parser = JsonOutputParser()

# LLM 输出：
llm_output = '好的，以下是结果：{"name": "test", "value": 42}'

try:
    result = parser.parse(llm_output)
except OutputParserException:
    # 提取 JSON 部分
    match = re.search(r'\{.*\}', llm_output)
    if match:
        result = json.loads(match.group())
        print(result)  # {'name': 'test', 'value': 42}
    else:
        raise
```

### 场景3：EnumOutputParser 大小写不匹配

```python
from langchain_core.output_parsers import EnumOutputParser
from langchain_core.exceptions import OutputParserException
from enum import Enum

class Status(Enum):
    ACTIVE = "active"
    INACTIVE = "inactive"

parser = EnumOutputParser(enum=Status)

# LLM 输出了 "Active" 而非 "active"
try:
    result = parser.parse("Active")
except OutputParserException:
    # 手动转为小写再解析
    result = parser.parse("Active".lower())
    print(result)  # Status.ACTIVE
```

**更好的方案：** 在枚举中包含常见变体（详见 [[langchain/modules/langchain_output_parsers/EnumOutputParser|EnumOutputParser]]）

### 场景4：LLM 返回了 tool_call 而非文本

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4o-mini")

# 如果模型绑定了 tools，可能返回 tool_call
model_with_tools = model.bind_tools([some_tool])

chain = prompt | model_with_tools | StrOutputParser()
result = chain.invoke({...})

if result == "":
    print("⚠️ 模型返回了 tool_call，content 为空")
    # 需要直接访问 AIMessage.tool_calls
```

### 场景5：空响应或截断响应

```python
from langchain_core.exceptions import OutputParserException

try:
    result = chain.invoke({...})
except OutputParserException as e:
    error_str = str(e).lower()
    if "empty" in error_str or "invalid" in error_str:
        print("可能是空响应或响应被截断")
        # 增加 max_tokens 或重试
    else:
        raise
```

## 日志记录解析失败

### 基本日志记录

```python
import logging
from langchain_core.exceptions import OutputParserException

# 配置日志
logger = logging.getLogger("output_parser")
logging.basicConfig(level=logging.INFO)

def safe_invoke(chain, inputs):
    """带日志的安全调用"""
    try:
        result = chain.invoke(inputs)
        logger.info("解析成功")
        return result
    except OutputParserException as e:
        logger.warning(
            f"解析失败 | 输入: {inputs} | 错误: {e} | "
            f"LLM输出: {getattr(e, 'llm_output', 'N/A')}"
        )
        return None

# 使用
result = safe_invoke(chain, {"question": "什么是Python？"})
if result is None:
    print("解析失败，使用默认回复")
```

### 批量调用时的错误统计

```python
from langchain_core.exceptions import OutputParserException
import logging

logger = logging.getLogger("batch_parser")

def batch_invoke(chain, inputs_list):
    """批量调用并统计错误"""
    results = []
    success_count = 0
    fail_count = 0

    for i, inputs in enumerate(inputs_list):
        try:
            result = chain.invoke(inputs)
            results.append(result)
            success_count += 1
        except OutputParserException as e:
            logger.warning(f"[{i}] 解析失败: {e}")
            results.append(None)
            fail_count += 1

    total = len(inputs_list)
    logger.info(
        f"批量调用完成 | 总计: {total} | "
        f"成功: {success_count} ({success_count/total*100:.1f}%) | "
        f"失败: {fail_count} ({fail_count/total*100:.1f}%)"
    )

    return results

# 使用
inputs_list = [
    {"text": "很好的产品", "format_instructions": fmt},
    {"text": "质量一般", "format_instructions": fmt},
    {"text": "太棒了", "format_instructions": fmt},
]
results = batch_invoke(chain, inputs_list)
```

### 结构化日志（JSON 格式）

```python
import json
import logging
from datetime import datetime
from langchain_core.exceptions import OutputParserException

class ParseFailureLogger:
    """结构化记录解析失败"""

    def __init__(self, log_file: str = "parse_failures.jsonl"):
        self.log_file = log_file

    def log_failure(self, inputs: dict, error: OutputParserException,
                    parser_type: str, model_name: str):
        record = {
            "timestamp": datetime.now().isoformat(),
            "parser_type": parser_type,
            "model": model_name,
            "inputs": str(inputs)[:200],  # 截断避免太长
            "error": str(error)[:500],
            "llm_output": str(getattr(error, 'llm_output', ''))[:500],
        }
        with open(self.log_file, "a", encoding="utf-8") as f:
            f.write(json.dumps(record, ensure_ascii=False) + "\n")

# 使用
failure_logger = ParseFailureLogger()

try:
    result = chain.invoke(inputs)
except OutputParserException as e:
    failure_logger.log_failure(
        inputs=inputs,
        error=e,
        parser_type="PydanticOutputParser",
        model_name="gpt-4o-mini",
    )
    result = None
```

## 自定义多次重试逻辑

由于 `OutputFixingParser` 只重试一次，如果需要更多重试，可以手动实现：

```python
from langchain_core.exceptions import OutputParserException
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

model = ChatOpenAI(model="gpt-4o-mini")

class Result(BaseModel):
    answer: str = Field(description="答案")
    confidence: float = Field(description="置信度")

parser = PydanticOutputParser(pydantic_object=Result)

def invoke_with_retry(chain, inputs, parser, max_retries=3):
    """带多次重试的调用"""
    last_error = None

    for attempt in range(max_retries + 1):
        try:
            result = chain.invoke(inputs)
            return result
        except OutputParserException as e:
            last_error = e
            print(f"第 {attempt + 1} 次尝试失败: {e}")

            if attempt < max_retries:
                # 在提示词中强调格式要求
                inputs["format_instructions"] = (
                    f"重要：请严格按照以下格式输出：\n"
                    f"{parser.get_format_instructions()}\n"
                    f"你之前的输出格式不正确，错误：{e}\n"
                    f"请重新生成正确的输出。"
                )

    raise last_error

# 使用
try:
    result = invoke_with_retry(chain, inputs, parser, max_retries=3)
    print(f"最终成功: {result}")
except OutputParserException as e:
    print(f"重试 {3} 次后仍然失败: {e}")
```

## 综合最佳实践

### 推荐的错误处理策略

```python
from langchain.output_parsers import OutputFixingParser
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.exceptions import OutputParserException
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field
import logging

logger = logging.getLogger(__name__)

class MyModel(BaseModel):
    title: str = Field(description="标题")
    content: str = Field(description="内容")
    tags: list[str] = Field(description="标签")

def build_robust_chain():
    """构建健壮的链"""
    model = ChatOpenAI(model="gpt-4o-mini")
    base_parser = PydanticOutputParser(pydantic_object=MyModel)

    # 1. 使用 OutputFixingParser 自动修正
    fixing_parser = OutputFixingParser.from_llm(llm=model, parser=base_parser)

    prompt = ChatPromptTemplate.from_messages([
        ("system", "生成内容。{format_instructions}"),
        ("human", "{request}"),
    ][[)

    return prompt | model | fixing_parser, base_parser

def safe_invoke(request: str) -> MyModel | None:
    """安全的调用入口"""
    chain, parser = build_robust_chain()

    try:
        result = chain.invoke({
            "request": request,
            "format_instructions": parser.get_format_instructions(),
        })
        return result

    except OutputParserException as e:
        logger.warning(f"即使 OutputFixingParser 也失败了: {e}")
        return None

    except Exception as e:
        logger.error(f"未预期的错误: {type(e).__name__}: {e}")
        return None

# 使用
result = safe_invoke("写一篇关于AI的文章")
if result:
    print(f"成功: {result.title}")
else:
    print("解析失败，使用默认回复")
```

### 策略优先级

```
1. 首选：with_structured_output（如果模型支持 tool calling）
   → 从根本上避免格式错误

2. 次选：OutputFixingParser + PydanticOutputParser
   → 自动修正一次，覆盖大部分情况

3. 兜底：try/except + 降级逻辑
   → 确保链不会崩溃

4. 辅助：日志记录
   → 监控解析失败率，优化提示词
```
