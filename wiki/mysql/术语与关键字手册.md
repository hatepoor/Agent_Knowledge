# MySQL 术语与关键字手册

> **本页定位：只给「是什么 + 一句话含义 + 详解在哪」，不展开解释。**
> 解释与机制在正文，本页只做兜底索引。**看不懂某个名词时先来这里查，再决定要不要回正文精读。**
> 用法：Ctrl+F 搜名词 → 看「详解」列的链接 → 跳过去。
>
> ⚠️ **SQL 关键字区分方言**：MySQL 与 PostgreSQL 有大量同名不同义的关键词（如 `LIMIT`/`TOP`、`SERIAL`/`SERIAL4`）。本页只列 MySQL 方言，PG 侧见 [[postgresql/术语与关键字手册]]。

## 二、存储引擎

| 名词 | 一句话含义 | 详解 |
|------|-----------|------|
| **InnoDB** | 默认引擎，支持事务、外键、行锁、MVCC | [[mysql/02-中段阶段-专题精讲/InnoDB存储引擎/专题概览]] |
| **聚簇索引（clustered index）** | InnoDB 中数据本身存放的 B+ 树索引，**只有一棵** | [[mysql/02-中段阶段-专题精讲/InnoDB存储引擎/专题概览]] |
| **二级索引（secondary index）** | 索引叶子指向主键值，回表才能拿完整行 | 同上 |
| **回表（lookup）** | 通过二级索引找到主键后再查聚簇索引取整行 | 同上 |
| **覆盖索引（covering index）** | 查询需要的列都在索引里，不用回表 | 同上 |
| **cardinality（基数）** | 索引值的估算去重数量，判断选择性 | 同上 |
| **B+ 树** | MySQL 索引默认的数据结构，非叶子节点只存键 | 同上 |
| **页（page）** | InnoDB 磁盘 IO 的基本单位，默认 16KB | [[mysql/03-进阶阶段-深度剖析/00-剖析方法论]] |
| **表空间（tablespace）** | 存放数据页的文件/区域，8.0 前有 ibdata1 共享表空间 | 同上 |
| **数据字典** | 8.0 起把表结构信息存 InnoDB 表空间（`mysql.ibd`） | 同上 |
| **行格式（row format）** | Compact、Dynamic、Compressed 等，决定行内冗余 | 同上 |
| **doublewrite** | 防页断裂（torn page）的双写缓冲 | [[mysql/03-进阶阶段-深度剖析/日志与复制内核/原理剖析-redo日志与WAL]] |
| **undo log** | 回滚日志，同时支撑 MVCC 的旧版本链 | [[mysql/03-进阶阶段-深度剖析/事务与锁内核/原理剖析-undo日志与MVCC]] |
| **redo log** | 物理重做日志，保证持久性与崩溃恢复 | [[mysql/03-进阶阶段-深度剖析/日志与复制内核/原理剖析-redo日志与WAL]] |
| **MyISAM** | 旧引擎：**无事务**、表级锁、每表两个文件（`.MYD` 数据 + `.MYI` 索引）、**无日志**。⚠️ 只适合只读/读多写少的遗留场景，新项目不要用 | [[mysql/02-中段阶段-专题精讲/存储引擎与选型/为什么只有InnoDB支持事务]] |
| **键缓存（key cache / key buffer）** | MyISAM 的索引缓存（参数 `key_buffer_size`）；⚠️ **只缓存索引、不缓存数据**，与 InnoDB Buffer Pool 的关键差异 | [[mysql/02-中段阶段-专题精讲/存储引擎与选型/三大引擎特性对比与选型]] |
| **并发插入（concurrent insert）** | MyISAM 特性：数据文件无空洞时，`INSERT` 可与 `SELECT` 同时执行（新行追加到文件尾部） | 同上 |
| **myisampack** | 把 MyISAM 表压成**只读**压缩表的工具，省空间；⚠️ 压缩后连 `INSERT` 都不能执行 | 同上 |
| **MEMORY**（旧名 HEAP） | 内存表：**无事务**、**表级锁**、固定长度行、默认哈希索引、不支持 `BLOB`/`TEXT`、上限受 `max_heap_table_size`（默认 16MB）。⚠️ 重启数据清空；⚠️ 官方说不一定比 InnoDB 快 | 同上 |
| **TempTable** | 8.0 起**内部临时表**的默认引擎（参数 `internal_tmp_mem_storage_engine`），取代了 MEMORY；⚠️ 与上面那个 MEMORY 引擎不是一回事 | [[mysql/02-中段阶段-专题精讲/存储引擎与选型/引擎全景与迁移实操]] |
| **NDB Cluster** | 内存型**分布式集群**引擎；⭐ **支持事务**（与 MEMORY 的关键差别）、行级锁、可选磁盘持久化。⚠️ 只在 NDB Cluster 构建中提供 | 同上 |
| **CSV** | 逗号分隔的纯文本表，**无索引**；只适合导入导出中间态 | [[mysql/02-中段阶段-专题精讲/存储引擎与选型/引擎全景与迁移实操]] |
| **ARCHIVE** | 压缩、**无索引**，只支持 `INSERT`/`SELECT`（不能 `UPDATE`/`DELETE`）；冷数据归档用 | 同上 |
| **BLACKHOLE** | 接受写入但**不存任何数据**（类似 `/dev/null`），查询永远返回空；复制中继用 | 同上 |
| **MERGE**（`MRG_MYISAM`） | 把多张结构相同的 **MyISAM** 表逻辑上合成一张；⚠️ 依赖 MyISAM，同样无事务 | 同上 |
| **FEDERATED** | 访问远端 MySQL 服务器上的表，本地只存定义；⚠️ 默认关闭，需显式启用 | 同上 |
| **EXAMPLE** | 源码示例用引擎（存不了数据），仅供开发插件参考 | 同上 |
| **Alternative Storage Engines** | 官方对 InnoDB / NDB 之外所有引擎的统称（9.7 手册第 18 章标题）；⚠️ 它们都被视为「特殊用途」而非生产默认 | 同上 |

## 三、事务与并发

| 名词 | 一句话含义 | 详解 |
|------|-----------|------|
| **事务（transaction）** | 一组要么全做要么全不做的操作 | [[mysql/01-入门阶段-基础教程/第04章-事务与权限/4.1-事务与ACID]] |
| **ACID** | 原子性、一致性、隔离性、持久性 | 同上 |
| **隔离级别** | 四种：RU / RC / RR / Serializable，⚠️ **RR 是默认值** | 同上 |
| **MVCC** | 多版本并发控制，读不阻塞写 | [[mysql/03-进阶阶段-深度剖析/事务与锁内核/原理剖析-undo日志与MVCC]] |
| **undo 版本链** | 一行数据的历史版本串成链，读操作沿链找可见版本 | 同上 |
| **ReadView** | 读视图，记录当前活跃事务 ID，决定哪个版本可见 | 同上 |
| **行锁 / 表锁 / 间隙锁 / Next-Key Lock** | 四种锁粒度，⚠️ RR 下用间隙锁避免幻读 | [[mysql/03-进阶阶段-深度剖析/事务与锁内核/原理剖析-锁体系与死锁]] |
| **意向锁（intention lock）** | 表级标记，表示表内有行锁，用于快速判断能否加表锁 | 同上 |
| **元数据锁（MDL）** | DDL 与 DML 互斥的锁，执行慢查询时 DDL 会排队 | 同上 |
| **死锁（deadlock）** | 两个事务互相等待，MySQL 会自动回滚一个 | 同上 |
| **savepoint** | 事务内的中间回滚点 | [[mysql/01-入门阶段-基础教程/第04章-事务与权限/4.1-事务与ACID]] |
| **长事务** | 长时间不提交的事务，会拖住 undo 膨胀和 purge | [[mysql/02-中段阶段-专题精讲/事务与并发控制/长事务与undo膨胀]] |

## 四、索引与优化

| 名词 | 一句话含义 | 详解 |
|------|-----------|------|
| **主键（PRIMARY KEY）** | 唯一且非空的索引，InnoDB 中决定聚簇索引组织 | [[mysql/01-入门阶段-基础教程/第02章-建表与约束/2.1-DDL建表与列定义]] |
| **唯一索引（UNIQUE）** | 值不能重复 | 同上 |
| **联合索引（复合索引）** | 多列索引，⚠️ 遵循最左前缀原则 | [[mysql/02-中段阶段-专题精讲/索引与查询优化/索引类型与选型]] |
| **最左前缀** | 联合索引只能从最左列开始连续使用 | 同上 |
| **最左前缀失效场景** | 跳过首列、范围查询后无法再优化 | 同上 |
| **覆盖索引** | 避免回表的索引设计 | [[mysql/02-中段阶段-专题精讲/索引与查询优化/覆盖索引与回表优化]] |
| **索引下推（ICP）** | 8.0 优化，在存储引擎层先过滤再回表 | 同上 |
| **前缀索引** | 只索引前 N 个字符，长文本/varchar 用 | [[mysql/02-中段阶段-专题精讲/索引与查询优化/索引类型与选型]] |
| **函数索引** | 8.0.13+ 支持，对表达式建索引 | 同上 |
| **降序索引** | 8.0+ 支持 `DESC` 索引，优化 ORDER BY ... DESC | 同上 |
| **不可见索引（invisible index）** | 保留索引结构但不用于优化器，测删索引的安全办法 | 同上 |
| **EXPLAIN** | 查看执行计划 | [[mysql/02-中段阶段-专题精讲/索引与查询优化/EXPLAIN解读]] |
| **EXPLAIN ANALYZE** | 8.0.18+ 实际执行并给出真实耗时 | 同上 |
| **type（访问类型）** | 从好到坏：const > eq_ref > ref > range > index > ALL | 同上 |
| **Extra 字段** | Using index / Using filesort / Using temporary 等执行信息 | 同上 |
| **filesort** | ⚠️ 不是「磁盘排序」，是排序但没走索引 | 同上 |
| **optimizer_trace** | 优化器决策全过程的追踪表 | [[mysql/02-中段阶段-专题精讲/索引与查询优化/索引诊断与慢查询优化]] |
| **直方图统计（histogram）** | 8.0+ 列直方图，改善数据倾斜下的基数估算 | 同上 |
| **基数估算误差** | 优化器误判行数导致选错索引 | 同上 |

| **XCom** | MGR 早期使用的组通信协议，⚠️ 26.7 起默认改为 MYSQL 通信栈 | 同上 |
| **pt-online-schema-change** | Percona 工具，在线改表不锁 | [[mysql/02-中段阶段-专题精讲/大表与在线DDL/在线DDL方案对比]] |
