# MySQL 函数手册

> **本页定位：只给「函数名 + 一句话作用」，不展开解释。**
> ⭐ **语法、参数、典型用法、坑，全部在 [[mysql/01-入门阶段-基础教程/第03章-查询与CRUD/3.5-常用函数详解]]。**
> **用法：查不到函数时来这里定位 → 跳到 3.5 看详解。**
>
> ⚠️ **版本标注约定**：`8.0+` 表示 8.0 起可用；`8.0.13+` / `8.0.18+` 表示具体小版本引入。
> ⚠️ **MySQL 与 PostgreSQL 函数差异巨大**（如 `SUBSTRING` vs `SUBSTR`、数组处理完全不同）。PG 侧见 [[postgresql/函数手册]]。

## 一、数值函数

| 函数 | 作用 |
|------|------|
| `ROUND(x[, d])` | 四舍五入，`d` 为小数位 |
| `CEIL(x)` / `CEILING(x)` | 向上取整 |
| `FLOOR(x)` | 向下取整 |
| `TRUNCATE(x, d)` | 截断到小数位（**不四舍五入**） |
| `ABS(x)` | 绝对值 |
| `SIGN(x)` | 符号：-1 / 0 / 1 |
| `MOD(x, y)` | 取模 |
| `POW(x,y)` / `POWER(x,y)` | 幂 |
| `SQRT(x)` | 平方根 |
| `EXP(x)` | e 的 x 次方 |
| `LN(x)` / `LOG(x)` | 自然对数 |
| `LOG10(x)` | 以 10 为底对数 |
| `RAND()` / `RAND(n)` | 随机数（带种子则序列固定） |
| `GREATEST(a,b,...)` | 最大值 |
| `LEAST(a,b,...)` | 最小值 |

## 二、字符串函数

| 函数 | 作用 |
|------|------|
| ⚠️ `CONCAT(s1, s2, ...)` | 拼接，⚠️ **任一参数为 NULL 则结果为 NULL** |
| ⭐ `CONCAT_WS(sep, s1, s2, ...)` | 带分隔符拼接，⚠️ **自动跳过 NULL** |
| ⚠️ `LENGTH(s)` / `OCTET_LENGTH(s)` | ⚠️ **字节**长度 |
| ⭐ `CHAR_LENGTH(s)` / `CHARACTER_LENGTH(s)` | ⭐ **字符**长度 |
| `UPPER(s)` / `UCASE(s)` | 转大写 |
| `LOWER(s)` / `LCASE(s)` | 转小写 |
| `TRIM(s)` | 去两端空格 |
| `LTRIM(s)` / `RTRIM(s)` | 去左 / 右空格 |
| `SUBSTRING(s, pos[, len])` / `SUBSTR` | 截取，`pos` **从 1 开始** |
| `LEFT(s, n)` / `RIGHT(s, n)` | 取左 / 右 n 个字符 |
| `REPLACE(s, from, to)` | 替换所有出现 |
| `LOCATE(sub, s)` | 找子串位置（⚠️ 返回 0 表示没找到） |
| `INSTR(s, sub)` | 同 `LOCATE`，⚠️ **参数顺序相反** |
| `FIND_IN_SET(sub, strlist)` | ⚠️ 在逗号分隔串中查找，只认**完整项** |
| `LPAD(s, n, pad)` / `RPAD` | 左 / 右侧补齐到 n 位 |
| `REPEAT(s, n)` | 重复 n 次 |
| `REVERSE(s)` | 反转 |
| `STRCMP(s1, s2)` | 比较：0 相等 / -1 / 1 |
| `MD5(s)` | ⚠️ **不能用于密码存储** |
| `SHA2(s, 256)` | SHA-256 |
| `HEX(s)` / `UNHEX(s)` | 十六进制互转 |
| `REGEXP_LIKE(s, pattern)` | 正则判断 |

## 三、日期时间函数

| 函数 | 作用 |
|------|------|
| `NOW()` / `CURRENT_TIMESTAMP` | 当前日期时间 |
| `CURDATE()` / `CURRENT_DATE` | 当前日期 |
| `CURTIME()` | 当前时间 |
| `SYSDATE()` | ⚠️ 执行时刻的时间（`NOW()` 在语句内恒定） |
| `DATE_ADD(d, INTERVAL n unit)` | 加时间 |
| `DATE_SUB(d, INTERVAL n unit)` | 减时间 |
| ⚠️ `DATEDIFF(d1, d2)` | 天数差，⚠️ **只算天，且参数顺序与 TIMESTAMPDIFF 相反** |
| ⭐ `TIMESTAMPDIFF(unit, d1, d2)` | 指定单位差，可到微秒 |
| `TIMESTAMPADD(unit, n, d)` | 指定单位加减 |
| `EXTRACT(unit FROM d)` | 抽取日期部分 |
| `YEAR/MONTH/DAY(d)` | 抽取年月日 |
| `HOUR/MINUTE/SECOND(t)` | 抽取时分秒 |
| ⚠️ `DAYOFWEEK(d)` | 星期几，⚠️ **1=周日** |
| ⭐ `WEEKDAY(d)` | 星期几，**0=周一** |
| `DAYNAME(d)` | 星期名（英文） |
| `LAST_DAY(d)` | 当月最后一天 |
| ⚠️ `DATE_FORMAT(d, fmt)` | 按格式输出，⚠️ **分钟是 `%i` 不是 `%M`** |
| `STR_TO_DATE(s, fmt)` | 字符串转日期 |
| `UNIX_TIMESTAMP([d])` | 转 Unix 时间戳 |
| `FROM_UNIXTIME(ts)` | 时间戳转日期时间 |
| `ADDDATE(d, days)` | 等价 `DATE_ADD(d, INTERVAL days DAY)` |
| `CONVERT_TZ(d, from, to)` | 时区转换 |

## 四、JSON 函数（8.0+）

| 函数/操作符 | 作用 |
|------|------|
| `JSON_EXTRACT(doc, path)` | 按路径取值（**带引号**） |
| ⭐ `doc->>'$.key'` | ⭐ 取值并**去引号**（最常用） |
| `doc->'$.key'` | 取值保留引号 |
| `JSON_UNQUOTE(v)` | 去引号 |
| `JSON_SET(doc, path, val)` | 设置值 |
| `JSON_INSERT(doc, path, val)` | 仅当路径不存在时插入 |
| `JSON_ARRAY(...)` | 构造数组 |
| `JSON_OBJECT(k, v, ...)` | 构造对象 |
| `JSON_LENGTH(doc, path)` | 数组长度或对象键数 |
| `JSON_CONTAINS(doc, val, path)` | 是否包含 |
| `JSON_MERGE_PATCH(d1, d2)` | 合并（8.0.3+） |
| ⭐ `JSON_TABLE(...)` | ⭐ 把 JSON 展开成行 |
| `JSON_VALID(s)` | 是否合法 JSON |

## 五、窗口函数（8.0+）

| 函数 | 作用 |
|------|------|
| `ROW_NUMBER() OVER (...)` | 行号，不并列 |
| `RANK() OVER (...)` | 排名，并列会跳号 |
| `DENSE_RANK() OVER (...)` | 排名，并列不跳号 |
| `LAG(col[, n[, default]])` OVER (...) | 取前 n 行值 |
| `LEAD(col[, n[, default]])` OVER (...) | 取后 n 行值 |
| `FIRST_VALUE(col)` / `LAST_VALUE(col)` | 首行 / 末行值（⚠️ 默认 frame 要显式写） |
| `NTILE(n)` OVER (...) | 分桶 |
| `PERCENT_RANK()` / `CUME_DIST()` | 百分位排名 |
| `SUM/COUNT/AVG(...) OVER (...)` | 窗口聚合 |

⚠️ **`FIRST_VALUE`/`LAST_VALUE` 的默认窗口帧是 `RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`**，所以 `LAST_VALUE` 拿到的是当前行而不是最后一行。必须显式写：

```sql
LAST_VALUE(x) OVER (ORDER BY id ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)
```

## 六、聚合函数

| 函数 | 作用 |
|------|------|
| `COUNT(*)` | 总行数 |
| ⚠️ `COUNT(列)` | ⚠️ **非 NULL 的数量** |
| `COUNT(DISTINCT 列)` | 去重数量 |
| `SUM(col)` / `AVG(col)` | 求和 / 均值（⚠️ **自动忽略 NULL**） |
| `MIN(col)` / `MAX(col)` | 最小 / 最大 |
| ⚠️ `GROUP_CONCAT(col [ORDER BY ..] [SEPARATOR ','])` | ⚠️ 拼接组内字符串，**默认上限 1024 字节** |
| `STDDEV(col)` / `VARIANCE(col)` | 标准差 / 方差 |

## 七、条件与取值

| 函数 | 作用 | 备注 |
|------|------|------|
| `IF(expr, v1, v2)` | 条件取值 | MySQL 特有 |
| ⭐ `IFNULL(v1, v2)` | v1 为 NULL 返回 v2 | MySQL 特有，**只支持两参数** |
| `NULLIF(v1, v2)` | 相等返回 NULL，否则返回 v1 | 标准 SQL |
| ⭐ `COALESCE(v1, v2, ...)` | 返回第一个非 NULL | 标准 SQL，**支持多参数** |
| `CASE WHEN c1 THEN r1 WHEN c2 THEN r2 ELSE r3 END` | 多分支 | 标准 SQL |
| `CASE col WHEN v1 THEN r1 ... END` | 简单映射 | 标准 SQL |
| `CAST(v AS type)` | 类型转换 | `CAST('123' AS UNSIGNED)` |
| `CONVERT(v, type)` | 转换（简写） | |

⭐ **跨库兼容优先用标准 SQL**（`COALESCE` / `CASE`），少用 MySQL 特有的 `IF` / `IFNULL`。

## 八、系统与信息函数

| 函数 | 作用 |
|------|------|
| `CONNECTION_ID()` | 当前连接 ID |
| `DATABASE()` / `SCHEMA()` | 当前数据库名 |
| `USER()` / `CURRENT_USER()` | 当前用户（⚠️ 两者语义不同，见下） |
| `VERSION()` | 版本号 |
| `LAST_INSERT_ID()` | 最近生成的自增 ID |
| `LAST_INSERT_ID(expr)` | 设置「下一个」自增值（⭐ 用于在一条 SQL 内传递 ID） |
| `FOUND_ROWS()` | 上一条 SELECT 影响行数（需 `SQL_CALC_FOUND_ROWS`） |
| `ROW_COUNT()` | 上一条语句影响行数 |
| `SLEEP(n)` | 休眠 n 秒（测试用） |
| `INET_ATON(ip)` / `INET_NTOA(n)` | IP 与整数互转 |
| `UUID()` | 生成 UUID |

⚠️ **`USER()` 和 `CURRENT_USER()` 不一样**：`USER()` 返回客户端传的用户名（**可伪造**），`CURRENT_USER()` 返回实际认证通过的用户。**权限判断必须用后者。**

## 九、加解密

| 函数 | 作用 | 备注 |
|------|------|------|
| `MD5(s)` / `SHA1(s)` | 摘要 | ⚠️ **不能用于密码存储**（有彩虹表） |
| `SHA2(s, 256)` | SHA-256 | |
| `AES_ENCRYPT(s, key)` / `AES_DECRYPT` | AES 加密解密 | `key` 长度决定模式 |
| `COMPRESS(s)` / `UNCOMPRESS(s)` | zlib 压缩 | |
| `PASSWORD()` | ⚠️ 已废弃，**不要用于密码** | |

⚠️ **密码存储不要用数据库函数**。用 `caching_sha2_password`（8.0 默认）或应用层的 argon2/bcrypt。

## 十、查不到函数时的三步法 ⚠️

⚠️⚠️ **⚠️ 注意：`information_schema.ROUTINES` 只列「存储过程和存储函数」，不列内置函数！**

```
① 直接用，看报错
   SELECT CONCAT('a', 'b');
   -- 报 "FUNCTION shop.CONCAT does not exist" → 该版本没有
   -- 正常返回 → 存在

② 查 MySQL 官方文档按类别找（权威）
   -- 手册 → Functions and Operators

③ 换等价函数（⚠️ 注意跨库差异）
   -- MySQL 没有 STRING_AGG → 用 GROUP_CONCAT
   -- MySQL 的 IFNULL 只支持两参数 → 用 COALESCE
```
