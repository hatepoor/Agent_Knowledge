# 生成器与异步迭代器

> 生成器是 Python 惰性求值的核心机制，在 LangChain 中用于流式输出（streaming）处理 LLM 的逐 token 响应，是构建高效 Agent 的关键。

## 生成器（Generator）

### 基础概念

生成器是一种特殊的迭代器，使用 `yield` 关键字**暂停函数执行并产出一个值**。每次从暂停处恢复时，函数继续运行到下一个 `yield` 处再次暂停。

**`yield` 的两件事**：

1. 把右边的值交给调用方
2. 暂停函数，保存所有局部变量（变量值、当前执行到的行号）

```python
def count_up(n):
    """从 1 数到 n"""
    i = 1
    while i <= n:
        yield i              # 产出 i 的值，暂停函数
        i += 1               # 下次从这一行继续

# 使用生成器
for num in count_up(5):
    print(num)  # 1, 2, 3, 4, 5

# 生成器表达式（类似列表推导式，但惰性）
squares = (x**2 for x in range(10))  # 不立即计算
```

### yield 执行时序

```python
def gen():
    print("开始")
    yield 1
    print("继续 1")
    yield 2
    print("继续 2")

g = gen()       # 仅创建生成器对象，函数体一行也没执行
# 输出: (无)

next(g)         # 执行到第一个 yield 暂停
# 输出: 开始
# 返回: 1

next(g)         # 从暂停处继续到下一个 yield
# 输出: 继续 1
# 返回: 2

next(g)         # 从暂停处继续到函数结束
# 输出: 继续 2
# 抛出: StopIteration
```

调用 `gen()` **不会执行函数体**——只是创建了一个生成器对象，函数体在第一次 `next(g)` 时才开始执行，且每次只跑到下一个 `yield` 就停下。

### yield vs return

| | `yield` | `return` |
|---|---|---|
| 函数执行 | 暂停，保留状态 | 结束，销毁所有局部变量 |
| 调用后 | 可多次恢复执行 | 函数结束，不能恢复 |
| 返回值 | 每次 yield 产出一个值 | 一次性返回 |
| 内存 | 常量级（只存当前状态） | 一次性分配全部结果 |

### 为什么需要 yield

普通函数必须全部算完才能返回结果。`yield` 让函数**算一个、给一个**，不需等全部算完，避免一次性内存占用：

```python
# 不用 yield：必须先准备 100 万个元素的列表
def get_numbers():
    return [i for i in range(1, 1000001)]  # 一次性占用 100 万个整数内存

# 用 yield：每次只产出一个
def get_numbers():
    for i in range(1, 1000001):
        yield i  # 占用的内存恒定
```

### 生成器 vs 列表

| 特性 | 列表 | 生成器 |
|------|------|--------|
| 内存 | 一次性加载所有元素 | 按需生成，内存占用恒定 |
| 访问 | 可索引、切片 | 只能顺序迭代 |
| 长度 | `len()` 可用 | 无法预知长度 |
| 重复 | 可多次迭代 | 只能迭代一次 |
| 适用场景 | 数据量小、需随机访问 | 大数据流、无限序列 |

### yield 与 send

```python
def accumulator():
    """累加器：可接收外部值"""
    total = 0
    while True:
        value = yield total  # 产出 total，接收 value
        if value is None:
            break
        total += value

# 使用
gen = accumulator()
next(gen)              # 启动生成器，到第一个 yield
gen.send(10)           # 10
gen.send(20)           # 30
gen.send(5)            # 35
gen.send(None)         # 停止
```

**`value = yield total` 的执行时序**：

```python
# 1. 首次启动：next(gen)
#   total = 0
#   value = yield total
#   ↓ 先计算右边的 total (0)
#   ↓ yield 暂停，把 0 交给调用方
#   返回 0

# 2. gen.send(10)
#   ↓ 从 yield 暂停处继续，10 被赋给 value
#   value = 10
#   value is None? → False
#   total += 10 → total = 10
#   ↓ 回到 while True
#   value = yield 10
#   ↓ yield 把 10 交给调用方
#   返回 10

# 3. gen.send(20)
#   value = 20
#   total = 30
#   value = yield 30
#   返回 30
```

**关键点**：`yield` 不仅能**产出值**，还能**接收外部传入的值**。`send(x)` 把 x 传进 `yield` 表达式作为整体的值，下一轮循环的 `value` 变量就拿到这个 x。

### yield from（委托生成器）

```python
def flatten(nested):
    """展平嵌套列表"""
    for item in nested:
        if isinstance(item, list):
            yield from flatten(item)  # 委托给子生成器
        else:
            yield item

list(flatten([1, [2, 3][[, [4, [5, 6]]]))
# [1, 2, 3, 4, 5, 6]
```

**与手写循环的等价关系**：

```python
# yield from item  ==  下面这段代码
for x in item:
    yield x
```

`yield from` 的额外能力：自动处理 `send()` 和 `throw()` 在内外层生成器之间的转发。当需要遍历嵌套结构或拆分大生成器为小生成器时，优先用 `yield from`。

## LangChain 流式输出

### 同步流式

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

# 流式输出 token
for chunk in llm.stream("写一首关于 Python 的诗"):
    print(chunk.content, end="", flush=True)

# 流式输出事件（更细粒度）
for event in llm.stream_events("你好", version="v2"):
    kind = event["event"]
    if kind == "on_chat_model_stream":
        print(event["data"]["chunk"].content, end="")
```

### 异步流式

```python
import asyncio
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

async def stream_response():
    async for chunk in llm.astream("写一首关于 Python 的诗"):
        print(chunk.content, end="", flush=True)

asyncio.run(stream_response())
```

### Agent 流式

```python
from langchain.agents import create_react_agent, AgentExecutor
from langchain.tools import tool

@tool
def search(query: str) -> str:
    """搜索信息"""
    return f"搜索结果: {query}"

agent = create_react_agent(llm, [search])
executor = AgentExecutor(agent=agent, tools=[search])

# 流式执行 Agent
async def stream_agent():
    async for event in executor.astream_events(
        {"input": "Python 最新版本是什么？"},
        version="v2"
    ):
        kind = event["event"]
        if kind == "on_chat_model_stream":
            print(event["data"]["chunk"].content, end="")
        elif kind == "on_tool_start":
            print(f"\n[调用工具: {event['name']}]\n")
        elif kind == "on_tool_end":
            print(f"[工具完成]\n")
```

## 异步迭代器

### 定义异步迭代器

```python
class AsyncCounter:
    """异步计数器"""
    def __init__(self, limit):
        self.limit = limit
        self.current = 0
    
    def __aiter__(self):
        return self
    
    async def __anext__(self):
        if self.current >= self.limit:
            raise StopAsyncIteration
        self.current += 1
        await asyncio.sleep(0.1)  # 模拟异步操作
        return self.current

# 使用
async def main():
    async for num in AsyncCounter(5):
        print(num)

asyncio.run(main())
```

### 异步生成器

```python
async def fetch_pages(urls):
    """异步生成器：逐个获取网页"""
    for url in urls:
        await asyncio.sleep(0.5)  # 模拟网络请求
        yield f"内容来自 {url}"

# 使用
async def main():
    urls = ["url1", "url2", "url3"][[
    async for content in fetch_pages(urls):
        print(content)

asyncio.run(main())
```

### 异步迭代器工具函数

```python
import asyncio

async def async_map(async_iter, func):
    """异步 map：对异步迭代器每个元素应用函数"""
    async for item in async_iter:
        yield func(item)

async def async_filter(async_iter, predicate):
    """异步 filter：过滤异步迭代器"""
    async for item in async_iter:
        if predicate(item):
            yield item

async def async_take(async_iter, n):
    """取前 n 个元素"""
    count = 0
    async for item in async_iter:
        if count >= n:
            break
        yield item
        count += 1
```

## 上下文管理器与生成器

```python
from contextlib import contextmanager

@contextmanager
def managed_resource():
    """使用生成器实现上下文管理器"""
    print("获取资源")
    resource = "resource"
    try:
        yield resource
    finally:
        print("释放资源")

# 使用
with managed_resource() as r:
    print(f"使用 {r}")
```

## 实际应用模式

### 数据管道

```python
def read_large_file(filepath):
    """逐行读取大文件"""
    with open(filepath) as f:
        for line in f:
            yield line.strip()

def filter_lines(lines, keyword):
    """过滤包含关键词的行"""
    for line in lines:
        if keyword in line:
            yield line

def transform_lines(lines):
    """转换行格式"""
    for line in lines:
        yield line.upper()

# 组合管道（惰性求值，内存友好）
lines = read_large_file("data.txt")
filtered = filter_lines(lines, "ERROR")
transformed = transform_lines(filtered)

for line in transformed:
    print(line)
```

### 流式处理 LLM 响应

```python
async def process_stream(llm, prompt):
    """流式处理 LLM 响应"""
    buffer = ""
    async for chunk in llm.astream(prompt):
        buffer += chunk.content
        # 按句子分割处理
        while "." in buffer:
            sentence, buffer = buffer.split(".", 1)
            yield sentence.strip() + "."
    
    # 处理剩余内容
    if buffer.strip():
        yield buffer.strip()
```
