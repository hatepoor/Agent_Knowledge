# 异步编程（asyncio）

> 异步编程是 LangChain Agent 的核心基础。LLM 调用、工具执行、向量检索等 I/O 密集型操作都依赖异步机制实现高效并发。

## 什么是异步编程

### 生活比喻

```
===== 同步（排队做）=====

你去餐厅点餐：
1. 点米饭 → 等 3 分钟 → 拿到米饭
2. 点炒菜 → 等 2 分钟 → 拿到炒菜
3. 点汤   → 等 1 分钟 → 拿到汤

总耗时：3 + 2 + 1 = 6 分钟
你全程在等，什么都不能干

===== 异步（同时做）=====

你去餐厅点餐：
1. 点米饭（不用等，告诉厨师就行）
2. 点炒菜（不用等）
3. 点汤（不用等）
   → 厨师同时做三道菜
4. 等所有菜好了再一起端走

总耗时：max(3, 2, 1) = 3 分钟
等待期间你可以玩手机
```

### 同步 vs 异步代码对比

```python
import time

# ===== 同步：一个做完再做下一个 =====
def sync_version():
    start = time.time()

    result1 = download_file("file1.pdf")   # 等 3 秒，CPU 空闲
    result2 = download_file("file2.pdf")   # 等 3 秒，CPU 空闲
    result3 = download_file("file3.pdf")   # 等 3 秒，CPU 空闲

    print(f"总耗时: {time.time() - start:.1f}s")  # 9 秒

# ===== 异步：三个同时下载 =====
async def async_version():
    start = time.time()

    # 三个下载同时开始，CPU 在等待时去做别的
    task1 = asyncio.create_task(download_file_async("file1.pdf"))
    task2 = asyncio.create_task(download_file_async("file2.pdf"))
    task3 = asyncio.create_task(download_file_async("file3.pdf"))

    # 等所有完成
    results = await asyncio.gather(task1, task2, task3)

    print(f"总耗时: {time.time() - start:.1f}s")  # 3 秒
```

### CPU 时间线对比

```
同步：
CPU: [等网络] [等网络] [等网络] [计算] [等网络] [等网络] [计算]
      ↑ 空闲    ↑ 空闲    ↑ 空闲         ↑ 空闲    ↑ 空闲
      浪费      浪费      浪费            浪费      浪费

异步：
CPU: [等网络1] [等网络2] [等网络3] [计算1] [计算2] [计算3]
      ↑ 同时等三个                ↑ 轮流计算
      不浪费                      不浪费
```

### 什么时候用异步

| 场景 | 是否适合异步 | 原因 |
|------|-------------|------|
| 网络请求（调 API、下载文件） | ✅ 适合 | 等网络响应，CPU 空闲 |
| 数据库查询 | ✅ 适合 | 等磁盘 I/O |
| 文件读写 | ✅ 适合 | 等磁盘 I/O |
| 调 LLM API | ✅ 适合 | 等网络响应（通常几秒） |
| MCP 服务器通信 | ✅ 适合 | 等网络/进程响应 |
| 纯计算（排序、数学运算） | ❌ 不适合 | CPU 一直在忙，没有"等"的时间 |
| 内存操作（列表、字典） | ❌ 不适合 | 瞬间完成 |

### 在 LangChain Agent 中的实际意义

```
同步模式（100 个用户同时提问）：
用户1: ████ 3秒
用户2:      ████ 3秒
用户3:           ████ 3秒
...
用户100:                              ████ 3秒
总耗时: 300 秒 ❌

异步模式（100 个用户同时提问）：
用户1:   ████ 3秒
用户2:   ████ 3秒
用户3:   ████ 3秒
...
用户100: ████ 3秒
总耗时: 3 秒 ✅
```

**异步不是让单个操作变快，而是让等待期间不浪费 CPU 时间。** 一个操作该等 3 秒还是 3 秒，但在这 3 秒里 CPU 可以去处理其他请求。

## 核心概念

### 协程（Coroutine）

```python
import asyncio

# 定义协程函数
async def fetch_data(url: str) -> dict:
    """异步获取数据"""
    await asyncio.sleep(1)  # 模拟 I/O 操作
    return {"url": url, "data": "..."}

# 调用协程（必须在事件循环中）
result = asyncio.run(fetch_data("https://api.example.com"))
```

### 关键关键字

| 关键字 | 作用 | 说明 |
|--------|------|------|
| `async def` | 定义协程函数 | 返回协程对象 |
| `await` | 等待协程完成 | 只能在 `async` 函数内使用 |
| `async for` | 异步迭代 | 迭代异步迭代器 |
| `async with` | 异步上下文管理器 | 异步资源管理 |

## 并发执行

### asyncio.gather — 并发运行多个协程

```python
import asyncio
import time

async def task(name: str, delay: float):
    print(f"[{name}] 开始")
    await asyncio.sleep(delay)
    print(f"[{name}] 完成")
    return f"{name} 结果"

async def main():
    # 并发执行多个任务
    results = await asyncio.gather(
        task("A", 2),
        task("B", 1),
        task("C", 3),
    )
    print(results)  # ['A 结果', 'B 结果', 'C 结果']

asyncio.run(main())
# 总耗时约 3 秒（最长任务的时间），而非 6 秒
```

### asyncio.create_task — 创建后台任务

```python
async def background_task():
    await asyncio.sleep(2)
    print("后台任务完成")

async def main():
    # 创建任务（立即调度，不等待）
    task = asyncio.create_task(background_task())
    
    # 做其他事情
    await asyncio.sleep(1)
    print("主任务完成")
    
    # 等待后台任务完成
    await task

asyncio.run(main())
```

### asyncio.wait — 等待条件满足

```python
async def main():
    tasks = [
        asyncio.create_task(task(f"task-{i}", i))
        for i in range(5)
    ]
    
    # 等待所有完成
    done, pending = await asyncio.wait(tasks, return_when=asyncio.ALL_COMPLETED)
    
    # 或等待第一个完成
    done, pending = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
    
    # 或设置超时
    done, pending = await asyncio.wait(tasks, timeout=2.0)
```

## 异步队列（asyncio.Queue）

```python
import asyncio

async def producer(queue: asyncio.Queue):
    """生产者：向队列添加任务"""
    for i in range(5):
        await queue.put(f"任务-{i}")
        await asyncio.sleep(0.5)
    await queue.put(None)  # 结束信号

async def consumer(queue: asyncio.Queue):
    """消费者：从队列取出任务"""
    while True:
        item = await queue.get()
        if item is None:
            break
        print(f"处理: {item}")
        await asyncio.sleep(1)
        queue.task_done()

async def main():
    queue = asyncio.Queue()
    
    # 并发运行生产者和消费者
    await asyncio.gather(
        producer(queue),
        consumer(queue),
    )

asyncio.run(main())
```

## 超时与取消

```python
async def slow_operation():
    await asyncio.sleep(10)
    return "完成"

async def main():
    try:
        # 设置超时
        result = await asyncio.wait_for(slow_operation(), timeout=3.0)
    except asyncio.TimeoutError:
        print("操作超时")

    task = asyncio.create_task(slow_operation())

        print("任务已取消")

asyncio.run(main())
```

## 最佳实践

1. **I/O 密集用 async，CPU 密集用多线程/多进程**
2. **避免在 async 函数中使用阻塞调用**（如 `time.sleep()`、`requests.get()`）
3. **使用 `asyncio.to_thread()` 包装阻塞调用**：
   ```python
   import asyncio
   import requests
   
   async def fetch_url(url):
       # 将阻塞调用放到线程池
       return await asyncio.to_thread(requests.get, url)
   ```
4. **使用信号量限制并发数**：
   ```python
   sem = asyncio.Semaphore(10)  # 最多 10 个并发
   
   async def limited_task():
       async with sem:
           await do_something()
   ```

## 常见陷阱

### 陷阱 1：忘记 await — 协程不会执行

```python
async def fetch_data():
    await asyncio.sleep(1)
    return "数据"

async def main():
    # ❌ 忘记 await：协程只是被创建了，没有执行
    result = fetch_data()
    print(result)  # <coroutine object fetch_data at 0x...>

    # ✅ 正确：加 await 才会真正执行
    result = await fetch_data()
    print(result)  # "数据"
```

### 陷阱 2：在同步函数中使用 await

```python
# ❌ await 只能在 async def 函数内使用
def main():  # 不是 async def
    result = await fetch_data()  # SyntaxError!

# ✅ 正确
async def main():
    result = await fetch_data()
```

### 陷阱 3：在 async 函数中使用阻塞调用

```python
import requests
import time

async def bad_example():
    # ❌ time.sleep 和 requests.get 都是阻塞调用
    # 它们会阻塞整个事件循环，其他协程全部卡住
    time.sleep(3)
    response = requests.get("https://api.example.com")
    return response.json()

# ✅ 正确方式一：用异步库替代
import aiohttp

async def good_example():
    async with aiohttp.ClientSession() as session:
        async with session.get("https://api.example.com") as response:
            return await response.json()

# ✅ 正确方式二：用 asyncio.to_thread 包装阻塞调用
async def also_good():
    # 把阻塞调用丢到线程池，不阻塞事件循环
    response = await asyncio.to_thread(requests.get, "https://api.example.com")
    return response.json()
```

### 陷阱 4：gather 中一个任务异常导致全部失败

```python
async def risky_task():
    raise ValueError("出错了")

async def safe_task():
    await asyncio.sleep(1)
    return "成功"

async def main():
    # ❌ 默认行为：一个异常，gather 整体抛出
    try:
        results = await asyncio.gather(risky_task(), safe_task())
    except ValueError:
        print("全部失败！")  # safe_task 的结果也丢了

    # ✅ 使用 return_exceptions=True：异常作为结果返回
    results = await asyncio.gather(
        risky_task(),
        safe_task(),
        return_exceptions=True,
    )
    for r in results:
        if isinstance(r, Exception):
            print(f"失败: {r}")
        else:
            print(f"成功: {r}")
```

### 陷阱 5：在 async 循环中串行执行

```python
async def main():
    urls = ["url1", "url2", "url3", "url4", "url5"]

    # ❌ 看似异步，实际串行（每次等一个完成才开始下一个）
    for url in urls:
        result = await fetch_url(url)  # 等完一个再下一个

    # ✅ 真正并发
    tasks = [fetch_url(url) for url in urls]
    results = await asyncio.gather(*tasks)  # 5 个同时执行
```

```python
# LangChain：管理多个后台 Agent 任务
class TaskManager:
    def __init__(self):
        self.tasks: dict[str, asyncio.Task] = {}
    
    def start_task(self, task_id: str, agent, message: str):
        """启动后台 Agent 任务"""
        coro = agent.ainvoke({"messages": [{"role": "user", "content": message}]})
        self.tasks[task_id] = asyncio.create_task(coro, name=task_id)
    
    def cancel_task(self, task_id: str):
        """取消任务（用户打断）"""
        task = self.tasks.get(task_id)
        if task and not task.done():
            task.cancel()
    
    async def get_result(self, task_id: str):
        """获取任务结果"""
        task = self.tasks.get(task_id)
        if not task:
            return None
        if not task.done():
            return "running"
        return task.result()["messages"][-1].content
```

```python
# LangChain：限制同时调用的 LLM 请求数（避免触发 rate limit）
class RateLimitedAgent:
    def __init__(self, agent, max_concurrent: int = 3):
        self.agent = agent
        self.sem = asyncio.Semaphore(max_concurrent)
    
    async def invoke(self, message: str):
        async with self.sem:  # 最多 3 个并发 LLM 调用
            return await self.agent.ainvoke(
                {"messages": [{"role": "user", "content": message}]}
            )

# 使用：10 个请求同时来，但最多 3 个同时调 LLM
agent = RateLimitedAgent(create_agent("openai:gpt-4o", tools=tools), max_concurrent=3)
results = await asyncio.gather(*[agent.invoke(q) for q in queries])
```

```python
# LangChain：多用户请求排队处理
request_queue = asyncio.Queue(maxsize=50)

async def producer(user_message: str):
    """接收用户请求，放入队列"""
    await request_queue.put(user_message)

async def consumer():
    """从队列取请求，调用 Agent 处理"""
    while True:
        message = await request_queue.get()
        result = await agent.ainvoke(
            {"messages": [{"role": "user", "content": message}]}
        )
        print(result["messages"][-1].content)
        request_queue.task_done()

# 启动 3 个消费者并发处理
async def main():
    consumers = [asyncio.create_task(consumer()) for _ in range(3)]
    # 接收用户输入...
    await asyncio.gather(*consumers)
```

### API 速查表

| 操作 | 作用 | LangChain 场景 |
|------|------|---------------|
| `asyncio.run(main())` | 启动事件循环 | Agent 程序入口 |
| `asyncio.gather(*coros)` | 并发执行，等全部完成 | 多个子 Agent 同时跑 |
| `asyncio.create_task(coro)` | 创建后台任务 | 长任务后台执行 |
| `asyncio.sleep(n)` | 异步等待 n 秒 | 轮询、限流、重试间隔 |
| `asyncio.wait_for(coro, timeout)` | 超时控制 | Agent 调用超时保护 |
| `asyncio.to_thread(func, *args)` | 同步函数异步化 | `input()`、同步 DB |
| `asyncio.wait(tasks)` | 等一组任务（可设条件） | 多搜索源取最快 |
| `asyncio.Semaphore(n)` | 限制并发数 | LLM API rate limit |
| `asyncio.Lock()` | 互斥锁 | 保护共享状态写入 |
| `asyncio.Event()` | 事件通知 | 初始化完成通知 |
| `asyncio.Queue()` | 异步队列 | 多用户请求排队 |
| `task.cancel()` | 取消任务 | 用户打断 Agent |
| `task.done()` | 检查是否完成 | 查询后台任务状态 |
