# 类型提示进阶

> Python 类型提示（Type Hints）在 LangChain 中广泛使用，从工具定义到 Agent 状态管理，类型提示提供了代码可读性、IDE 支持和运行时验证。

## 基础类型提示

```python
from typing import Optional, Union, List, Dict, Tuple, Set

# 基本类型
name: str = "Alice"
age: int = 30
height: float = 1.75
is_active: bool = True

# 容器类型
names: List[str] = ["Alice", "Bob"]
ages: Dict[str, int] = {"Alice": 30, "Bob": 25}
coords: Tuple[float, float] = (1.0, 2.0)
unique_ids: Set[int] = {1, 2, 3}

# 可选类型
middle_name: Optional[str] = None  # 等价于 str | None
```

## 函数类型提示

```python
from typing import Optional, List

def greet(name: str, greeting: str = "Hello") -> str:
    """打招呼函数"""
    return f"{greeting}, {name}!"

def process_items(
    items: List[str],
    *,  # 强制后续参数使用关键字
    max_count: int = 10,
    filter_func: Optional[callable] = None
) -> List[str]:
    """处理项目列表"""
    result = items[:max_count]
    if filter_func:
        result = [x for x in result if filter_func(x)]
    return result
```

## 高级类型

### Union 与 Optional

```python
from typing import Union, Optional

# Union：多种类型之一
def parse(value: Union[int, str, float]) -> str:
    return str(value)

# Optional：等价于 Union[T, None]
def get_user(id: int) -> Optional[dict]:
    # 可能返回 dict 或 None
    pass

# Python 3.10+ 新语法
def parse(value: int | str | float) -> str:
    return str(value)

def get_user(id: int) -> dict | None:
    pass
```

### Literal 类型

```python
from typing import Literal

def set_mode(mode: Literal["read", "write", "append"]) -> None:
    """只接受特定的字面量值"""
    pass

set_mode("read")    # OK
# set_mode("delete")  # 类型检查错误
```

### Annotated（带元数据的类型）

```python
from typing import Annotated
from pydantic import Field

# 结合 Pydantic 使用
class User:
    age: Annotated[int, Field(gt=0, le=150)]
    name: Annotated[str, Field(min_length=1, max_length=100)]

# 自定义元数据
from typing import get_type_hints

def process(
    value: Annotated[int, "positive", "even"]
) -> Annotated[int, "result"]:
    return value * 2

# 获取元数据
hints = get_type_hints(process, include_extras=True)
```

### TypeVar（泛型）

```python
from typing import TypeVar, Generic, List

T = TypeVar("T")  # 类型变量

class Stack(Generic[T]):
    """泛型栈"""
    def __init__(self):
        self.items: List[T] = []
    
    def push(self, item: T) -> None:
        self.items.append(item)
    
    def pop(self) -> T:
        return self.items.pop()
    
    def peek(self) -> T:
        return self.items[-1]

# 使用
int_stack = Stack[int]()
int_stack.push(1)
int_stack.push(2)
value = int_stack.pop()  # 类型推断为 int

str_stack = Stack[str]()
str_stack.push("hello")
```

### Callable（可调用类型）

```python
from typing import Callable, List

def apply_func(items: List[int], func: Callable[[int], int]) -> List[int]:
    """对列表每个元素应用函数"""
    return [func(item) for item in items]

# 使用
result = apply_func([1, 2, 3], lambda x: x * 2)  # [2, 4, 6]
```

### TypeAlias（类型别名）

```python
from typing import TypeAlias

# 定义类型别名
UserId: TypeAlias = int
UserData: TypeAlias = dict[str, str | int]
Callback: TypeAlias = Callable[[str], None]

def get_user(user_id: UserId) -> UserData:
    pass

def register_callback(callback: Callback) -> None:
    pass
```

### Any（任意类型）

> `Any` = "任意类型"的特殊类型标记，类型体系中的**万能通配符**。它告诉类型检查器（mypy/pyright/IDE）：这个位置可以是任何类型，**不要做任何类型检查**。

```python
from typing import Any
```

**什么时候需要它**：Python 是动态语言，有些函数确实要接收/返回任意类型的数据（JSON、通用工具函数、`**kwargs`），这时用 `Any` 明确表达"此处类型多变"。

**三个典型场景**：

```python
# 场景1：JSON 等外部数据（值类型不可预知）
def parse_config(raw: str) -> dict[str, Any]:
    """返回 dict，但值可能是 str/int/list/dict/None"""
    import json
    return json.loads(raw)

# 场景2：通用工具函数
def safe_first(items: list[Any]) -> Any:
    """返回列表第一个元素，元素类型不确定"""
    return items[0] if items else None

# 场景3：**kwargs 任意关键字参数
def log(message: str, **kwargs: Any):
    """记录日志，附带任意附加信息"""
    print(message, kwargs)
```

**Any vs object vs 不写类型提示**：

| | `Any` | `object` | 不写类型提示 |
|---|---|---|---|
| 能赋任何值 | ✅ | ✅ | ✅ |
| 能调用任意方法？ | ✅（不检查） | ❌（只有 object 的方法） | ✅ |
| 类型检查器行为 | **完全跳过检查** | 严格检查（只能调基类方法） | 隐式 Any |
| 语义 | "我不关心类型" | "所有类型的公共基类" | 同 Any |

```python
def f(x: Any) -> int:
    return x + 1      # ✅ Any：不检查，x 可以是 int/str/任何东西

def g(x: object) -> int:
    return x + 1      # ❌ object：报错！object 没有 __add__（加法）
```

> **`Any` 是"退出类型检查"，`object` 是"所有类型的祖先但只能用基类方法"**。用错的话，`object` 会得到一堆类型报错，而 `Any` 什么都检查不出来。

**使用纪律**——`Any` 用多了会让类型检查形同虚设：

```python
# ❌ 过度使用：全部 Any，等于放弃类型安全
def process(data: Any, config: Any) -> Any:
    ...

# ✅ 能写具体的就写具体
def process(data: dict[str, str], config: Settings) -> str:
    ...

# ✅ 只在"确实类型多变"的地方用 Any（如 JSON、外部接口）
def api_response() -> dict[str, Any]:
    ...
```

**Agent 框架中的典型位置**（LangChain/DeepAgents 源码里到处都是 `Any`——框架层不知道你的业务类型）：

```python
# LangChain Runnable 的通用接口
from typing import Any
from langchain_core.runnables import Runnable

class MyRunnable(Runnable[dict, Any]):
    """输入是 dict，输出是任意类型"""
    def invoke(self, input: dict, config=None) -> Any:
        return {"result": ...}

# 中间件钩子的 state/runtime 参数
def before_model(self, state: Any, runtime: Any) -> dict:
    ...
```

## LangChain 中的类型应用

### Agent 状态定义

```python
from typing import Annotated, TypedDict, Literal
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage

class AgentState(TypedDict):
    """Agent 状态类型定义"""
    # 消息列表，使用 add_messages 注解实现自动追加
    messages: Annotated[list[BaseMessage], add_messages]
    
    # 当前步骤
    current_step: Literal["think", "act", "observe"]
    
    # 迭代计数
    iteration: int
    
    # 可选的中间结果
    intermediate_steps: list[tuple] | None
```

### 工具参数类型

```python
from langchain.tools import tool
from pydantic import BaseModel, Field
from typing import Literal

class SearchInput(BaseModel):
    """搜索工具输入"""
    query: str = Field(description="搜索关键词")
    search_type: Literal["web", "news", "academic"] = Field(
        default="web",
        description="搜索类型"
    )
    max_results: int = Field(
        default=5,
        ge=1,
        le=20,
        description="最大结果数"
    )

@tool(args_schema=SearchInput)
def search(query: str, search_type: str = "web", max_results: int = 5) -> str:
    """执行搜索"""
    return f"搜索 {query}（{search_type}），返回 {max_results} 条"
```

### 回调类型

```python
from typing import Any, Dict, List
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.outputs import LLMResult

class CustomHandler(BaseCallbackHandler):

        pass
```
