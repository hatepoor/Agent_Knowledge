# 序列化与状态管理

> 序列化是将 Python 对象转换为可存储或传输格式的过程。在 Agent 开发中，序列化用于持久化对话历史、保存检查点、跨进程传递数据等关键场景。

## JSON 序列化

JSON 是最常用的序列化格式，跨语言兼容，人类可读。

### 基础用法

```python
import json

# Python 对象 → JSON 字符串
data = {
    "name": "Alice",
    "age": 30,
    "tags": ["python", "ai"],
    "active": True,
    "score": None
}

json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)
# {
#   "name": "Alice",
#   "age": 30,
#   "tags": ["python", "ai"],
#   "active": true,
#   "score": null
# }

# JSON 字符串 → Python 对象
parsed = json.loads(json_str)
```

### 文件操作

```python
import json

# 写入 JSON 文件
data = {"key": "value"}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取 JSON 文件
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```

### 自定义序列化

```python
from datetime import datetime
import json

class Event:
    def __init__(self, name, timestamp):
        self.name = name
        self.timestamp = timestamp

# 自定义编码器
class EventEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, Event):
            return {
                "__type__": "Event",
                "name": obj.name,
                "timestamp": obj.timestamp.isoformat()
            }
        return super().default(obj)

# 自定义解码器
def event_decoder(dct):
    if dct.get("__type__") == "Event":
        return Event(
            dct["name"],
            datetime.fromisoformat(dct["timestamp"])
        )
    return dct

# 使用
event = Event("会议", datetime.now())
json_str = json.dumps(event, cls=EventEncoder)
restored = json.loads(json_str, object_hook=event_decoder)
```

## Pickle 序列化

Pickle 是 Python 特有的二进制序列化格式，支持更多类型，但不跨语言。

```python
import pickle

# 序列化
data = {"key": "value", "numbers": [1, 2, 3]}
pickled = pickle.dumps(data)  # bytes
print(pickled)

# 反序列化
restored = pickle.loads(pickled)

# 文件操作
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)

with open("data.pkl", "rb") as f:
    data = pickle.load(f)
```

### Pickle 安全警告

```python
# ⚠️ 不要反序列化不可信数据！
# 恶意 pickle 可以执行任意代码

import pickle
import os

class Malicious:
    def __reduce__(self):
        # 反序列化时执行系统命令
        return (os.system, ("rm -rf /",))

# 永远不要这样做：
# pickle.loads(untrusted_data)
```

## LangChain 中的序列化

### 消息序列化

```python
from langchain_core.messages import HumanMessage, AIMessage, messages_to_dict, messages_from_dict

# 消息列表
messages = [
    HumanMessage(content="你好"),
    AIMessage(content="你好！有什么可以帮助的？"),
]

# 序列化为字典
serialized = messages_to_dict(messages)
print(serialized)
# [
#   {"type": "human", "data": {"content": "你好", ...}},
#   {"type": "ai", "data": {"content": "你好！", ...}}
# ]

# 反序列化
restored = messages_from_dict(serialized)
```

### JSON 序列化消息

```python
from langchain_core.messages import HumanMessage
import json

msg = HumanMessage(content="你好")

# 转为 JSON
json_str = msg.model_dump_json()
print(json_str)
# {"type":"human","content":"你好",...}

# 从 JSON 恢复
from langchain_core.messages import HumanMessage
restored = HumanMessage.model_validate_json(json_str)
```

## Checkpoint 状态持久化

LangGraph 使用 Checkpoint 系统持久化 Agent 状态。

### SqliteSaver

```python
from langgraph.checkpoint.sqlite import SqliteSaver
from langchain.agents import create_react_agent, AgentExecutor

# 创建检查点保存器
checkpointer = SqliteSaver.from_conn_string("checkpoints.db")

# 创建 Agent
agent = create_react_agent(llm, tools)
executor = AgentExecutor(
    agent=agent,
    tools=tools,
    checkpointer=checkpointer,
    thread_id="user-123"  # 会话标识
)

# 运行 Agent（状态自动保存）
result = executor.invoke({"input": "你好"})

# 恢复会话（使用相同 thread_id）
result = executor.invoke({"input": "继续刚才的话题"})
```

### PostgresSaver

```python
from langgraph.checkpoint.postgres import PostgresSaver

# 生产环境使用 PostgreSQL
checkpointer = PostgresSaver.from_conn_string(
    "postgresql://user:pass@localhost:5432/dbname"
)
```

### 内存检查点（测试用）

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()  # 内存中，重启丢失
```

## 序列化格式对比

| 格式 | 可读性 | 跨语言 | 支持类型 | 安全性 | 速度 | 适用场景 |
|------|--------|--------|---------|--------|------|---------|
| JSON | 高 | 是 | 基础类型 | 安全 | 中 | API、配置、日志 |
| Pickle | 低 | 否 | 几乎所有 Python 对象 | **不安全** | 快 | Python 内部缓存 |
| MessagePack | 低 | 是 | 基础类型 | 安全 | 快 | 高性能 API |
| YAML | 高 | 是 | 基础类型 | 安全 | 慢 | 配置文件 |
| Protocol Buffers | 低 | 是 | 定义的类型 | 安全 | 最快 | 微服务通信 |

## 最佳实践

1. **优先使用 JSON**：跨语言兼容，安全，可读
2. **避免 Pickle 处理不可信数据**：存在远程代码执行风险
3. **大对象考虑分片**：避免单个文件过大
4. **使用版本控制**：序列化格式变更时保持向后兼容
5. **压缩大文件**：使用 gzip 压缩 JSON/Pickle 文件

```python
import gzip
import json

# 压缩保存
with gzip.open("data.json.gz", "wt", encoding="utf-8") as f:
    json.dump(data, f)

# 压缩读取
with gzip.open("data.json.gz", "rt", encoding="utf-8") as f:
    data = json.load(f)
```
