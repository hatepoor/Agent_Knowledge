# Python 列表（list）

> 列表是 Python 中最常用的**可变**有序容器，可以存放任意类型的元素，支持索引、切片和原地修改。

## 创建列表

```python
a = [1, 2, 3]                    # 字面量
b = list("abc")                  # 从可迭代对象构造：['a','b','c']
c = list(range(5))               # [0, 1, 2, 3, 4]
d = [0] * 5                      # [0, 0, 0, 0, 0]（注意嵌套引用问题）
e = [x**2 for x in range(5)]     # 列表推导式：[0, 1, 4, 9, 16]
f = [[0]*3 for _ in range(3)]    # 二维列表（避免引用陷阱）
```

## 索引与切片

```python
lst = [10, 20, 30, 40, 50]

lst[0]       # 10（首个）
lst[-1]      # 50（末尾）
lst[1:3]     # [20, 30]（切片，不含 stop）
lst[::2]     # [10, 30, 50]（步长 2）
lst[::-1]    # [50, 40, 30, 20, 10]（反转）
```

## 列表内置方法（全部）

### 增删元素

| 方法 | 说明 | 示例 | 返回值 |
|------|------|------|--------|
| `list.append(x)` | 末尾添加 | `[1,2].append(3)` → `[1,2,3]` | None |
| `list.insert(i, x)` | 在位置 i 插入 | `[1,3].insert(1, 2)` → `[1,2,3]` | None |
| `list.extend(iter)` | 扩展（追加多个） | `[1].extend([2,3])` → `[1,2,3]` | None |
| `list.pop(i)` | 移除并返回位置 i 的元素 | `[1,2,3].pop(1)` → `2`，列表变 `[1,3]` | 被移除的元素 |
| `list.remove(x)` | 移除首个值为 x 的元素 | `[1,2,1].remove(1)` → `[2,1]` | None |
| `list.clear()` | 清空所有元素 | `[1,2,3].clear()` → `[]` | None |

### 查找与计数

| 方法 | 说明 | 示例 |
|------|------|------|
| `list.index(x)` | 首个值为 x 的位置 | `[10,20,30].index(20)` → `1` |
| `list.count(x)` | 值为 x 的元素个数 | `[1,2,1,1].count(1)` → `3` |

### 排序与反转

| 方法 | 说明 | 示例 |
|------|------|------|
| `list.sort(key, reverse)` | 原地排序 | `[3,1,2].sort()` → `[1,2,3]` |
| `list.reverse()` | 原地反转 | `[1,2,3].reverse()` → `[3,2,1]` |
| `list.copy()` | 浅拷贝 | `[1,2,3].copy()` → `[1,2,3]`（新对象） |

> **`sort()` vs `sorted()`**：`sort()` 是原地修改（返回 None），`sorted()` 返回新列表（不修改原列表）。

### 排序进阶

```python
# 按 key 函数排序
words = ["banana", "apple", "cherry"]
words.sort(key=len)              # ['apple', 'banana', 'cherry']（按长度）

# 降序
nums = [3, 1, 4, 1, 5]
nums.sort(reverse=True)          # [5, 4, 3, 1, 1]

# 按字典的某个 key 排序
students = [{"name": "Alice", "age": 20}, {"name": "Bob", "age": 18}]
students.sort(key=lambda s: s["age"])  # Bob 在前
```

## 常用操作

```python
# 拼接
[1, 2] + [3, 4]           # [1, 2, 3, 4]

# 重复
[0] * 3                    # [0, 0, 0]

# 成员检测
3 in [1, 2, 3]             # True

# 长度、最大、最小、求和
len([1, 2, 3])             # 3
max([1, 2, 3])             # 3
min([1, 2, 3])             # 1
sum([1, 2, 3])             # 6

# 解包
a, b, c = [1, 2, 3]
first, *rest = [1, 2, 3, 4]  # first=1, rest=[2,3,4]

# 列表推导式
[x**2 for x in range(10)]                    # [0,1,4,9,16,25,36,49,64,81]
[x for x in range(10) if x % 2 == 0]        # [0,2,4,6,8]（带条件）
[(x, y) for x in range(3) for y in range(3)] # 嵌套推导
```

## zip() 函数

`zip()` 用于**将多个可迭代对象按位置打包成元组**，常用来并行遍历多个序列。

### 基础用法

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]

# 将两个列表按位置配对
result = list(zip(names, ages))
print(result)
# [('Alice', 25), ('Bob', 30), ('Charlie', 35)]
```

### 常见场景

```python
# 1. 并行遍历
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["Beijing", "Shanghai", "Guangzhou"]

for name, age, city in zip(names, ages, cities):
    print(f"{name}, {age}岁, 来自{city}")

# 2. 创建字典
keys = ["name", "age", "city"]
values = ["Alice", 25, "Beijing"]
user = dict(zip(keys, values))
# {'name': 'Alice', 'age': 25, 'city': 'Beijing'}

# 3. 矩阵转置
matrix = [[1, 2, 3], [4, 5, 6][[, [7, 8, 9]]
transposed = list(zip(*matrix))
# [(1, 4, 7), (2, 5, 8), (3, 6, 9)]

# 4. 解包（unzip）
pairs = [('Alice', 25), ('Bob', 30)]
names, ages = zip(*pairs)
# names = ('Alice', 'Bob'), ages = (25, 30)
```

### 长度不一致时

默认以**最短序列为准**：

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30]  # 只有2个元素

list(zip(names, ages))
# [('Alice', 25), ('Bob', 30)]  # Charlie 被丢弃
```

Python 3.10+ 可用 `strict=True` 强制长度一致：

```python
list(zip(names, ages, strict=True))
# ValueError: zip() argument 2 is shorter than argument 1
```

## 列表作为栈和队列

```python
# 栈（LIFO）：用 append/pop
stack = []
stack.append(1)    # [1]
stack.append(2)    # [1, 2]
stack.pop()        # 2，stack=[1]

# 队列（FIFO）：推荐用 collections.deque（list.pop(0) 是 O(n)）
from collections import deque
queue = deque()
queue.append(1)    # 入队
queue.append(2)
queue.popleft()    # 1（O(1) 出队）
```

## 浅拷贝 vs 深拷贝

```python
import copy

original = [[1, 2][[, [3, 4]]

shallow = original.copy()          # 浅拷贝：外层新对象，内层共享引用
deep = copy.deepcopy(original)     # 深拷贝：完全独立

original[0].append(99)
shallow    # [[1, 2, 99][[, [3, 4]]  ← 受影响
deep       # [[1, 2][[, [3, 4]]      ← 不受影响
```
