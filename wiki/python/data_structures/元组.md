# Python 元组（tuple）

> 元组是**不可变**的有序序列，一旦创建就不能修改。这种不可变性使其可以作为字典的 key 或集合的元素，也保证了线程安全。

## 为什么需要元组？

| 场景 | 为什么用 tuple |
|------|---------------|
| 数据保护 | 防止意外修改（如坐标、配置项） |
| 字典键 | 不可变对象可作为 dict 的 key |
| 集合元素 | 不可变对象可加入 set |
| 函数返回 | 多值返回的惯用方式 |
| 性能优化 | 比 list 占用更少内存，创建更快 |
| 语义表达 | 表示"结构"（异构数据）而非"集合"（同质数据） |

## 创建元组

### 基础创建

```python
# 字面量（最常用）
t1 = (1, 2, 3)
t2 = ("Alice", 25, "Beijing")  # 异构数据

# 省略括号（隐式元组）
t3 = 1, 2, 3
t4 = "hello",  # 单元素元组（注意逗号！）

# 空元组
t5 = ()
t6 = tuple()

# 从可迭代对象构造
t7 = tuple([1, 2, 3])           # 从列表
t8 = tuple("abc")               # 从字符串：('a', 'b', 'c')
t9 = tuple(range(5))            # 从 range：(0, 1, 2, 3, 4)
t10 = tuple({1, 2, 3})          # 从集合（顺序不保证）

# 单元素元组的陷阱
t11 = (1)      # ❌ 这是 int，不是 tuple！
t12 = (1,)     # ✅ 单元素元组必须有逗号
type(t11)      # <class 'int'>
type(t12)      # <class 'tuple'>
```

### 元组推导式？

Python **没有**元组推导式，`()` 会生成生成器：

```python
# 这不是元组推导式，而是生成器表达式
gen = (x**2 for x in range(5))
type(gen)  # <class 'generator'>

# 要生成元组，用 tuple() 包装
t = tuple(x**2 for x in range(5))
# (0, 1, 4, 9, 16)
```

## 访问元素

### 索引与切片

```python
t = (10, 20, 30, 40, 50)

# 正向索引（从 0 开始）
t[0]       # 10
t[2]       # 30

# 反向索引（从 -1 开始）
t[-1]      # 50（最后一个）
t[-2]      # 40（倒数第二个）

# 切片 [start:stop:step]
t[1:3]     # (20, 30)（不含 stop）
t[:3]      # (10, 20, 30)（从头到索引 2）
t[2:]      # (30, 40, 50)（从索引 2 到尾）
t[::2]     # (10, 30, 50)（步长 2）
t[::-1]    # (50, 40, 30, 20, 10)（反转）

# 切片返回新元组
t[1:3] is t  # False
```

### 解包（Unpacking）

```python
# 基础解包
a, b, c = (1, 2, 3)
print(a, b, c)  # 1 2 3

# 星号解包（Python 3+）
first, *rest = (1, 2, 3, 4, 5)
print(first)  # 1
print(rest)   # [2, 3, 4, 5]（注意：rest 是 list）

# 中间星号
first, *middle, last = (1, 2, 3, 4, 5)
print(middle)  # [2, 3, 4]

# 忽略某些值
a, _, c = (1, 2, 3)  # _ 表示忽略

# 嵌套解包
(a, b), c = (1, 2), 3
print(a, b, c)  # 1 2 3

# 函数参数解包
def add(x, y):
    return x + y

args = (3, 5)
add(*args)  # 8
```

## 内置方法

元组只有**两个**内置方法（因为不可变）：

```python
t = (10, 20, 30, 20, 10)

# count(x)：统计元素 x 出现的次数
t.count(20)  # 2
t.count(10)  # 2
t.count(99)  # 0

# index(x)：返回元素 x 首次出现的索引
t.index(20)  # 1
t.index(30)  # 2
# t.index(99)  # ValueError: tuple.index(x): x not in tuple
```

## 运算操作

```python
# 拼接（返回新元组）
(1, 2) + (3, 4)  # (1, 2, 3, 4)

# 重复
(0,) * 3          # (0, 0, 0)
(1, 2) * 2        # (1, 2, 1, 2)

# 成员检测
3 in (1, 2, 3)    # True
4 not in (1, 2, 3)  # True

# 长度
len((1, 2, 3))    # 3

# 比较（按字典序）
(1, 2, 3) < (1, 2, 4)  # True
(1, 2, 3) == (1, 2, 3)  # True

# 最大值、最小值、求和
max((1, 5, 3))    # 5
min((1, 5, 3))    # 1
sum((1, 2, 3))    # 6

# 排序（返回 list，不是 tuple）
sorted((3, 1, 2))  # [1, 2, 3]
tuple(sorted((3, 1, 2)))  # (1, 2, 3)

# 反转（返回迭代器）
tuple(reversed((1, 2, 3)))  # (3, 2, 1)
```

## 不可变性的含义

### 元组本身不可变

```python
t = (1, 2, 3)
# t[0] = 10  # ❌ TypeError: 'tuple' object does not support item assignment
# t.append(4)  # ❌ AttributeError: 'tuple' object has no attribute 'append'
# del t[0]  # ❌ TypeError: 'tuple' object doesn't support item deletion
```

### 但元素可以是可变的

```python
# 元组包含可变对象时，对象内部可以修改
t = ([1, 2], [3, 4])
t[0].append(3)
print(t)  # ([1, 2, 3], [3, 4])

# 但不能替换整个元素
# t[0] = [5, 6]  # ❌ TypeError
```

### 哈希值

```python
# 不可变元组可哈希
hash((1, 2, 3))  # 可以

# 包含可变对象的元组不可哈希
hash(([1, 2],))  # ❌ TypeError: unhashable type: 'list'
```

## 命名元组（namedtuple）

命名元组是 tuple 的子类，可以通过名称访问元素。

### 基础用法

```python
from collections import namedtuple

# 定义命名元组
Point = namedtuple("Point", ["x", "y"])

# 创建实例
p = Point(1, 2)

# 通过名称访问
print(p.x)  # 1
print(p.y)  # 2

# 通过索引访问（仍是 tuple）
print(p[0])  # 1
print(p[1])  # 2

# 解包
x, y = p
```

### 高级特性

```python
from collections import namedtuple

# 定义
Person = namedtuple("Person", ["name", "age", "city"])

# 创建
alice = Person("Alice", 25, "Beijing")

# _asdict()：转为字典
d = alice._asdict()
# {'name': 'Alice', 'age': 25, 'city': 'Beijing'}

# _replace()：返回新实例（不可变）
alice2 = alice._replace(age=26)
# Person(name='Alice', age=26, city='Beijing')

# _fields：字段名元组
Person._fields  # ('name', 'age', 'city')

# _make()：从可迭代对象创建
bob = Person._make(["Bob", 30, "Shanghai"])
```

### 带默认值

```python
from collections import namedtuple

# Python 3.7+
Person = namedtuple("Person", ["name", "age", "city"], defaults=["Unknown", "Unknown"])

alice = Person("Alice")
# Person(name='Alice', age='Unknown', city='Unknown')

bob = Person("Bob", 30)
# Person(name='Bob', age=30, city='Unknown')
```

### 应用场景

```python
from collections import namedtuple

# 代替简单的类
Point = namedtuple("Point", ["x", "y"])
points = [Point(1, 2), Point(3, 4), Point(5, 6)]

# 计算距离
import math
for p in points:
    distance = math.sqrt(p.x**2 + p.y**2)
    print(f"{p}: {distance:.2f}")

# CSV 数据处理
Record = namedtuple("Record", ["name", "age", "city"])
with open("data.csv") as f:
    next(f)  # 跳过表头
    for line in f:
        record = Record(*line.strip().split(","))
        print(record.name, record.age)
```

## tuple vs list

| 特性 | tuple | list |
|------|-------|------|
| 语法 | `(1, 2, 3)` | `[1, 2, 3]` |
| 可变性 | **不可变** | 可变 |
| 性能 | 创建更快，占用更少内存 | 略慢 |
| 方法 | 只有 `count` 和 `index` | 丰富的方法 |
| 作为 dict key | ✅ 可以（元素也需不可变） | ❌ 不可以 |
| 作为 set 元素 | ✅ 可以 | ❌ 不可以 |
| 线程安全 | ✅ 是（不可变） | ❌ 否（需加锁） |
| 语义 | 结构化数据（异构） | 同质集合 |
| 使用场景 | 配置项、坐标、函数返回 | 动态集合、需要修改 |

### 性能对比

```python
import sys
import timeit

# 内存占用
t = (1, 2, 3, 4, 5)
l = [1, 2, 3, 4, 5]
sys.getsizeof(t)  # 80 bytes
sys.getsizeof(l)  # 120 bytes（多 50%）

# 创建速度
timeit.timeit("(1, 2, 3, 4, 5)", number=1000000)  # ~0.03s
timeit.timeit("[1, 2, 3, 4, 5]", number=1000000)  # ~0.15s（慢 5 倍）
```

## 常见用法

### 函数多值返回

```python
def get_min_max(numbers):
    """返回最小值和最大值"""
    return min(numbers), max(numbers)

# 返回的是 tuple
result = get_min_max([3, 1, 4, 1, 5])
print(result)  # (1, 5)

# 解包
min_val, max_val = get_min_max([3, 1, 4, 1, 5])
```

### 字典键

```python
# 用 tuple 作为二维坐标的键
locations = {
    (0, 0): "原点",
    (1, 0): "右",
    (0, 1): "上",
}

print(locations[(1, 0)][[)  # "右"
```

### 数据交换

```python
a, b = 1, 2
a, b = b, a  # Python 风格的交换（底层用 tuple 实现）
print(a, b)  # 2 1
```

### 常量集合

```python
# 用 tuple 表示不应修改的常量
DIRECTIONS = ("north", "south", "east", "west")
COLORS = ("red", "green", "blue")

# 比 list 更安全，比字符串更结构化
```
