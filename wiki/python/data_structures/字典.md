# Python 字典（dict）

> 字典是 Python 中的**键值对**映射，**可变**、**有序**（Python 3.7+ 保持插入顺序）。底层基于哈希表实现，查找/插入/删除平均 O(1)。

## 创建字典

```python
d1 = {"name": "Alice", "age": 30}       # 字面量
d2 = dict(name="Alice", age=30)          # 关键字参数
d3 = dict([("name", "Alice"), ("age", 30)])  # 键值对列表
d4 = {k: v for k, v in zip(["a","b"], [1,2])}  # 字典推导式
d5 = {}                                  # 空字典
d6 = dict.fromkeys(["a","b","c"], 0)     # 从键列表创建，默认值 0
```

## 访问元素

```python
d = {"name": "Alice", "age": 30}

# 直接访问（key 不存在会抛 KeyError）
d["name"]              # "Alice"

# 安全访问（key 不存在返回默认值）
d.get("name")          # "Alice"
d.get("gender", "N/A") # "N/A"（默认值）

# 成员检测
"name" in d            # True
"gender" not in d      # True
```

## 字典内置方法（全部）

### 增删改

| 方法 | 说明 | 示例 | 返回值 |
|------|------|------|--------|
| `dict[key] = value` | 设置/更新键值对 | `d["age"] = 31` | — |
| `dict.setdefault(key, default)` | key 存在则返回其值，否则设为 default 并返回 | `d.setdefault("gender", "N/A")` → `"N/A"` | 值 |
| `dict.update(other)` | 批量更新/合并 | `d.update({"age": 31, "city": "BJ"})` | None |
| `dict.pop(key, default)` | 移除并返回值 | `d.pop("age")` → `30` | 值 |
| `dict.popitem()` | 移除并返回最后插入的键值对 | `d.popitem()` → `("age", 30)` | (key, value) |
| `dict.clear()` | 清空字典 | `d.clear()` → `{}` | None |
| `dict \| other` | 合并（返回新字典，3.9+） | `{"a":1} \| {"b":2}` → `{"a":1,"b":2}` | 新 dict |
| `dict \|= other` | 就地合并（3.9+） | `d \|= {"b":2}` | — |

### 查询

| 方法 | 说明 | 示例 |
|------|------|------|
| `dict.keys()` | 所有键的视图 | `d.keys()` → `dict_keys(["name","age"])` |
| `dict.values()` | 所有值的视图 | `d.values()` → `dict_values(["Alice",30])` |
| `dict.items()` | 所有键值对的视图 | `d.items()` → `dict_items([("name","Alice"),("age",30)])` |
| `dict.get(key, default)` | 安全获取 | `d.get("x", 0)` → `0` |
| `dict.copy()` | 浅拷贝 | `d.copy()` → 新 dict |
| `dict.fromkeys(seq, value)` | 类方法：从序列创建 | `dict.fromkeys("abc", 0)` → `{"a":0,"b":0,"c":0}` |

### 遍历字典

```python
d = {"name": "Alice", "age": 30, "city": "Beijing"}

# 遍历键
for key in d:
    print(key)

# 遍历键值对
for key, value in d.items():
    print(f"{key}: {value}")

# 遍历值
for value in d.values():
    print(value)

# 排序遍历（按键排序）
for key in sorted(d):
    print(key, d[key])

# 推导式
{k: v for k, v in d.items() if v > 20}   # {"age": 30, "city": "Beijing"}
```

## 字典推导式

```python
# 键值翻转
names = ["alice", "bob"]
{name: len(name) for name in names}       # {"alice": 5, "bob": 3}

# 翻转键值
d = {"a": 1, "b": 2}
{v: k for k, v in d.items()}              # {1: "a", 2: "b"}

# 嵌套字典
matrix = {(i,j): i*j for i in range(3) for j in range(3)}
```

## 嵌套字典

```python
users = {
    "alice": {"age": 30, "city": "Beijing"},
    "bob": {"age": 25, "city": "Shanghai"},
}

# 访问
users["alice"]["age"]           # 30

# 安全访问嵌套
users.get("charlie", {}).get("age", "N/A")  # "N/A"

# 更新嵌套
users.setdefault("charlie", {})["age"] = 28
```

## 默认字典（collections.defaultdict）

```python
from collections import defaultdict

# 自动初始化缺失的 key
dd = defaultdict(list)
dd["fruits"].append("apple")    # 无需先检查 key 是否存在
dd["fruits"].append("banana")
dd["fruits"]                    # ["apple", "banana"]

# 计数
counter = defaultdict(int)
for word in ["apple", "banana", "apple"]:
    counter[word] += 1
counter                         # {"apple": 2, "banana": 1}
```

> **`defaultdict` vs `dict.setdefault()`**：`defaultdict` 在访问时自动初始化，`setdefault` 在设置时提供默认值。频繁使用默认值时 `defaultdict` 更简洁。

## 有序字典（collections.OrderedDict）

```python
from collections import OrderedDict

# Python 3.7+ 普通 dict 已保持插入顺序
# OrderedDict 额外提供：move_to_end、popitem(last=False)、相等性比较考虑顺序
od = OrderedDict()
od["a"] = 1
od["b"][[ = 2
od.move_to_end("a")            # a 移到最后
od.popitem(last=False)          # 弹出第一个（b）
```
