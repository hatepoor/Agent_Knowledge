# Python 数值类型

> Python 有四种数值类型：`int`（整数）、`float`（浮点数）、`bool`（布尔）、`complex`（复数）。所有数值类型都是**不可变**的。

## int（整数）

Python 的整数**没有大小限制**（受内存限制），可以任意大。

```python
a = 42           # 普通整数
b = -100         # 负整数
c = 10**100      # 大整数（1后面100个0）
d = 0b1010       # 二进制：10
e = 0o17         # 八进制：15
f = 0xFF         # 十六进制：255
```

### int 常用操作

| 操作 | 示例 | 结果 |
|------|------|------|
| 加法 | `3 + 2` | `5` |
| 减法 | `3 - 2` | `1` |
| 乘法 | `3 * 2` | `6` |
| 除法（浮点） | `7 / 2` | `3.5` |
| 整除 | `7 // 2` | `3` |
| 取余 | `7 % 2` | `1` |
| 幂运算 | `2 ** 10` | `1024` |
| 绝对值 | `abs(-5)` | `5` |
| 四舍五入 | `round(3.7)` | `4` |
| 类型转换 | `int("42")` | `42` |
| 进制转换 | `bin(10)` / `hex(255)` | `'0b1010'` / `'0xff'` |

### int 内置方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `int.bit_length()` | 二进制位数 | `(10).bit_length()` → `4` |
| `int.bit_count()` | 二进制中 1 的个数 (3.10+) | `(7).bit_count()` → `3` |
| `int.to_bytes(length, byteorder)` | 转为字节串 | `(256).to_bytes(2, 'big')` → `b'\x01\x00'` |
| `int.from_bytes(bytes, byteorder)` | 从字节串构造 | `int.from_bytes(b'\x01\x00', 'big')` → `256` |

## float（浮点数）

基于 IEEE 754 双精度（64 位），约 15-17 位有效数字。

```python
x = 3.14
y = 1e-10        # 科学计数法：0.0000000001
z = float('inf')  # 正无穷大
w = float('nan')  # 非数字（Not a Number）
```

### 浮点数陷阱

```python
0.1 + 0.2 == 0.3          # False!（IEEE 754 精度问题）
0.1 + 0.2                 # 0.30000000000000004

# 精确计算用 decimal
from decimal import Decimal
Decimal('0.1') + Decimal('0.2') == Decimal('0.3')  # True
```

### float 内置方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `float.is_integer()` | 是否为整数 | `(3.0).is_integer()` → `True` |
| `float.hex()` | 十六进制表示 | `(3.14).hex()` → `'0x1.91eb851eb851fp+1'` |
| `float.fromhex(s)` | 从十六进制字符串构造 | `float.fromhex('0x1.91eb851eb851fp+1')` → `3.14` |

### math 模块常用函数

```python
import math

math.ceil(3.2)       # 4（向上取整）
math.floor(3.8)      # 3（向下取整）
math.sqrt(16)         # 4.0（平方根）
math.pow(2, 10)       # 1024.0（幂运算）
math.log(100, 10)     # 2.0（对数）
math.pi               # 3.141592653589793
math.e                # 2.718281828459045
```

## bool（布尔）

`bool` 是 `int` 的子类：`True == 1`，`False == 0`。

```python
True + True    # 2
isinstance(True, int)  # True

# 假值（Falsy）：以下值在布尔上下文中为 False
bool(0)        # False
bool("")       # False
bool([][[)       # False
bool({})       # False
bool(None)     # False
bool(())       # False
```

## complex（复数）

```python
z = 3 + 4j
z.real          # 3.0（实部）
z.imag          # 4.0（虚部）
z.conjugate()   # 3-4j（共轭）
abs(z)          # 5.0（模长）
```

## 类型转换

```python
int(3.7)       # 3（截断小数）
int("42")      # 42
int("0xff", 16)  # 255（指定进制）
float(42)      # 42.0
float("3.14")  # 3.14
str(42)        # "42"
bool(1)        # True
bool(0)        # False
```

## 运算符优先级（从高到低）

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1 | `**` | 幂 |
| 2 | `+x`, `-x`, `~x` | 正、负、按位取反 |
| 3 | `*`, `/`, `//`, `%` | 乘、除、整除、取余 |
| 4 | `+`, `-` | 加、减 |
| 5 | `<<`, `>>` | 位移 |
| 6 | `&` | 按位与 |
| 7 | `^` | 按位异或 |
| 8 | `\|` | 按位或 |
| 9 | `==`, `!=`, `<`, `>`, `<=`, `>=` | 比较 |
| 10 | `not` | 逻辑非 |
| 11 | `and` | 逻辑与 |
| 12 | `or` | 逻辑或 |
