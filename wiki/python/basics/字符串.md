# Python 字符串（str）

> 字符串是 Python 中最常用的数据类型之一。`str` 是**不可变**的有序序列，支持索引、切片和丰富的内置方法。

## 创建字符串

```python
s1 = "hello"              # 双引号
s2 = 'world'              # 单引号（效果相同）
s3 = """多行
字符串"""                  # 三引号：保留换行
s4 = r"C:\Users\name"     # 原始字符串（不转义）
s5 = f"Hello, {name}!"    # f-string 格式化（3.6+）
s6 = "Hello\nWorld"       # 转义字符
```

## 字符串格式化（4 种方式）

```python
name, age = "Alice", 30

# 方式1：f-string（推荐，最简洁）
f"{name} is {age} years old"           # "Alice is 30 years old"
f"{3.14159:.2f}"                        # "3.14"（保留2位小数）
f"{'hi':>10}"                           # "        hi"（右对齐，宽10）
f"{255:#x}"                             # "0xff"（十六进制）

# 方式2：str.format()
"{} is {} years old".format(name, age)
"{name} is {age} years old".format(name="Alice", age=30)

# 方式3：% 格式化（旧式）
"%s is %d years old" % (name, age)

# 方式4：字符串拼接
"Hello, " + name + "!"
```

## 索引与切片

```python
s = "Hello, World!"

# 索引（从 0 开始，负数从末尾倒数）
s[0]       # 'H'
s[-1]      # '!'

# 切片 [start:stop:step]
s[0:5]     # "Hello"
s[7:]      # "World!"
s[:5]      # "Hello"
s[::2]     # "Hlo ol!"（步长2）
s[::-1]    # "!dlroW ,olleH"（反转）
```

## 字符串内置方法（全部）

### 查找与替换

| 方法 | 说明 | 示例 |
|------|------|------|
| `str.find(sub)` | 查找子串，返回首个位置，未找到返回 -1 | `"hello".find("ll")` → `2` |
| `str.rfind(sub)` | 从右侧查找 | `"hello".rfind("l")` → `3` |
| `str.index(sub)` | 同 find，但未找到抛 ValueError | `"hello".index("ll")` → `2` |
| `str.rindex(sub)` | 从右侧 index | `"hello".rindex("l")` → `3` |
| `str.count(sub)` | 子串出现次数 | `"hello".count("l")` → `2` |
| `str.replace(old, new)` | 替换 | `"hello".replace("l", "x")` → `"hexxo"` |
| `str.startswith(prefix)` | 是否以...开头 | `"hello".startswith("he")` → `True` |
| `str.endswith(suffix)` | 是否以...结尾 | `"hello".endswith("lo")` → `True` |
| `str.removeprefix(prefix)` | 移除前缀 (3.9+) | `"hello".removeprefix("he")` → `"llo"` |
| `str.removesuffix(suffix)` | 移除后缀 (3.9+) | `"hello".removesuffix("lo")` → `"hel"` |

### 大小写转换

| 方法 | 说明 | 示例 |
|------|------|------|
| `str.upper()` | 转大写 | `"hello".upper()` → `"HELLO"` |
| `str.lower()` | 转小写 | `"HELLO".lower()` → `"hello"` |
| `str.title()` | 每个单词首字母大写 | `"hello world".title()` → `"Hello World"` |
| `str.capitalize()` | 仅首字母大写 | `"hello world".capitalize()` → `"Hello world"` |
| `str.swapcase()` | 大小写互换 | `"Hello".swapcase()` → `"hELLO"` |
| `str.casefold()` | 激进小写（用于忽略大小写比较） | `"ß".casefold()` → `"ss"` |

### 对齐与填充

| 方法 | 说明 | 示例 |
|------|------|------|
| `str.center(width)` | 居中 | `"hi".center(10)` → `"    hi    "` |
| `str.ljust(width)` | 左对齐 | `"hi".ljust(10)` → `"hi        "` |
| `str.rjust(width)` | 右对齐 | `"hi".rjust(10)` → `"        hi"` |
| `str.zfill(width)` | 左侧填零 | `"42".zfill(5)` → `"00042"` |
| `str.expandtabs(tabsize)` | 制表符转空格 | `"a\tb".expandtabs(4)` → `"a   b"` |

### 分割与拼接

| 方法 | 说明 | 示例 |
|------|------|------|
| `str.split(sep)` | 按分隔符拆分 | `"a,b,c".split(",")` → `["a","b","c"]` |
| `str.rsplit(sep)` | 从右侧拆分 | `"a,b,c".rsplit(",", 1)` → `["a,b","c"]` |
| `str.splitlines()` | 按行拆分 | `"a\nb\nc".splitlines()` → `["a","b","c"]` |
| `str.partition(sep)` | 按首个分隔符拆为三元组 | `"a:b:c".partition(":")` → `("a",":","b:c")` |
| `str.rpartition(sep)` | 从右侧 partition | `"a:b:c".rpartition(":")` → `("a:b",":","c")` |
| `sep.join(iterable)` | 拼接（str 的类方法） | `",".join(["a","b","c"])` → `"a,b,c"` |

### 判断类方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `str.isalpha()` | 全为字母 | `"abc".isalpha()` → `True` |
| `str.isdigit()` | 全为数字字符 | `"123".isdigit()` → `True` |
| `str.isdecimal()` | 全为十进制数字 | `"123".isdecimal()` → `True` |
| `str.isnumeric()` | 全为数字（含中文数字等） | `"½".isnumeric()` → `True` |
| `str.isalnum()` | 字母或数字 | `"abc123".isalnum()` → `True` |
| `str.isidentifier()` | 合法标识符 | `"my_var".isidentifier()` → `True` |
| `str.islower()` | 全小写 | `"abc".islower()` → `True` |
| `str.isupper()` | 全大写 | `"ABC".isupper()` → `True` |
| `str.istitle()` | 标题格式 | `"Hello World".istitle()` → `True` |
| `str.isspace()` | 全为空白字符 | `" \t\n".isspace()` → `True` |
| `str.isascii()` | 全为 ASCII | `"abc".isascii()` → `True` |
| `str.isprintable()` | 全为可打印字符 | `"abc".isprintable()` → `True` |

### 清理与编码

| 方法 | 说明 | 示例 |
|------|------|------|
| `str.strip(chars)` | 去除两端指定字符 | `" hi ".strip()` → `"hi"` |
| `str.lstrip(chars)` | 去除左端 | `" hi ".lstrip()` → `"hi "` |
| `str.rstrip(chars)` | 去除右端 | `" hi ".rstrip()` → `" hi"` |
| `str.encode(encoding)` | 编码为 bytes | `"你好".encode("utf-8")` → `b'\xe4\xbd\xa0\xe5\xa5\xbd'` |
| `str.maketrans(x, y)` | 创建翻译表 | `str.maketrans("ae","AE")` |
| `str.translate(table)` | 按翻译表替换 | `"apple".translate(table)` → `"ApplE"` |

```python
len("hello")        # 5（长度）

sorted("hello")     # ['e','h','l','l','o'][[
chr(65)             # 'A'（ASCII 码转字符）
ord('A')            # 65（字符转 ASCII 码）
```
