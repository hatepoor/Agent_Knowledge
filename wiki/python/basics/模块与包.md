# 模块与包

> 模块（Module）是一个 Python 文件，包（Package）是包含多个模块的目录。模块和包是组织 Python 代码的基本单位。

## 模块（Module）

任何 `.py` 文件都是一个模块。模块名就是文件名（不含 `.py`）。

```python
# math_utils.py
def add(a, b):
    return a + b

PI = 3.14159
```

### 导入方式

```python
# 导入整个模块
import math
math.sqrt(16)              # 4.0

# 导入特定对象
from math import sqrt, pi
sqrt(16)                   # 4.0

# 起别名
import numpy as np
from collections import defaultdict as dd

# 导入所有（不推荐，命名空间污染）
from math import *

# 相对导入（包内部使用）
from . import utils            # 同级目录
from .. import config          # 上级目录
from ..utils import helper     # 上级目录的 utils 模块
```

### `__name__` 与 `__main__`

```python
# 每个模块都有 __name__ 属性
# 当模块被直接运行时，__name__ == "__main__"
# 当模块被导入时，__name__ == 模块名

if __name__ == "__main__":
    # 这段代码只在直接运行该文件时执行
    # 被 import 时不会执行
    main()
```

## 包（Package）

包含 `__init__.py` 的目录就是一个包（Python 3.3+ 也支持隐式命名空间包，但推荐使用 `__init__.py`）。

```
my_package/
├── __init__.py          # 包初始化，可以是空的
├── module_a.py
├── module_b.py
└── sub_package/
    ├── __init__.py
    └── module_c.py
```

```python
# 导入包中的模块
import my_package.module_a
from my_package import module_b
from my_package.sub_package import module_c

# __init__.py 可以定义 __all__ 控制 from package import * 的行为
# my_package/__init__.py
from .module_a import func_a
from .module_b import func_b

__all__ = ["func_a", "func_b"]   # import * 时只导出这些
```

## 常用标准库

### 文件与路径

| 模块 | 用途 |
|------|------|
| `os` | 操作系统接口（路径、环境变量、进程） |
| `os.path` | 路径操作（旧式，推荐用 pathlib） |
| `pathlib` | 面向对象的路径操作（推荐） |
| `shutil` | 文件复制、移动、压缩 |
| `glob` | 文件名模式匹配 |
| `tempfile` | 创建临时文件和目录 |

### 数据处理

| 模块 | 用途 |
|------|------|
| `json` | JSON 编解码 |
| `csv` | CSV 文件读写 |
| `re` | 正则表达式 |
| `datetime` | 日期和时间 |
| `collections` | 增强容器（defaultdict, Counter, deque, namedtuple） |
| `itertools` | 迭代器工具 |
| `functools` | 函数工具（partial, lru_cache, wraps） |

### 系统与网络

| 模块 | 用途 |
|------|------|
| `sys` | 系统参数（sys.argv, sys.path） |
| `logging` | 日志框架 |
| `argparse` | 命令行参数解析 |
| `subprocess` | 执行外部命令 |
| `urllib` | HTTP 请求（标准库） |
| `socket` | 底层网络通信 |

### 开发工具

| 模块 | 用途 |
|------|------|
| `typing` | 类型提示 |
| `dataclasses` | 数据类 |
| `enum` | 枚举类型 |
| `abc` | 抽象基类 |
| `unittest` | 单元测试框架 |
| `doctest` | 文档字符串中的测试 |
| `pdb` | 调试器 |

## 包管理

### pip

```bash
pip install requests               # 安装包
pip install requests==2.31.0       # 指定版本
pip install -r requirements.txt    # 从依赖文件安装
pip list                           # 列出已安装包
pip show requests                  # 查看包详情
pip uninstall requests             # 卸载
```

### 虚拟环境

```bash
python -m venv .venv               # 创建虚拟环境
source .venv/bin/activate          # Linux/macOS 激活
.venv\Scripts\activate             # Windows 激活
deactivate                         # 退出虚拟环境
```

### requirements.txt

```
requests==2.31.0
flask>=3.0,<4.0
numpy~=1.26        # 兼容版本：>=1.26, ==1.*
```

## `__init__.py` 的作用

```python
# 1. 标记目录为包（Python 3.3 前必须，现在推荐保留）
# 2. 初始化包级别的变量或导入
# 3. 控制 from package import * 的行为

# my_package/__init__.py 示例
"""我的工具包"""

from .core import process_data
from .utils import helper

__version__ = "1.0.0"

__all__ = ["process_data", "helper"][[   # 明确导出列表
```
