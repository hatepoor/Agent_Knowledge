# 控制流

> 控制流语句决定代码的执行顺序。Python 通过缩进来划分代码块，而非使用花括号。

## 条件语句

### if / elif / else

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
```

### 三元表达式（条件表达式）

```python
status = "成年" if age >= 18 else "未成年"
```

### 模式匹配（match-case，Python 3.10+）

```python
match command:
    case "quit":
        exit()
    case "hello" | "hi":       # 多值匹配
        print("你好！")
    case {"action": "move", "x": x, "y": y}:  # 结构解构
        move(x, y)
    case _:                     # 默认分支（类似 default）
        print("未知命令")
```

## 循环

### for 循环

```python
# 遍历列表
for item in [1, 2, 3]:
    print(item)

# 遍历字典
for key, value in my_dict.items():
    print(f"{key}: {value}")

# range 函数
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 8):       # 2, 3, 4, 5, 6, 7
    print(i)

for i in range(0, 10, 2):   # 0, 2, 4, 6, 8（步长为2）
    print(i)

# enumerate：同时获取索引和值
for i, item in enumerate(["a", "b", "c"]):
    print(f"{i}: {item}")

# zip：并行遍历多个序列
for name, score in zip(["Alice", "Bob"], [90, 85]):
    print(f"{name}: {score}")
```

### while 循环

```python
count = 0
while count < 5:
    print(count)
    count += 1

# while-else：循环正常结束时执行 else
while count < 10:
    count += 1
else:
    print("循环正常结束")  # 不被 break 中断时执行
```

## 循环控制

| 语句 | 作用 |
|------|------|
| `break` | 立即退出循环 |
| `continue` | 跳过本次迭代，进入下一轮 |
| `pass` | 空操作，占位符 |
| `else`（跟在循环后） | 循环未被 `break` 中断时执行 |

```python
# break 示例
for i in range(10):
    if i == 5:
        break       # 到 5 就停
    print(i)        # 输出 0, 1, 2, 3, 4

# continue 示例
for i in range(5):
    if i == 2:
        continue    # 跳过 2
    print(i)        # 输出 0, 1, 3, 4

# for-else：查找失败时执行 else
for item in items:
    if item == target:
        print("找到了！")
        break
else:
    print("没找到")  # 循环没被 break 时执行
```

## 推导式（Comprehensions）

```python
# 列表推导式
squares = [x**2 for x in range(10)]
evens = [x for x in range(20) if x % 2 == 0]

# 字典推导式
word_lengths = {word: len(word) for word in ["hello", "world"]}

# 集合推导式
unique_lengths = {len(word) for word in ["hello", "hi", "hey"]}

# 嵌套推导式
matrix = [[1, 2], [3, 4][[, [5, 6]]
flat = [x for row in matrix for x in row]  # [1, 2, 3, 4, 5, 6][[
```
