# 魔法方法（Dunder Methods）

> 魔法方法（也叫魔术方法、dunder 方法）是 Python 中以双下划线 `__` 开头和结尾的特殊方法。Python 会在特定操作发生时**自动调用**它们，让自定义类表现得像内置类型一样。

## 核心思想

没有魔法方法，你得写 `v1.add(v2)`、`v1.to_string()` 这种普通方法。有了它们，`+`、`len()`、`==`、`for x in obj` 这些操作符和内置函数就能直接用在你的自定义类上：

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __len__(self):
        return int((self.x**2 + self.y**2)**0.5)

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

v1 = Vector(1, 2)
v2 = Vector(3, 4)

print(v1)        # Vector(1, 2)     ← 自动调 __repr__
print(v1 + v2)   # Vector(4, 6)     ← 自动调 __add__
print(len(v1))   # 2                ← 自动调 __len__
print(v1 == v2)  # False            ← 自动调 __eq__
```

## 分类详解

### 1. 对象生命周期

| 方法 | 触发 | 说明 |
|------|------|------|
| `__new__(cls, ...)` | `MyClass(...)` | 创建实例（在 `__init__` 之前），返回新实例 |
| `__init__(self, ...)` | `MyClass(...)` | 初始化实例属性 |
| `__del__(self)` | 垃圾回收时 | 析构方法，慎用 |

```python
class Singleton:
    """__new__ 实现单例模式"""
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
a is b  # True（同一个实例）
```

### 2. 字符串表示

| 方法 | 触发 | 说明 |
|------|------|------|
| `__str__(self)` | `print(obj)` / `str(obj)` | 面向用户的友好字符串 |
| `__repr__(self)` | `repr(obj)` / 交互式显示 | 面向开发者的字符串，理想情况应可重建对象 |

```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def __str__(self):
        """用户看到的"""
        return f"{self.name} ¥{self.price}"

    def __repr__(self):
        """开发者看到的，可以用来重建对象"""
        return f"Product('{self.name}', {self.price})"

p = Product("咖啡", 28)
print(p)          # 咖啡 ¥28           ← __str__
print(repr(p))    # Product('咖啡', 28)  ← __repr__
```

**规则**：如果只实现一个，选 `__repr__`。Python 在找不到 `__str__` 时会自动回退到 `__repr__`，反过来不会。

### 3. 比较运算

| 方法 | 触发 |
|------|------|
| `__eq__(self, other)` | `==` |
| `__ne__(self, other)` | `!=` |
| `__lt__(self, other)` | `<` |
| `__le__(self, other)` | `<=` |
| `__gt__(self, other)` | `>` |
| `__ge__(self, other)` | `>=` |

```python
from functools import total_ordering

@total_ordering  # 只需实现 __eq__ 和一个比较方法，自动补全其余
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __eq__(self, other):
        return self.score == other.score

    def __lt__(self, other):
        return self.score < other.score

    def __repr__(self):
        return f"{self.name}({self.score})"

students = [Student("Alice", 90), Student("Bob", 85), Student("Carol", 95)]
sorted(students)
# [Bob(85), Alice(90), Carol(95)]  ← 自动用 __lt__ 排序
```

### 4. 算术运算

| 方法 | 触发 | 方法 | 触发 |
|------|------|------|------|
| `__add__` | `+` | `__sub__` | `-` |
| `__mul__` | `*` | `__truediv__` | `/` |
| `__floordiv__` | `//` | `__mod__` | `%` |
| `__pow__` | `**` | `__neg__` | `-obj` |
| `__abs__` | `abs(obj)` | `__pos__` | `+obj` |

**反向运算符**（当左操作数不支持时，由右操作数处理）：

| 方法 | 触发 |
|------|------|
| `__radd__(self, other)` | `other + self`（other 不支持 `+`） |
| `__rsub__(self, other)` | `other - self` |
| `__rmul__(self, other)` | `other * self` |

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        """Vector * 3"""
        return Vector(self.x * scalar, self.y * scalar)

    def __rmul__(self, scalar):
        """3 * Vector（左边的 int 不知道乘 Vector，交给右边）"""
        return self.__mul__(scalar)

v = Vector(1, 2)
v * 3    # Vector(3, 6)   ← __mul__
3 * v    # Vector(3, 6)   ← __rmul__（int 的 __mul__ 返回 NotImplemented）
```

### 5. 容器协议

让你的类像 list/dict 一样工作：

| 方法 | 触发 | 说明 |
|------|------|------|
| `__len__(self)` | `len(obj)` | 返回元素个数 |
| `__getitem__(self, key)` | `obj[key]` | 索引/切片访问 |
| `__setitem__(self, key, val)` | `obj[key] = val` | 索引赋值 |
| `__delitem__(self, key)` | `del obj[key]` | 索引删除 |
| `__contains__(self, item)` | `item in obj` | 成员检测 |
| `__iter__(self)` | `for x in obj` | 返回迭代器 |
| `__next__(self)` | `next(obj)` | 迭代器下一步 |

```python
class Matrix:
    """二维矩阵，支持 matrix[1][2] 和 matrix[1, 2] 两种访问"""
    def __init__(self, rows):
        self.rows = rows

    def __len__(self):
        return len(self.rows)

    def __getitem__(self, key):
        if isinstance(key, tuple):
            row, col = key
            return self.rows[row][col]
        return self.rows[key]  # 返回整行，支持 matrix[1]

    def __setitem__(self, key, value):
        row, col = key
        self.rows[row][col] = value

    def __contains__(self, item):
        return any(item in row for row in self.rows)

    def __iter__(self):
        """逐行迭代"""
        return iter(self.rows)

m = Matrix([
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
])

m[1, 2]       # 6         ← __getitem__ with tuple
m[0]          # [1, 2, 3] ← __getitem__ with int
m[1, 1] = 99  #           ← __setitem__
5 in m        # True      ← __contains__
len(m)        # 3         ← __len__
```

### 6. 属性访问

| 方法 | 触发 | 说明 |
|------|------|------|
| `__getattr__(self, name)` | `obj.name`（属性不存在时） | 动态属性，常用于代理/委托模式 |
| `__setattr__(self, name, value)` | `obj.name = value` | 每次属性赋值都触发（包括 `__init__` 中） |
| `__delattr__(self, name)` | `del obj.name` | 属性删除 |
| `__getattribute__(self, name)` | `obj.name`（每次都触发） | 比 `__getattr__` 更底层，慎用 |

```python
class DynamicAttrs:
    """__getattr__ 只在属性不存在时触发"""
    def __init__(self):
        self.name = "Alice"  # 正常属性

    def __getattr__(self, name):
        """访问不存在的属性时触发"""
        return f"动态属性: {name}"

obj = DynamicAttrs()
obj.name      # "Alice"          ← 正常属性，不触发 __getattr__
obj.age       # "动态属性: age"   ← 属性不存在，触发 __getattr__
obj.email     # "动态属性: email"
```

```python
class Validated:
    """__setattr__ 拦截属性赋值，做验证"""
    def __setattr__(self, name, value):
        if name == "age" and (not isinstance(value, int) or value < 0):
            raise ValueError("age 必须是非负整数")
        super().__setattr__(name, value)

v = Validated()
v.age = 25    # 正常
v.age = -1    # ValueError!
```

**常见陷阱**：`__setattr__` 在 `__init__` 中也会触发，所以用 `super().__setattr__` 避免无限递归：

```python
# ❌ 无限递归
class Bad:
    def __setattr__(self, name, value):
        self.name = value  # 又触发 __setattr__ → 死循环

# ✅ 正确
class Good:
    def __setattr__(self, name, value):
        super().__setattr__(name, value)
```

### 7. 可调用对象

`__call__` 让实例可以像函数一样被调用：

```python
class Counter:
    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count

counter = Counter()
counter()   # 1
counter()   # 2
counter()   # 3
```

**实用场景：装饰器类**

```python
class Retry:
    """可重试的装饰器"""
    def __init__(self, max_retries=3):
        self.max_retries = max_retries

    def __call__(self, func):
        def wrapper(*args, **kwargs):
            for i in range(self.max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if i == self.max_retries - 1:
                        raise
                    print(f"重试 {i+1}/{self.max_retries}...")
        return wrapper

@Retry(max_retries=3)
def fetch_data(url):
    # 可能失败的网络请求
    pass
```

### 8. 上下文管理器

`__enter__` + `__exit__` 让对象支持 `with` 语句：

```python
class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        self.elapsed = time.time() - self.start
        print(f"耗时: {self.elapsed:.2f}s")
        return False  # False = 不吞掉异常，True = 吞掉

with Timer() as t:
    sum(range(10_000_000))
# 耗时: 0.15s
```

`__exit__` 的参数：

| 参数 | 含义 |
|------|------|
| `exc_type` | 异常类型（无异常时为 None） |
| `exc_val` | 异常值 |
| `exc_tb` | traceback 对象 |
| 返回值 | `True` = 吞掉异常，`False` = 正常传播 |

### 9. 哈希与集合

| 方法 | 触发 | 说明 |
|------|------|------|
| `__hash__(self)` | `hash(obj)` | 返回哈希值（用于 dict key 和 set） |
| `__eq__(self, other)` | `obj == other` | 相等比较 |

**规则**：如果实现了 `__eq__`，Python 会自动将 `__hash__` 设为 None（不可哈希）。如果你的类需要作为 dict 的 key 或放入 set，必须同时实现两者：

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

    def __hash__(self):
        return hash((self.x, self.y))  # 基于不可变属性

p1 = Point(1, 2)
p2 = Point(1, 2)
{p1, p2}   # {Point(1, 2)}  ← 去重，因为 hash 和 eq 都一致
```

## 常见陷阱

### 陷阱 1：__str__ 和 __repr__ 搞混

```python
# __str__ 面向用户，__repr__ 面向开发者
# 只实现一个时，选 __repr__
# Python 在找不到 __str__ 时会自动用 __repr__

class Item:
    def __repr__(self):
        return "Item('apple', 5)"  # 可以直接 eval 重建

# ❌ 不要这样：__str__ 不返回有意义的信息
def __str__(self):
    pass  # 返回 None，print() 会报错

# ✅ 正确
def __str__(self):
    return "apple ¥5"
```

### 陷阱 2：__setattr__ 无限递归

```python
# ❌ __setattr__ 中用 self.x = val 会无限递归
class Bad:
    def __setattr__(self, name, value):
        self.x = value  # 又触发 __setattr__！

# ✅ 用 super().__setattr__ 或 object.__setattr__
class Good:
    def __setattr__(self, name, value):
        super().__setattr__(name, value)
```

### 陷阱 3：__eq__ 和 __hash__ 不一致

```python
# 如果两个对象 __eq__ 返回 True，它们的 __hash__ 必须相同
# 否则 dict/set 行为会异常

# ❌ 错误：__eq__ 基于 name，__hash__ 基于 id
class Bad:
    def __eq__(self, other):
        return self.name == other.name
    # __hash__ 被自动设为 None → 不可哈希

# ✅ 正确：__hash__ 和 __eq__ 基于相同属性
class Good:
    def __eq__(self, other):
        return self.name == other.name
    def __hash__(self):
        return hash(self.name)
```

### 陷阱 4：__getattr__ vs __getattribute__

```python
# __getattr__：属性不存在时才触发（安全）
# __getattribute__：每次都触发（危险，容易递归）

class Safe:
    def __getattr__(self, name):
        return f"没有 {name} 这个属性"

class Dangerous:
    def __getattribute__(self, name):
        # 即使访问 self.x 也会触发 __getattribute__ → 递归
        return self.x  # ❌ 无限递归！

    # ✅ 正确用法
    def __getattribute__(self, name):
        return super().__getattribute__(name)
```
