# Python 输入输出

> Python 的标准输入输出通过 `print()` 和 `input()` 实现。`print()` 支持丰富的格式化能力，f-string 是最推荐的格式化方式。

## print() 函数

### 基础用法

```python
print("Hello, World!")                    # 输出字符串
print(42)                                 # 输出数字
print([1, 2, 3])                          # 输出列表（自动调用 __repr__）
print("Name:", "Alice", "Age:", 30)       # 多参数，默认空格分隔
```

### 参数详解

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `*objects` | — | 要输出的对象（可多个） |
| `sep` | `" "` | 多个对象之间的分隔符 |
| `end` | `"\n"` | 输出结尾字符 |
| `file` | `sys.stdout` | 输出目标（文件流） |
| `flush` | `False` | 是否立即刷新缓冲区 |

```python
# sep：自定义分隔符
print("a", "b", "c", sep=", ")           # a, b, c
print("a", "b", "c", sep="")             # abc
print("2026", "07", "08", sep="-")       # 2026-07-08

# end：自定义结尾
print("hello", end=" ")
print("world")                           # hello world（同一行）

for i in range(5):
    print(i, end=" ")                    # 0 1 2 3 4（不换行）

# file：输出到文件
with open("output.txt", "w") as f:
    print("Hello", file=f)               # 写入文件而非终端

# flush：立即刷新（进度条常用）
import time
for i in range(10):
    print(f"\r进度: {i*10}%", end="", flush=True)
    time.sleep(0.5)
```

## f-string 格式化（推荐）

f-string 是 Python 3.6+ 引入的格式化方式，以 `f` 或 `F` 前缀标记字符串，花括号 `{}` 内嵌入表达式。

### 基础用法

```python
name = "Alice"
age = 30

# 嵌入变量
print(f"姓名: {name}, 年龄: {age}")       # 姓名: Alice, 年龄: 30

# 嵌入表达式
print(f"明年 {name} 就 {age + 1} 岁了")   # 明年 Alice 就 31 岁了

# 嵌入函数调用
print(f"名字长度: {len(name)}")           # 名字长度: 5

# 嵌入条件表达式
status = "成年" if age >= 18 else "未成年"
print(f"{name} 是 {status}")              # Alice 是 成年

# Python 3.8+ 调试格式（= 自动显示变量名和值）
print(f"{name=}, {age=}")                # name='Alice', age=30
```

### 数字格式化

```python
pi = 3.141592653589793
big_num = 1234567890

# 小数位数
print(f"{pi:.2f}")                       # 3.14（保留2位小数）
print(f"{pi:.4f}")                       # 3.1416（保留4位，四舍五入）
print(f"{pi:.0f}")                       # 3（无小数）

# 千分位分隔
print(f"{big_num:,}")                    # 1,234,567,890
print(f"{big_num:_}")                    # 1_234_567_890（下划线分隔）

# 百分比
ratio = 0.8567
print(f"{ratio:.1%}")                    # 85.7%
print(f"{ratio:.2%}")                    # 85.67%

# 科学计数法
print(f"{big_num:.2e}")                  # 1.23e+09
print(f"{big_num:.2E}")                  # 1.23E+09

# 进制转换
num = 255
print(f"{num:b}")                        # 11111111（二进制）
print(f"{num:o}")                        # 377（八进制）
print(f"{num:x}")                        # ff（十六进制小写）
print(f"{num:X}")                        # FF（十六进制大写）
print(f"{num:#b}")                       # 0b11111111（带前缀）
print(f"{num:#x}")                       # 0xff（带前缀）
```

### 字符串格式化

```python
text = "hello"

# 对齐方式
print(f"{text:<10}|")                    # hello     |（左对齐，宽10）
print(f"{text:>10}|")                    #      hello|（右对齐，宽10）
print(f"{text:^10}|")                    #   hello   |（居中，宽10）

# 填充字符
print(f"{text:*^10}")                    # **hello***（用 * 填充居中）
print(f"{text:->10}")                    # -----hello（用 - 填充右对齐）

# 截断
long_text = "Hello, World!"
print(f"{long_text:.5}")                 # Hello（截取前5个字符）
print(f"{long_text:.5:>10}")            #      Hello（截断后右对齐）

# 大小写转换
print(f"{text!r}")                       # 'hello'（repr 格式）
print(f"{text!s}")                       # hello（str 格式）
print(f"{text!a}")                       # 'hello'（ascii 格式）
```

### 日期时间格式化

```python
from datetime import datetime

now = datetime(2026, 7, 8, 14, 30, 45)

print(f"{now:%Y-%m-%d}")                 # 2026-07-08
print(f"{now:%H:%M:%S}")                 # 14:30:45
print(f"{now:%Y年%m月%d日}")             # 2026年07月08日
print(f"{now:%Y-%m-%d %H:%M:%S}")        # 2026-07-08 14:30:45
print(f"{now:%A}")                       # Wednesday（星期全称）
print(f"{now:%a}")                       # Wed（星期缩写）
print(f"{now:%B}")                       # July（月份全称）
print(f"{now:%b}")                       # Jul（月份缩写）
```

### 对齐表格输出

```python
# 生成对齐的表格
headers = ["姓名", "年龄", "城市"]
data = [
    ("Alice", 30, "Beijing"),
    ("Bob", 25, "Shanghai"),
    ("Charlie", 35, "Guangzhou"),
]

# 表头
print(f"{'姓名':<8} {'年龄':>4} {'城市':<10}")
print("-" * 24)

# 数据行
for name, age, city in data:
    print(f"{name:<8} {age:>4} {city:<10}")

# 输出：
# 姓名       年龄 城市      
# ------------------------
# Alice      30 Beijing   
# Bob        25 Shanghai  
# Charlie    35 Guangzhou 
```

### 动态宽度和精度

```python
width = 10
precision = 3
value = 3.14159

# 动态宽度
print(f"{value:{width}.{precision}f}")   # "     3.142"

# 动态精度
for p in range(1, 5):
    print(f"π ≈ {pi:.{p}f}")
# π ≈ 3.1
# π ≈ 3.14
# π ≈ 3.142
# π ≈ 3.1416
```

## 其他格式化方式

### str.format()

```python
name, age = "Alice", 30

# 位置参数
print("{} is {} years old".format(name, age))

# 命名参数
print("{name} is {age} years old".format(name="Alice", age=30))

# 索引
print("{0} {1} {0}".format("hello", "world"))  # hello world hello

# 格式化规范（与 f-string 相同）
print("{:>10}".format("hi"))             # "        hi"
print("{:.2f}".format(3.14159))          # "3.14"
print("{:,}".format(1234567))            # "1,234,567"
```

### % 格式化（旧式）

```python
name, age = "Alice", 30

print("%s is %d years old" % (name, age))
print("Pi is %.2f" % 3.14159)
print("%10s" % "hi")                     # "        hi"
print("%-10s" % "hi")                    # "hi        "
```

### 三种方式对比

| 特性 | f-string | str.format() | % 格式化 |
|------|----------|-------------|---------|
| 可读性 | 最高 | 高 | 低 |
| 性能 | 最快 | 中 | 慢 |
| 灵活性 | 高 | 高 | 低 |
| 版本要求 | 3.6+ | 2.6+ | 所有 |
| 推荐度 | **首选** | 模板复用 | 避免使用 |

## 标准输入：input()

```python
# 基础用法（返回字符串）
name = input("请输入姓名：")
print(f"你好, {name}!")

# 转为数值
age = int(input("请输入年龄："))
price = float(input("请输入价格："))

# 带默认值
response = input("继续？(y/n) [y]: ").strip() or "y"

# 多行输入
print("请输入多行文本（空行结束）：")
lines = [][[
while True:
    line = input()
    if not line:
        break
    lines.append(line)
text = "\n".join(lines)

# 密码输入（不回显）
import getpass
password = getpass.getpass("请输入密码：")
```

### input() 注意事项

```python
# input() 始终返回 str
value = input("输入数字：")
type(value)              # <class 'str'>

# 需要手动转换类型
num = int(input("输入整数："))
flt = float(input("输入浮点数："))

# 处理空输入
raw = input("输入（可为空）：")
if raw.strip():
    value = int(raw)
else:
    value = 0  # 默认值

# 安全转换（避免 ValueError）
def safe_int(prompt, default=0):
    raw = input(prompt)
    try:
        return int(raw)
    except ValueError:
        return default

age = safe_int("年龄：", default=18)
```
