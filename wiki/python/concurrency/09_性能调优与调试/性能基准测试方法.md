# 性能基准测试方法

> 系统化的性能测试框架和 Amdahl 定律指导并发优化上限。

## 基准测试框架

```python
import time
import statistics

def benchmark(func, runs=5, *args, **kwargs):
    """运行多次取平均"""
    times = []
    for _ in range(runs):
        start = time.perf_counter()
        func(*args, **kwargs)
        times.append(time.perf_counter() - start)

    avg = statistics.mean(times)
    best = min(times)
    worst = max(times)

    print(f"  {func.__name__}:")
    print(f"    平均: {avg:.4f}s, 最佳: {best:.4f}s, 最差: {worst:.4f}s")
    return avg
```

## Amdahl 定律

```python
def amdahl_speedup(serial_ratio, num_processors):
    """加速比 = 1 / (S + (1-S)/N)
    S = 串行比例, N = 处理器数"""
    return 1 / (serial_ratio + (1 - serial_ratio) / num_processors)

# 不同串行比例下的加速比（8 核）
for s in [0.01, 0.05, 0.10, 0.20, 0.50]:
    speedup = amdahl_speedup(s, 8)
    max_speedup = 1 / s
    print(f"  串行 {s*100:>4.0f}%: 加速 {speedup:.2f}x (上限 {max_speedup:.1f}x)")
```

输出：
```
串行 1%: 加速 7.06x (上限 100.0x)
串行 5%: 加速 5.93x (上限 20.0x)
串行 10%: 加速 4.71x (上限 10.0x)
串行 20%: 加速 3.33x (上限 5.0x)
串行 50%: 加速 1.78x (上限 2.0x)
```

## 线程数优化实验

```python
import time
from concurrent.futures import ThreadPoolExecutor
import requests

urls = ["https://httpbin.org/delay/0.5"] * 50

for num_workers in [1, 5, 10, 20, 50, 100]:
    start = time.perf_counter()
    with ThreadPoolExecutor(max_workers=num_workers) as ex:
        list(ex.map(requests.get, urls))
    elapsed = time.perf_counter() - start
    print(f"  {num_workers:>3} 线程: {elapsed:.2f}s")

# 典型：20 线程接近最优，100 线程反而变慢
```
