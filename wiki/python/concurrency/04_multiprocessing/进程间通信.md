# 进程间通信（IPC）

> 多进程中每个进程有独立内存空间，必须通过 IPC（进程间通信）机制传递数据。`multiprocessing` 提供 Queue 和 Pipe 两种方式。

## Queue

```python
from multiprocessing import Process, Queue
import time

def producer(q):
    for i in range(10):
        item = f"产品-{i}"
        q.put(item)
        print(f"  [生产者] 生产 {item}")
        time.sleep(0.1)
    q.put(None)  # 哨兵值

def consumer(q):
    while True:
        item = q.get()
        if item is None:
            break
        print(f"  [消费者] 消费 {item}")
        time.sleep(0.2)

if __name__ == "__main__":
    q = Queue(maxsize=5)
    p = Process(target=producer, args=(q,))
    c = Process(target=consumer, args=(q,))
    p.start(); c.start()
    p.join(); c.join()
```

**注意**：`multiprocessing.Queue` 不是 `queue.Queue`。前者通过 pickle 序列化传递数据，后者直接内存共享。

## Pipe

```python
from multiprocessing import Process, Pipe

def sender(conn):
    for i in range(5):
        conn.send(f"消息-{i}")
    conn.close()

def receiver(conn):
    while True:
        msg = conn.recv()
        if msg is None:
            break
        print(f"  收到: {msg}")
    conn.close()

if __name__ == "__main__":
    parent_conn, child_conn = Pipe()
    p1 = Process(target=sender, args=(parent_conn,))
    p2 = Process(target=receiver, args=(child_conn,))
    p1.start(); p2.start()
    p1.join()
    child_conn.send(None)
    p2.join()
```

## Queue vs Pipe

| 维度 | Queue | Pipe |
|------|-------|------|
| 通信方向 | 多对多 | 一对一 |
| 底层 | Pipe + Lock | 原始管道 |
| 性能 | 略低（额外同步） | 略高 |
| 功能 | put/get/put_nowait | send/recv/poll |
| 缓冲 | 有（maxsize 可配） | OS 管道缓冲区 |
| 多消费者 | 支持 | 不支持 |
