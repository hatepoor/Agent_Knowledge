# 进程启动方式

> `multiprocessing` 支持三种进程启动方式，各有优缺点和平台限制。

## 三种方式

| 方式 | 说明 | 适用平台 | 默认 |
|------|------|----------|------|
| `spawn` | 重新启动 Python 进程，导入模块 | Windows, macOS (3.8+) | Windows/macOS |
| `fork` | fork 系统调用，复制进程 | Unix | Linux (3.13 前) |
| `forkserver` | 预创建服务进程，按需 fork | Unix | — |

## 设置方式

```python
import multiprocessing as mp

# 必须在创建任何 Process/Pool 之前设置
mp.set_start_method('spawn', force=True)
```

## fork vs spawn

```
fork: 子进程继承父进程的内存（写时复制）
  - 优点：启动快，内存共享
  - 缺点：不安全（fork 后锁状态不一致、线程丢失）

spawn: 子进程从零启动，重新导入模块
  - 优点：安全，干净的状态
  - 缺点：启动慢，所有对象需要 pickle 传输
```

**Python 3.14+ 默认改为 `spawn`**：从 Python 3.14 开始，所有平台默认使用 `spawn`，因为 `fork` 与多线程不安全。

## 常见陷阱

### Windows 上必须用 `if __name__ == "__main__"`

```python
# 错误（Windows 上会无限递归创建进程）
p = Process(target=func)
p.start()

# 正确
if __name__ == "__main__":
    p = Process(target=func)
    p.start()
```

### 参数必须可 pickle

```python
from multiprocessing import Process
import threading

def worker(x): pass

# Lock 不可 pickle
lock = threading.Lock()
p = Process(target=worker, args=(lock,))  # TypeError

# lambda 不可 pickle
p = Process(target=lambda: print("hi"))  # AttributeError

# 正确：使用 multiprocessing.Lock
from multiprocessing import Lock
lock = Lock()
p = Process(target=worker, args=(lock,))  # OK
```
