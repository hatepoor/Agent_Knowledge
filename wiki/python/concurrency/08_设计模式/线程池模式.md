# 线程池模式

> 预创建一组工作线程，复用线程处理大量同类任务，避免频繁创建销毁开销。

## 原理

```
     ┌─────────────────────────────────────────────────┐
     │              任务队列 (Task Queue)                │
     │  [任务1] [任务2] [任务3] [任务4] [任务5] [任务6]   │
     └─────────────────────────────────────────────────┘
                         ↓ 分发
     ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
     │ Worker 1 │ │ Worker 2 │ │ Worker 3 │ │ Worker 4 │
     └──────────┘ └──────────┘ └──────────┘ └──────────┘
```

## 实现（concurrent.futures 方式）

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
import time
import random

def process_task(task_id, data):
    delay = random.uniform(0.5, 2.0)
    time.sleep(delay)
    return {"task_id": task_id, "result": data * 2, "time": delay}

tasks = [(i, random.randint(1, 100)) for i in range(20)]

with ThreadPoolExecutor(max_workers=4) as executor:
    future_to_task = {
        executor.submit(process_task, tid, data): (tid, data)
        for tid, data in tasks
    }
    for future in as_completed(future_to_task):
        result = future.result()
        print(f"  完成: {result}")
```

## 自定义工作线程池

```python
import threading
import queue

class WorkerPool:
    def __init__(self, num_workers, worker_func):
        self.task_queue = queue.Queue()
        self.result_queue = queue.Queue()
        self._stop = threading.Event()
        self._workers = []
        for i in range(num_workers):
            t = threading.Thread(target=self._worker_loop, args=(i, worker_func), daemon=True)
            self._workers.append(t)
            t.start()

    def _worker_loop(self, worker_id, worker_func):
        while not self._stop.is_set():
            try:
                task_id, args = self.task_queue.get(timeout=1)
            except queue.Empty:
                continue
            try:
                result = worker_func(*args)
                self.result_queue.put((task_id, result, None))
            except Exception as e:
                self.result_queue.put((task_id, None, e))
            self.task_queue.task_done()

    def submit(self, task_id, *args):
        self.task_queue.put((task_id, args))

    def join(self):
        self.task_queue.join()
```
