# 生产者-消费者模式

> 解耦生产与消费速率，通过队列缓冲自动平衡速率差异。

## 原理

```
     ┌──────────┐         ┌──────────┐         ┌──────────┐
     │ Producer │ ──put──→ │   Queue  │ ──get──→ │ Consumer │
     │ (生产者)  │         │ (缓冲区)  │         │ (消费者)  │
     └──────────┘         └──────────┘         └──────────┘
          ↑                                           ↑
     速率可能快或慢                              速率可能快或慢
     Queue 自动平衡速率差异
```

## 基本实现

```python
import threading
import queue
import time
import random

task_queue = queue.Queue(maxsize=10)
result_queue = queue.Queue()
stop_event = threading.Event()

def producer(pid):
    item_id = 0
    while not stop_event.is_set():
        item = f"产品-P{pid}-{item_id}"
        task_queue.put(item, timeout=1)
        print(f"  [生产者-{pid}] 生产: {item}")
        item_id += 1
        time.sleep(random.uniform(0.01, 0.2))

def consumer(cid):
    while not stop_event.is_set() or not task_queue.empty():
        try:
            item = task_queue.get(timeout=1)
            time.sleep(random.uniform(0.01, 0.3))
            result_queue.put(f"处理完-{item}")
            task_queue.task_done()
        except queue.Empty:
            continue

# 启动 2 个生产者 + 3 个消费者
producers = [threading.Thread(target=producer, args=(i,), daemon=True) for i in range(2)]
consumers = [threading.Thread(target=consumer, args=(i,), daemon=True) for i in range(3)]
for t in producers + consumers: t.start()

time.sleep(5)
stop_event.set()
for t in producers + consumers: t.join(timeout=2)
```

## 优先级变体

```python
from queue import PriorityQueue

class PriorityTask:
    def __init__(self, priority, data):
        self.priority = priority
        self.data = data
    def __lt__(self, other):
        return self.priority < other.priority

pq = PriorityQueue()
pq.put(PriorityTask(3, "低优先级"))
pq.put(PriorityTask(1, "高优先级"))
# 消费者先获取高优先级任务
```
