# 线程安全与原子操作

> 线程安全是多线程编程的核心概念。GIL 保证了单条字节码的原子性，但不保证多步操作的原子性。

## 什么是线程安全

一个函数或数据结构在**多线程环境下被同时调用时，不需要额外的同步就能正确工作**，则称为线程安全的。

## 原子操作

GIL 使得**某些**单条字节码操作是原子的：

```python
# 以下操作在 GIL 下是原子的（单条字节码完成）
x = 5              # STORE_NAME
x.attr = value     # STORE_ATTR，GIL 下原子
list.append(x)     # 单条字节码调用，GIL 下原子
list[i] = x        # STORE_SUBSCR，GIL 下原子

# 以下操作不是原子的
x += 1             # 多条字节码
dict[key] += 1     # 多条字节码
```

```python
# 验证：list.append 在 GIL 下是原子的
import threading

data = []
def append_items(n):
    for i in range(n):
        data.append(i)

threads = [threading.Thread(target=append_items, args=(10000,)) for _ in range(5)]
for t in threads: t.start()
for t in threads: t.join()
print(len(data))  # 50000，正确
```

**注意**：依赖 GIL 的原子性是一种脆弱的假设。Python 文档**不正式保证**字节码层面的原子性，行为可能在实现层面变化。**生产代码应该始终使用显式同步原语。**

## 线程安全的实现方式

### 1. 互斥锁

```python
import threading

class SafeCounter:
    def __init__(self):
        self._count = 0
        self._lock = threading.Lock()

    def increment(self):
        with self._lock:
            self._count += 1

    def get(self):
        with self._lock:
            return self._count
```

### 2. 不可变对象

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class ImmutablePoint:
    x: float
    y: float

# 不可变对象天然线程安全
point = ImmutablePoint(1.0, 2.0)
new_point = ImmutablePoint(point.x + 1, point.y)  # 新对象
```

### 3. 线程局部存储

```python
import threading

local_data = threading.local()

def worker(worker_id):
    local_data.worker_id = worker_id  # 每个线程独立
    local_data.counter = 0
    for _ in range(5):
        local_data.counter += 1
        print(f"  Worker-{local_data.worker_id}: counter={local_data.counter}")
```
