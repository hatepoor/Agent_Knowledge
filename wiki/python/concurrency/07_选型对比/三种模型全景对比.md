# 三种并发模型全景对比

> Python 提供三种主流并发模型：threading、multiprocessing、asyncio。本页通过核心维度对比帮助建立全景认知。

## 核心维度对比

| 维度 | threading | multiprocessing | asyncio |
|------|-----------|----------------|---------|
| **执行单元** | 线程（OS 调度） | 进程（OS 调度） | 协程（用户态调度） |
| **GIL 限制** | 受限 | 不受限 | 不适用 |
| **并行能力** | I/O 并行，CPU 不并行 | CPU 真并行 | I/O 并行，CPU 不并行 |
| **内存模型** | 共享内存 | 独立内存空间 | 单线程，无竞争 |
| **启动开销** | ~0.01ms | ~10-100ms | ~0.001ms |
| **并发规模** | 百~千 | 十~百 | 万~十万 |
| **代码侵入** | 低（同步风格） | 中（需 pickle） | 高（async/await） |
| **调试难度** | 中 | 高 | 高 |
| **生态兼容** | 几乎所有同步库 | 大部分库 | 需异步库 |

## 并发与并行图解

```
=== threading（GIL 限制下的并发）===
线程1:  [I/O等]  [计算]  [I/O等]  [计算]
线程2:      [I/O等]  [计算]  [I/O等]
        ↑ I/O 等待时释放 GIL，可并发
        ↑ 计算时持有 GIL，不能并行

=== multiprocessing（真正的并行）===
CPU核心1:  [计算]  [计算]  [计算]
CPU核心2:  [计算]  [计算]  [计算]
CPU核心3:  [计算]  [计算]  [计算]
CPU核心4:  [计算]  [计算]  [计算]
        ↑ 每个进程独立 GIL，真正的多核并行

=== asyncio（单线程并发）===
事件循环: ──────────────────────────→
协程1:  [await I/O]        [继续]
协程2:       [await I/O]   [继续]
        ↑ 单线程内交替执行，I/O 等待不占 CPU
```

## 代码侵入性对比

| 维度 | threading | multiprocessing | asyncio |
|------|-----------|----------------|---------|
| 函数签名 | 无需修改 | 无需修改 | 必须 `async def` |
| 调用方式 | 普通调用 | 普通调用 | 必须 `await` |
| 库依赖 | 同步库 | 同步库 | 异步库 |
| 测试 | 直接调用 | 需要 `if __name__` | 需要 `asyncio.run()` |
