# Docker 学习路线图

> 目标：从"能跑起来一个容器"到"能构建镜像、编排多容器、把服务跑进生产"。路线按阶段划分，每阶段有明确的**能力出口**与**自测清单**。

## 一、总览

| 阶段 | 能力出口（学完能做到什么） | 组织范式 |
|------|----------------------------|----------|
| 一、入门 | 会拉镜像、会起停容器、会写 Dockerfile、会用 Compose 起一套多容器服务 | 顺序章节式 |
| 二、中段 | 镜像能做小、容器能隔离、能配资源限制、能接 CI/CD、能上生产 | 平行专题式 |
| 三、沙箱（应用专题） | 能用 Docker 给 Agent 搭建安全的代码执行环境 | 场景方案式 |

**关键前置**：本地必须有一个**可用的 Docker 环境**。Windows / macOS 装 Docker Desktop，Linux 装 Docker Engine，见 [[docker/01-入门阶段-基础教程/第00章-学前准备/0.3-跑通第一个容器]]。

**起点**：零基础请从 [[docker/01-入门阶段-基础教程/第00章-学前准备/0.1-容器与Docker是什么]] 开始，它不要求任何前置知识。

**自学时的常备参考（遇到不认识的东西查这三处）**

| 卡在哪 | 查哪里 |
|--------|--------|
| 不认识的**命令或名词**（`docker exec`、`containerd`、`overlay2`…） | [[docker/Docker命令与术语手册]] |
| 忘记**参数或语法**（`-v` 还是 `--mount`、`CMD` 和 `ENTRYPOINT` 的区别） | [[docker/速查索引]] |
| 看不懂**报错** | [[docker/01-入门阶段-基础教程/第00章-学前准备/0.4-看懂报错信息]] |

**阶段一自测清单**

- [ ] 能说清**镜像**（image）与**容器**（container）的区别，以及"容器是镜像的运行实例"这句话的确切含义
- [ ] 能解释 `docker run` 与 `docker start` 的区别，以及 `docker run --rm` 的作用
- [ ] 能说明容器内进程的 **PID 1** 是什么，以及为什么它决定了容器会不会"自动退出"
- [ ] 能写出一个多阶段构建的 Dockerfile，并说出为什么它能减小镜像体积
- [ ] 能解释 `COPY` 与容器运行时 `-v` 挂载的区别（一个是构建期，一个是运行期）
- [ ] 能解释 `CMD` 与 `ENTRYPOINT` 的区别，以及两者同时存在时会发生什么
- [ ] 能说出**匿名卷**、**具名卷**、**绑定挂载**三者的差异与各自适用场景
- [ ] 能解释为什么两个容器默认**无法**通过容器名互相访问，以及自定义网络如何解决它
- [ ] 能用 `docker compose up -d` 起一套 `app + db` 服务，并用 `docker compose logs -f` 排错
- [ ] 能对容器施加内存与 CPU 限制，并验证限制生效

## 五、难度分层与"看不懂怎么办"

Docker 的学习曲线有个特点：**前面非常平，后面突然陡**。

| 阶段 | 曲线特征 | 典型卡点 | 卡住时怎么办 |
|------|----------|----------|--------------|
| 入门 | 平缓，命令即效果 | 命令背后的"为什么"不清楚 | 不必深究，先会用，中段会补上原理 |
| 中段 | 变陡，需要理解隔离机制 | 资源限制、网络、安全为何这样设计 | 回到入门对应章节确认基础概念 |
| 沙箱 | 最陡，涉及内核与安全边界 | 隔离强度、逃逸面 | 先看 [[agent/harness/Agent沙箱与安全隔离]] 建立全局观 |

> **重要**：中段阶段会大量出现 `namespace`（命名空间）、`cgroup`（控制组）、`overlayfs`（联合文件系统）这类术语。这些是**容器隔离的底层机制**，入门阶段会明确标注"这是中段内容"而不展开——**如果你在入门阶段看到它们感到困惑，那是正常的，不要在入门阶段硬啃。**
