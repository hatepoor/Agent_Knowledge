# 中段阶段 · 专题导航

> **组织范式：平行专题式。** 本阶段的主题之间**没有依赖关系**——"镜像瘦身"与"网络安全"谁先看都行。因此目录**不带序号**，每个专题是一个自包含的"工具箱"，可跳读、可按需抽取。
>
> 每个专题内部采用四段结构：**专题概览 → 方法清单 → 实战要点 → 常见陷阱**。

## 学习建议

1. **先看"何时该翻这个专题"那一列。** 中段知识不是用来背的，是用来查的。
2. **每个专题的"常见陷阱"优先级最高** —— 那是实战里真正付出过代价的部分。
3. **遇到问题时的推荐排查路径**：
   [[docker/01-入门阶段-基础教程/第05章-资源限制与日常维护/5.3-容器排错流程|容器排错流程]] →
   按现象定位到对应专题 →
   若涉及底层机制（namespace / cgroup / veth），转入《容器隔离内核》（进阶阶段，规划中）。
4. **不要跳过入门阶段直接看安全加固。** 安全加固的每一条措施（`--cap-drop`、`--read-only`、`--user`、`no-new-privileges`）都建立在"理解容器默认行为"的基础上，否则会变成抄配置。
