# 入门阶段 · 章节目录

> **组织范式：顺序章节式。** 本阶段的知识彼此存在依赖：镜像 → 容器 → 构建 → 数据与网络 → 编排 → 运维。因此目录带序号，**请按顺序推进，不要跳。**
>
> 每篇文档统一采用五段结构：**学习目标 → 前置知识 → 正文 → 小结 → 练习**。
>
> **零基础请从第 00 章开始。** 第 00 章不要求任何前置知识，只解决三件事：让你装好环境、跑通第一个容器、看懂报错。
>
> **入门阶段的定位**：学完能**独立把一套服务容器化并跑起来**（拉镜像 → 起容器 → 写 Dockerfile 自建镜像 → 挂卷存数据 → 配网络通信 → 用 Compose 编排）。镜像优化、安全加固、CI/CD、内核原理属于中段与进阶阶段。

## 本阶段统一实践项目

本阶段所有练习围绕**同一个项目**展开，便于概念层层叠加而不必反复换例子：

> **目标**：把「一个 Python Web 应用 + PostgreSQL 数据库」完整容器化。

| 章 | 在这个项目里做什么 |
|----|--------------------|
| 第00章 | 装好环境，跑通 nginx 容器 |
| 第01章 | 拉取 `postgres:18` 与 `python:3.12-slim`，管理这些镜像与容器 |
| 第02章 | 为自己的 Python 应用写 Dockerfile，构建出镜像 `myapp:1.0` |
| 第03章 | 给数据库挂数据卷（数据不丢）；让应用容器能通过服务名访问数据库 |
| 第04章 | 用 `compose.yaml` 把应用与数据库编排成一套，一条命令启动 |
| 第05章 | 给两个容器加资源限制，检查磁盘占用，练习排错 |

> **给初学者的提示**：第 00 章就会用到 `-p`、`-v` 这类参数，但它们的完整讲解在第 03 章。**现在看不懂细节完全正常，照着敲即可**——等学完第 03 章回头看，每一段都会读得懂。这不影响练习。
