# 沙箱常见使用案例（端到端）

三个完整场景：数据分析、代码审查、代码生成。每个含 skill 文件 + Agent 配置 + 沙箱执行流程，可直接套用到自己的项目。

---

## 一、数据分析 Agent

**场景**：用户上传 CSV，Agent 在沙箱中用 pandas 分析数据并返回统计结果。

### 1.1 Skill 文件

```python
# skills_data/data_analysis.py
import pandas as pd
import json
import sys
from pathlib import Path

def analyze(csv_path: str):
    """分析 CSV 数据，返回统计摘要"""
    df = pd.read_csv(csv_path)
    return {
        "rows": len(df),
        "columns": list(df.columns),
        "dtypes": {c: str(df[c].dtype) for c in df.columns},
        "numeric_summary": df.describe().to_dict(),
        "missing_values": df.isnull().sum().to_dict(),
    }

if __name__ == "__main__":
    csv_path = sys.argv[1] if len(sys.argv) > 1 else "/workspace/data.csv"
    result = analyze(csv_path)
    print(json.dumps(result, ensure_ascii=False, indent=2, default=str))
```

### 1.2 Agent 配置

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ToolCallLimitMiddleware, SummarizationMiddleware
from sandbox.tools import sandbox_execute, sandbox_run_skill
from langchain_deepseek import ChatDeepSeek

llm = ChatDeepSeek(model="deepseek-v4-flash", temperature=0.0)

data_analysis_agent = create_agent(
    model=llm,
    tools=[
        sandbox_execute,
        sandbox_run_skill,
    ],
    system_prompt="""你是数据分析助手。工作流程：
1. 调用 sandbox_run_skill("data_analysis") 加载分析技能
2. 用 sandbox_execute 在沙箱中运行分析脚本
3. 把统计结果用简洁的中文表格回复用户

重要：所有数据处理必须在沙箱中执行，不要在本地处理。""",
    middleware=[
        ToolCallLimitMiddleware(run_limit=8),
        SummarizationMiddleware(model=llm, trigger=("tokens", 4000)),
    ],
)
```

### 1.3 执行流程

```
用户: "分析 /workspace/data.csv 的数据分布"
  │
  ▼
Agent 第 1 轮: 加载 skill
  → sandbox_run_skill("data_analysis", input_text="/workspace/data.csv")
  → 沙箱执行 data_analysis.py，返回分析结果 JSON
  │  （容器: CPU 1核 / 内存 512m / 网络禁用 / 超时 60s）
  │
  ▼
Agent 第 2 轮: 直接回复用户
  → "数据共 1000 行，5 列。数值列：age, salary...
     缺失值：age 列缺 12 个，salary 列缺 3 个。
     salary 平均值 8500，标准差 2300..."
```

### 1.4 关键配置

| 配置 | 值 | 原因 |
|------|-----|------|
| `memory_limit` | `512m` | pandas 加载大 CSV 需要更多内存 |
| `timeout` | `60s` | 数据分析可能较慢 |
| `network_enabled` | `False` | 纯本地分析不需要网络 |
| `tools` | 2 个 | sandbox_execute + sandbox_run_skill |

## 二、代码审查 Agent

**场景**：用户提交代码，Agent 在沙箱中执行审查技能，按安全/性能/规范三个维度给出报告。

### 2.1 Skill 文件

```markdown
---
name: code_review
description: 按 SQL注入/XSS/性能/规范三维度审查代码
tags: [代码审查, 安全, 性能]
version: 1.0
triggers: ["审查代码", "review", "code review"]
---

# 代码审查技能

## 角色
你是一位资深代码审查专家。

## 审查流程
1. 检查安全隐患：SQL 注入、XSS、敏感信息泄露、路径遍历
2. 检查性能问题：N+1 查询、不必要的循环、内存泄漏
3. 检查代码规范：命名、注释、函数长度、单一职责
4. 检查错误处理：未捕获异常、边界条件

## 输出格式
| # | 严重程度 | 维度 | 问题 | 建议 |
|---|---------|------|------|------|

## 评分
- 评分：X/10
- 一句话总结
```

### 2.2 Agent 配置

```python
code_review_agent = create_agent(
    model=llm,
    tools=[
        sandbox_execute,      # 沙箱执行代码（可选：跑 lint 工具）
        sandbox_run_skill,    # 加载审查技能
    ],
    system_prompt="""你是代码审查助手。工作流程：
1. 调用 sandbox_run_skill("code_review", input_text="<用户代码>") 加载审查标准
2. 严格按照技能中的审查流程和输出格式执行
3. 如果需要验证代码行为，用 sandbox_execute 在沙箱中运行""",
    middleware=[
        ToolCallLimitMiddleware(run_limit=5),
    ],
)
```

### 2.3 执行流程

```
用户: "审查这段代码: query = f'SELECT * FROM users WHERE id={user_id}'"
  │
  ▼
Agent 第 1 轮: 加载审查技能
  → sandbox_run_skill("code_review", input_text="query = f'SELECT...'")
  → 沙箱返回 skill.md 的完整内容（含审查流程和输出格式）
  │  （容器: 只读挂载 /skills，执行完销毁）
  │
  ▼
Agent 第 2 轮: 按技能流程审查
  → 直接输出审查报告（不需要沙箱）

  "## 代码审查结果

  | # | 严重程度 | 维度 | 问题 | 建议 |
  |---|---------|------|------|------|
  | 1 | 高 | 安全 | SQL 注入：f-string 拼接 SQL | 用参数化查询 |
  | 2 | 低 | 规范 | 变量名 user_id 未验证类型 | 添加类型检查 |

  评分：3/10
  总结：存在严重 SQL 注入漏洞"
```

### 2.4 关键配置

| 配置 | 值 | 原因 |
|------|-----|------|
| `memory_limit` | `128m` | 审查不需要大内存 |
| `timeout` | `10s` | 读 skill 文件很快 |
| `network_enabled` | `False` | 不需要网络 |
| `run_limit` | `5` | 审查最多 5 步 |

## 三、代码生成 + 测试 Agent

**场景**：用户描述需求，Agent 在沙箱中生成代码、运行测试、迭代修复。

### 3.1 Agent 配置

```python
code_gen_agent = create_agent(
    model=llm,
    tools=[
        sandbox_execute,   # 沙箱执行生成的代码
        sandbox_run_skill, # 加载测试模板技能
    ],
    system_prompt="""你是代码生成助手。工作流程：
1. 根据用户需求生成 Python 代码
2. 用 sandbox_execute 在沙箱中运行代码
3. 如果执行失败，根据 stderr 修正代码再运行
4. 最多迭代 3 次，成功后返回最终代码和运行结果

重要：所有代码执行必须通过 sandbox_execute，绝不在本地执行。""",
    middleware=[
        ToolCallLimitMiddleware(run_limit=10),   # 生成+测试+修正最多 10 步
    ],
)
```

### 3.2 执行流程

```
用户: "写一个函数计算斐波那契数列前 N 项，并测试 N=10"
  │
  ▼
Agent 第 1 轮: 生成代码
  → AIMessage(content="我来写一个斐波那契函数...")
  → sandbox_execute(code="def fib(n): ...; print(fib(10))")
  → 沙箱返回: "55"
  │  （容器: CPU 1核 / 内存 128m / 超时 10s）
  │
  ▼
Agent 第 2 轮: 验证 + 回复
  → "代码执行成功，结果为 55。最终代码如下：
     def fib(n):
         a, b = 0, 1
         for _ in range(n):
             a, b = b, a + b
         return a"
```

### 3.3 迭代修正场景

```
用户: "写一个读取 JSON 文件并统计键数量的函数"
  │
  ▼
Agent 第 1 轮: 生成代码 → sandbox_execute
  → stderr: "FileNotFoundError: /workspace/data.json 不存在"
  │
  ▼
Agent 第 2 轮: 修正代码（先创建测试数据）
  → sandbox_execute(code="import json; json.dump({'a':1,'b':2}, open('/workspace/data.json','w'))")
  → sandbox_execute(code="import json; d=json.load(...); print(len(d))")
  → stdout: "2"
  │
  ▼
Agent 第 3 轮: 回复用户
  → "函数已测试通过，统计结果：2 个键"
```

### 3.4 关键配置

| 配置 | 值 | 原因 |
|------|-----|------|
| `memory_limit` | `256m` | 代码生成不需要大内存 |
| `timeout` | `30s` | 测试可能需要时间 |
| `network_enabled` | `False` | 代码执行不需要网络 |
| `run_limit` | `10` | 生成+测试+修正迭代空间 |
| `tmpfs` | `{"size": "100m"}` | 需要写测试文件 |

## 四、三个场景的配置对比

| 维度 | 数据分析 | 代码审查 | 代码生成 |
|------|---------|---------|---------|
| `memory_limit` | 512m | 128m | 256m |
| `timeout` | 60s | 10s | 30s |
| `network_enabled` | False | False | False |
| `run_limit` | 8 | 5 | 10 |
| Skill 类型 | .py（可执行） | .md（指令） | 无（直接生成） |
| 需要写文件 | 是（读 CSV） | 否 | 是（写测试代码） |
| 迭代次数 | 1-2 | 1 | 1-3 |
