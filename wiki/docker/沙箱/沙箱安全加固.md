# 沙箱安全加固

生产环境 Docker 沙箱的安全不止于容器隔离——覆盖文件系统、网络、资源、镜像、密钥五个维度。

## 一、文件系统隔离

### 1.1 只读根文件系统

```python
self.client.containers.run(
    read_only=True,                    # 根文件系统只读，不能写 /etc /bin
    tmpfs={"/workspace": "size=100m"}, # 只有 /workspace 可写，上限 100MB
    mounts=[docker.types.Mount(        # skills 目录只读挂载
        target="/skills",
        source="/host/skills",
        type="bind",
        read_only=True,
    )],
)
```

### 1.2 禁止敏感目录挂载

```python
# ❌ 绝不要挂载以下路径
FORBIDDEN_MOUNTS = [
    "/", "/etc", "/home", "/root",
    "/proc", "/sys", "/dev",
    "~/.ssh", "~/.aws", "~/.config",
]

def _validate_mount(self, source: str):
    for forbidden in FORBIDDEN_MOUNTS:
        if Path(source).resolve().is_relative_to(Path(forbidden).resolve()):
            raise SecurityError(f"禁止挂载路径: {source}")
```

### 1.3 临时文件系统限制

```python
tmpfs={
    "/workspace": "size=100m,mode=1777",   # 工作区 100MB
    "/tmp": "size=50m,mode=1777,noexec",   # /tmp 50MB + 不可执行
}
# noexec: 禁止在 /tmp 下执行二进制，防止下载恶意程序
```

## 二、网络隔离

### 2.1 默认禁网、按需开启

```python
# 全局默认禁网
config = SandboxConfig(network_enabled=False)

# 特定 tool 调用时按需开启
@tool
def sandbox_api_call(endpoint: str, data: str) -> str:
    """需要网络的 tool 单独开启网络"""
    code = f"""
import requests
resp = requests.post('{endpoint}', json={data})
print(resp.text)
"""
    result = sandbox.execute(code, network_enabled=True)  # ← 只此 tool 开网
    return result.stdout
```

### 2.2 白名单出站

```python
# 创建自定义 Docker 网络，用 iptables 限制出站
docker network create \
  --driver bridge \
  --opt "com.docker.network.bridge.name=sandbox-net" \
  sandbox-isolated

# iptables 白名单（只允许访问特定 IP/域名）
iptables -I FORWARD -i sandbox-net -d api.example.com -j ACCEPT
iptables -I FORWARD -i sandbox-net -j DROP
```

```python
# Python 侧指定网络
self.client.containers.run(
    network="sandbox-isolated",  # 用白名单网络
)
```

### 2.3 DNS 限制

```python
self.client.containers.run(
    dns=["1.1.1.1"],         # 强制用指定 DNS
    dns_search=["sandbox"],   # 限制搜索域
)
```

## 三、资源限制（防 DoS）

```python
self.client.containers.run(
    # CPU: 单核
    nano_cpus=int(1.0 * 1e9),
    cpu_period=100000,        # CFS 周期 100ms
    cpu_quota=50000,          # 每周期最多用 50ms → 等效 0.5 核

    # 内存: 硬限 + 软限
    mem_limit="256m",         # 硬限制，超限 OOM kill
    mem_reservation="128m",   # 软限制，用于调度

    # 磁盘 I/O: 限制读写速度
    device_read_bps=[{"Path": "/dev/sda", "Rate": 10 * 1024 * 1024}],  # 读 10MB/s
    device_write_bps=[{"Path": "/dev/sda", "Rate": 5 * 1024 * 1024}],  # 写 5MB/s

    # 进程数限制
    pids_limit=50,            # 最多 50 个进程，防 fork 炸弹

    # 文件描述符限制
    ulimits=[docker.types.Ulimit(name="nofile", soft=100, hard=200)],
)
```

## 四、内核安全

```python
self.client.containers.run(
    # 丢弃所有 Linux capabilities（即使以 root 运行也无特权）
    cap_drop=["ALL"],

    # 按需添加必要的能力
    cap_add=["NET_BIND_SERVICE"],  # 仅在需要绑定端口时添加

    # 禁止权限提升
    security_opt=["no-new-privileges:true"],

    # 只读根文件系统
    read_only=True,

    # AppArmor / Seccomp profile
    security_opt=["apparmor=docker-sandbox-default"],
)
```

**AppArmor profile 示例** (`/etc/apparmor.d/docker-sandbox`)：

```
#include <tunables/global>
profile docker-sandbox flags=(attach_disconnected,mediate_deleted) {
  # 只允许必要的系统调用
  capability,
  network,
  file,
  umount,
  deny mount,
  deny ptrace,
  deny /bin/su x,
  deny /usr/bin/passwd x,
}
```

## 五、镜像安全

### 5.1 镜像扫描

```bash
# CI/CD 中集成 Trivy 扫描
trivy image --severity HIGH,CRITICAL python:3.11-slim

# 或在 docker-py 中检查
docker scout cves python:3.11-slim
```

### 5.2 最小化镜像

```dockerfile
# ❌ 含 shell/tar/curl 等不必要工具
FROM python:3.11

# ✅ 最小化 + 固定版本
FROM python:3.11.9-slim-bookworm@sha256:abc123...
RUN pip install --no-cache-dir requests
USER 1000:1000              # 非 root 用户运行
```

### 5.3 镜像签名

```bash
# 启用 Docker Content Trust
export DOCKER_CONTENT_TRUST=1
docker pull python:3.11-slim  # 只拉取签名镜像
```

## 六、密钥管理

### 6.1 环境变量注入（不落地）

```python
# ✅ 通过 env 参数注入，不写入镜像/代码
sandbox.execute(
    code="import os; print(os.environ['SKILL_API_KEY'])",
    env={"SKILL_API_KEY": os.getenv("PROD_API_KEY")},
)
```

### 6.2 Docker secrets（Swarm 模式）

```yaml
# docker-compose.yml
secrets:
  api_key:
    external: true

services:
  agent:
    secrets:
      - api_key
```

### 6.3 禁止密钥写入文件

```python
# ❌ 绝不要在容器内 .env 或 config 文件中写密钥
# ✅ 始终通过环境变量传递
```

## 七、审计日志

每次沙箱执行记录：

```python
import structlog

logger = structlog.get_logger()

def execute(self, code: str, **kwargs) -> SandboxResult:
    result = ...

    # 结构化的审计日志
    logger.info("sandbox.execute",  # 不用 print，用结构化日志
        container_id=result.container_id,
        exit_code=result.exit_code,
        duration_ms=result.duration_ms,
        code_length=len(code),
        language=kwargs.get("language", "python"),
        network_enabled=kwargs.get("network_enabled", False),
    )
    return result
```

## 八、安全检查清单

| 检查项 | 配置 |
|--------|------|
| ✅ 根文件系统只读 | `read_only=True` |
| ✅ 工作区有大小限制 | `tmpfs={"size": "100m"}` |
| ✅ CPU 限制 | `nano_cpus=1e9`, `cpu_quota` |
| ✅ 内存限制 | `mem_limit="256m"` |
| ✅ 进程数限制 | `pids_limit=50` |
| ✅ 默认禁网 | `network_mode="none"` |
| ✅ 丢弃所有 capability | `cap_drop=["ALL"]` |
| ✅ 禁止提权 | `security_opt=["no-new-privileges"]` |
| ✅ 执行完自动销毁 | `remove=True` |
| ✅ 非 root 用户 | `user="1000:1000"` |
| ✅ 目录白名单挂载 | `_validate_mount()` |
| ✅ 镜像签名 | Content Trust |
| ✅ 结构化审计日志 | structlog |
| ✅ 密钥不落地 | env 参数注入 |
