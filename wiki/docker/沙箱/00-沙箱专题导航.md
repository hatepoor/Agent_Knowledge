# 沙箱专区 · 专题导航

> **这个专区是什么。** 它是 `wiki/docker/` 下的一个**应用专题**，回答的问题是：「**用 Docker 给 AI Agent 做一个能安全执行代码的容器**」。
>
> **它不是什么。** 它不是 Docker 的入门教程。Docker 本身是什么、命令怎么敲、镜像怎么构建、Compose 怎么编排——这些在 [[docker/01-入门阶段-基础教程/00-章节目录]] 与 [[docker/02-中段阶段-专题精讲/00-专题导航]]，**与本专区完全分开**。

## 一、为什么沙箱内容要单独放

本目录原先的 12 篇文档全部是"沙箱视角"——它们讲的不是 Docker 怎么用，而是"**用 Docker 的能力去解决 Agent 场景的一个特定问题**"。

这两类知识的目标、前置、读法都不同：

| | Docker 本体（01/02） | 沙箱专区（本页所在目录） |
|---|---|---|
| 回答的问题 | Docker 是什么、怎么用 | 怎么用 Docker 隔离 Agent 的代码执行 |
| 知识性质 | 通用工具技能，越完整越好 | 特定场景的方案设计，按需取用 |
| 前置要求 | **零基础起步** | **需要先会用 Docker 本体**，否则看不懂 |
| 更新驱动力 | Docker 官方版本演进 | Agent 工程实践与安全需求 |

把它独立出来，是为了让两条线**各自都能写透**：Docker 本体不再被"只剩下沙箱"绑架，沙箱也专心讲它的隔离设计与生产落地。

## 四、与知识库其他部分的关系

本专区不是孤岛，它是"Agent 安全执行"这条线在 Docker 侧的具体实现：

```
Agent 为什么需要沙箱(理念与选型)
  └─ [[agent/harness/Agent沙箱与安全隔离]]      ← 五种隔离层次、主流产品对比

用 Docker 实现沙箱(本专区)
  ├─ Docker 本体能力支撑 → [[docker/01-入门阶段-基础教程/00-章节目录]]
  └─ 沙箱方案与落地     → 本专区 12 篇

托管式沙箱 / 平台后端(非自建)
  ├─ [[deepagents/backend/Sandbox后端详解]]
  └─ [[deepagents/backend/Backend实战配置]]

沙箱内的 Skills 运行机制
  └─ [[agent/skills/Skills实现与集成]]
```

**为什么不自己写容器运行时？** 沙箱的隔离能力来自 Linux 内核（命名空间 + 控制组），Docker 只是把这些内核能力包装成了好用的命令行与 API。想理解这层，见 [[docker/02-中段阶段-专题精讲/容器安全加固/专题概览]] 与进阶阶段（规划中）的「容器隔离内核」。
