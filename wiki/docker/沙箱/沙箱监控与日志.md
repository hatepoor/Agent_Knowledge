# 沙箱监控与日志

生产环境沙箱的可观测性：每次执行的结构化日志、执行指标、异常追踪。

## 一、结构化日志（structlog）

用 `structlog` 替代 `print`，所有日志以 JSON 格式输出，便于被 ELK/Loki/Datadog 采集：

```python
import structlog
import time

logger = structlog.get_logger()

# 配置：JSON 输出 + 时间戳
structlog.configure(
    processors=[
        structlog.stdlib.add_log_level,
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.JSONRenderer(),
    ],
)

class DockerSandbox:
    def execute(self, code: str, **kwargs) -> SandboxResult:
        container_id = str(uuid.uuid4())[:12]
        start = time.time()

        try:
            result = ...  # 执行逻辑

            logger.info("sandbox.execute.success",
                container_id=container_id,
                exit_code=result.exit_code,
                duration_ms=round((time.time() - start) * 1000, 2),
                code_length=len(code),
                language=kwargs.get("language", "python"),
                network_enabled=kwargs.get("network_enabled", False),
                stdout_preview=result.stdout[:200],
            )
            return result

        except docker.errors.ContainerError as e:
            logger.error("sandbox.execute.container_error",
                container_id=container_id,
                exit_code=e.exit_status,
                duration_ms=round((time.time() - start) * 1000, 2),
                stderr_preview=str(e)[:200],
            )
            raise

        except Exception as e:
            logger.error("sandbox.execute.exception",
                container_id=container_id,
                error_type=type(e).__name__,
                error=str(e),
                duration_ms=round((time.time() - start) * 1000, 2),
            )
            raise
```

**日志样本（JSON 行）**：

```json

```

## 二、关键指标

| 指标 | 维度 | 告警条件 |
|------|------|----------|
| `sandbox_execute_total` | 总执行次数 | — |
| `sandbox_execute_success` | 成功次数 | 成功率 < 95% |
| `sandbox_execute_duration_ms` | 执行耗时 | P99 > 5s |
| `sandbox_container_errors` | 容器异常 | > 10/min |
| `sandbox_timeout_total` | 超时次数 | > 5/min |
| `sandbox_oom_total` | OOM 事件（exit_code=137） | > 0 |
| `sandbox_docker_daemon_errors` | Docker daemon 异常 | > 0 |

## 三、Prometheus metrics

```python
from prometheus_client import Counter, Histogram, Gauge

# 定义 metrics
execute_total = Counter("sandbox_execute_total", "总执行次数", ["status"])
execute_duration = Histogram("sandbox_execute_duration_ms", "执行耗时(ms)", buckets=[50,100,200,500,1000,2000,5000])
active_containers = Gauge("sandbox_active_containers", "活跃容器数")
timeout_total = Counter("sandbox_timeout_total", "超时次数")
oom_total = Counter("sandbox_oom_total", "OOM事件次数")

class DockerSandbox:
    def execute(self, code: str, **kwargs) -> SandboxResult:
        active_containers.inc()
        start = time.time()
        try:
            result = ...
            execute_total.labels(status="success").inc()
            execute_duration.observe((time.time() - start) * 1000)
            if result.exit_code == 137:
                oom_total.inc()
            return result
        except Exception:
            execute_total.labels(status="error").inc()
            raise
        finally:
            active_containers.dec()
```

## 四、Agent 层面的工具调用追踪

```python
from langchain.agents.middleware import AgentMiddleware

class SandboxMetricsMiddleware(AgentMiddleware):
    """记录 Agent 调用沙箱工具的次数和耗时"""

    def wrap_tool_call(self, request, handler):
        tool_name = request.tool_call["name"]
        if not tool_name.startswith("sandbox_"):
            return handler(request)

        tool_total.labels(tool=tool_name).inc()
        start = time.time()
        try:
            result = handler(request)
            tool_duration.labels(tool=tool_name).observe((time.time() - start) * 1000)
            return result
        except Exception as e:
            tool_errors.labels(tool=tool_name).inc()
            raise
```

## 五、日志级别使用规范

| 级别 | 场景 |
|------|------|
| DEBUG | 每次执行的具体代码内容 |
| INFO | 执行成功、容器创建/销毁 |
| WARNING | 超时、OOM、接近资源限制 |
| ERROR | Docker daemon 不可用、容器创建失败、代码执行异常 |

## 六、追踪 ID 贯穿全链路

```python
# Agent 请求 → 沙箱执行 全程用同一 trace_id
trace_id = str(uuid.uuid4())

# Agent 层
logger.info("agent.request", trace_id=trace_id, user_input=req.message)

# 沙箱层（通过 env 传递给容器感知）
sandbox.execute(code, env={"TRACE_ID": trace_id})

# 返回层
logger.info("agent.response", trace_id=trace_id, duration_total_ms=...)
```
