# 知识库三层架构

## 定义

本知识库采用**三层分离架构**，各层职责清晰、协作有序。这是 LLM Wiki 方法论的核心基础设施设计。

## 三层结构

### 1. 原始来源层 (`raw/`)

- **用途**：存储你精心整理的来源文档集合
- **内容**：文章、论文、图片、数据文件、教程
- **特性**：**不可变**——LLM 读取但从不修改
- **价值**：你的**事实来源**和真相基准

### 2. Wiki 层 (`wiki/`)

- **用途**：LLM 生成和维护的 Markdown 文件目录
- **内容**：摘要、实体页、概念页、对比分析、概览、综合
- **特性**：**LLM 完全拥有**——创建页面、更新、维护交叉引用、保持一致性
- **分工**：**你读，LLM 写**

### 3. Schema 层 (`SCHEMA.md`)

- **用途**：定义 wiki 的结构、约定和工作流
- **特性**：**你和 LLM 之间的协议**
- **价值**：让 LLM 成为有纪律的 wiki 维护者，而非通用聊天机器人
- **演进**：随实践迭代更新

## 辅助文件

- **`index.md`** — 内容索引，按类别组织的 wiki 目录
- **`log.md`** — 操作日志，按时间顺序记录所有操作

## 工作流程

```
来源 → [摄取] → raw/ → [LLM 阅读] → wiki/ → [索引更新][[ → index.md
                ↓
            SCHEMA.md (规范约束)
```

## 与 Git 的关系

整个知识库本质上是**一个 Git 仓库中的 Markdown 文件集合**。Git 为知识库提供版本控制、分支管理和协作能力。参见 [[tools/Git]]。
