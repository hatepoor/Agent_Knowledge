# 异步处理

FastAPI 原生支持 `async/await`，这在 Agent API 中至关重要——Agent 调用 LLM 需要等待网络 I/O，同时服务还要处理其他请求。

## 一、async def vs def

```python
# async def：在事件循环中执行
@app.get("/async")
async def async_endpoint():
    result = await some_io_operation()  # 不阻塞其他请求
    return result

# def：在线程池中执行
@app.get("/sync")
def sync_endpoint():
    result = some_blocking_function()   # 在线程池中阻塞
    return result
```

**选择规则**：

| 场景 | 用 `async def` | 用 `def` |
|------|:---:|:---:|
| 调用 `await agent.ainvoke()` | ✓ | |
| 调用同步库（无 async 版本） | | ✓ |
| CPU 密集型计算 | | ✓（线程池） |
| I/O 密集型（DB、HTTP、LLM API） | ✓ | |

## 二、Agent API 中的异步实践

```python
# ✅ 正确：用 ainvoke + async def
@app.post("/chat")
async def chat(req: ChatRequest):
    result = await agent.ainvoke(...)  # 非阻塞
    return result

# ❌ 错误：在 async 路由中调用同步 invoke
@app.post("/chat")
async def chat(req: ChatRequest):
    result = agent.invoke(...)  # 阻塞事件循环！
    return result

# ✅ 折中：用 run_in_executor 让同步调用不进事件循环
import asyncio
@app.post("/chat")
async def chat(req: ChatRequest):
    loop = asyncio.get_event_loop()
    result = await loop.run_in_executor(None, agent.invoke, ...)
    return result
```

## 三、并发处理多请求

FastAPI + Uvicorn 允许同时处理多个聊天请求：

```
时间线（4 个并发请求）:
请求1: ─await LLM─────────await LLM───→ 返回
请求2: ──await DB──await LLM──────────→ 返回
请求3: ───────await LLM────await tool──→ 返回
请求4: ─await LLM──→ 返回

所有请求并发进行，不互相等待
```

### 启动多 worker

```bash
# 每个 worker 独立的事件循环
uvicorn main:app --workers 4
```

## 四、Streaming 的异步模式

```python
@app.post("/chat/stream")
async def chat_stream(req: ChatRequest):
    async def generator():
        async for event in agent.astream_events(...):
            # astream_events 是异步生成器
            yield f"data: {json.dumps(event)}\n\n"

    return StreamingResponse(generator(), media_type="text/event-stream")
```

## 五、超时控制

```python
import asyncio

@app.post("/chat")
async def chat(req: ChatRequest):
    try:
        result = await asyncio.wait_for(
            agent.ainvoke(...),
            timeout=60.0,  # 最长等待 60 秒
        )
        return result
    except asyncio.TimeoutError:
        raise HTTPException(status_code=504, detail="Agent 执行超时")
```
