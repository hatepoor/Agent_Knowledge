# 安全认证

FastAPI 提供标准化的安全方案，支持 OAuth2、JWT、Bearer Token、API Key。

## 一、Bearer Token（Agent API 最常用）

```python
from fastapi import Depends, HTTPException, Header

async def verify_token(authorization: str = Header(default="")):
    if not authorization.startswith("Bearer "):
        raise HTTPException(status_code=401)
    token = authorization.split(" ", 1)[1]
    if token != "your-secret-token":  # 实际应验证 JWT
        raise HTTPException(status_code=403)
    return token

@app.post("/chat")
async def chat(req: ChatRequest, token=Depends(verify_token)):
    ...
```

### 调用方式

```bash
curl -X POST http://localhost:8000/chat \
  -H "Authorization: Bearer your-secret-token" \
  -H "Content-Type: application/json" \
  -d '{"message": "你好", "thread_id": "user_001"}'
```

## 二、OAuth2 + JWT

```python
from fastapi.security import OAuth2PasswordBearer
import jwt

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

@app.post("/token")
async def login(form_data: OAuth2PasswordRequestForm = Depends()):
    # 验证用户名密码...
    token = jwt.encode({"sub": user.username}, SECRET_KEY, algorithm="HS256")
    return {"access_token": token, "token_type": "bearer"}

async def get_current_user(token: str = Depends(oauth2_scheme)):
    payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
    return payload.get("sub")

@app.get("/users/me")
async def read_current_user(username=Depends(get_current_user)):
    return {"username": username}
```

## 三、Agent 的多层安全设计

```python
# 1. API 层：Bearer Token 认证
@app.post("/chat")
async def chat(
    req: ChatRequest,
    token=Depends(verify_token),
):
    ...

# 2. Agent 层：HumanInTheLoopMiddleware 审批关键操作
agent = create_agent(
    middleware=[
        HumanInTheLoopMiddleware(interrupt_on={"send_email": True, "delete_*": True}),
    ],
)

# 3. 数据层：PIIMiddleware 脱敏
agent = create_agent(
    middleware=[
        PIIMiddleware(pii_type="email", strategy="redact"),
    ],
)
```
