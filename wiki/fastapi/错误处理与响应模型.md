# 错误处理与响应模型

FastAPI 提供声明式错误处理，配合 Pydantic 的 `response_model` 控制输出格式。

## 一、HTTPException

```python
from fastapi import HTTPException

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id not in fake_db:
        raise HTTPException(status_code=404, detail="物品不存在")
    return fake_db[item_id]
# 客户端收到: {"detail": "物品不存在"} (status 404)
```

## 二、全局异常处理器

```python
from fastapi import Request
from fastapi.responses import JSONResponse

@app.exception_handler(ValueError)
async def value_error_handler(request: Request, exc: ValueError):
    return JSONResponse(status_code=400, content={"message": str(exc)})

# 任何路由抛出 ValueError → 自动返回 400
```

### Agent API 中的错误处理

```python
@app.post("/chat")
async def chat(req: ChatRequest):
    try:
        result = await asyncio.wait_for(
            agent.ainvoke(...), timeout=60.0
        )
        return result
    except asyncio.TimeoutError:
        raise HTTPException(status_code=504, detail="Agent 响应超时")
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"Agent 错误: {str(e)}")
```

## 三、响应模型（response_model）

```python
class ItemPublic(BaseModel):      # 公开模型（不含内部字段）
    name: str
    price: float

class ItemCreate(BaseModel):      # 内部模型（含所有字段）
    name: str
    price: float
    internal_notes: str

@app.post("/items/", response_model=ItemPublic)
async def create_item(item: ItemCreate):
    return item  # 返回所有字段，但 response_model 过滤掉 internal_notes
```
