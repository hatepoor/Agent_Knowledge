# FastAPI 模块

> FastAPI 是基于 Python 类型提示的高性能 Web 框架，在 Agent 项目中充当 **HTTP 外壳**——接收请求、调用 Agent、返回结果。

## 有什么用

- 把 LangChain/LangGraph Agent 暴露为 REST API
- 流式输出 Agent 的逐字回复（SSE / WebSocket）
- 文件上传 → RAG 知识库索引
- 认证、限流、日志等生产级能力

## 安装

```bash
pip install "fastapi[standard]"
```

## 在 Agent 架构中的位置

```
用户/前端 ←─HTTP─→ FastAPI ←─invoke()─→ LangChain/LangGraph Agent
                        ←─stream()──→ （流式响应）
                  ↑
             中间件层（CORS、认证、限流）
```

## 关键概念

| 概念 | 作用 |
|------|------|
| `@app.get/post` | 定义路由（HTTP 端点） |
| `BaseModel`（Pydantic） | 请求/响应数据校验 |
| `Depends` | 依赖注入（认证、Agent 实例） |
| `StreamingResponse` | SSE 流式输出 |
| `WebSocket` | 双向实时通信 |
| `BackgroundTasks` | 后台执行耗时任务 |
| `UploadFile` | 文件上传 |
| `Middleware` | 请求拦截（日志、CORS） |
