## 二、各文件职责

### app/main.py — 入口

```python
"""FastAPI 应用入口"""
from contextlib import asynccontextmanager
from fastapi import FastAPI
from app.config import settings
from app.api.router import api_router
from app.core.agent import init_agent, cleanup_agent
from app.middleware.cors import setup_cors
from app.middleware.logging import setup_logging

@asynccontextmanager
async def lifespan(app: FastAPI):
    """应用生命周期：启动时初始化，关闭时清理"""
    # 启动
    await init_agent()
    print(f"[启动] Agent 已初始化，模型: {settings.MODEL_NAME}")
    yield
    # 关闭
    await cleanup_agent()
    print("[关闭] 资源已清理")

app = FastAPI(
    title=settings.APP_NAME,
    version=settings.APP_VERSION,
    lifespan=lifespan,
)

# 中间件
setup_cors(app)
setup_logging(app)

# 路由
app.include_router(api_router)
```

### app/core/agent.py — Agent 单例

```python
"""Agent 初始化：全局单例，启动时创建一次"""
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver
from app.config import settings
from app.tools import get_all_tools

_agent = None
_checkpointer = None

async def init_agent():
    """启动时调用：初始化 Agent"""
    global _agent, _checkpointer
    
    _checkpointer = InMemorySaver()  # 生产用 PostgresSaver
    tools = get_all_tools()
    
    _agent = create_agent(
        settings.MODEL_NAME,
        tools=tools,
        checkpointer=_checkpointer,
    )

def get_agent():
    """获取 Agent 实例（供路由函数使用）"""
    if _agent is None:
        raise RuntimeError("Agent 未初始化，请先调用 init_agent()")
    return _agent

async def cleanup_agent():
    """关闭时调用：清理资源"""
    global _agent, _checkpointer
    _agent = None
    _checkpointer = None
```

### app/api/router.py — 路由汇总

```python
"""路由汇总：所有子路由在这里注册"""
from fastapi import APIRouter
from app.api import chat, documents, tasks, health

api_router = APIRouter()
api_router.include_router(health.router, tags=["系统"])
api_router.include_router(chat.router, prefix="/chat", tags=["对话"])
api_router.include_router(documents.router, prefix="/documents", tags=["文档"])
api_router.include_router(tasks.router, prefix="/tasks", tags=["任务"])
```

### app/api/chat.py — 对话路由

```python
"""对话端点"""
from fastapi import APIRouter, Depends
from app.schemas.chat import ChatRequest, ChatResponse
from app.core.agent import get_agent
from app.middleware.auth import verify_token

router = APIRouter()

@router.post("", response_model=ChatResponse)
async def chat(req: ChatRequest, token: str = Depends(verify_token)):
    """与 Agent 对话"""
    agent = get_agent()
    result = await agent.ainvoke(
        {"messages": [{"role": "user", "content": req.message}]},
        config={"configurable": {"thread_id": req.thread_id}},
    )
    return ChatResponse(
        reply=result["messages"][-1].content,
        thread_id=req.thread_id,
    )
```

### app/schemas/chat.py — 请求/响应模型

```python
"""对话相关的 Pydantic 模型"""
from pydantic import BaseModel, Field

class ChatRequest(BaseModel):
    message: str = Field(..., min_length=1, max_length=5000, description="用户消息")
    thread_id: str = Field(default="default", description="会话 ID")

class ChatResponse(BaseModel):
    reply: str
    thread_id: str
```

## 三、分层原则

```
请求进入
  │
  ▼
┌─────────────────────────────────────┐
│  middleware/（中间件层）              │  认证、日志、限流、CORS
└──────────────────┬──────────────────┘
                   ▼
┌─────────────────────────────────────┐
│  api/（路由层）                      │  接收请求、参数校验、调用 core
│  schemas/（数据模型）                │  定义请求/响应格式
└──────────────────┬──────────────────┘
                   ▼
┌─────────────────────────────────────┐
│  core/（业务逻辑层）                 │  Agent 调用、RAG 检索、记忆管理
│  tools/（Agent 工具）                │  工具实现
│  skills/（Agent 技能）               │  SOP 模板
└──────────────────┬──────────────────┘
                   ▼
┌─────────────────────────────────────┐
│  外部服务                            │  LLM API、向量数据库、MCP 服务器
└─────────────────────────────────────┘
```

**核心规则：**
- `api/` 不写业务逻辑，只做参数接收和结果返回
- `core/` 不关心 HTTP 协议，只处理业务
- `schemas/` 只定义数据结构，不含逻辑
- `middleware/` 处理横切关注点（认证、日志）

## 五、开发 vs 生产差异

| 维度 | 开发 | 生产 |
|------|------|------|
| 服务器 | `fastapi dev`（热重载） | `uvicorn --workers 4` |
| Checkpointer | InMemorySaver | PostgresSaver |
| 向量库 | Chroma（本地） | PgVector / Pinecone |
| 认证 | 可跳过 | JWT + 限流 |
| 日志 | print | 结构化日志（JSON） |
| 部署 | 本地运行 | Docker + Nginx |
