# 路径操作

路径（Path）和查询参数（Query）是 REST API 最基本的参数来源。FastAPI 的类型提示系统让声明路由参数极为简洁。

## 一、三种参数来源

```
URL: https://api.example.com/items/42?q=phone&sort=desc
      \__________________/ \______/ \________________/
            路径           路径参数    查询参数
                          {item_id}   ?key=value
```

| 来源 | 位置 | 声明方式 |
|------|------|----------|
| **路径参数** | URL 路径中 `/items/{item_id}` | 直接写在函数签名中 |
| **查询参数** | URL `?` 之后 `?q=phone` | 函数参数（非路径参数自动判定）|
| **请求体** | HTTP Body（POST/PUT）| Pydantic Model → 详见 [[fastapi/请求体与Pydantic]] |

## 二、路径参数

### 2.1 基础

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):   # 类型提示 int → FastAPI 自动转换并校验
    return {"item_id": item_id}

# GET /items/42   → {"item_id": 42}
# GET /items/abc  → 422 Unprocessable Entity（校验失败）
```

**数据流向**：
```
传入 URL: /items/42
    ↓ FastAPI 路由解析
匹配到 @app.get("/items/{item_id}")
    ↓ 提取 item_id = "42"（原始为字符串）
类型提示 int → 自动转换 "42" → 42
    ↓ 校验
成功 → 传入函数 item_id=42
失败 → 返回 422 + {"detail": "value is not a valid integer"}
```

### 2.2 枚举路径参数

```python
from enum import Enum

class ModelName(str, Enum):
    openai = "openai"
    deepseek = "deepseek"
    claude = "claude"

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name == ModelName.deepseek:
        return {"model": "deepseek-v4-flash", "provider": "DeepSeek"}
    return {"model": model_name}
# GET /models/deepseek → 匹配
# GET /models/gemini → 422（不在枚举中）
```

### 2.3 包含文件路径的路径参数

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
# :path 告诉 FastAPI file_path 可以包含 /
# GET /files/home/user/data.json → {"file_path": "home/user/data.json"}
```

## 三、查询参数

### 3.1 基础

```python
@app.get("/items/")
async def list_items(skip: int = 0, limit: int = 10, q: str | None = None):
    # skip: int = 0     → 默认值 0，可选
    # limit: int = 10   → 默认值 10，可选
    # q: str | None = None → 可选，不传则为 None
    return {"skip": skip, "limit": limit, "q": q}

# GET /items/                         → {"skip": 0, "limit": 10, "q": null}
# GET /items/?skip=5&limit=20         → {"skip": 5, "limit": 20, "q": null}
# GET /items/?q=phone                 → {"skip": 0, "limit": 10, "q": "phone"}
```

**判定规则**：函数参数名不在路径模板中 → FastAPI 自动作为查询参数。

### 3.2 必填 vs 可选

```python
@app.get("/search")
async def search(query: str, page: int = 1):
    # query: str          → 必填（没有默认值）
    # page: int = 1       → 可选（有默认值）
    return {"query": query, "page": page}

# GET /search?query=python           → OK
# GET /search?query=python&page=2    → OK
# GET /search                         → 422（缺少必填 query）
```

### 3.3 bool 类型查询参数

```python
@app.get("/items/")
async def list_items(is_active: bool = False):
    return {"is_active": is_active}

# GET /items/?is_active=true    → True
# GET /items/?is_active=1       → True
# GET /items/?is_active=false   → False
# GET /items/?is_active=0       → False
```

FastAPI 自动识别 `true/false`、`1/0`、`yes/no`、`on/off` 等变体。

## 四、多路径/查询参数组合

```python
@app.get("/users/{user_id}/items/{item_id}")
async def get_user_item(
    user_id: int,       # 路径参数（必填）
    item_id: str,       # 路径参数（必填）
    q: str | None = None,  # 查询参数（可选）
    short: bool = False,   # 查询参数（可选）
):
    return {
        "user_id": user_id,
        "item_id": item_id,
        "q": q,
        "short": short,
    }

# GET /users/42/items/abc?q=phone&short=true
# → {"user_id": 42, "item_id": "abc", "q": "phone", "short": true}
```

## 五、在 Agent 路由中的应用

```python
# Agent 查询接口：路径参数 + 查询参数
@app.get("/agents/{agent_id}/sessions/{session_id}")
async def get_session(
    agent_id: str,
    session_id: int,
    include_messages: bool = True,    # 查询参数：是否包含消息
    limit: int = 100,                  # 查询参数：消息数量限制
):
    result = await session_store.get_session(
        agent_id=agent_id,
        session_id=session_id,
        include_messages=include_messages,
        limit=limit,
    )
    return result
```
