# FastAPI 快速入门

按步骤创建一个最小 FastAPI 应用，理解每个部分的作用。

## 一、安装与创建项目

```bash
# 用 uv 创建（官方推荐，自动管理虚拟环境）
uv init my-api --bare
cd my-api
uv add "fastapi[standard]"

# 运行开发服务器
uv run fastapi dev main.py
```

## 二、第一个应用：逐行拆解

```python
# 第 1 步：导入 FastAPI 类
from fastapi import FastAPI
# FastAPI 继承自 Starlette，是一个完整的 ASGI Web 框架

# 第 2 步：创建 app 实例
app = FastAPI()
# 这个 app 是核心对象：所有路由、中间件、事件处理器都挂载在它上面
# 之后 uvicorn main:app 中的 "app" 指的就是这个变量

# 第 3 步：定义路径操作（path operation）
@app.get("/")           # 装饰器：告诉 FastAPI 这个函数处理 GET /
#   ↑         ↑
#   操作      路径
#   GET/POST  / 表示根路径
#   /users/{user_id} 表示带路径参数的 URL

async def root():       # 第 4 步：路径操作函数
# async def 表示异步函数（也可以 def）
# FastAPI 自动检测：async → 事件循环执行，def → 线程池执行

    return {"message": "Hello World"}
# 第 5 步：返回内容（dict/list/Pydantic模型 → 自动序列化为 JSON）
```

### 数据流向

```
浏览器请求 GET /
    │
    ▼
Uvicorn (ASGI 服务器) 接收 HTTP 请求
    │
    ▼
FastAPI 路由匹配 → 找到 @app.get("/")
    │
    ▼
执行 root() 函数 → 返回 {"message": "Hello World"}
    │
    ▼
Pydantic/JSON 序列化 → '{"message": "Hello World"}'
    │
    ▼
HTTP Response → 浏览器显示 JSON
```

## 三、路径操作装饰器速查

| 装饰器 | HTTP 方法 | 典型用途 |
|--------|----------|----------|
| `@app.get("/items")` | GET | 查询数据 |
| `@app.post("/items")` | POST | 创建数据 |
| `@app.put("/items/{id}")` | PUT | 完整更新 |
| `@app.patch("/items/{id}")` | PATCH | 部分更新 |
| `@app.delete("/items/{id}")` | DELETE | 删除数据 |
| `@app.options("/items")` | OPTIONS | CORS 预检 |

## 四、运行服务器

```bash
# 开发模式（自动重载、调试信息）
uv run fastapi dev main.py

# 会输出:
# INFO:  Uvicorn running on http://127.0.0.1:8000
# INFO:  Application startup complete.

# 生产模式（多 worker、无热重载）
uv run fastapi run main.py
```

|-----|------|

## 六、完整示例：CRUD API

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="物品管理 API", version="1.0.0")

# 数据模型
class Item(BaseModel):
    name: str
    price: float
    is_offer: bool | None = None
# Pydantic BaseModel：
#   - name: str   → 必须是字符串，否则 FastAPI 返回 422
#   - is_offer: bool | None = None → 可选字段，不传则为 None

# 模拟数据库
fake_db = {}

# 创建
@app.post("/items/{item_id}")
async def create_item(item_id: int, item: Item):
    # item_id: int → FastAPI 自动从 URL 提取并转 int
    # item: Item → FastAPI 自动从请求 body 解析 JSON
    fake_db[item_id] = item
    return {"item_id": item_id, "item": item}

# 查询
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    item = fake_db.get(item_id)
    if item is None:
        from fastapi import HTTPException
        raise HTTPException(status_code=404, detail="物品不存在")
    return item

# 更新
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    fake_db[item_id] = item
    return {"message": "更新成功", "item": item}

# 删除
@app.delete("/items/{item_id}")
async def delete_item(item_id: int):
    if item_id in fake_db:
        del fake_db[item_id]
        return {"message": "删除成功"}
    raise HTTPException(status_code=404, detail="物品不存在")
```

## 七、在 Agent 项目中的应用骨架

```python
from fastapi import FastAPI
from pydantic import BaseModel
from langchain_deepseek import ChatDeepSeek
from langchain.agents import create_agent

app = FastAPI(title="AI Agent API")

# 全局初始化（启动时加载一次）
llm = ChatDeepSeek(model="deepseek-v4-flash", temperature=1.0)
agent = create_agent(model=llm, tools=[...])

class ChatRequest(BaseModel):
    message: str            # 用户消息
    thread_id: str = "default"  # 会话 ID

class ChatResponse(BaseModel):
    reply: str
    thread_id: str

@app.post("/chat", response_model=ChatResponse)
async def chat(req: ChatRequest):
    result = await agent.ainvoke(
        {"messages": [HumanMessage(content=req.message)]},
        config={"configurable": {"thread_id": req.thread_id}},
    )
    return ChatResponse(
        reply=result["messages"][-1].content,
        thread_id=req.thread_id,
    )
```
