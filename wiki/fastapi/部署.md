# 部署

将 FastAPI + Agent 应用部署到生产环境。

## 一、启动方式

```bash
# 开发模式（热重载）
uv run fastapi dev main.py

# 生产模式（多 worker）
uv run fastapi run main.py --workers 4
# 等价于：
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

## 二、Docker 部署

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000", "--workers", "2"]
```

```bash
docker build -t agent-api .
docker run -p 8000:8000 --env-file .env agent-api
```

## 三、Agent 应用的生产 checklist

| 项 | 说明 |
|----|------|
| `workers` | CPU 核数 × 1-2 |
| checkpointer | PostgresSaver（不要 InMemory） |
| LLM 初始化 | 应用启动时一次（非每次请求） |
| timeout | Agent 超时控制（60s-120s） |
| 日志 | 结构化日志（JSON 格式） |
| 健康检查 | `/health` 端点 |
