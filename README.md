# LLM 驱动的知识库

本知识库基于 `LLM wiki.md` 的方法论构建：LLM 增量式地构建和维护一个持久化的 wiki。

## 快速开始

1. **添加来源**：将文档（文章、论文、图片、数据文件）放入 `raw/` 目录
2. **摄入**：告诉 LLM 处理某个来源——它会阅读、摘要，并将信息整合进 wiki
3. **查询**：对知识库提问——LLM 会搜索 wiki 并给出带引用的答案
4. **浏览**：用 Obsidian 打开此文件夹，探索 wiki、使用图谱视图、跟随链接

## 目录结构

- `raw/` — 来源文档，不可变
- `wiki/` — LLM 生成的 wiki 页面
- `SCHEMA.md` — wiki 的结构定义和操作规范
- `index.md` — 所有 wiki 页面的目录索引
- `log.md` — 操作日志
- `README.md` — 本文件

## 核心理念

> 大多数 RAG 系统每次查询时从头检索——没有积累。本知识库不同：LLM 读取来源后**编译**进一个持久化的 wiki，交叉引用预先建立，矛盾预先标记，综合分析持续更新。

**人类负责**：策展来源、指导分析、提出好问题
**LLM 负责**：所有编写、维护、交叉引用和一致性工作

## 工作流

### 摄取来源
将文件放入 `raw/`，然后告诉 LLM：「请摄入 [文件名]」

### 提问
对知识库提问，LLM 会搜索 wiki 综合答案。有价值的答案可归档为新 wiki 页面。

### 检查
定期让 LLM 健康检查 wiki 的矛盾、过时信息或缺失连接。

## 提示

- 用 Obsidian 的 **Graph View** 可视化连接关系
- wiki 本质是 Markdown 文件——可直接用 git 版本控制
- 从单个来源开始，保持参与感
- 在实践中迭代 `SCHEMA.md`
